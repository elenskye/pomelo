# 验证方法

> 怎么测、用什么命令。原则在 CLAUDE.md：平时只用模拟的模型和编的数据；真模型、真接口、要花钱的先问我；绝不碰真实数据目录。

- **界面**：用 Bash 后台跑 `pnpm dev`（预览面板没有「文稿」权限，自己启动不了），再用 `.claude/launch.json` 的 `ui-mock` 打开 `http://localhost:1420/?mock`（内存里的模拟数据）。仓库里改任何文件（文档也算）页面都会刷新、模拟数据清空，等结果时别动文件。参数：`&notes=prototype` 真实的 179 条笔记；`&vault=new|open`（默认锁着，测试主密码 `mock-master-1`）、`&touch=fail|none`；`&picky=ready` 一打开就有模拟的本地模型；`&kb=demo` 先放两个知识库；`&brief=fail|off` 今日简报（`&mood=calm|busy|good|worry` 换简报的心情，柚子跟着变）；`&year=card` 首页任何一天都显示年度总结卡片；`&site=sandbox|missing|clean|big|ahead` 呦呦漫游（开发版还没副本、找不到文件夹、没有改动、有超大的文件、有没推的提交；commit 文本写「失败测试」「上线失败」得到检查没过 / 上线失败；「作品」里有三篇模拟作品，图片是按网址画的色块）；问题里写「滚动测试」「失败测试」得到长回复 / 失败；`&pub2md=keys` Pub2MD 像正式版那样要填 Mathpix 的 Key，它的「选择文件…」依次拿到一篇论文、「失败测试」（第 3 块出错一次，能「继续」或「删除」）、两张照片、「读书笔记.md」（只翻译），选了先列在「待发送」，点「发送」才开始；小拾选文件第二次多选拿到 xlsx、pptx、png，第一次是 pdf、md；Seeker 有编的资料（林小柚，中文和英文，七个子页都有内容），选文件夹、读模板（英文模板照成稿的样子编的段落）、导出、从 transfer/ 导入都是模拟的（不写文件）；`&picky=ready` 时小拾的「模板」按钮有置顶模板；想直接看某页用 `/?mock#/finance`。截图常慢一拍，关键结果用 JS 读页面确认；拖拽用 `left_click_drag` 测。
- **真实窗口**：新加或改了 Rust 命令的页面，除了 `?mock` 还要在真实窗口里点进去一次（`?mock` 不走 Rust）。`pnpm app:build` 后 `open -n --env POMELO_DATA_DIR=<临时目录> "src-tauri/target/release/bundle/macos/Pomelo OS.app"`，用 `screencapture -x` 截全屏看（我在用别的 App 时，新窗口可能被台前调度缩成左边的缩略图，不是 bug，也别为了截图把它拉到前面；红黄绿的位置按截图量：圆心在 `trafficLightPosition` 的 y − 2 处，按钮之间约 23）；查数据用 `sqlite3` 看临时目录。测完 `pkill -f "target/release/bundle"`（别用 osascript quit，会连正式版一起关）并删掉这个 `.app`。**不要用 osascript 碰 System Events**（会弹「辅助功能」授权框），交互在浏览器里测；要在真实窗口里点，用电脑操作（computer use，会弹授权框由我同意），只授权「Pomelo OS」，点之前确认正式版没在运行。
- **升级测试（装正式版前做）**：先在正式版二进制里 `grep -c -a` 各 migration 的特征 SQL，确定它在哪个版本（不要读真实数据目录；`picky.db` 的升级脚本也要查）；在临时目录里用 `sqlite3` 依次执行到那个版本的 migration、`PRAGMA user_version=<版本>`、插几条会被新 migration 改动的数据，再用上面的方法打开新打包的 App，检查版本号、`backups/` 里的「升级前」备份和数据。没有新 migration 时（只改了数据文件格式或记录的 JSON 形状）：确认二进制里已有全部 migration，用单元测试读旧形状的记录，再用临时目录打开新 App 确认能启动、版本号不变、数据没被改。
- **真的本地模型（先问我）**：`~/Documents/LLM/scripts/llmctl.sh start qwen359b`，等 `curl -sf 127.0.0.1:8080/health` 通了再跑，用完马上 `llmctl.sh stop`。
  - 小拾：`POMELO_REAL_LLM=1 POMELO_ASK='问题1|问题2>>追问' cargo test --manifest-path src-tauri/Cargo.toml real_local_model -- --ignored --nocapture`（导入文件加编的数据，在内存里；`POMELO_SHOW=1` 显示查到的原文，`POMELO_AS_CLOUD=1` 按云端的规则，`POMELO_SCHEDULED=1` 按定时任务只读）。一次跑一个问题、给个时限：Qwen3.5 9B 偶尔会想很久停不下来。
  - 润色补全、一句话填好：`real_assist`、`real_quick`；今日简报：`real_brief`（`POMELO_TODAY` 换日期）；Translator：`real_translate`（`POMELO_TR_CASE=zh|keywords|long`，一次一个；`POMELO_THINK=0` 不思考，开思考时 9B 两句话也会想几分钟）；长资料补读：`real_read_file`（编的 60 章手册，`POMELO_ASK` 换问题）；Word / 文本工具箱：`real_toolbox`（临时文件夹里编的 Word、Markdown 等 15 种情况，打出调用、卡片和写入后读回的结果；`POMELO_TB_CASE=kb,table…` 挑几个，`POMELO_TB_DUMP=1` 只看读出来的段落；我同意用云端时把 `POMELO_REAL_LLM=1` 换成 `POMELO_CLOUD_KEY_FILE=<放 Key 的文件>`，默认 DeepSeek，`POMELO_CLOUD_SERVICE=openrouter POMELO_CLOUD_MODEL=<模型>` 换 OpenRouter；`real_local_model` 也能这样用云端，只用编的数据）；知识库看图：`real_kb_image`（只能用云端，编一张带字的图）。`POMELO_CLOUD_SERVICE` 能选 deepseek、openrouter、openai、anthropic、google、aliyun。测试打出云端的原始报错（`[cloud]` 开头），App 里不显示。
  - 向量和重排：`llmctl.sh start embedding`（或 `rerank`）后跑 `real_embedding`、`real_rerank`，用完停；`real_services_start_and_stop`、`real_meaning_search`、`real_knowledge`（知识库：临时目录里编的文件夹，建索引、提问、改文件再问）自己启停（先确认都没在跑）。
- **真接口**：书单 / 影单检索 `POMELO_REAL_WEB=1 cargo test real_works -- --ignored --nocapture`（示例书名，可以直接跑）；小拾的真模型测试加 `POMELO_REAL_WEB=1` 就用真检索；Tavily 要我的 Key，先问我。
- **Pub2MD 真测（先说用量，我同意再测；Mathpix 按页收费）**：Key 文件我给；结果放 `~/Downloads/Pub2MD 测试/第 N 轮/`（过程放 `运行记录/`，写进 `测试记录.md`）。`cargo test --manifest-path src-tauri/Cargo.toml real_pub2md -- --ignored --exact picky::assistants::pub2md::job::tests::real_pub2md --nocapture`：真的 Mathpix 和云端模型走完整个流程，打出块数、请求、用时和每个模型的词元用量；开关（各模型的 Key 文件、服务和思考，几张图合成一份，几步，文体和领域，精修，另存为，用上次的 Mathpix 结果，接着做停下的那份）写在测试注释里，思考关不掉的模型（OpenRouter 的 GLM-5.3）加 `POMELO_CLOUD_THINK=always`。跑的时候用 Monitor 边算费用边盯输出（到我给的上限就停），出问题就改。`real_pub2md_probe` 单问 Supervisor 一步（`POMELO_PROBE=terms|fix|plan|read|search`，不用 Mathpix）。改了切块或检查，用 `replay_cut_points`、`replay_neighbor_trim`、`replay_stray_traditional`（`POMELO_REPLAY=<以前的结果文件夹>`）拿真结果回放。
- **呦呦漫游**：开发版在页面上点「建副本」，从网站文件夹复制到开发数据目录的 `site-sandbox/`，推到旁边的假远端 `remote.git`；`?mock` 里是模拟的网站。下面的测试都是 `cargo test --manifest-path src-tauri/Cargo.toml <名字> -- --ignored --nocapture`，在临时副本上跑（真文件夹只读）：`real_site_sandbox` 整套发布（真的 `npm run qa`、提交、推到假远端）；`real_site_edit` 把每个作品和其余每一页读了又存（一个文件都不能变），再改遍各页，最后跑 `npm run qa`；`real_site_server` 用 Pomelo 启停真的本地服务；`real_site_read`（只读真文件夹）改动清单和用 gh 读的「最近发布」；`real_yaml_like_js_yaml`（只读真文件夹）全部内容文件和 js-yaml 逐字比对。小拾的帮忙（补全、按中文起草）用真的本地模型测：`POMELO_REAL_LLM=1` 跑 `real_site_draft`（编的作品，先问我）。真的推到 GitHub 只在正式版、由我点。
- **搜索速度**：`cargo test --release --manifest-path src-tauri/Cargo.toml search_speed -- --ignored --nocapture`（20 万条编的数据：按字 0.1 秒内、按意思 0.3 秒内）。
- **真实数据**：`POMELO_SEED_DB=<临时目录>/pomelo.db cargo test --manifest-path src-tauri/Cargo.toml seed_scratch_db -- --ignored` 生成含全部导入文件的临时数据库；`cargo test -- --ignored --skip seed_scratch_db` 跑真实导入文件的测试。
- **Rater**：`cargo test --manifest-path src-tauri/Cargo.toml rater`（秒数、保存的版本号和历史、删除撤销、数据文件往返、`qbank.md` / `interview.md` 导入成 Rater 的规则、不进 Seeker 的任务；题库 SKILL：各类读的资料和工作流、模型回答的检查、补题一步撤销、确认卡片写题和撤销；卡片练习：练习记录和复习顺序、一张一张答、每步撤销、追问最多 2 次、存进题库、挑卡 / 追问 / 点评读的资料和回答的检查；面试：准备读的简历和题、复盘保存和检查、对照读的准备、存进题库和加进规则各一步撤销、另存 Word 不覆盖；数据文件往返和旧文件）。真模型（先问我）：`real_qbank`，编的资料跑简历题、通用题、突击题、润色，自动查 JSON、条数、秒数和「资料里没有的数字」，`POMELO_QBANK_OUT=<文件>` 写报告（放「下载/Rater 测试/第 N 轮/」）；云端照下面的 `POMELO_CLOUD_KEY_FILE`，OpenRouter 上的 GLM 5.3 要加 `POMELO_CLOUD_THINK=always`（它停不下思考，不给余量会被截断）。面试的真模型：`real_interview`（编的两段经历、简历、题库和 JD：准备面试，再拿一次编的复盘对照，`POMELO_INTERVIEW_OUT=<文件>`）。卡片练习的真模型（先问我）：`real_practice`，编的资料跑按 JD 挑卡、两道题各追问两次（一道打字时故意说错）、一轮的点评（看能不能抓到说错的数字），自动查条数、顺序和「资料里没有的数字」，`POMELO_PRACTICE_CASE=挑卡|追问|反馈` 挑一项，`POMELO_PRACTICE_OUT=<文件>` 写报告。「Seeker 资料」技能在 `skills::seeker`（只读启用的、隐藏和云端挡住，题库带练习记录、最近几轮）。`?mock` 里有五道编的题（一道超过 90 秒、一道还没写答案、一道突击题挂着「腾讯 · 后台开发」）和 Rater 的四条规则；卡片页、面试页能走完整个流程（先选一个本地模型：模拟的挑卡、追问、点评、准备、对照有一秒左右的等待；打的字里写「失败测试」得到追问 / 点评失败，复盘的反馈里写「失败测试」得到对照失败），按 JD 选「腾讯 · 后台开发」能挑到那道突击题；投石问路腾讯的岗位面板「面试」一栏能跳到 Rater。
- **Seeker**：`cargo test --manifest-path src-tauri/Cargo.toml seeker`（照整理后的 `transfer/` 格式编的假 Seeker 文件夹：导入（字段行、按小节的规则、按条的事实、档案挂素材、文件里没有了）、发给模型的资料、组装、排序、删除和撤销、按模板写 Word（第二行联系方式、去掉缩略图）、另存不覆盖、做简历、按公司名对上 `knowledge/` 里的公司、数据文件往返；英文：`en-modules/` 导入、档案挂中英两条素材、按语言挑规则、Summary、章节顺序、Resume / CV 的提醒、中英草稿互不影响、英文 Word 的两行抬头和空行、旧数据文件和升级脚本 23）。真的中文模板 `cv/cn/seek-it-cn-template.docx` 和英文成稿 `cv/en/seek-it-keyreply-resume-v5.docx` 只读、复制到临时文件夹里测（`qlmanage -t` 出一张图对照模板看；快速查看不画列表的圆点和右对齐的制表位，模板自己也一样）；cv/ 和 material/：`seeker` 里的 `cv_resumes_…` 用临时文件夹里编的文件测分组、版本、模板 / 导出标记、对上岗位、只读 cv/ 和小拾的两种查法。真模型：`real_seeker`（编的中英文资料跑选材、整份审查、润色要点、润色一条素材、英文选材、Summary、英文润色，`POMELO_SEEKER_OUT=<文件>`）。`?mock` 里是编的资料（林小柚）、编的 `knowledge/`（腾讯、字节跳动等四家，投石问路里的腾讯会按名字对上）、编的 `cv/`（一组 keyreply 的三版能比较）和 `material/`（选了 Seeker 文件夹后才有）。
- **界面原型**：`prototype/ui-rN/` 改 `app.js` / `style.css` 后跑 `node build.mjs` 合成单个 `index.html`（双击能开）。预览面板直接打开 `file://` 地址，打开的是快照：改完要重新打开，刷新不算。截图常慢一拍，细节用脚本读页面（比如量顶栏图标的中线）。
