# 开发路线

## 当前进度

- **阶段 0 已完成**（2026-09-28）：分析 Excel 原型，确定架构和数据结构，搭好目录，写好文档。
- **下一步：阶段 1。** 开工前需要先装 Rust 和 pnpm（目前本机还没有）。

## 规矩

- 每个阶段结束时，功能必须真正能用；验收通过后，才进入下一阶段。
- 阶段 6 之前，Excel 仍然是主要数据来源。App 里的数据随时可以从 Excel 重新导入，开发中不用担心弄坏数据。

## v0.1 阶段

| 阶段 | 做什么 | 怎样算完成 |
|---|---|---|
| 0 规划 ✅ | 分析原型；定架构、数据结构、目录、视觉方向 | 文档定稿 |
| 1 骨架 | 初始化 Tauri + React + TS；侧边栏和空白页面；Rust 端的数据目录、数据库连接、升级机制和升级前自动备份 | 打开 App 后，数据目录里出现 `pomelo.db`；设置页显示数据位置和数据库版本；开发数据和真实数据分开 |
| 2 摸鱼读读 | 第一个完整模块：建表、命令、列表 / 筛选 / 编辑；写 Excel 转换脚本，导入书单 | 导入 21 本，已读 15 本；增删改之后重启，数据都还在 |
| 3 好奇看看 | 把书单的界面整理成共用组件，给影单复用 | 导入 50 部，已看 12 部（Excel 里显示 9，是原表公式出错），待标记 38 部 |
| 4 随意画画 | 课程、课节、进度 | 5 门课 202 节；改状态时自动记完成时间；进度数字正确 |
| 5 出门走走 | 场景模板、每次出行的清单 | 3 个模板共 34 件物品；能从模板建出行、勾选，模板不受影响 |
| 6 数据安全，正式启用 | 完整的导出 / 导入，备份列表和恢复，每天自动备份 | 导出、清空、再导入后，数据完全一致；能从备份恢复。之后 Excel 只作归档，Pomelo 成为唯一数据来源 |

## 页面（v0.1）

| 页面 | 主要内容 |
|---|---|
| 摸鱼读读 | 顶部统计；搜索、按状态筛选、排序；在表格里直接改状态和星级；右侧面板编辑全部字段 |
| 好奇看看 | 同上，另外可以按类型（电影 / 剧集 / 动漫）筛选 |
| 随意画画 | 左边是课程列表和各自的进度条，右边是该课程的课节；点击切换状态；顶部显示总进度和「下一课」 |
| 出门走走 | 「出行」：出行列表，点进去按类别勾选；「模板」：编辑场景和物品 |
| 设置 | 数据位置；备份和恢复；导出和导入；版本信息 |

v0.1 不做：首页 Dashboard、拖拽排序、附件和封面、标签、全局搜索。
