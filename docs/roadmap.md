## 1.1.0 文件备份（计划）

DevJanitor 的子页「备份」：电脑上的「下载」只传改过的，备到移动硬盘、PikPak、Google Drive。需求见 `requirements.md`「DevJanitor › 备份」。界面要的新设计（图标等）直接更新 visual-atelier 的 Design System，不用等批。

| Phase | 做什么 | 验收 |
|---|---|---|
| 1 移动硬盘 | 「备份」子页；任务（电脑上的文件夹 → 硬盘上的文件夹）；插上硬盘自动对一遍、分类；选全部或某几个任务、开始、进度、停下接着；只加不删、旧版、默认不备份的；每次的记录；VAULT 写进受保护的地方；`youzi.db` 升级脚本 44、`janitor.db` 版本 2 | 假 Mac 里编的「下载」和移动硬盘：插上、对、备份、改文件再备份（旧版进「旧版」）、停下再接着；正式版里用真硬盘做一次，你点「开始」 |
| 2 柚子参与 | Agent 对上文件夹、认改名和挪位置（卡片：在硬盘上跟着改）、分清归档和旧名字、找重复（卡片：移到废纸篓）；对完一遍自动看一眼 | 模拟模型下几种情况都出对的建议和卡片；真模型先问你 |
| 3 PikPak | rclone 接进来，授权进钥匙串；整个硬盘（VAULT 除外）同步，删了的进 PikPak 回收站；硬盘插着时后台传、断了接着、限速、进度 | 本机目录当假云端测；真 PikPak 先问你 |
| 4 Google Drive | 自己的客户端 ID（写好步骤）；挑文件夹、点了才传、不传开发产物；收尾 | 同上；全部做完装正式版 |

- **Phase 3 做完**（11-25，还没装正式版）：rclone（Homebrew）接进来，PikPak 的登录在 rclone 自己加密的配置里、密码在钥匙串；整块硬盘（VAULT 和系统小文件除外）在后台同步到 PikPak：插上硬盘、备份完、柚子的卡片改了硬盘、登录或改设置后自己传，往硬盘上备份时先让开；改名在 PikPak 上是挪、删了的进 PikPak 回收站、一次要删超过 100 个先停下等确认；能停下、接着传、限速；记录和硬盘的放在一起；没加升级脚本。验收（本机文件夹当假 PikPak）：Rust 测试里传完和硬盘一样、没有 VAULT 和系统小文件、名字是 NFC，改了名的文件夹在云上是挪、不重传，删了的进回收站，删得太多停下、「照样同步」放开，1 MB/s 时中途停下云上没有半个文件、再传只传剩下的；打包版里插上硬盘自己传了 17 个，柚子的改名卡片点了以后云上跟着挪，点「开始备份」后 PikPak 自己接着传，停下、接着传都对。还差：正式版里用真 PikPak 登录、传一次（你来）。
- **Phase 2 做完**（11-25，还没装正式版）：每次对比顺带对出线索（文件夹在硬盘上对应哪个、任务里整个改了名的文件夹、硬盘里的重复、归档和旧名字），Agent 照线索提议三种新卡片（在硬盘上改名或挪、移到硬盘的废纸篓、新建或改任务），插上硬盘（第一次选它、点「重新对比」也算）线索变了就自动看一眼，回答和卡片出在「备份」页和 Agent 里；没加升级脚本。验收：假 Mac 和假硬盘上四种情况（`小柚` 在硬盘上换了名字放着、`照片/其它` 在电脑上改了名、`回忆_2606` 一大块重复、`作品` 从没备过）和归档 `影音` 都对出对的线索，模拟模型照线索出的卡片都过得了检查；打包版（临时数据目录）里打开「备份」自动看了一眼（四张卡片），点了建任务两次、在硬盘上改、移到硬盘的废纸篓，硬盘上和任务都对；「柚子看一眼」说没有要改的；拔了再插、线索变了才再看一次；也点了「开始备份」（复制 4 个，时间对，被覆盖的进了旧版，记录对）。真模型（11-25，本地 Qwen3.5 9B 对着假硬盘，`real_backup_look`，三次）：开思考的一次和不开思考的一次，四种情况都出了对的卡片、影音说留着、没提 VAULT（不开思考那次还多提了一个重复的任务，被检查拦下、没出卡片）；另一次不开思考只在回答里写了四条建议、一张卡片都没出。还差：云端模型（要一个 Key 文件，或在正式版里看）。
- **Phase 1 做完**（11-25，还没装正式版）：假 Mac 和假移动硬盘上，四种任务的对比、复制（带时间和标签）、旧版、不覆盖、停下不留半个文件、硬盘不够不开始、跟着改名、记录都有测试；VAULT 在扫描、Agent、备份里都看不到。真硬盘上只读对比了四对文件夹（结果和手算的一致，冷读约 4 秒、之后不到 0.3 秒）。`?mock` 里点过选硬盘、新任务、展开、跟着改、开始和停下。还差：在正式版里用真硬盘点一次「开始备份」。
