## v0.3.5 · 小拾懂 Pomelo（等你验收）

需求见[需求](requirements.md)「小拾懂 Pomelo」。小拾只通过 Rust 读数据，这一版不写数据；芝麻开门永远不给小拾。

| 做了什么 | 验收 |
|---|---|
| **问我的数据**：小拾自己决定查哪些模块（只读，一次回答最多查 4 轮），回复上方写「查了什么」，提到的记录能点开，追问还记得 | 问「这周该跟进哪些投递」「总资产这半年怎么变的」，数字和 App 里一致；选云端问钱来钱往，回答写明这部分没看 |
| **右侧小窗**：⌘J 或侧栏的小鸟，任何页面都能呼出，带上当前页面、打开或多选的记录 | 打开一条投递问「该怎么跟进」，回答用上了它；芝麻开门页什么都不带 |
| **润色和补全**：备注角上的润色；书影、JD、拆子任务、出门漏带 | 润色能替换、能 ⌘Z；补全只填进面板，点「加上」才加 |
| **一句话填好**：收支、任务、投递、书影、新出行的新建面板最上面一行 | 每个写一句，填对后自己保存 |
| **允许发给云端**：「设置 → 小拾」按模块设（默认钱来钱往只给本地） | 关掉某个模块后选云端问它，回答写明没看 |

- 升级测试已做：用正式版的数据库版本（`pomelo.db` 22、`picky.db` 5）打开新版，`picky.db` 先备份再升到 6，旧对话都在；`pomelo.db` 不变、不备份。

## 已完成的版本

- **v0.3**：小拾（把 Picky 按 Pomelo 的架构重写进来，只搬已有功能）：底座（固定签名、`picky.db`、菜单栏常驻、连本地和云端模型）→ 聊天页 → 会话整理 → 模板与指令 → 附件与项目资料 → 记忆 → 从 Picky 导入、数据文件加上小拾、空间管理。
- **v0.2**：一步一步（分组、目标、多级任务；重复、打卡、进度条；月历、回看；拖拽排序、⌘Z 撤销）→ 钱来钱往（收支、固定支出、资产和总资产、持仓、报表、预算）→ 投石问路（每条投递的状态时间线、跟进提醒、统计）→ 念念不忘（参考 Flomo，导入 179 条）→ 芝麻开门（主密码 / Touch ID、加密）→ 全局搜索与侧栏（⌘K、隐藏模块、书影重读重看）→ 首页简单版；之间按 8 份优化清单改过。
- **v0.1**：骨架与升级备份 → 摸鱼读读（21 本）→ 好奇看看（50 部）→ 随意画画（5 门课 202 节）→ 出门走走（3 个模板 34 件）→ 导出、备份、恢复。

## 规矩

- 每个阶段结束时，功能必须真正能用；我亲自验收通过后，才进入下一阶段。
- 每次更新正式版前，都要验证正式版的数据库能顺利升级。
