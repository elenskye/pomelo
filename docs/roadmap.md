# 开发路线

## 现在

- **v0.5 完成**（你 2026-10-20 验收过了）。验收后的一轮优化也做完、装进了正式版：网站的图片和文档统一放进资源库（`public/assets/`，都登记，别处只引用；在别的页刚加的文件马上能在「资源库…」里挑到），资源库显示大小和「没在用」，简历也能从资源库挑，右上角加了 love-shuyu 入口。网站项目里的改动（搬文件、改引用、只留引用式字段、Logo 源文件移到 `design/brand/`）等你提交。
- **正式版**：v0.5 和验收后的优化（2026-10-20 装的）。
- **版本号**（开发版和正式版一样）：`pomelo.db` 30、`picky.db` 19、`search.db` 2、数据文件格式 18。
- **你那边的事**：申请到 Anthropic、Google 的 Key 后在正式版里填上试一试；OpenRouter 上的 Qwen 常被限流时，可以在 OpenRouter 绑定自己的阿里云 Key，或换模型。
- 优化清单放 `docs/pomelo-improve-N.rtf`（下一份是 10），问卷放 `docs/`，做完都移到 `archive/`。

## 已完成的版本

- **v0.5**：呦呦漫游，个人网站接进 Pomelo：待发布的改动和差异、本地检查后一键提交推送、上线结果和最近发布；在 Pomelo 里编辑网站的全部内容（作品、Now、关于我、职业页、资源库、话题与类别、外部链接；中英并排、边写边显示、图片自动压缩、预览窗口）；小拾帮忙润色、补全、按中文起草英文版；网站项目拿掉 Keystatic。
- **v0.4.5**：附件（笔记、任务、目标）和补回 Flomo 图片；来日方长；五花八门和循序渐进；笔记转待办；小拾读更多文件（Word、PowerPoint、表格、网页、图片）；知识库（文件夹和网页、整篇读、看图）；助手和翻译；Work（保存为 Word，插件库的 Word 工具箱、文本工具箱：改文件、新建 Word、改表格）；小拾同时做几件事（每个对话各自生成，本地模型排队）；云端限流自动重试。
- **v0.4**：小拾动手（14 个写数据的工具和确认卡片）、搜索底座和「意思相近」、出处、插件库和联网搜索、定时任务、今日简报和年度总结、思考开关、开机自动启动；芝麻开门的分类和归档、笔记边写边显示、云端加上 Anthropic 和 Google。
- **v0.3.5**：小拾懂 Pomelo：查数据、右侧小窗（⌘J）、润色和补全、一句话填好、按模块允许发给云端。
- **v0.3**：小拾（把 Picky 按 Pomelo 的架构重写进来）：聊天、会话整理、模板与指令、附件与项目资料、记忆、空间管理。
- **v0.2**：一步一步、钱来钱往、投石问路、念念不忘、芝麻开门、全局搜索与侧栏、首页简单版。
- **v0.1**：骨架与升级备份、摸鱼读读、好奇看看、随意画画、出门走走、导出、备份、恢复。

## 规矩

- 每个阶段结束时功能必须真正能用；你验收通过后才进入下一阶段。
- 每次更新正式版前，先验证正式版的数据库能顺利升级。
