## 验收要点（阶段 2～6）

**先做一次**：打开正式版（会自动备份并升级）；在「设置 → 导入」先选 `prototype/jobs-import.json` 导入 Seeker 的 3 条投递（只替换投石问路，文件由 `pnpm import:seeker` 生成），再选 `prototype/notes-import.json` 导入 Flomo 的笔记（只替换念念不忘，文件由 `pnpm import:flomo` 生成）。

**一步一步**
- 任务栏只有圆圈、标题和紧跟的日期；有子任务的在最右边「1/3 ⌄」；在 Diploma 里按住一行拖动排序。
- 普通 / 打卡 / 进度条的时间是「不设 / 时间段」；打卡在时间段里全部打完、或时间段过了，自动算完成。
- 重复：每天 / 每周 / 每月（点选几号）/ 每年（几月几号，可以每隔几年）/ 每隔只填「一共几次」「已经做了几次」；「完成后」填天、周、月或年数和开始日期。把「每周六交周报」改成重复任务。
- 回看：周 / 月 / 年 / 全部，柱状图、按分组排行、清单。
- 链接图标能打开网页；⌘Z 撤销、⌘⇧Z 重做。

**全局**：左侧栏能收起成图标、能按住拖动排序，重开还记得；界面里没有使用提示。

**钱来钱往**：建账户（一个账户一种币）→「更新余额」填余额和汇率 → 看总资产和曲线；记一笔、记一周小额；加一个固定支出（如房租每月 1 号）看它自动记上；报表按月 / 年、按币种看分类占比、趋势和预算。

**念念不忘**：导入后左栏是 179 条、42 个标签；标签树能展开，点标签只看它（含下一级）；在输入框写一条带 `#` 的笔记（会提示已有标签），⌘↩ 记下；双击一条就地修改；菜单里「引用」一条，新笔记下面和被引用的那条都能看到链接，点一下跳过去；置顶后排在最上面；给标签改名，所有笔记里的写法一起改；点热力图里的某天只看那天；搜索框能搜正文。Flomo 里带图片和录音的 17 条，附件没导入（v0.3 补）。

**芝麻开门**：第一次打开时设置主密码（至少 8 个字符，只有你知道）；设好后会存一份 Touch ID 用的钥匙。锁上（右上角「锁上」）再进来，会自动弹 Touch ID；指纹框里 3 次都没对上，就只能输主密码。新增一条：名称、链接、用户名、账号、密码（能显示、能随机生成）、备注；列表里鼠标移到用户名、账号、密码上能复制，复制的 30 秒后从剪贴板清掉。5 分钟不碰 App 会自动锁上。在「设置 → 芝麻开门」修改主密码，要先输原来的。以后每次更新正式版，第一次打开芝麻开门都要输一次主密码。

**投石问路**：新投递 → 改成「已投递」自动记投递日期；投出满 14 天出现在「该跟进」，点「已跟进」后 14 天内不再提醒；想投且有截止日期、笔试 / 面试有日期的，会在一步一步「💼 求职」里自动出现任务，状态往前走会自动勾掉；状态和渠道都能自己增删改；统计页看漏斗和每周投递数。
