  - **落签只量图标自己**：指着时那块方形浅底不算，没亮出来的透明下划线也不算。线从图标最低那一笔下面 3 像素开始（`tips.ts` 的 `inkBottom`）。柚子瓣、叠着的页量出来和以前一样。
  - **柚子瓣里念念不忘那块半透明的方形**（第二次修）：
    - **原因**：贴纸的阴影滤镜，WebKit 是按它第一次画的大小记着的。那时贴纸正在弹出来、还很小，之后拉大了用，就成了一块糊的、发白的方形，正好是滤镜的范围。叶子又细又斜，格子里空的地方多，所以只看得出它。
    - **为什么一转就好**：转柚子瓣时会改 `--pm-a`，这个变量往下传给每张贴纸，贴纸的样式一变，WebKit 才重画阴影。上午那次只摘了格子上的动画，贴纸本身的样式没变，所以阴影照旧用记着的那张。
    - **现在的改法**：弹完以后，把每张贴纸重新建一遍（`Bloom.tsx`：`.ic` 的 `key` 跟着 `still` 换）。上午加的 `is-still` 去掉了。
    - **没在真窗口里看过**：Chrome 里没有这个毛病，要我在 App 里打开柚子瓣看一眼。
  - **验证**：
    - `pnpm check` 通过（`tsc`、Rust 628 个）。
    - 无头 Chrome，`?mock`：柚子瓣开了 1.85 秒以后，23 张贴纸都是新建的，外面的格子没换，23 个阴影滤镜的 id 各不相同，截图和以前一样；念念不忘的落签离叶子 2.83 像素。
    - 落签上午量过：时间穿梭、顶栏、「桌上开着」的五页都是 2.6～3.0 像素；叠着的页、柚子瓣和上一轮一样。
    - 升级：只改了前端，库不动。

## v0.9 剩下的（我 2026-11-12 定）

来自 Pomelo 计划问卷的答案。需求写在 `requirements.md`：笔记模块在「文章「见字如面」」，Atlas 在「Atlas（年度总结）」，通知和书摘在「以后」。

- **日期**：不定日期，按顺序做完为止；不因时间压力降低完成度。
- **顺序**：设计 → A 底子 → B 搬家 → C 导出 → D Atlas → E 小功能 → 收口。笔记模块先做（我定的）。
- **装正式版**：每一段做完先做升级测试、装正式版，我在 App 里看。这算我同意，直接装。
- **范围**：不做云端同步。Pomelo 只读 Bear，不往里写。

### B · 从 Bear 搬家

- **怎么读**：用 Bear 自带的命令行 `bearcli`，只读，一次导完。11-12 只数了数：143 篇、29 个标签、37 张图。

- **核对**：在临时数据目录里用我的 Bear 跑一遍，只比篇数、标签、日期、图片。跑完删掉，不进仓库。正式导入由我在 App 里点。

### C · 导出

- **导什么**：一篇、选中的几篇、一个标签、全部都能导；格式是 Markdown、PDF、Word。
- **文件夹**：按标签分，放第一个标签最深的那一级。附件放在每篇旁边的同名文件夹里。
- **PDF**：
  - 两种样式；
  - 每次导出弹设置：目录、页眉页码、印标签和日期，各自能勾（我说的）；

### D · Atlas

- **Tabloid 1.1.0**：这一幕批了就是新的定稿。1.0.3 也留着，以前照 1.0.x 做的几份照旧用 1.0.3 画，没有这一幕。

## 你手头的小事

1. 在 App 里打开柚子瓣，看念念不忘那片叶子周围还有没有那块方形（11-12 第二次修的）。
2. 钥匙串访问里「Pomelo OS 芝麻开门」：下次用主密码打开芝麻开门后只留最新的一项，其余手动删。
3. Word / Excel 卡片默认存的文件夹现在是「下载/v0.8 Phase 3 测试」，下次保存时换回「文稿」。
4. 一网打尽里没显示全的网址填的是网站首页，要换成具体的页：Paint 里三个「课后挑战」（`appqm4zd22n4131.h5.xiaoeknow.com`）、《原创绘画全攻略》《通用板绘上手》（`appwtd0zghj7591.h5.xet.pomoho.com`）；API 里的「API keys」（`console.mathpix.com`）；Scholar 里的 ESS「Themes - Politics」（`ess.sikt.no/en/`）。
5. Excel 原表的小瑕疵，需要时在 App 里改：「绘画大地图」在 3 门课里同时是第 0 节和第 1 节；有一节课名只有「加餐 -」；`7S_1` 和 `7S_2` 同名。
6. 你说了再删「下载」里的测试文件夹：「v0.8 Excel 测试」「v0.8 Phase 3 测试」、「ELEN/test_pub2md/Key」。
7. 一步一步的分组名里以前打的 emoji（🖥️、📈 这些）还在名字里：想换成图标库的图标，在「编辑分组」里把 emoji 从名字里删掉，再点名字前那一格挑一个。
8. 终端里（或别的 Agent）以前开着的 `dw serve` 是旧的，有板有眼认不出它：先把它停掉（那个终端里 Ctrl-C），再在有板有眼里点「启动」。
9. 今日简报的提示词你在正式版里改过（「个人管理 App」那版），装了 0.9.0 后不会自动更新：在「定时 → 今日简报」里把两条新规则加进去（笔记带日期、心情多了「一般」，原文见「恢复默认」），或者点「恢复默认」再改回你的说法。
10. 在 App 里点顶栏「＋」再关掉贴纸簿（Esc 和点旁边各一次），看顶栏还会不会被挤上去；网站文件夹里 `src/pages/about.astro`、`src/pages/en/about.astro` 两个文件改了没提交。

## 要留意

- 每装一次新版，打开时 macOS 弹一次钥匙串授权框（Key），第一次用 Touch ID 开芝麻开门前再弹一次，输登录密码、点「始终允许」（原因见 `architecture.md`「签名」）。
- Importer：没有月份的截图靠星期几推月份，微信转账算支出还是不计收支，都因模型而异，导入前加一条提示词清单最稳。
- 卡片练习、面试的追问和复盘建议，参考答案偶尔会替你补资料里没有的过程，存进题库前看一眼。
- OpenRouter 的 GLM 5.3 FlashX 思考要设「只能思考」。
