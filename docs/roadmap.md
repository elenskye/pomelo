# 开发路线

## 当前进度

- **v0.1 已完成**（2026-09-29）：四个模块、导出和备份都能用了，正式版已经启用，Pomelo 是唯一的数据来源。数据库版本 7。
- **v0.2 开发中**：需求见[需求](requirements.md)。阶段 1（一步一步 · 基础）做完了，等我验收；数据库升到版本 8。

## v0.2 计划

| 阶段 | 内容 |
|---|---|
| 1 待办 · 基础（待验收） | 模块叫「一步一步」：分组、目标、任务和多级子任务、日期、今天视图、完成与回看；导入「近期待办」 |
| 2 待办 · 进阶 | 重复任务、进度条任务、打卡任务、月历视图、拖拽排序（顺带课节、物品、模板）、撤销 |
| 3 记账与财务 | 账户和余额、收支、固定支出自动记账、预算、投资持仓、报表 |
| 4 求职投递 | 投递表格、状态、跟进提醒、统计；导入 Seeker 的 3 条；和待办联动 |
| 5 通用清单与进度 | 自建清单（能自己加字段）和进度；书影重读重看；课节默认「未开始」 |
| 6 搜索与侧栏 | 全局搜索；隐藏模块、调整侧栏顺序 |
| 7 首页简单版 | 今天的待办、求职近况、总资产、在读在看、绘画进度、最近记录、今年的数字、问候语 |

撤销放在前面做，后面的模块就能直接用上；搜索等所有模块都有了再做。

## v0.1（已完成）

| 阶段 | 结果 |
|---|---|
| 0 规划 | 架构、数据结构、视觉定稿 |
| 1 骨架 | 升级前自动备份；数据库比 App 新时拒绝打开 |
| 2 摸鱼读读 | 21 本，已读 15 |
| 3 好奇看看 | 50 部，已看 12；书单和影单共用一套界面 |
| 4 随意画画 | 5 门课 202 节；类型可以自定义 |
| 5 出门走走 | 3 个模板 34 件；从模板建出行后，两边互不影响 |
| 6 数据安全 | 导出再导入完全一致；备份列表、恢复、每日自动备份；正式启用 |

## 规矩

- 每个阶段结束时，功能必须真正能用；我亲自验收通过后，才进入下一阶段。
- 每个阶段都要验证正式版的数据库能从上一个版本顺利升级。
