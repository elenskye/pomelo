1. 钥匙串访问里「Pomelo OS 芝麻开门」：下次用主密码打开芝麻开门后只留最新的一项，其余手动删。
2. Word / Excel 卡片默认存的文件夹现在是「下载/v0.8 Phase 3 测试」，下次保存时换回「文稿」。
3. 一网打尽里没显示全的网址填的是网站首页，要换成具体的页：Paint 里三个「课后挑战」（`appqm4zd22n4131.h5.xiaoeknow.com`）、《原创绘画全攻略》《通用板绘上手》（`appwtd0zghj7591.h5.xet.pomoho.com`）；API 里的「API keys」（`console.mathpix.com`）；Scholar 里的 ESS「Themes - Politics」（`ess.sikt.no/en/`）。
4. Excel 原表的小瑕疵，需要时在 App 里改：「绘画大地图」在 3 门课里同时是第 0 节和第 1 节；有一节课名只有「加餐 -」；`7S_1` 和 `7S_2` 同名。
5. 你说了再删「下载」里的测试文件夹：「v0.8 Excel 测试」「v0.8 Phase 3 测试」、「ELEN/test_pub2md/Key」。

## 要留意

- 每装一次新版，打开时 macOS 弹一次钥匙串授权框（Key），第一次用 Touch ID 开芝麻开门前再弹一次，输登录密码、点「始终允许」（原因见 `architecture.md`「签名」）。
- Importer：没有月份的截图靠星期几推月份，微信转账算支出还是不计收支，都因模型而异，导入前加一条提示词清单最稳。
- 卡片练习、面试的追问和复盘建议，参考答案偶尔会替你补资料里没有的过程，存进题库前看一眼。
- OpenRouter 的 GLM 5.3 FlashX 思考要设「只能思考」。

## 规矩

- 每个阶段结束时功能必须真正能用；你验收通过后才进入下一阶段。
- 每次更新正式版前，先验证正式版的数据库能顺利升级。
