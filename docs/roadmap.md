## v0.4 · 小拾懂 Pomelo + Pub2MD 并入

| 段 | 内容 |
|---|---|
| v0.3.5 小拾懂 Pomelo | 问我的数据（只读）；右侧小窗，任何页面都能呼出，知道当前页面和打开的记录；编辑面板里润色、补全；新建时一句话填好；按模块「允许发给云端」 |

- 小拾只通过 Rust 命令读数据，碰不到数据库；这一版小拾自己不写数据（一句话直接记好、改好放在 v0.5）。
- 芝麻开门永远没有小拾能用的命令；读到的 Pomelo 数据默认只给本地模型。
- 开发和测试只用模拟的模型（也会模拟「查数据」）；用真模型验收前先问你。每个阶段做完你验收，正式版由你来装。

### v0.3.5 的阶段

| 阶段 | 做什么 | 验收 |
|---|---|---|
| 1 查询底座 | Rust 的只读查询：各模块的记录和合计（投递的漏斗和统计从界面搬进 Rust，统计页也改用它）；模型的工具调用（本地、三家云端、模拟模型都会），一次回答最多查 4 轮，查到的内容截短到放得下；按模块判断能不能读、这次能不能发给云端；`picky.db` 升到 6，存查过的内容；「设置 → 小拾」加「允许发给云端」（默认钱来钱往只给本地）；回复上方的「查了什么」和展开 | 在小拾页问「这周该跟进哪些投递」「总资产这半年怎么变的」，答得对、数字和 App 里一致；选云端问钱来钱往，回答写明这部分没看 |
| 2 问我的数据 | 按问卷勾的七类问题补齐和打磨查询（时间段、高分书影、笔记主题、绘画预计完成时间、出门可能漏的东西）；回答里提到的记录能点开；追问用得上查过的内容；导出带上查了什么 | 七类问题各问一遍，答得对、记录能点开 |
| 3 右侧小窗 | ⌘J 和侧栏的小鸟按钮；右侧一栏、编辑面板排在左边、窗口窄时浮起；最近对话切换和新对话；各页面告诉小窗当前页面、打开的记录和多选的记录（只传编号，内容由 Rust 按规则去取）；输入框上方的小胶囊和 × | 在任何页面呼出，问「这条投递该怎么跟进」，回答用上了打开的那条；芝麻开门页什么都不带 |
| 4 润色和补全 | 输入框角上的润色按钮、写要求、改动对比和替换；书影、JD、拆子任务、出门漏带四种补全；本地模型没运行时自动启动；选云端时钱来钱往不可用 | 润色一段备注能替换、能 ⌘Z；四种补全都能用，只填进面板或点「加上」才加 |
| 5 一句话填好 | 五个新建面板最上面的输入框；Rust 检查填好的值（日期按今天算，分类、渠道、模板按名称对上，币种）；填过的地方浅柚红底 | 五个模块各写一句，都填对，自己保存 |
| 6 收尾 | 整理文档；升级测试（`picky.db` 5 → 6，`pomelo.db` 不变）；正式版由你来装 | 你验收 |

- 数据：`pomelo.db` 不改；`picky.db` 加一张表存查过的内容（属于哪次回复、查了什么、结果、提到的记录）；「允许发给云端」存在 `picky.db` 的设置里。
- 新增依赖：没有（改动对比自己写）。

## 已完成的版本

- **v0.3**：小拾（把 Picky 按 Pomelo 的架构重写进来，只搬已有功能）：底座（固定签名、`picky.db`、菜单栏常驻、连本地和云端模型）→ 聊天页 → 会话整理 → 模板与指令 → 附件与项目资料 → 记忆 → 从 Picky 导入、数据文件加上小拾、空间管理。
- **v0.2**：一步一步（分组、目标、多级任务；重复、打卡、进度条；月历、回看；拖拽排序、⌘Z 撤销）→ 钱来钱往（收支、固定支出、资产和总资产、持仓、报表、预算）→ 投石问路（每条投递的状态时间线、跟进提醒、统计）→ 念念不忘（参考 Flomo，导入 179 条）→ 芝麻开门（主密码 / Touch ID、加密）→ 全局搜索与侧栏（⌘K、隐藏模块、书影重读重看）→ 首页简单版；之间按 8 份优化清单改过。
- **v0.1**：骨架与升级备份 → 摸鱼读读（21 本）→ 好奇看看（50 部）→ 随意画画（5 门课 202 节）→ 出门走走（3 个模板 34 件）→ 导出、备份、恢复。

## 规矩

- 每个阶段结束时，功能必须真正能用；我亲自验收通过后，才进入下一阶段。
- 每次更新正式版前，都要验证正式版的数据库能顺利升级。
