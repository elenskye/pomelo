## 要留意

- 每装一次新版，打开时 macOS 会弹一次钥匙串授权框（Key），第一次用 Touch ID 开芝麻开门前再弹一次，输登录密码、点「始终允许」（App 没有苹果开发者团队签名，「始终允许」只认那一版）。
- Word / Excel 卡片默认存的文件夹现在是「下载/v0.8 Phase 3 测试」（测试时选的），下次保存时换回「文稿」。
- Excel 工具箱：公式的结果要等 Excel 打开文件时才重算，柚子读回来时看到的可能是旧的；有图表、表格对象、批注、透视表的表不能加删行（改格子可以）；在明细最后一行后面加行时，下面合计的范围会扩到新行（和 Excel 不同）。
- Importer：没有月份的截图靠星期几推月份，不同模型结果不一，所以都标了疑点，导入前加一条清单要点最稳；微信转账算支出还是不计收支，模型之间不一样，也靠清单定。
- 卡片练习、面试的追问和复盘建议，参考答案偶尔会替你补资料里没有的过程，存进题库前看一眼。
- OpenRouter 的 GLM 5.3 FlashX 思考要设「只能思考」。
- Excel 原表的小瑕疵已原样导入，需要时在 App 里改：「绘画大地图」在 3 门课里同时是第 0 节和第 1 节；有一节课名只有「加餐 -」；`7S_1` 和 `7S_2` 同名。
