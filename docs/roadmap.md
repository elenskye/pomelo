## 已完成的版本

- **1.0.5**（11-24）：见字如面的行内代码不再和后面的字叠在一起（日历的样式撞了名）；见字如面的列表、书架和别处的列表在鼠标停在截断的字、折起来的卡片上时也能用滚轮滚（WebKit 里 `overflow: hidden` 的盒子会接走滚轮，改成 `clip`）；附件链接前的 📎 不会被读进正文；所有样式开窗就全部载入，模块之间的样式不串；写字的框有了测试台（Chrome 和 WebKit 各跑一遍：叠字、串样式、读回来的字、光标、重画、能点到），`pnpm check` 里查样式不串和测试台，`ui-lint` 多查会卡滚轮的盒子。
- **1.0.4**（11-24）：侧栏的树和分组（标签树、一步一步、有板有眼、柚子的对话、一网打尽）展开时子项一行接一行滑下来、落到位弹一下，收起倒着收回去；见字如面标题的折叠箭头点得动了，折着的行尾「…」点了展开；右键菜单不再留空的图标位、宽度跟着字；提交信息全英文；加了交接文档 `HANDOFF.md`。
- **1.0.3**（11-23）：念念不忘、速记、记到念念不忘、写提示词的框、呦呦漫游的正文照见字如面排：空行是整整一行，每行后面一样的小段距，输入法在空行上拼字不再和下一行叠在一起；格式符号只在光标那一处露出，列表的 `- ` 画成点；念念不忘的卡片和首页便签同样排。
- **1.0.2**（11-22）：柚子续写 / 润色、记到念念不忘的卡能拖；弹窗打开时不给第一个按钮画框（有文字框就落在文字框里）；见字如面专心写铺纸纹、格式栏抬高，导出的柚儿园 PDF 有纸纹；呦呦漫游编辑页的框跟着字长高、卡片里的框淡一档；写了 `space-y` 的手画卡底色铺到下边的线。
- **1.0.1**（11-21）：落签只写动作；柚子润色 / 续写、记到念念不忘换成手画卡，量过再摆、不出窗口；字里的图标对着字心；柚子转为待办的勾和标题对齐、去掉卡片下的灰阴影；念念不忘和见字如面正文里的标签显示图标；有板有眼画布的边四边连上。
- **1.0.0**（11-17）：v0.1～v1.0 一路做下来的全部模块、柚子和它的助手（见 `README.md`「模块」）；最后一段加的是见字如面（从 Bear 搬家、导出 PDF / Word）、柚子链接、玩物有志、系统通知、Atlas 的新几幕（Tabloid 1.1.1）。
