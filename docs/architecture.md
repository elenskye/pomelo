# 技术架构

## 基本原则

- **个人、轻量**：只给我一个人在一台 Mac 上用，不做账号、协作、云端、跨平台。
- **够用就好**：能用简单办法的，不用复杂办法。
- **数据能长期保存、随时带走**：App 随时可以换掉，数据不丢。
- **默认离线**：只有 AI 联网搜索和可选的云端模型（默认关）会联网。

## 技术选型

| 部分 | 选择 |
|---|---|
| 桌面应用 | Tauri 2 |
| 界面 | React + TypeScript + Vite，Tailwind CSS；少量自己写的组件，不用组件库 |
| 数据层 | Rust + SQLite |
| 辅助脚本 | TypeScript（Node） |

## 分层

```
界面（React） ──┐
               ├── 调用命令 ──▶ Rust 命令层 ──▶ SQLite
AI 助手（以后）──┘              业务规则、校验都在这里
```

- 只有 Rust 端读写数据库，界面只调用 `books_list` 这样的命令。
- 以后 AI 用的工具就是这些命令，AI 永远碰不到数据库本身。

## 数据存放在哪里

| 位置 | 放什么 | 备份 |
|---|---|---|
| `/Applications/Pomelo OS.app` | App 本体 | 不用 |
| `~/Library/Application Support/Pomelo OS/` | 真实数据：`pomelo.db`（含设置）、`backups/` | **要** |
| `~/Library/Application Support/Pomelo OS Dev/` | 开发用的测试数据 | 不用 |
| macOS 钥匙串 | 以后的 API Key 等密钥 | 不进备份 |

不要把数据库放进 iCloud、Dropbox 等同步文件夹，同步可能把它弄坏；想异地保存，就复制**备份文件**。

## 开发版和正式版

同一份代码的两种运行方式，区别只在数据目录：

- **正式版**：「应用程序」里的 App，我日常使用，读写真实数据。
- **开发版**：开发时直接从代码运行，读写测试数据，随便清空。

分开是因为开发中的代码可能有 bug，数据库升级脚本也要先在测试数据上试好。阶段验收后运行 `pnpm app:install` 更新正式版；新版第一次打开时，会先自动备份再升级。「应用程序」里只应该有一个 Pomelo OS。

## 数据库升级

- 每次改结构都新增一个编号脚本（`src-tauri/migrations/`），已经用过的脚本永远不改。
- App 启动时如果需要升级：**先自动备份**，再逐个执行。
- 数据库版本比 App 新（比如装回了旧版）时，App 拒绝打开，防止写坏数据。

## 备份与导入导出

| | 快照备份 | 数据文件（JSON） |
|---|---|---|
| 是什么 | 整个数据库的副本，放在数据目录的 `backups/` 里 | 所有模块的数据，人能看懂 |
| 用途 | 出问题时恢复 | 长期归档、换工具、从 Excel 导入 |
| 什么时候做 | 每天第一次打开、升级前、覆盖导入前、恢复前自动做；也可以「立即备份」 | 在设置里「导出…」 |
| 怎么用回来 | 设置里的备份列表，点「恢复」 | 设置里「导入」 |

- **每日备份**保留最近 30 份，更早的每个月只留最后一份。其他备份不会自动删除，想清理可以在 Finder 里删。
- **恢复**会把当前的全部数据换成那份备份；恢复前先自动备份当前数据。老版本的备份恢复后会自动升级；损坏的、或者比 App 新的备份会被拒绝。
- **导入**时，文件里只要有一条不合格就一条都不导入；覆盖已有数据前会先确认并备份。
- 备份文件名里写着时间和原因，比如 `pomelo-20260929-093000-daily.db`（每日）、`manual`（手动）、`before-v7`（升级到版本 7 前）、`before-import`、`before-restore`。

## 占用空间和内存

- **实测**：App 本体约 6 MB；运行内存约 85 MB（不到这台 Mac 内存的 1%）；导入全部 Excel 数据后，数据库约 0.1 MB。
- **估算**：以后加上 Todo、财务、AI 对话记录，数据库十年也在几百 MB 以内。真正占空间的会是照片类附件，存的时候会先压缩。

## 本地 AI 和外部工具（v1.0 前）

- **本地模型**由 llama.cpp 运行，放在 `~/Documents/LLM`，用 `scripts/llmctl.sh` 启动和切换；同一时间只跑一个，接口是 `http://127.0.0.1:8080/v1`。14B 模型约占 9 GB 内存。Pomelo 只连接它，不负责下载模型。
- **云端模型**可以接，但默认关闭。
- AI 和界面一样，只能通过 Rust 命令读写数据；改数据前必须我确认。
- **Pub2MD**（翻译工具）保持独立，由 Pomelo 负责启动和关闭；**Seeker**（简历和面试材料）也保持独立，Pomelo 只记里面文件的位置。
