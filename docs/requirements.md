# 需求

> 来自两轮需求问卷（2026-09-29，原件在 `archive/`）和之后对话里的决定。版本安排见[开发路线](roadmap.md)。

## 总体

- **定位**：第二大脑，个人事务都在这里管。App 一直开着，想到就记，每周整理一次；每天花 5～15 分钟。
- **最想解决**：事情会忘、截止日期错过；想回顾时找不到记录；录入太麻烦。
- **风格**：适度自动——自动填日期、提醒、汇总，但不替我做决定。
- **只在这台 Mac 上用**，手机不用。
- **提醒只在 App 里**：不弹系统通知，关掉窗口后不在后台常驻。
- **界面不放使用提示**（快捷键、怎么操作、撤销提醒之类）。需要解释的，只在设置页用 (?) 说明。
- **删除**确认后直接删，不设废纸篓。
- **撤销**：⌘Z 撤销、⌘⇧Z 重做最近 100 步修改（新增、修改、删除、勾选、排序都算）；关掉 App 后就不能撤销了。导入和恢复备份不能撤销。
- **联网**：默认完全离线。只有 AI 联网搜索和可选的云端模型（默认关）会联网；汇率、书影信息、天气都不联网获取。
- **侧栏**：所有模块平铺；能收起成只有图标的窄条，能按住拖动调整顺序（都会记住）。隐藏模块以后再做。首页做好后，打开 App 先显示首页。
- **v1.0 的标准**：功能齐了，视觉也打磨好了。视觉在 v1.0 前统一做。
- **不做**：日记、习惯打卡模块、心愿单、物品管理、人情往来、健康记录、整个 App 的锁（只有「芝麻开门」要解锁）、全局标签（笔记的标签只在笔记里用）、今日三件事、今日时间线、月度复盘、计时、快捷指令接入、浏览器剪藏、桌面小组件、豆瓣导入、拍照识别。

## 待办「一步一步」（v0.2，参考「目标地图 GoalMap」）

- 完全替代现在的 Markdown 待办。
- **结构**：分组 → 目标 → 任务 → 多级子任务。分组只有一层（可以带 emoji）；零散的任务直接放在分组里。不要标签、优先级、情境。
- **目标**：开始和结束时间；状态（进行中、暂停、已完成、已放弃）；进度按完成的任务自动算；完成后写几句复盘。
- **子任务**可以多层、能折叠；全部完成时，上一层自动勾上。
- **时间**：不设，或者一个时间段（开始可以不填，只有截止日期）。时间段内每天都出现在今天；过期的标红，留在原来的日期。没有「计划哪天做」。
- **完成后**收进「已完成」，可以展开；自动记完成时间。
- **回看**：按周、月、年、全部看完成了什么。有柱状图（每天或每月完成几件）、按分组的排行、合计和日均 / 月均，下面是清单。
- **视图**：今天（默认）、按分组 / 目标、月历。按住一行拖动就能排序。左侧的分组能收起、展开下面的目标。分组页里，已完成和已放弃的目标收进「已完成的目标」，点开才看到。
- **任务栏只显示标题和截止时间**：日期写成 2026 / 10 / 03，紧跟在标题后面。有子任务的，在最右边显示「1/3 ⌄」，点它收起、展开。任何列表都不标所属分组。目标前面没有图标，想要就在名字里用 emoji。
- **每条记**：标题、内容（多行，支持 **加粗**）、链接（网址、`www.…` 或本机文件路径，点任务栏上的链接图标打开）。分组和目标页右上角有「新任务」（在「新目标」右边），⌘N 也一样；今天页仍是底部的快速添加。
- **四种任务**：
  - **普通**：做完勾掉。
  - **重复**：不用填日期，由规则推算每一次是哪天。勾掉就跳到下一次；也可以「跳过这次」。
    - 每天、每周某几天、每月某几号（在 1～31 里点选，可以多选）、每年某月某日（可以每隔几年，比如每 3 年的 12 月 31 日）、每隔几天或几周：填「一共几次」（可以不限）和「已经做了几次」，系统推算每一次和最后一次是哪天。
    - 完成后再过几天 / 几周 / 几个月 / 几年：填数字和开始日期。比如银行账户「完成后过 1 年」、交通卡「完成后过 3 年」，每次做完都从那天重新算。
  - **打卡**：每天或每周固定几天。时间和普通任务一样「不设 / 时间段」，没有目标天数。该打卡的日子出现在今天，点一下就打卡。面板里有月历，漏了能补打；显示连续天数。时间段里该打卡的日子都打了，马上算完成（只设了截止日期的，从添加那天算起）；取消其中一天又变回没完成。时间段结束后也自动算完成。
  - **进度条**：有目标数量和单位（比如「今年读 20 本」），可以设时间段。点圆圈加 1，面板里能记任意数量。只按累计算，达到目标自动完成。
  - 重复、打卡、进度条不能有子任务。
- **联动**：求职的截止、笔试、面试自动变成待办（已做，见投石问路）；以后：出门走走出发前提醒打包；首页显示今天的待办。
- 不要：备忘、每周回顾。
- **导入「近期待办」**已完成（阶段 1）。「每周六交周报」要在 App 里改成重复任务：每周六，一共 20 次，填上已经做了几次；密码那一行没有导入，等「芝麻开门」做好后放进去。

## 记账「钱来钱往」（v0.2）

- **最重要**：看总资产怎么变化；管好订阅和固定支出。也要：知道钱花在哪、每月按分类的预算、投资。
- 从零开始，每周或每月集中整理一次。
- **三页**：收支（每一笔 + 固定支出）· 资产（账户、每月余额、汇率、持仓、总资产曲线）· 报表（分类占比、每月趋势、年度总结、预算）。
- **记多细**：300 元以上（其他币种大概等值）单独记；小额每周按分类合成一笔，用「记一周小额」一次填完各分类。
- **币种**：人民币、新加坡元、港币、美元，平时分开记、不用汇率，报表也按币种分开看。总资产：每月「更新余额」时顺手填当月汇率，折成人民币合成一个总数。
- **账户**：一个账户一种币（香港账户里有港币和美元就建两个）。类型分银行、钱包、券商；不用的可以停用。不记转账和换汇。
- **一笔记录**：支出 / 收入、金额、币种、日期、分类（一层，可以自己改）、账户（可不填，填了就用它的币种）、备注。
- **固定支出**（房租、话费、订阅，也可以是固定收入）：每月几号或每年哪天，到日子自动记一笔，漏掉的也会补上；可以停用。「订阅与续费」并进这里。
- **投资**：每月手动更新一次券商账户的总值（在「更新余额」里）和持仓（名称、数量、市值）。
- **预算**：按「支出分类 + 币种」设每月金额，比如「餐饮 每月 S$600」。快到时变黄，超出变红并写明超出多少。
- **报表**：分类占比（饼图 + 排行）、每月支出和收入、年度总结、净资产变化曲线（在资产页）。按分类看，不要标签。
- 不记：贵重物品、负债、借出和 AA、信用卡；不和出门走走关联；不额外加密。

## 求职「投石问路」（v0.2）

- 预计毕业前集中投：全职、中国大陆，一个求职季 200 个以上。
- **两页**：投递（表格，顶上是「该跟进」，能按想投 / 进行中 / 拿到 / 已结束筛选、搜索）· 统计（漏斗、每天 / 每周投了几份、现在的状态分布）。
- **一条记录**从「想投」走到结束。记：公司、岗位、地点、JD 链接、渠道（能自己增删改）、简历和求职信（Seeker 里的文件位置，能选文件、点一下打开）、截止日期、薪资、备注。
- **状态**：默认想投、已投递、网申测评 / 笔试、面试、Offer、已接受、被拒；名字、顺序、增删都能改。每个状态属于一个阶段：准备 / 等回音 / 进行中 / 拿到 / 结束，系统靠阶段判断规则。
- 不记状态变化的历史，只记：投递日期（第一次到「等回音」及以后时自动填）、这一步的日期（笔试 / 面试哪天）、最远到过哪一步（算漏斗用，被拒的也算到它停下的那一步）。
- **跟进**：等回音满 14 天提醒；点「已跟进」后再过 14 天才又提醒。
- **和待办联动**：想投且有截止日期 →「投递 公司 · 岗位」；进行中且有日期 →「面试 公司 · 岗位」（用状态名）。自动建在一步一步的「💼 求职」分组（改了组名也会继续用那个组），日期跟着改，状态往前走自动勾掉，删投递时删掉没做完的那条。
- 已导入 Seeker 里记的 3 次投递（`pnpm import:seeker`）；2024 年的旧表不导入。「每天投一份」这类目标以后再说。
- **Seeker 保持独立**：它管简历和面试材料，Pomelo 只管投递和进度。
- **面试题库**（v1.0 前）和投递分开：Seeker 继续维护题库，Pomelo 从 Bear 导出的 Markdown 导入，只用来练习。能筛选题目，像闪卡一样练习（正面题目，背面参考答案）；每张卡记题目、参考答案、类型、熟练度（练完标「会 / 不会」，下次先出不会的）、练过几次。

## 笔记「念念不忘」（v0.2，参考 Flomo）

- **定位**：想到就记的收集箱，替代 Flomo。一条笔记只有正文和记录时间，没有标题、分类这些要填的东西。
- **标签**直接写在正文里：`#标签`，多级用 `#一级/二级`。`#` 要在开头或空格后面，到空格为止。只在笔记里用，和别的模块无关。
- **正文格式**：**加粗**、==高亮==、++下划线++、列表（`- ` 或 `1. `，Tab 缩进一级），网址能点开。快捷键：⌘B 加粗、⌘U 下划线、⌘⇧H 高亮、⌘↩ 记下；输入 `#` 时提示已有的标签；列表里回车自动接着编号。
- **页面**：左栏是笔记数、标签数、记了几天，最近 16 周的热力图（点某天只看那天），「全部笔记」和标签树（多级、能折叠，按拼音排）。右边上面是输入框，下面是一条条卡片，新的在上面，置顶的排最上。搜索框搜正文，几个词要同时出现。标签、日期、搜索可以叠加，筛选条件显示在卡片上方，点 × 去掉。在某个标签下新建，输入框自动带上这个标签。
- **每条笔记**：双击或菜单「编辑」就地修改；「引用」（Flomo 的批注）：新写一条引用它，两边都显示链接，点一下只看那一条；「置顶」；「删除」确认后直接删，引用一起去掉。太长的笔记折起来，点「展开全文」。
- **标签改名**：标签树上点铅笔，所有笔记里的写法一起改，下一级跟着走；改成已有的标签就是合并。
- **从 Flomo 搬家**（`pnpm import:flomo`，读 `prototype/flomo-*` 里的导出）：179 条全部导入，保留原来的时间、标签和格式。17 条带的图片和录音这次不导入，v0.3 做附件时按时间补回；Flomo 里的 4 处笔记链接保留成网址（导出文件里没有笔记编号，没法自动连上）；录音那条的文字稿和正文几乎一样，没有重复加。
- **以后**：AI 年度总结，和 Pomelo 的 Agent 一起做：读一年的笔记，总结出对我重要的人、事和变化（像 Flomo 的年度总结那样）。

## 密码「芝麻开门」（v0.2）

- 统一管理一般性的密码（网站、App 账号这类），不放银行卡密码这样敏感的信息。现有的密码我自己手动录入。
- **每条记**：名称（必填）、链接、用户名、账号、密码、备注（比如两步验证的备用码）。密码能显示 / 隐藏，能随机生成（像 Apple 那样三组字母，带一个大写和一个数字）。
- **列表**：名称（带网站名，点一下打开）、用户名、账号、密码（只显示圆点）。鼠标移上去能复制；复制的内容 30 秒后从剪贴板清掉，剪贴板管理工具也不会记下它。按名称排，能搜索。改和删都能 ⌘Z 撤销。
- **主密码**：第一次打开时我自己设，至少 8 个字符。Pomelo 不保存它，只有我知道；更新 App 不会丢。修改要先输原来的，没有「忘记密码」，忘了就打不开。
- **怎么打开**：平时用 Touch ID（到这一页时自动弹出）。这些情况必须输主密码：指纹框里 3 次都没对上（macOS 每次弹框给 3 次机会）；距上次输主密码满 3 天；App 更新后第一次打开。
- **自动锁**：5 分钟没碰 App 就锁上（电脑睡眠也算）；也能手动「锁上」；恢复备份后也会锁上。
- **任何云端 Agent 都读不到**：每条密码都加密后才存进数据库，备份里也是加密的；导出文件里不带密码。Touch ID 用的钥匙在 macOS 钥匙串里，别的程序要读，系统会弹窗要电脑的登录密码。以后的 AI 也不会有读密码的命令。

## 本地 AI（v1.0 前，先 Chat 后 Agent）

- **模型**：llama.cpp 在这台 Mac 上运行（`~/Documents/LLM`），同一时间只跑一个，接口是 `http://127.0.0.1:8080/v1`。现有 Qwen3 14B、Ministral 3 14B、Qwen3-VL 8B（能看图）。
- **Pomelo 只切换接口**：本地接口、云端接口 1、云端接口 2……云端默认关闭。用哪个本地模型，我自己用 `llmctl.sh` 切换；模型没运行时，提示我去启动。
- **侧边栏**一直在右侧，可以收起；知道当前是哪一页，能选中一条记录直接问。编辑面板里能一键润色、补全；新建时一句话填好各项。
- **Chat**：日常问答、学习、模拟面试、问我自己的数据。多个对话（改名、置顶）、预设角色、发文件、发图片、重新生成和修改、导出 Markdown；记录全部保存，能搜索、能手动清理；有能查看、修改的长期记忆。
- **AI 年度总结**：读一年的笔记（念念不忘），总结重要的人、事和变化。
- **Agent**：一句话记录和查询、贴 JD 建投递、模拟面试、账单建议、推荐书影、批量整理、每周总结、调用 Pub2MD 翻译；也能起草周报、整理待办、写求职信。改数据前每次都要我确认，并显示每一步。能读指定的文件夹（比如 Seeker）、联网搜索、调用 Pub2MD；支持定时任务。
- **知识库**：能引用 Pomelo 的全部记录和指定文件夹的文档；支持模糊搜索。到时候再加一个做「向量」的小模型。
