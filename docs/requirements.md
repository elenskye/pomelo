# 需求

> 来自两轮需求问卷（2026-09-29，原件在 `archive/`）。版本安排见[开发路线](roadmap.md)。

## 总体

- **定位**：第二大脑，个人事务都在这里管。App 一直开着，想到就记，每周整理一次；每天花 5～15 分钟。
- **最想解决**：事情会忘、截止日期错过；想回顾时找不到记录；录入太麻烦。
- **风格**：适度自动——自动填日期、提醒、汇总，但不替我做决定。
- **只在这台 Mac 上用**，手机不用。
- **提醒只在 App 里**：不弹系统通知，关掉窗口后不在后台常驻。
- **界面不放使用提示**（快捷键、怎么操作、撤销提醒之类）。需要解释的，只在设置页用 (?) 说明。
- **删除**确认后直接删，不设废纸篓。
- **撤销**：⌘Z 撤销、⌘⇧Z 重做最近 100 步修改（新增、修改、删除、勾选、排序都算）；关掉 App 后就不能撤销了。导入和恢复备份不能撤销。
- **联网**：默认完全离线。只有 AI 联网搜索和可选的云端模型（默认关）会联网；汇率、书影信息、天气都不联网获取。
- **侧栏**：所有模块平铺；v0.2 起可以隐藏模块、调整顺序。首页做好后，打开 App 先显示首页。
- **v1.0 的标准**：功能齐了，视觉也打磨好了。视觉在 v1.0 前统一做。
- **不做**：日记、习惯打卡模块、心愿单、物品管理、人情往来、健康记录、App 锁、全局标签、今日三件事、今日时间线、月度复盘、计时、快捷指令接入、浏览器剪藏、桌面小组件、豆瓣导入、拍照识别。

## 待办「一步一步」（v0.2，参考「目标地图 GoalMap」）

- 完全替代现在的 Markdown 待办。
- **结构**：分组 → 目标 → 任务 → 多级子任务。分组只有一层（可以带 emoji）；零散的任务直接放在分组里。不要标签、优先级、情境。
- **目标**：开始和结束时间；状态（进行中、暂停、已完成、已放弃）；进度按完成的任务自动算；完成后写几句复盘。
- **子任务**可以多层、能折叠；全部完成时，上一层自动勾上。
- **时间**：不设，或者一个时间段（开始可以不填，只有截止日期）。时间段内每天都出现在今天；过期的标红，留在原来的日期。没有「计划哪天做」。
- **完成后**收进「已完成」，可以展开；自动记完成时间；能回看某天、某周完成了什么。
- **视图**：今天（默认）、按分组 / 目标、月历。按住一行拖动就能排序。左侧的分组能收起、展开下面的目标。
- **任务栏只显示标题和截止时间**：日期写成 2026 / 10 / 03，紧跟在标题后面。有子任务的，在最右边显示「1/3 ⌄」，点它收起、展开。任何列表都不标所属分组。目标前面没有图标，想要就在名字里用 emoji。
- **每条记**：标题、内容（多行，支持 **加粗**）、链接（网址、`www.…` 或本机文件路径，点任务栏上的链接图标打开）。⌘N 快速新增。
- **四种任务**：
  - **普通**：做完勾掉。
  - **重复**：不用填日期，由规则推算每一次是哪天。勾掉就跳到下一次；也可以「跳过这次」。
    - 每天、每周某几天、每隔几天或几周：填「一共几次」（可以不限）和「已经做了几次」。
    - 每月：在 1～31 号里点选几天（可以多选），再填时间段（开始和结束）。
    - 完成后再过几天：填天数和开始日期。
  - **打卡**：每天或每周固定几天。当天出现在今天，点一下就打卡。面板里有月历，漏了能补打；显示连续天数；可以设目标天数和结束日期。
  - **进度条**：有目标数量和单位（比如「今年读 20 本」），可以设时间段。点圆圈加 1，面板里能记任意数量。只按累计算，达到目标自动完成。
  - 重复、打卡、进度条不能有子任务。
- **联动**（以后）：求职的笔试、面试、截止日期自动变成待办；出门走走出发前提醒打包；首页显示今天的待办。
- 不要：备忘、每周回顾。
- **导入「近期待办」**已完成（阶段 1）。「每周六交周报」要在 App 里改成重复任务：每周六，一共 20 次，填上已经做了几次；密码那一行没有导入（请移到「密码」App）。

## 记账与财务（v0.2）

- **最重要**：看总资产怎么变化；管好订阅和固定支出。也要：知道钱花在哪、每月按分类的预算、投资。
- 从零开始，每周或每月集中整理一次。
- **记多细**：300 元以上（其他币种大概等值）单独记；小额每周按分类合成一笔（比如「餐饮 本周 320」）。
- **币种**：人民币、新加坡元、港币、美元，平时分开记、不用汇率。总资产：每月更新余额时填一次当月汇率，折成人民币合成一个总数。
- **账户**：中国的银行卡、新加坡的银行卡、香港的银行账户、支付宝 / 微信、券商（嘉信）。不记转账和换汇。
- **一笔记录**：金额、币种、日期、分类（一层）、账户、备注。收入也记。
- **固定支出**（房租、话费、订阅）到日子自动记一笔。「订阅与续费」并进这里，不单独做。
- **投资**：每月手动更新一次账户总值和持仓。
- **报表**：分类占比、每月趋势、年度总结、净资产变化曲线。按分类看，不要标签。
- 不记：贵重物品、负债、借出和 AA、信用卡；不和出门走走关联；不额外加密。

## 求职投递（v0.2）

- 预计毕业前集中投：全职、中国大陆，一个求职季 200 个以上。
- **一条记录**从「想投」走到结束。记：公司、岗位、地点、JD 链接、渠道、投的简历和求职信（记 Seeker 里的文件位置）、截止日期、薪资、备注。
- **状态**：想投、已投递、网申测评 / 笔试、面试、Offer、已接受、被拒；可以自己增删改。不记状态变化的历史；面试只记到这一步和日期。
- 投出 2 周没回音，在 App 里提醒跟进。
- **表格**查看；统计投递漏斗、每天 / 每周投了几份。「每天投一份」这类目标以后再说。
- 导入 Seeker 里记的 3 次投递；2024 年的旧表不导入。
- **Seeker 保持独立**：它管简历和面试材料，Pomelo 只管投递和进度。
- **面试题库**（v1.0 前）和投递分开：Seeker 继续维护题库，Pomelo 从 Bear 导出的 Markdown 导入，只用来练习。能筛选题目，像闪卡一样练习（正面题目，背面参考答案）；每张卡记题目、参考答案、类型、熟练度（练完标「会 / 不会」，下次先出不会的）、练过几次。

## 首页（v0.2 先做简单版）

- v0.2 的简单版：今天的待办、求职近况、总资产、在读在看、绘画进度、最近记录、今年的数字、问候语。日历、AI 简报等以后再加。
- 打开 App 先显示首页。**要有**：今天和过期的待办、求职近况（近期笔试面试、该跟进的投递）、总资产、在读的书和在看的剧、绘画课进度、最近添加和完成的记录、今年读了几本看了几部、日历、本地 AI 写的今日简报、问候语。
- **不要**：7 天内到期、本月花费和预算、出行打包、天气。
- 图表直接放在首页；年底生成年度回顾。布局由我来设计。

## 通用清单与通用进度（v0.2）

- **通用清单**：自己建游戏、播客、展览这类清单；能自己加字段（文字、数字、日期、单选……），像 Notion 那样。
- **通用进度**：自己建课程、教程这类进度，和随意画画一样是「课程 → 课节」两层，叫法能改（比如「书 → 章节」）。
- **分工**：通用进度管有固定章节的东西；待办里的目标管要达成的事。

- 不做：封面、自动填信息、读书进度、标签、长篇读后感、绘画作品图和学习时长、出行归档对比、导出 CSV。

## 本地 AI（v1.0 前，先 Chat 后 Agent）

- **模型**：llama.cpp 在这台 Mac 上运行（`~/Documents/LLM`），同一时间只跑一个，接口是 `http://127.0.0.1:8080/v1`。现有 Qwen3 14B、Ministral 3 14B、Qwen3-VL 8B（能看图）。
- **Pomelo 只切换接口**：本地接口、云端接口 1、云端接口 2……云端默认关闭。用哪个本地模型，我自己用 `llmctl.sh` 切换；模型没运行时，提示我去启动。
- **侧边栏**一直在右侧，可以收起；知道当前是哪一页，能选中一条记录直接问。编辑面板里能一键润色、补全；新建时一句话填好各项。
- **Chat**：日常问答、学习、模拟面试、问我自己的数据。多个对话（改名、置顶）、预设角色、发文件、发图片、重新生成和修改、导出 Markdown；记录全部保存，能搜索、能手动清理；有能查看、修改的长期记忆。
- **Agent**：一句话记录和查询、贴 JD 建投递、模拟面试、账单建议、推荐书影、批量整理、每周总结、调用 Pub2MD 翻译；也能起草周报、整理待办、写求职信。改数据前每次都要我确认，并显示每一步。能读指定的文件夹（比如 Seeker）、联网搜索、调用 Pub2MD；支持定时任务。
- **知识库**：能引用 Pomelo 的全部记录和指定文件夹的文档；支持模糊搜索。到时候再加一个做「向量」的小模型。

## Pub2MD 接入（v1.0 前）

- 每月用几次。由 Pomelo 负责启动和关闭它，在 Pomelo 窗口里使用：上传文件、看进度、拿结果。
- 翻译结果留在 Pub2MD 自己的文件夹，API Key 它自己管，不改用本地模型。
