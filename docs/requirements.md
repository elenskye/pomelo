# 需求

> 已定的需求，写现状。来源：问卷、优化清单（原件在 `archive/`）和对话里的决定。进度见[开发路线](roadmap.md)，表和计算规则见[数据结构](schema.md)，做法见[技术架构](architecture.md)，样子见[视觉规范](design.md)。

## 总体

- **定位**：第二大脑，个人事务都在这里管。App 一直开着，想到就记，每周整理一次，每天 5～15 分钟。
- **最想解决**：事情会忘、截止日期错过；想回顾时找不到记录；录入太麻烦。
- **风格**：适度自动（填日期、提醒、汇总），不替我做决定。
- **只在这台 Mac 上用**，手机不用。提醒只在 App 里，不弹系统通知。关窗口不退出（菜单栏留小拾的小鸟），⌘Q 才退出；登录 Mac 时自动在菜单栏启动、不弹窗口（「设置 → 启动」能关）。
- **界面不放使用提示**，要解释的只在设置页的 (?) 里（细则见视觉规范）。
- **删除**确认后直接删，没有废纸篓。**撤销**：⌘Z / ⌘⇧Z 撤销、重做最近 100 步；关掉 App、导入、恢复备份后不能撤销。
- **联网**：默认离线。只有小拾的云端模型（填了 Key、主动选了才用）、插件库（书单 / 影单检索、联网搜索）、「添加网页」、呦呦漫游的发布（推到 GitHub、读 Vercel 的上线结果）和 Pub2MD（Mathpix、选中的云端模型）联网；汇率、天气不联网。
- **导航**：见下面的「界面外框」。打开 App 先到首页。隐藏的模块：导航、全局搜索、首页、小拾里都没有它，数据还在。
- **全局搜索**（⌘K 或顶栏的搜索框）：搜所有模块和小拾的对话，隐藏的模块和芝麻开门除外。几个词空格隔开、都要出现，不分大小写；按模块分组，每类最多 6 条，名字开头对上的在前，其余新的在前；↑↓ 选、↩ 打开那条记录。下面一组「意思相近」（见「小拾 · 搜索和出处」）。
- **v1.0 的标准**：功能齐了，视觉也打磨好（v1.0 前统一做）。
- **不做**：日记、习惯打卡模块、心愿单、物品管理、人情往来、健康记录、整个 App 的锁、全局标签、今日三件事、今日时间线、月度复盘、计时、快捷指令接入、浏览器剪藏、桌面小组件、豆瓣导入、拍照识别。

## 界面外框（v0.7 阶段 ①，照原型 r4）

- **整体**：「手账本 · 页签」：一条横贯窗口的顶栏，下面内容是一页手账纸，右边伸出索引签。各模块自己的布局不变（呦呦漫游的页签、小拾的对话列表、Seeker 的分段都照旧）。不做「摊开两页」（挤）。
- **顶栏**：左起红黄绿、柚子、‹ ›、页签；右边日期（窗口窄时不显示）、搜索（⌘K）、设置、小拾小窗（⌘J；在小拾页和小拾隐藏时点不了）。图标、页签和红黄绿在同一条中线上。⌘K 的搜索照旧只搜记录，和柚子瓣中间的输入框分开。
- **页签**：像 Safari：点导航（索引签、模块坞、柚子瓣、全局搜索的结果）在当前页签里换页；已在别的页签开着的模块直接切过去；页面里的链接就在当前页签里走。「＋」开新页签，先显示模块坞，点哪个模块这页就变成哪个；页签自己关（关掉最后一个回到首页）。切页签时那一页重新打开（滚动位置、开着的面板不留）。⌘Q 退出后再打开，上次的页签都在（各自停在当时的那一页，不记前进后退），先显示首页页签（没有就在最前面加一个）。
- **前进后退**：每个页签自己记走过的页（最近 50 步）：进一个模块、换一个子页都算一步（呦呦漫游、Seeker、Translator、Pub2MD、钱来钱往、投石问路的子页），打开一条记录不算。‹ › 按钮、鼠标侧键、⌘[ ⌘]、⌘← ⌘→（在输入框里不算）都能用；右键 ‹ › 列出走过的页，点了跳过去。
- **索引签**（纸的右边）：首页、模块坞，下面是置顶的模块（模块色，拖动换顺序，把模块拖进来就置顶，右键是它的菜单）。窗口窄时只露彩色图标，鼠标移上去出名字。
- **模块坞**：所有模块都在这里（自带的、五花八门和循序渐进建的、小拾的助手），最上面「置顶」一排，下面按分类分组，每个模块写着一句实时小字（见下），窗口窄时图标变小。点模块就进去。
  - 自己建分类、点名字改名、删空的分类；拖动换分类和顺序，拖进「置顶」或索引签就置顶，拖进「已隐藏」就隐藏；每个模块的「⋯」或右键：置顶、隐藏、移到别的分类；分类里的「＋」建五花八门或循序渐进，建好就在这个分类里（以后能挪）。
  - 一开始照原型 r4 分：日常（一步一步、念念不忘、来日方长）、生活（钱来钱往、出门走走）、兴趣（摸鱼读读、好奇看看、随意画画，以前建的模块也在这里）、求职（投石问路、Seeker）、创作（呦呦漫游）、小拾（小拾、Translator、Pub2MD）、工具（芝麻开门）；置顶一步一步、念念不忘、投石问路、Seeker、小拾。
  - 隐藏的收在最下面「已隐藏」，不再在设置里管。分类、置顶、隐藏都记住，不进撤销。
  - 实时小字：一步一步「今天 N 件」（今天要做的和过期的）；念念不忘「今天 N 条」，今天没写就「共 N 条」；来日方长最近的日子「妈妈生日 5 天」；钱来钱往「本月 N 笔」；出门走走下一次出行「东京 11 / 08」；书影「在读 / 在看 N」，没有就「想读 / 想看 N」；随意画画「完成 / 全部 节」；投石问路「该跟进 N」，没有就「进行中 N」或「共 N 个」；芝麻开门「已锁上 / 已打开」；小拾「N 个对话」，在写时「正在写…」；Translator 目标语言；Pub2MD「N 份在做」；Seeker「有草稿」；五花八门「N 条」、循序渐进「完成 / 全部」。没什么可说的就空着；呦呦漫游不写（要跑 git）。
- **柚子瓣**：点顶栏的柚子，模块坞像剥开的柚子一样从柚子那里展开：每一瓣是一个分类，模块排在瓣上；中间输入框打字筛选、回车进第一个，什么都对不上就回车问小拾（在小窗里开一个新对话问）。瓣上也能拖动换分类、点瓣名改名、加分类、看已隐藏；和模块坞是同一份分类、置顶、隐藏。只在打开时展开一次，在里面调整分类、拖动、改名时原地更新、保持打开。点空白处或 Esc 收起。
- **柚子**：照我画的四个表情做图标（平常、在想、开心、出错），再加眨眼、哇、困了、担心四个；带轻微的动画（呼吸；眨眼、叶子摆、光点浮起；弹跳、闪光；摇头、红色「!」），系统开了「减少动态效果」就不动。什么时候换：
  - 鼠标移上去眨眼或「哇」。
  - 平时按当天的心情：今日简报写好时顺带给一个（轻松 → 平常、很忙 → 在想、有好消息 → 开心、有烦心事 → 担心），没有简报按时刻随机（早上平常 / 哇 / 眨眼，下午平常 / 在想，傍晚平常 / 眨眼），深夜（23 点到 6 点）困了。
  - 报状态（优先于心情）：小拾在写（对话、小窗、定时任务）→ 在想；写好 → 开心一会儿，不在小拾页时冒一句「小拾写好了」；出错 → 出错，冒一句话，点柚子清掉。出错包括：每天的自动备份没成功、呦呦漫游的发布没成功或网站没上线、Pub2MD 有一份没做完（开始以后离开那一页也会报）。
- **小拾的助手当模块**：Translator、Pub2MD、Seeker（以后还有 Rater）只在形式上是独立模块，名字照旧：在模块坞、索引签、柚子瓣里和别的模块一样（能分类、置顶、隐藏，名字旁一只小鸟），打开是整页工作台（标题旁一只小鸟，子页在路径里）。数据和代码还在小拾，不改数据结构；小拾左栏的「助手」组照旧，点了打开对应的模块；隐藏小拾时它们一起隐藏。

## 附件（笔记、任务、目标）

- 图片显示小图，点开看大图；PDF 和其他文件显示文件名，点了用默认程序打开。不做录音。
- 加附件时复制一份进数据文件夹（同样的内容只存一份），原文件删了也不影响。附件不进每日备份（交给 Time Machine 这类工具），导出的数据文件里只有名字；「设置 → 数据 → 附件」看占多少、清理没用到的。小拾的附件和资料另存一份（「设置 → 小拾 → 空间」），两边不共用。

## 待办「一步一步」（参考目标地图 GoalMap）

- 完全替代原来的 Markdown 待办。**结构**：分组（一层，可带 emoji）→ 目标 → 任务 → 多级子任务；零散的任务直接放在分组里。不要标签、优先级、情境。
- **目标**：开始和结束时间；状态（进行中、暂停、已完成）；进度按完成的任务自动算；完成后写复盘。不要的目标直接删。
- **子任务**多层、能折叠；全部完成时上一层自动勾上。
- **时间**：不设，或一个时间段（开始可不填）。时间段内每天都出现在「今天」；过期的标红，留在原来的日期。没有「计划哪天做」。
- **完成后**收进「已完成」，记下完成时间；分组页里已完成的目标和任务一起收在「已完成 N」里。
- **视图**：今天（默认）、按分组 / 目标、月历、回看（周 / 月 / 年 / 全部：柱状图、按分组排行、合计和日均，下面是清单）。拖动排序。
- **任务栏**只有标题和紧跟的截止日期（2026 / 10 / 03），有子任务的最右边「1/3 ⌄」；不标分组，目标前没有图标。
- **每条记**：标题、内容（多行，能加粗）、链接（网址或本机文件）。分组和目标页右上角「新任务」（⌘N），今天页底部快速添加。
- **四种任务**（后三种不能有子任务）：
  - **普通**：做完勾掉。
  - **重复**：按规则推算每次是哪天，勾掉跳到下一次，能「跳过这次」。规则：每天、每周几天、每月几号（可多选）、每年某月某日（可隔几年）、每隔几天或几周，都能填一共几次（可不限）和已经做了几次；或者完成后再过几天 / 周 / 月 / 年（从做完那天重新算）。
  - **打卡**：每天或每周固定几天，时间不设或一个时间段。该打卡的日子出现在今天；面板里有月历，能补打，显示连续天数。时间段里该打的都打了、或时间段结束，自动算完成。
  - **进度条**：目标数量和单位（「今年读 20 本」），可设时间段。点圆圈 +1，面板里能记任意数量；达到目标自动完成。
- **来自笔记**：念念不忘转来的任务，面板里「来自笔记」点了回到那条笔记。
- 不要：备忘、每周回顾、和求职联动。以后：出门走走出发前提醒打包。

## 书影「摸鱼读读」「好奇看看」· 画画 · 出行

- **书影**：名称、作者 / 导演、国家、类型（可自己改）、状态、尝尝咸淡（1～5 星）、完成时间（只记年）、备注。**重读、重看**：标成已读 / 已看后，面板里能一次次加「重读」/「重看」（哪一年 + 几颗星）；表格的完成时间和排序按最近一次。
- **随意画画**：课程 → 课节（编号、类型、课名、状态未开始 / 进行中 / 已完成、完成时间到年月、备注）。新课节默认未开始。
- **出门走走**：场景模板 + 每次出行。新出行的清单从模板、以前的某次出行（物品都变回没装）或空白开始。
- 课程、课节、模板、物品都能拖动排序，筛选时也能拖。
- 不做：封面、自动填信息（只有手动点的小拾「补全」）、读书进度、标签、长篇读后感、绘画作品图和学习时长、出行归档对比、导出 CSV。

## 记账「钱来钱往」

- **最重要**：看总资产怎么变；管好订阅和固定支出。也要：钱花在哪、每月按分类的预算、投资。每周或每月集中整理一次。
- **三页**：收支（明细 + 固定支出）· 资产（账户、余额、汇率、持仓、总资产曲线）· 报表（月 / 年：分类占比、每月趋势、预算；「资产」：账户和持仓的曲线）。
- **币种**：人民币、新加坡元、港币、美元，分开记、不换算，报表也按币种分开；只有总资产按汇率折成人民币。
- **一笔记录**：支出 / 收入、金额、币种、日期、分类（一层，可自己改）、备注。不挂账户。
- **记多细**：300 元以上（其他币种约等值）单独记；小额用「记小额」：选一个时间段（默认接着上一段到今天），一次填完各分类花了多少；明细里写「9/28 – 10/4」，跨月的两个月都列；月合计、报表、预算按天平摊。
- **明细**：表格里点分类就能换，分类筛选里能管理分类。多选（「多选」按钮、⌘ 点、⇧ 点）后能批量改分类（同是支出或收入时）、改币种（数字不变）、删除。
- **固定支出**（房租、话费、订阅，也可以是固定收入）：每月几号或每年哪天，到日子自动记一笔，漏掉的补上；能停用。
- **账户**：一个账户一种币，分银行、钱包、券商；能停用。不记转账和换汇。
- **更新余额**：选一天（默认今天），填各账户余额和汇率（先带出上次的数），总资产按每次更新的日子算。**持仓**（券商账户）：选一天，填名称、数量、单价，市值自动算。
- **报表 · 资产**：账户、持仓各一张曲线，只列报表顶上那个币种的；横轴只有更新过的日子；上面的小标签选显示哪些（会记住）。
- **预算**：按「支出分类 + 币种」设每月金额；快到变黄，超出变红并写超出多少。
- 不记：贵重物品、负债、借出和 AA、信用卡；不和出门走走关联；不额外加密。

## 求职「投石问路」

- 预计毕业前集中投：全职、中国大陆，一个求职季 200 个以上。简历在 Seeker、题库和面试在 Rater（见小拾的「Seeker」「Rater」），投石问路只管投递和进度；岗位面板里能「做简历」、选公司资料、在「Seeker」一栏选这次用 `cv/` 里的哪份简历（没有单独的「简历」一栏了），「面试」一栏的「准备面试」「复盘」两个按钮打开 Rater。
- **两页**：投递（表格；顶上「该跟进」；按状态筛选、搜索）· 统计（几个数字、每天 / 每周投了几份、漏斗、现在的状态分布）。
- **一条记录**：公司、岗位、地点、渠道（可自己改）、状态、JD 链接、简历（Seeker 里的文件，能选、能点开）、备注。
- **状态**：默认想投、已投递、网申测评 / 笔试、面试、Offer、已接受、被拒；名字、顺序、增删都在「管理状态」里改。默认状态各有作用：想投 = 一个没勾，已投递满 14 天提醒跟进，Offer 和已接受算拿到，被拒算结束；新加的都算中间一步。时间线上有它的状态不能删。
- **时间线**（每条投递自己的）：先点选它有哪些状态（新建默认除了想投、被拒都选上，被拒时再选进来），选中的按顺序排成时间线，勾上自动填今天（能改）。现在的状态 = 最后一个勾上的；投递日期 = 最早勾上的那天。
- **漏斗**：已投递 → … → Offer，每一步写「勾上的 / 有这一步的」；没有这一步的、还没投的不算。
- **跟进**：在等回音的，离那一步满 14 天提醒；点「已跟进」后再过 14 天才又提醒。

## 笔记「念念不忘」（参考 Flomo）

- **定位**：想到就记的收集箱，替代 Flomo（179 条和图片已导入）。一条笔记只有正文和记录时间。
- **标签**写在正文里：`#标签`、多级 `#一级/二级`，只在笔记里用。
- **正文格式**：**加粗**、==高亮==、++下划线++、列表（`- ` / `1. `，Tab 缩进），网址能点。⌘B / ⌘U / ⌘⇧H 加格式，⌘↩ 记下；输入 `#` 时提示已有标签；列表里回车接着编号。输入框边写边显示成卡片的样子（标记符号还在，变淡）。
- **页面**：左栏是笔记数、标签数、记了几天，最近 16 周的热力图（点某天只看那天），「全部笔记」、置顶的标签、标签树（能折叠，按拼音排）。右边上面输入框，下面卡片（新的在上，置顶的最上）。搜索正文（几个词同时出现，也按意思找）；标签、日期、搜索能叠加。在某个标签下新建自动带上这个标签。
- **每条笔记**：双击或「编辑」就地改；「引用」（两边都显示链接）；「置顶」；「删除」。太长的折起来，「展开全文」。
- **标签的「⋯」**：置顶（只有第一级；置顶的能展开子标签，标签树里不再重复）；图标（48 个线条图标或一个 emoji，任何一级都能设，点标签前的图标也能换）；改名（所有笔记里一起改，下一级、置顶、图标跟着走；改成已有的就是合并）。
- **转成待办**：卡片「⋯」里「转成待办」，右边滑出一步一步的新任务面板（标题是第一行去掉符号和标签，内容是全文，分组默认第一个），改好再保存；笔记留着，两边互相链接（笔记下面列出转成的待办，做完的划掉；任务面板里「来自笔记」）。一条笔记能转好几条。
- **让小拾拆成待办**：一条笔记写了几件事时，像「拆成子任务」那样先列出来（转过的不再列，默认都勾上），选「加到」哪个分组或进行中的目标，点「加上」才加，一步 ⌘Z。
- 删笔记时待办留着，只是不再链接；导出导入时链接跟着。年度总结由小拾写（见「小拾 · 定时任务、今日简报、年度总结」）。

## 重要日期「来日方长」（参考 Days Matter）

- **三种**：纪念日和倒数日（不重复、每年、每月、每周）；生日（每年；出生年份可不填，填了显示几岁；「礼物点子」和「送过的」，每行年份和礼物，新的在上）；证件（只记名称和到期日，不记号码和照片）。不要农历。
- **怎么算**：每条显示「还有 N 天」或「已经 N 天」，重复的数到下一次（当天写「今天」），每年的纪念日写「第 N 周年」，过期证件写「已过期 N 天」。2 月 29 日在平年算 2 月 28 日；每月 31 号在小月算月底。
- **页面**：上面「全部 · 纪念日 · 生日 · 证件」（带个数）和「新日子」；置顶的一条（最多一条）是大卡片；下面一张列表。顺序：过期的证件、按还有几天、已经过去的放最后。在哪个分类下新建就是哪一种。
- **提醒**：每条自己选提前几天（当天、1、3、7、14、30、60、90 天前，最多 5 个；新建时纪念日和生日默认 7 天前，证件 30 天和 7 天前）。首页「快到的日子」从最早的提醒那天显示到当天，过期的证件一直显示到改了为止；今日简报只在提醒的那几天和当天提。不自动生成待办。
- **小拾**能查快到的和全部日子；证件只读名称和到期日，备注不读、不进按意思搜索。不能写。

## 五花八门 · 循序渐进（做模块的模板）

- **是模板，不是模块**：模块坞分类里的「＋」选「五花八门（清单）」或「循序渐进（进度）」，填名称（不能和已有的重名）、选一个图标（24 个），建出来的每一个（比如「游戏」「日语」）都是一个模块：能分类、置顶、隐藏，颜色按模板固定。标题右边「⋯」：改名和图标（循序渐进还能改叫法）、管理字段（五花八门）、删除（里面的东西一起删，能 ⌘Z）。
- **五花八门**（通用清单）：每条有「名称」，再加最多 20 个字段：文字、长文字、数字、年份（只记年）、单选、多选、勾选、评分（1～5）、链接（建好后不能换类型）。
  - 表格 + 右侧面板：表格里是名称和选了「表格里显示」的字段；点表头排序（第三下恢复）；搜索（名称和文字）；能筛选的字段各一个下拉框（单选多选的选项、勾选的是 / 否、评分几星以上），几个一起筛；没排序、没筛选时拖动换顺序。

  - **类型**：每个模块自己一组（一开始没有，标题右边「⋯ → 管理类型…」里加、改名、排序、删除；删掉的类型那些节变「未分类」），像单选一样按顺序配色，表格里点一下就换，能按类型筛选。

- **小拾、搜索、导出**：每个都像一个模块：隐藏了小拾不读、全局搜索不搜；「发给云端」各有一个标签（默认能发）。小拾能查清单和条目、进度和每一节，不能改。全局搜索能搜到条目、课程和课节。导出的数据文件里都有；导入时整个替换它们（在导航里的位置、隐藏、云端设置不跟着）。
- 摸鱼读读、好奇看看、随意画画还是专门的模块。

### 知识库

- **放什么**：选定的文件夹（原地读，不复制；文件变了自动更新）和保存的网页（存一份正文）。文件夹里小拾能读的都读（格式同附件，含子文件夹，大表格读全部行；图片列出来但不建索引，按意思找不到，用云端模型时小拾能看）；隐藏的、Office 临时文件（~$ 开头）、替身、应用程序包、node_modules 跳过；每个文件夹最多 2000 个文件，每个文件 200 MB 以内。不能放 Pomelo 自己的数据文件夹；同一个库里的文件夹不能一个套一个。
- **库**：分成几个库（名字最多 30 字、不重名），能新建、改名、删除、拖动；删库、移除文件夹或网页都不碰原来的文件。都能 ⌘Z。
- **管理**：左栏最下面的「知识库」（输入框「知识库」菜单里也有）：左边是库，右边是这个库的文件夹和网页，每行写着几个文件、几张图片、几个扫描件（没有文字的 PDF，和图片一样只认文件名）、正在建立（几 / 几）、几个待更新、几个读不了（点开看原因），找不到文件夹时标红；「发给云端」开关和「⋯」（在访达中打开 / 打开网页、重新建立索引、移除）。
- **查哪些库**：对话选的；没选就跟着项目（「项目设置」里选）；项目也没选就是全部。
- **「知识库」按钮**（输入框，小窗里也有）：按下后这个对话每个问题都查（每个对话记住；新对话默认不按，在选了库的项目里新开的默认按下）。旁边小箭头是菜单：查哪些库、用云端模型时不查的文件夹、「管理知识库…」（开关就是按钮本身，菜单里不重复）。没按时小拾也能自己用「查知识库」技能。
- **看文件、整篇读**：「查知识库」技能也能列出库里有哪些文件（路径、类型、大小、修改日期，能按路径里的字筛），整篇读某个文件（看目录、按段读、按字找，从原来的文件夹现读），读到的段落标出处，点了「打开文件」。这样能回答「这个文件夹里有什么」「总结某份文档」。
- **看图片**：用云端模型时，小拾能看库里的图片（一次一张，一个回答最多 8 张，发之前同附件一样缩小），看的图片也算出处；本地模型看不了，会这样说。Word、PowerPoint、PDF 里嵌的图片看不了。不改文件夹里的文件（要改用 Word / 文本工具箱）。
- **怎么查**：和项目资料一样按意思找、重排，至多 6 段，和项目资料的段落一起编号；出处写「知识库 · 库名：文件名 · 第 3 页」，点了看原文那一段和「打开文件」（网页是「打开网页」）。查之前先把变了的文件算好（「正在更新并检索知识库…」）。
- **什么时候更新**：不监听文件夹；打开小拾页、打开知识库对话框、每 10 分钟比一遍大小和修改时间，只重算变了的（没变的段落沿用原来的）。向量服务本来开着就马上算，没开着就等下次用知识库提问时先算完；添加和「重新建立索引」会启动向量服务。后台正在建立时提问，先用已经建好的。
- **云端**：每个文件夹（和网页）自己设能不能发给云端（默认能）；用云端模型时不能发的不查，菜单里写明。
- 知识库不进导出的数据文件。

### Pub2MD（助手）

- **是什么**：把 PDF、Word、图片经 Mathpix 转成 Markdown，再整理、翻译，每月用几次（原来的 Python 小项目已删，用 Rust 重做）。
- **能做的事**：只提取（不经过模型）；提取 + 整理；提取 + 整理 + 翻译；只翻译（MD、MMD、TXT）。PDF、Word、图片（几张合成一份，多页 TIFF 每页一页）、文本都能放；选好或拖进来的先列在「待发送」，点「发送」才开始；一次一份，后面的排队；停下或出错的在「最近」里「继续」或「删除」（它的文件夹移到废纸篓）。
- **语言和要求**：英文 → 简体中文；简繁互转（先用 OpenCC，再让模型换成读者那边的用词：繁转简用大陆用词和“”，简转繁用台湾用词和「」，书名、品牌只转字形）。文体（通用、学术、文学、新闻）、领域（公共管理、数学、计算机，能多选），再加自己写的一段。一份文件里有几篇文章的各自输出；双语内容能选只留英文或都留。
- **两个模型**：Worker 做每块的整理和翻译；Supervisor 审定切块、定术语表（只在英文 → 简体中文时）、排查出错、通读，开「精修」时逐块审校。各选模型和思考（Supervisor 默认高、Worker 默认关；术语表最多「低」），再选一个云端备用模型（默认 DeepSeek Flash，能选「不用」），都记住。Supervisor 的规则写在程序里，提示词页能看到实际发给两个模型的说明。
- **流程**（程序排好，模型只管内容；页面显示「翻译 · 第 3 / 12 块」）：Mathpix 提取（PDF 同时画原页图）→ 程序按章节和页切块草案（2～4 页一块，不拆表格、公式、图，论文不跨各部分），Supervisor 审定 → 每块整理（云端 Worker 带这几页的原页图：改 OCR 错误、去页眉页脚、接上跨页的句子、补公式编号，只整理这一块）→ 每块翻译（带术语表和前一块的结尾；参考文献、附录、致谢、作者和单位默认不翻，原样放在原位置）→ Supervisor 通读，只改跨块的问题（术语不一致、编号、断开的句子、漏译的英文词），程序照改。几块同时做（默认 4）。模型常出的小毛病（丢了的 `\$` `\%`、编出来的链接和图片、零宽字符、混进的繁体字）程序顺手修掉。
- **检查和出错**：程序只比文字：截断、长短、公式表格图片脚注标题的个数、段落对不对得上（漏了，或照原页图抄了别的块）、语言比例、给模型的说明混进了结果。不合格的交 Supervisor 选：带提示重做、拆开重做、开思考、换模型、接受或停下（每块最多 2 次，一份最多 6 次或每三块一次）。网络出错、限流等 15 秒、45 秒再试，还不行用备用模型，再不行停下（做完的留着，能「继续」）。被阿里云内容审核拦下的那一次直接改用备用模型。长段里只漏一句查不出来，要靠精修。
- **精修**：开关，默认关；Supervisor 逐块对照审校、程序照改；长论文的费用约翻倍，交稿时开。
- **联网查术语**（只在英文 → 简体中文时）：Supervisor 查，有自带搜索的服务用自带的（DeepSeek、Aliyun、OpenAI、Anthropic、Google），其他和本地模型用 Tavily；有自带搜索时默认开。
- **输出**：默认存到「下载」（记住上次的），每份一个子文件夹：原文.mmd 和 assets/、Mathpix 原始结果.zip（同样的文件再放进来直接用它，不再上传）、整理稿、译文、术语表、工作日志.md。另存为 Word（默认）、PDF、LaTeX、HTML：最后一步交给 Mathpix 转，所以整理稿和译文也会上传；图片链接 30 天内有效，转不成不算出错。处理中的放在隐藏文件夹，做完删掉，出错时留着用来继续。
- **页面**：「Pub2MD · 提示词」两页：设置、进度、停止和继续、打开结果；MMD / MD 结果在页面里预览（Mathpix 的显示库，能切译文、整理稿、原文、术语表、工作日志）；最下面是功能简述和测出来的模型搭配。只记住设置和最近 10 次；离开页面也接着做。
- **Key 和云端**：Mathpix 的 App ID、App Key 在钥匙串，没填不能选文件。不另设「发给云端」：点了「发送」就是同意上传给 Mathpix 和选中的模型。
- **速度目标**（提取 + 整理 + 翻译，不开精修）：11 页的论文 20 次请求、20 分钟以内；几页的文档 5 分钟以内；50 页、3 万词以上的长论文 40 分钟以内。

- **中文 / English**：子页那一排右边切换，简历、素材、规则、历史和 Word 模板跟着切，两种语言互不影响、不互译；档案、网申两边共用。记住上次选的；投石问路的「做简历」用当前语言。
- **排序和多选**：素材、档案、规则、网申的卡片在自己那一组里拖动排序（整张卡片拖）；工具栏「选择」后点卡片就选上（底色变了；按住 Shift 连选、⌘A 全选、Esc 退出），一起启用、停用或删除，都是一步 ⌘Z。v0.7 的页面不用勾选框：选几样是点了换底色的按钮，开关是左右拨的开关（和 Pub2MD 一样）。
- **七个子页**：简历（左选材、中间正文、右「岗位与建议」）、素材（基本信息，再按类别分组的折叠卡片：名称、角色、时间、地点、概览、技术栈、要点）、档案（经历档案挂到中文和英文素材上；已确认事实「事项：口径」）、规则（按用途：共用准则、写作规则、素材润色、整体审查；每条规则是「标题 + 分点」，每点一句，能拖动排序；规则和个人范例有语言：中文、English 或中英共用；没有「个人约定」）、网申（能复制的卡片，下面是 `material/` 的证书原件）、历史（Word 导出的清单，下面「简历版本 · 资料修订」）、设置（文件夹、知识库、允许发给云端）。
- **不留简历副本**：Seeker 不存整份简历的副本。没有「确认版本」；Word 导出只记文件名、位置、语言、时间和用了哪些素材（准备面试按它找简历题和经历档案），历史页的「Word 导出」是一张清单，点了打开那个 Word（只列 `cv/` 里还在的）。看一份简历的正文、和上一版比，都在「简历版本」里读 `cv/` 的文件。
- **分组**：素材、规则的每一组标题右边「⋯」：重命名（程序自带的组只改显示的名字，程序照样认它：教育照样按教育排版、规则照样发给原来的功能；自己建的组改名就是把里面的条目移过去）、删除这一组（删掉里面的全部条目，一步撤销，程序自带的组留着空组）。
- **规则去向**：规则页每组标题下淡墨写「发给：…」（这一组发给哪些功能，Seeker 和 Rater 的都算）。工具栏「发给模型的说明」：左边每个功能，右边它读哪几组规则和这次会发给模型的完整说明（程序自带的 + 我的规则，和真正调用时同一套代码拼；JD、简历这些资料调用时才附上）。Seeker：按 JD 推荐素材、审查整份简历、按 JD 改写 Summary（英文）读共用准则、所有任务、选材和审查、个人范例；润色要点、润色一条素材读共用准则、所有任务、素材润色、个人范例。Rater：补题读共用准则、题库维护和那一类的工作流；润色答案读那道题那一类的；卡片练习和面试读共用准则、题库维护、面试。
- **长列表用弹窗选**：会越来越长的选择（岗位、题目、素材、公司资料）不用下拉框，点了打开一个小弹窗：上面搜索框，下面分组的列表，点一行就选上（回车选第一条）。用在：简历右栏的岗位、导出时关联的岗位、补题和题目编辑里的岗位 / 素材 / 改自、按 JD 挑卡的岗位和「加一道」、面试页的岗位、档案挂的素材、岗位面板的公司资料。
- **草稿**：每种语言一份，自动保存；新建只带基本信息和教育（英文还带第一条 Summary）。页首字段能自定义、显隐、排序；章节、经历、要点能拖动，拖框或点选（再点取消，⌘ / Shift 加选）一起删，一步撤销；改简历不回写素材。要点边写边显示，和 Word 一个读法（`**` 之间加粗）。「增加」只追加没有的素材，「重新组装」从头来（保留 JD 和岗位）；技术栈在草稿的目标 JD 像开发类岗位时默认勾上（选材也按 JD 决定要不要）；素材有新版只在「来源差异」里提示。
- **岗位**：投石问路岗位面板「Seeker」一栏的「做简历」或右栏「岗位」：备注（JD）填进目标 JD，一步撤销；导出默认关联这个岗位。岗位能关联 `cv/` 里的任何一份简历（Pomelo 导出的、模板也算）：「选择简历…」弹窗按中文 / English、按文件名找，同一份简历的各版一组，对上这家公司的排前面，用过的标「用过」；面板里只显示「本次使用」的那一份（点名字打开，旁边在访达中显示），一步撤销。关联过的记录都留着。文件从 `cv/` 删了就不显示（记录留着，放回来又出现）。
- **右栏「岗位与建议」**：岗位、目标 JD；选材模型和「按 JD 推荐素材」；审查与润色模型、本次要求和几个按钮；最下面「思考」（选材和审查都用）。都是上面小字标题、下面占满一栏的输入。
- **模型**：选材、审查润色各自选模型；整份审查只给建议；只润色一轮，不自动反复改。发给模型的：这项工作用途的规则（共用准则、写作规则、这项工作的组，排成 `# 组`、`## 标题`、`1. 分点`）、个人范例、已确认事实、这次经历的经历档案，岗位有公司资料时加至多 6 段。云端只在设置里允许了才发。
- **Word**：模板固定、内置在 Pomelo 里，不在设置里选：英文照 `cv/en/seek-it-keyreply-resume-v5.docx` 的样式和格式；中文是整理过的 `cv/cn/seek-it-cn-template-v1.docx`（`cv/cn/seek-it-cn-template-v2.docx` 是用内置模板导出的完整样例，编的林小柚；A4、等线、经历抬头一行三栏「公司或项目 ⇥ 职位或角色 ⇥ 时间」（字号一样，时间灰字靠右，地点不写）、章节标题下一条深蓝细线）。内置模板只留格式，文字是占位的，不含个人资料。默认存进 `cv/cn/`、`cv/en/`，只新建不覆盖；页数在 Word 里看。
- **英文**：「Resume / CV」（Resume 一页、CV 两页，只提醒超过 2 个项目、每段超过 3 条）；章节顺序 Summary、Skills、Education、Projects、Experience、Certifications；Summary 是一条素材，选材里单选，右栏「按 JD 改写 Summary」看差异确认。英文正文保持英文，说明和建议用中文。
- **公司资料（`knowledge/`）**：设置里「加进知识库」（知识库「Seeker」，原地只读）。每个子文件夹是一家公司，名字取自招聘索引.md 和文件夹名；设置里「名称…」能给每个文件夹起名字（空着就用找到的），起了名字的显示它、按它对上岗位；岗位的公司名对上了，岗位面板「公司资料」显示出来（能改成别的或「不用」）。选材、审查、突击题、准备面试按 JD 查这家公司的资料，告诉模型这是招聘方的情况。
- **简历版本（`cv/` 里的简历）**：历史页认出 `cv/cn/`、`cv/en/` 里的 Word 和 PDF，同一份简历的各版归一组（名字去掉末尾的 `-v3` 或日期），标出模板（名字里有 template / 模板的那组里最新的一版）、Pomelo 导出，按名字对上投石问路的公司（`keyreply` ↔ KeyReply）；能打开、在访达中显示、看正文、和上一版比较。历史页的「Word 导出」也只列 `cv/` 里还在的。设置里能把 `cv/` 也加进知识库「Seeker」。
- **`material/` 证书原件**：网申页最下面按子文件夹列出文件名，点了用默认程序打开，也能在访达中显示。Pomelo 不读它们的内容，也不发给模型；小拾只知道文件名。
- **小拾读 Seeker**：插件库只读技能 seeker-toolkit（默认开）：素材和基本信息、草稿、导出的 Word（还在的）和岗位、Rater 的题库和练习记录、最近几轮卡片练习、面试准备和复盘、`cv/` 的简历列表和某一份的正文、`material/` 的文件名。停用的素材、规则、档案、网申不读；云端跟 Seeker 的「允许发给云端」走；Seeker 或 Rater 在模块坞里隐藏了就不读它。全局搜索不搜 Seeker 和 Rater。

### Rater（v0.7）

- **是什么**：小拾的助手（名字我定的），当模块用（分组「求职」），只做中文。页签：题库 · 卡片 · 面试 · 规则；「Rater 的模型」和「思考」在页签那一排右边（规则页不显示），补题、润色、挑卡、追问、点评、准备、复盘都用它（不跟对话的模型，不进撤销）。用云端要 Seeker 允许发给云端。
- **规则页**：Rater 的规则是 Seeker 资料里用途「题库维护」「面试」的规则，和 Seeker 的规则页一样编辑（标题 + 分点），没有语言选项；三个题库 SKILL 各一组工作流，还没写自己的时显示程序自带的（虚线卡片，「改成我的」）。
- **题库**：三类：简历题（照着简历问，挂一段中文素材）、通用题、突击题（挂一个岗位，可「改自」别的题）。一道题记问题、答案（我的口述稿）、标签，不编号、不分档；先看差异再确认保存、留历史，删除和保存都能 ⌘Z。秒数按 90 秒 400 字算（汉字一字，英文单词或数字两字），超过 90 秒标柚红。每道题的练习记录（会几次、不熟几次、最近一次）从卡片练习算出来，打开题目时显示。答案的骨架：一句话结论 → 我做了什么 → 结果（数字和范围）→ 局限或如果重来；假设题只答「我会怎么做」。题在自己那一组（素材、岗位）里拖动排序；「选择」后能一起删除，或「练一轮」直接开卡片练习。
- **三个题库 SKILL**：题库页「✦ 让小拾补题」（选类别、经历或岗位、几道、本次要求 → 点选要的题后一步写进）、每题的「润色」（看差异接受），和小拾对话里的三个技能（题放进确认卡片，确认才写）是同一套。读的资料：简历题读选的经历和经历档案；通用题读基本信息、已确认事实和经历；突击题读岗位、JD、公司资料、经历和已有的简历题、通用题。都告诉模型已有哪些题；事实只用资料里的，缺的写「（待补：缺什么）」。默认条数：突击题这个岗位第一次 8 道，其余 5 道，最多 12。
- **卡片练习**：
  - 出卡：自己挑（类别、标签、只要不熟的，再勾题）、按 JD（小拾按岗位挑 8 张左右，先通用再简历最后突击，能去掉、能加）、随机（默认 10 张，一轮最多 50）。上次「不熟」的排最前，连着两次「会」的排最后；同一轮只能有一个在练。
  - 练：一张大卡，点了翻面看题库里的答案，再点「会」「不熟」（只答当前这张，最后一张答完自动结束；「停下」一张没答就当没开始）。默认不打字，「⌨ 打字」能打。「追问」让小拾按这道题、我的答案、打的字和 JD 出一张虚线追问卡（背面是参考答案，每张卡一次，同一道题一轮最多 2 次），「存进题库」才进题库。
  - 「最近几轮」能「选择」后一起删除。
  - 一轮的反馈：程序列出不熟、会、追问；打了字或追问过时小拾写点评（总评、说得好、讲不清的、每张打字卡一条）；「再练不熟的」直接开一轮。
  - 练习记录按轮存，不写进题目；开始、每次会 / 不熟、追问、存进题库、停下、点评、删一轮各是一步 ⌘Z。
- **面试**（每个岗位一组，投石问路岗位面板的「面试」一栏也能进）：
  - **准备面试**：选面试语言（中文 / English）、形式、本次要求，小拾读这个岗位用的简历（「本次使用」的那份：Pomelo 导出的读当时的草稿，别的读 Word / PDF 的正文；没有就是那种语言的草稿）、JD、公司资料、相关的题（通用题、简历上经历的简历题、这个岗位的突击题）和经历档案，挑出 8～15 道（按面试顺序）、补 5～10 个可能的追问（带参考答案，「存进题库」才进），写一页速查卡（岗位要点、自我介绍要点、经历速记「本人职责｜关键数据｜已知边界」、高频题、可能的追问、反问）。速查卡能改，「另存 Word」（文件夹记住上次的，默认「文稿」，只新建不覆盖）；「用这些题练一轮」直接开卡片练习。准备稿不改题库和简历。
  - **复盘**：每轮记日期、轮次、形式、结果（待定 / 通过 / 没过），每个实际问题、我的回答、面试官的反应，面试官的整体反馈，和我的判断（和事实分开）。「对照」：小拾拿这次和这个岗位的准备（几份时能选）比，列出准备到了的、没准备到的（缺在哪段经历、什么事实）、值得加进题库的题（「存进题库」）和至多 2 条长期规则的提议（一句话的要点；「加进规则」才写进 Rater 规则里那个标题的规则，没有就新建一条）。一次录取或拒绝不说明简历好坏。
  - 每次准备、改速查卡、记复盘、对照、存进题库、加进规则、删除各是一步 ⌘Z；Word 文件不撤销。

### Work（在对话里）

对标 Claude / ChatGPT 的 Work，但保持轻量，真正难的活交给它们。不单独做页面，放进对话里：资料、追问、确认都用对话现成的，用对话现在选的模型。

- **写报告**：照常在对话里问（资料用附件、项目资料、知识库、联网）。写完的回答下面多一个「保存为 Word」：文件名（默认是回答的第一个标题，没有就用对话标题，加日期）、文件夹（记住上次的，默认「文稿」），点「保存」才存；同名不覆盖，加「 (2)」。Word 有真正的标题、列表、表格、引用和代码样式，用到的出处按编号列在文末。存好后能「打开」「在访达中显示」。
- **改文件**（Word 工具箱改 Word，文本工具箱改 Markdown、纯文本；小拾觉得需要时自己用）：能改的是这个问题的附件（点选或拖进来的，改的是原文件；粘贴的截图、从附件库选的没有原文件）、以前用「改文件…」选的那个文件，和知识库里的文件。原地读、原地写，不复制、不留备份。
  - 能改哪些文件直接告诉小拾；它按段读要改的部分（页码目录这类、文本框、空段不能改），再提议改哪几段（能删段、在一段后面加新段落）。真的提议了才有卡片，只在回答里写改法不算。一条回答改一个文件。卡片每段一个勾（默认勾上）和前后差异；「写入文件」只写勾上的，「取消」不写；写入后「打开文件」。
  - 写之前检查文件这期间有没有被改过，改过就不写。Markdown / 纯文本保留原来的换行和编码。Word 只改变了的地方：没改的字保留格式，新加的字跟着旁边的格式，图片、批注、样式不动。
  - Word 的格式也能改：加粗、斜体、下划线，段落改成标题（几级）或列表（项目符号、编号），都用文档里已有的样式（没有「标题 N」样式、没有那种列表可照着时改不了）；新加的段落照着前面那段的样子。字体、颜色、版式不改。
  - 表格当作一段（一行一行，格子用 | 隔开）：只改格子里的字和加粗、斜体、下划线，行数、每行的格数不变，空格子能填；一格里有好几段的、和上面合并的格子、表格里套表格的不能改。
  - 碰到制表符、段内换行的改动，和删掉有书签、批注、图片、分节符的段落，不放进卡片，回答里写明几段。
  - 写文件不能 ⌘Z；卡片存在对话里，导出也有。
- **新建 Word**：Word 工具箱也能新建：小拾把写好的内容（Markdown）放进卡片，写着文件名和文件夹（记住上次的，默认「文稿」），可以改名、换文件夹，点「保存」才存（同名不覆盖）；存好后「打开」「在访达中显示」。
- **读文件**（技能）：读这个问题带的附件和项目资料（小拾里存的那份）：看目录、按段号读、按字找，读到的段落标出处。资料太长放不下时，先给小拾目录和按问题挑出的段落，它再补读。
- 工具箱只提议，写进文件、存成 Word 都由我点。以后助手、定时任务也能用（现在定时任务不给）。

### 导出、空间、设置

- **导出**：小拾页导出当前版本的 Markdown，或含全部版本、附件、摘要的完整包。「设置 → 导出」的数据文件只带记忆、模板、用途预设、全局指令、项目和背景指令、定时任务；导入时全局指令、模板、记忆、定时任务整个替换，项目和预设按名称更新或新增（对话还在原来的项目里）。
- **空间管理**（「设置 → 小拾 → 空间」）：数据库和附件、资料各占多少（附件和资料不进每日备份，也不需要另外备份）；每份副本多大、被几个问题和资料用着，确认后才删（原文件不受影响，用到它的消息显示「文件已删除」，不能撤销）；没有记录的文件也能删；30 天没动过的空对话一键清理（能撤销）。
- **设置 → 小拾**：本地模型状态、向量和重排服务（各自能选模型）、搜索索引、发给云端、云端 Key 和常用模型（按服务分组，每组能折叠、记住开合，组里拖动排序）、记忆总开关。模板、预设、全局指令、记忆在小拾页的「管理」里。
- **不做**：删除单条消息、临时聊天、导入其他 App 的旧聊天、退出后恢复草稿、语音；v1.0 前不做音视频；正文字号和消息间距的设置。
