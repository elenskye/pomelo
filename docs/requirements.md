# 需求

> 来自两轮需求问卷（2026-09-29）、历次优化清单（原件都在 `archive/`）和对话里的决定。版本安排见[开发路线](roadmap.md)；字段和计算规则见[数据结构](schema.md)。

## 总体

- **定位**：第二大脑，个人事务都在这里管。App 一直开着，想到就记，每周整理一次；每天花 5～15 分钟。
- **最想解决**：事情会忘、截止日期错过；想回顾时找不到记录；录入太麻烦。
- **风格**：适度自动——自动填日期、提醒、汇总，但不替我做决定。
- **只在这台 Mac 上用**，手机不用。**提醒只在 App 里**：不弹系统通知，关掉窗口后不在后台常驻。
- **界面不放使用提示**（快捷键、怎么操作、撤销提醒、输入框示例）。需要解释的，只在设置页用 (?) 说明。
- **删除**确认后直接删，不设废纸篓。**撤销**：⌘Z / ⌘⇧Z 撤销、重做最近 100 步修改；关掉 App 后就不能撤销了，导入和恢复备份不能撤销。
- **联网**：默认完全离线。只有 AI 联网搜索和可选的云端模型（默认关）会联网；汇率、书影信息、天气都不联网获取。
- **侧栏**：所有模块平铺；能收起成图标窄条、按住拖动排序（都会记住）。不用的模块在「设置 → 侧栏」里关掉：侧栏和全局搜索里都不出现，数据还在。最上面是「首页」（不能拖、不能隐藏），打开 App 总是先显示首页。
- **全局搜索**（⌘K，或侧栏顶上的放大镜）：搜所有模块，隐藏的模块和芝麻开门除外。几个词用空格隔开、要同时出现，不分大小写。结果按模块分组，每类最多 6 条，名字开头就对上的排前面，其余新的在前。↑↓ 选、↩ 打开：跳到那个模块并打开那条记录。搜的范围见 `src-tauri/src/search.rs`。
- **v1.0 的标准**：功能齐了，视觉也打磨好了。视觉在 v1.0 前统一做。
- **不做**：日记、习惯打卡模块、心愿单、物品管理、人情往来、健康记录、整个 App 的锁、全局标签、今日三件事、今日时间线、月度复盘、计时、快捷指令接入、浏览器剪藏、桌面小组件、豆瓣导入、拍照识别。

## 待办「一步一步」（参考「目标地图 GoalMap」）

- 完全替代原来的 Markdown 待办（「近期待办」已导入）。
- **结构**：分组 → 目标 → 任务 → 多级子任务。分组只有一层（可以带 emoji）；零散的任务直接放在分组里。不要标签、优先级、情境。
- **目标**：开始和结束时间；状态（进行中、暂停、已完成）；进度按完成的任务自动算；完成后写几句复盘。不要的目标直接删除。
- **子任务**可以多层、能折叠；全部完成时，上一层自动勾上。
- **时间**：不设，或者一个时间段（开始可以不填）。时间段内每天都出现在今天；过期的标红，留在原来的日期。没有「计划哪天做」。
- **完成后**收进「已完成」，自动记完成时间。分组页里，已完成的目标和任务一起收在「已完成 N」里。
- **视图**：今天（默认）、按分组 / 目标、月历、回看（周 / 月 / 年 / 全部：柱状图、按分组排行、合计和日均，下面是清单）。按住一行拖动排序。
- **任务栏只显示标题和截止日期**（紧跟标题，写成 2026 / 10 / 03）；有子任务的在最右边「1/3 ⌄」。不标所属分组；目标前面没有图标。
- **每条记**：标题、内容（多行，支持 **加粗**）、链接（网址或本机文件，点链接图标打开）。分组和目标页右上角有「新任务」，⌘N 也一样；今天页是底部的快速添加。
- **四种任务**（后三种不能有子任务）：
  - **普通**：做完勾掉。
  - **重复**：由规则推算每一次是哪天，勾掉就跳到下一次，也能「跳过这次」。每天、每周某几天、每月某几号（可多选）、每年某月某日（可以每隔几年）、每隔几天或几周：填「一共几次」（可不限）和「已经做了几次」。完成后再过几天 / 几周 / 几个月 / 几年：填数字和开始日期，每次做完从那天重新算。
  - **打卡**：每天或每周固定几天，时间是「不设 / 时间段」。该打卡的日子出现在今天；面板里有月历，能补打，显示连续天数。时间段里该打的都打了马上算完成，时间段结束也自动算完成。
  - **进度条**：目标数量和单位（比如「今年读 20 本」），可以设时间段。点圆圈加 1，面板里能记任意数量；达到目标自动完成。
- 不要：备忘、每周回顾、和求职自动联动。以后：出门走走出发前提醒打包。

## 书影「摸鱼读读」「好奇看看」· 画画 · 出行

- **书影**：名称、作者 / 导演、国家、类型（可自己改）、状态、尝尝咸淡（1～5 星）、完成时间（只记年）、备注。
- **重读、重看**：第一次就是书 / 影自己的完成时间和星级；之后每一次在面板的「重读」/「重看」里加一行（哪一年 + 几颗星），标成已读 / 已看后才出现这块。表格的完成时间显示最近一次，排序也按它。
- **随意画画**：课程 → 课节（编号、类型、课名、状态、完成时间记到年月、备注）。新建课节默认「未开始」。
- **出门走走**：场景模板 + 每次出行。新出行的清单从模板、以前的某次出行（物品全部变回「没装」）或空白开始；下拉框按「模板」「以前的出行」分组。
- 拖拽排序（课程、课节、模板、物品），筛选时也能拖。
- 不做：封面、自动填信息、读书进度、标签、长篇读后感、绘画作品图和学习时长、出行归档对比、导出 CSV。

## 记账「钱来钱往」

- **最重要**：看总资产怎么变化；管好订阅和固定支出。也要：知道钱花在哪、每月按分类的预算、投资。每周或每月集中整理一次。
- **三页**：收支（明细 + 固定支出）· 资产（账户、余额、汇率、持仓、总资产曲线）· 报表（月 / 年：分类占比、每月趋势、预算；「资产」：账户和持仓的变化曲线）。
- **币种**：人民币、新加坡元、港币、美元，平时分开记、不换算，报表也按币种分开看；只有总资产按汇率折成人民币。
- **一笔记录**：支出 / 收入、金额、币种、日期、分类（一层，可以自己改）、备注。不挂账户。
- **记多细**：300 元以上（其他币种大概等值）单独记；小额用「记小额」：选一个时间段（默认从上一段的第二天到今天），一次填完各分类花了多少。明细里写成「9/28 – 10/4」，跨月的两个月都列出；月合计、报表和预算按天平摊（每天 = 总额 ÷ 天数）。
- **明细**：表格里直接点分类就能换；分类筛选里有「管理支出分类… / 管理收入分类…」。**多选**：点「多选」，或 ⌘ 点行加选、⇧ 点行连选；底部能批量改分类（都是支出或都是收入时）、改币种（数字不变）、删除。
- **固定支出**（房租、话费、订阅，也可以是固定收入）：每月几号或每年哪天，到日子自动记一笔，漏掉的也补上；可以停用。
- **账户**：一个账户一种币；类型分银行、钱包、券商；不用的可以停用。不记转账和换汇。
- **更新余额**：选一天（默认今天），填各账户余额和汇率，先带出最近一次的数。多久更新一次都行，总资产按每次更新的日子算。
- **持仓**（券商账户）：选一天，填名称、数量、单价，市值自动算。
- **报表 · 资产**：账户、持仓各一张曲线，跟着报表顶上的币种，只列这个币种的；横轴只有更新过的日子；上面的小标签选显示哪些（会记住）。
- **预算**：按「支出分类 + 币种」设每月金额。快到时变黄，超出变红并写明超出多少。
- 不记：贵重物品、负债、借出和 AA、信用卡；不和出门走走关联；不额外加密。

## 求职「投石问路」

- 预计毕业前集中投：全职、中国大陆，一个求职季 200 个以上。
- **两页**：投递（表格；顶上是「该跟进」；按状态筛选、搜索）· 统计（几个数字、每天 / 每周投了几份、漏斗、现在的状态分布）。
- **一条记录**：公司、岗位、地点、渠道（可自己改）、状态、JD 链接、简历（Seeker 里的文件，能选、能点开）、备注。
- **状态**：默认想投、已投递、网申测评 / 笔试、面试、Offer、已接受、被拒；名字、顺序、增删都能改（「管理状态」里只有这些）。默认状态各有作用：想投 = 还一个没勾，已投递满 14 天提醒跟进，Offer 和已接受算拿到，被拒算结束；新加的状态都当作中间一步。时间线上有它的状态不能删。
- **每条投递的时间线**：① 先点选它有哪些状态（比如中国银行新加坡分行没有网申、笔试；新建时默认除了想投、被拒都选上，被拒时再选进来）；② 选中的按顺序排成时间线，左边勾选框、右边日期；③ 勾上自动填今天，能改。
- **现在的状态** = 最后一个勾上的；一个没勾就是想投。投递日期 = 最早勾上的那天。
- **漏斗**：已投递 → … → Offer，每一步写「勾上的 / 有这一步的」；没有这一步的、还没投的都不算。
- **跟进**：在等回音的，离那一步满 14 天提醒；点「已跟进」后再过 14 天才又提醒。
- **Seeker 保持独立**：它管简历和面试材料，Pomelo 只管投递和进度。
- **以后 · 面试题库**（v1.0 前）：从 Bear 导出的 Markdown 导入，像闪卡一样练（正面题目、背面参考答案），记熟练度和练过几次，先出不会的。

## 笔记「念念不忘」（参考 Flomo）

- **定位**：想到就记的收集箱，替代 Flomo。一条笔记只有正文和记录时间。Flomo 的 179 条已导入（图片、录音等 v0.3 做附件时补回）。
- **标签**写在正文里：`#标签`，多级 `#一级/二级`。只在笔记里用。
- **正文格式**：**加粗**、==高亮==、++下划线++、列表（`- ` / `1. `，Tab 缩进），网址能点。⌘B / ⌘U / ⌘⇧H 加格式，⌘↩ 记下；输入 `#` 时提示已有标签；列表里回车接着编号。
- **页面**：左栏是笔记数、标签数、记了几天，最近 16 周的热力图（点某天只看那天），「全部笔记」、置顶的标签、标签树（能折叠，按拼音排）。右边上面是输入框，下面是卡片，新的在上，置顶的排最上。搜索框搜正文（几个词同时出现）。标签、日期、搜索能叠加，条件显示在卡片上方。在某个标签下新建，自动带上这个标签。
- **每条笔记**：双击或「编辑」就地修改；「引用」（Flomo 的批注）：两边都显示链接；「置顶」；「删除」。太长的折起来，点「展开全文」。
- **标签的「⋯」菜单**：
  - **置顶**：只有第一级标签能置顶；置顶的列在「置顶」里（按先后），能展开子标签，下面的标签树里不再重复。
  - **图标**：48 个 Pomelo 风格的线条图标，或自己输入一个 emoji；直接点标签前的图标（或 #）也能换。任何一级都能设。
  - **改名**：所有笔记里的写法一起改，下一级跟着走；改成已有的就是合并。置顶和图标跟着走。
- **以后 · AI 年度总结**：和 Agent 一起做，读一年的笔记，总结对我重要的人、事和变化。

## 密码「芝麻开门」

- 管一般性的密码（网站、App 账号），不放银行卡密码这类。我自己手动录入。
- **每条记**：名称（必填）、链接、用户名、账号、密码（能显示、能随机生成：三组字母，带一个大写和一个数字）、备注。
- **列表**：名称（带网站名，点一下打开）、用户名、账号、密码（只显示圆点）。鼠标移上去能复制，30 秒后从剪贴板清掉，剪贴板工具也不会记。按名称排，能搜索，能撤销。
- **主密码**：我自己设（至少 8 个字符），Pomelo 不保存，只有我知道；更新 App 不会丢；修改要先输原来的；忘了就打不开。
- **怎么打开**：平时 Touch ID（到这一页自动弹出）。这些时候必须输主密码：指纹框里 3 次都没对上、距上次输主密码满 3 天、App 更新后第一次打开。
- **自动锁**：5 分钟没碰 App（电脑睡眠也算）、手动「锁上」、恢复备份后。
- **任何云端 Agent 都读不到**：加密后才存，备份里也是密文，导出文件里没有，全局搜索不搜；以后的 AI 也没有读密码的命令。

## 首页（简单版）

- **布局固定**：顶上问候语（早上好 / 中午好 / 下午好 / 晚上好 / 夜深了）和日期；下面一排「今年的数字」；再下面两栏，左边今天的待办、最近记录，右边总资产、求职近况、在读在看、绘画进度。窗口窄时变成一栏。设置里隐藏的模块，首页也没有它那一块。
- 每块的标题点一下进那个模块，每一行点一下打开那条记录（和全局搜索一样）。
- **今年的数字**：读完几本、看完几部、画完几节、完成几件待办、记了几条笔记、投出几份。
- **今天的待办**：和一步一步的「今天」一样，已过期的排前面；圆圈能直接勾。右上角写已过期几件、今天完成了几件。
- **最近记录**：最近 8 条，按时间混排：新加的笔记、书影、课程和课节、出行、投递、收支，加上勾掉的待办。
- **总资产**：最近一次的总数、比上次多了还是少了、曲线。**求职近况**：本周投了几份、进行中、拿到，下面是该跟进的和笔试面试中的（最多 6 条）。**在读在看**：在读的书、在看的影视。**绘画进度**：没画完的课程，进度条和「下一节」，点一下打开下一节。
- 完整版以后再加：日历、本地 AI 写的今日简报、年底的年度回顾。图表直接放在首页，布局由我来设计。
- **不要**：7 天内到期、本月花费和预算、出行打包、天气、问候语下面的「一句话」。
