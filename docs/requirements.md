# 需求

> 已定的需求，写现状。来源：问卷、优化清单（原件在 `archive/`）和对话里的决定。进度见[开发路线](roadmap.md)，表和计算规则见[数据结构](schema.md)，做法见[技术架构](architecture.md)，样子见[视觉规范](design.md)。

## 总体

- **定位**：第二大脑，个人事务都在这里管。App 一直开着，想到就记，每周整理一次，每天 5～15 分钟。
- **最想解决**：事情会忘、截止日期错过；想回顾时找不到记录；录入太麻烦。
- **风格**：适度自动（填日期、提醒、汇总），不替我做决定。
- **只在这台 Mac 上用**，手机不用。提醒只在 App 里，不弹系统通知。关窗口不退出（菜单栏留小拾的小鸟），⌘Q 才退出；登录 Mac 时自动在菜单栏启动、不弹窗口（「设置 → 启动」能关）。
- **界面不放使用提示**，要解释的只在设置页的 (?) 里（细则见视觉规范）。
- **删除**确认后直接删，没有废纸篓。**撤销**：⌘Z / ⌘⇧Z 撤销、重做最近 100 步；关掉 App、导入、恢复备份后不能撤销。
- **联网**：默认离线。只有小拾的云端模型（填了 Key、主动选了才用）、插件库（书单 / 影单检索、联网搜索）、「添加网页」、呦呦漫游的发布（推到 GitHub、读 Vercel 的上线结果）和 Pub2MD（Mathpix、选中的云端模型）联网；汇率、天气不联网。
- **侧栏**：所有模块平铺，能收成图标窄条、拖动排序（都记住）。「设置 → 侧栏」隐藏不用的模块：侧栏、全局搜索、首页、小拾里都没有它，数据还在。最上面是「首页」（不能拖、不能隐藏），打开 App 先到首页。
- **全局搜索**（⌘K 或侧栏顶上的放大镜）：搜所有模块和小拾的对话，隐藏的模块和芝麻开门除外。几个词空格隔开、都要出现，不分大小写；按模块分组，每类最多 6 条，名字开头对上的在前，其余新的在前；↑↓ 选、↩ 打开那条记录。下面一组「意思相近」（见「小拾 · 搜索和出处」）。
- **v1.0 的标准**：功能齐了，视觉也打磨好（v1.0 前统一做）。
- **不做**：日记、习惯打卡模块、心愿单、物品管理、人情往来、健康记录、整个 App 的锁、全局标签、今日三件事、今日时间线、月度复盘、计时、快捷指令接入、浏览器剪藏、桌面小组件、豆瓣导入、拍照识别。

## 附件（笔记、任务、目标）

- 图片显示小图，点开看大图；PDF 和其他文件显示文件名，点了用默认程序打开。不做录音。
- 加附件时复制一份进数据文件夹（同样的内容只存一份），原文件删了也不影响。附件不进每日备份（交给 Time Machine 这类工具），导出的数据文件里只有名字；「设置 → 数据 → 附件」看占多少、清理没用到的。小拾的附件和资料另存一份（「设置 → 小拾 → 空间」），两边不共用。

## 待办「一步一步」（参考目标地图 GoalMap）

- 完全替代原来的 Markdown 待办。**结构**：分组（一层，可带 emoji）→ 目标 → 任务 → 多级子任务；零散的任务直接放在分组里。不要标签、优先级、情境。
- **目标**：开始和结束时间；状态（进行中、暂停、已完成）；进度按完成的任务自动算；完成后写复盘。不要的目标直接删。
- **子任务**多层、能折叠；全部完成时上一层自动勾上。
- **时间**：不设，或一个时间段（开始可不填）。时间段内每天都出现在「今天」；过期的标红，留在原来的日期。没有「计划哪天做」。
- **完成后**收进「已完成」，记下完成时间；分组页里已完成的目标和任务一起收在「已完成 N」里。
- **视图**：今天（默认）、按分组 / 目标、月历、回看（周 / 月 / 年 / 全部：柱状图、按分组排行、合计和日均，下面是清单）。拖动排序。
- **任务栏**只有标题和紧跟的截止日期（2026 / 10 / 03），有子任务的最右边「1/3 ⌄」；不标分组，目标前没有图标。
- **每条记**：标题、内容（多行，能加粗）、链接（网址或本机文件）。分组和目标页右上角「新任务」（⌘N），今天页底部快速添加。
- **四种任务**（后三种不能有子任务）：
  - **普通**：做完勾掉。
  - **重复**：按规则推算每次是哪天，勾掉跳到下一次，能「跳过这次」。规则：每天、每周几天、每月几号（可多选）、每年某月某日（可隔几年）、每隔几天或几周，都能填一共几次（可不限）和已经做了几次；或者完成后再过几天 / 周 / 月 / 年（从做完那天重新算）。
  - **打卡**：每天或每周固定几天，时间不设或一个时间段。该打卡的日子出现在今天；面板里有月历，能补打，显示连续天数。时间段里该打的都打了、或时间段结束，自动算完成。
  - **进度条**：目标数量和单位（「今年读 20 本」），可设时间段。点圆圈 +1，面板里能记任意数量；达到目标自动完成。
- **来自笔记**：念念不忘转来的任务，面板里「来自笔记」点了回到那条笔记。
- 不要：备忘、每周回顾、和求职联动。以后：出门走走出发前提醒打包。

## 书影「摸鱼读读」「好奇看看」· 画画 · 出行

- **书影**：名称、作者 / 导演、国家、类型（可自己改）、状态、尝尝咸淡（1～5 星）、完成时间（只记年）、备注。**重读、重看**：标成已读 / 已看后，面板里能一次次加「重读」/「重看」（哪一年 + 几颗星）；表格的完成时间和排序按最近一次。
- **随意画画**：课程 → 课节（编号、类型、课名、状态未开始 / 进行中 / 已完成、完成时间到年月、备注）。新课节默认未开始。
- **出门走走**：场景模板 + 每次出行。新出行的清单从模板、以前的某次出行（物品都变回没装）或空白开始。
- 课程、课节、模板、物品都能拖动排序，筛选时也能拖。
- 不做：封面、自动填信息（只有手动点的小拾「补全」）、读书进度、标签、长篇读后感、绘画作品图和学习时长、出行归档对比、导出 CSV。

## 记账「钱来钱往」

- **最重要**：看总资产怎么变；管好订阅和固定支出。也要：钱花在哪、每月按分类的预算、投资。每周或每月集中整理一次。
- **三页**：收支（明细 + 固定支出）· 资产（账户、余额、汇率、持仓、总资产曲线）· 报表（月 / 年：分类占比、每月趋势、预算；「资产」：账户和持仓的曲线）。
- **币种**：人民币、新加坡元、港币、美元，分开记、不换算，报表也按币种分开；只有总资产按汇率折成人民币。
- **一笔记录**：支出 / 收入、金额、币种、日期、分类（一层，可自己改）、备注。不挂账户。
- **记多细**：300 元以上（其他币种约等值）单独记；小额用「记小额」：选一个时间段（默认接着上一段到今天），一次填完各分类花了多少；明细里写「9/28 – 10/4」，跨月的两个月都列；月合计、报表、预算按天平摊。
- **明细**：表格里点分类就能换，分类筛选里能管理分类。多选（「多选」按钮、⌘ 点、⇧ 点）后能批量改分类（同是支出或收入时）、改币种（数字不变）、删除。
- **固定支出**（房租、话费、订阅，也可以是固定收入）：每月几号或每年哪天，到日子自动记一笔，漏掉的补上；能停用。
- **账户**：一个账户一种币，分银行、钱包、券商；能停用。不记转账和换汇。
- **更新余额**：选一天（默认今天），填各账户余额和汇率（先带出上次的数），总资产按每次更新的日子算。**持仓**（券商账户）：选一天，填名称、数量、单价，市值自动算。
- **报表 · 资产**：账户、持仓各一张曲线，只列报表顶上那个币种的；横轴只有更新过的日子；上面的小标签选显示哪些（会记住）。
- **预算**：按「支出分类 + 币种」设每月金额；快到变黄，超出变红并写超出多少。
- 不记：贵重物品、负债、借出和 AA、信用卡；不和出门走走关联；不额外加密。

## 求职「投石问路」

- 预计毕业前集中投：全职、中国大陆，一个求职季 200 个以上。简历和面试材料在 Seeker（v0.7 做成小拾的助手，见开发路线），投石问路只管投递和进度。
- **两页**：投递（表格；顶上「该跟进」；按状态筛选、搜索）· 统计（几个数字、每天 / 每周投了几份、漏斗、现在的状态分布）。
- **一条记录**：公司、岗位、地点、渠道（可自己改）、状态、JD 链接、简历（Seeker 里的文件，能选、能点开）、备注。
- **状态**：默认想投、已投递、网申测评 / 笔试、面试、Offer、已接受、被拒；名字、顺序、增删都在「管理状态」里改。默认状态各有作用：想投 = 一个没勾，已投递满 14 天提醒跟进，Offer 和已接受算拿到，被拒算结束；新加的都算中间一步。时间线上有它的状态不能删。
- **时间线**（每条投递自己的）：先点选它有哪些状态（新建默认除了想投、被拒都选上，被拒时再选进来），选中的按顺序排成时间线，勾上自动填今天（能改）。现在的状态 = 最后一个勾上的；投递日期 = 最早勾上的那天。
- **漏斗**：已投递 → … → Offer，每一步写「勾上的 / 有这一步的」；没有这一步的、还没投的不算。
- **跟进**：在等回音的，离那一步满 14 天提醒；点「已跟进」后再过 14 天才又提醒。
- **面试题库和模拟面试**（v0.7，不在 Seeker 的第一轮，开工前再细问）：题库从 Bear 导出的 Markdown 导入，像闪卡一样练，记熟练度和练过几次，先出不会的。

## 笔记「念念不忘」（参考 Flomo）

- **定位**：想到就记的收集箱，替代 Flomo（179 条和图片已导入）。一条笔记只有正文和记录时间。
- **标签**写在正文里：`#标签`、多级 `#一级/二级`，只在笔记里用。
- **正文格式**：**加粗**、==高亮==、++下划线++、列表（`- ` / `1. `，Tab 缩进），网址能点。⌘B / ⌘U / ⌘⇧H 加格式，⌘↩ 记下；输入 `#` 时提示已有标签；列表里回车接着编号。输入框边写边显示成卡片的样子（标记符号还在，变淡）。
- **页面**：左栏是笔记数、标签数、记了几天，最近 16 周的热力图（点某天只看那天），「全部笔记」、置顶的标签、标签树（能折叠，按拼音排）。右边上面输入框，下面卡片（新的在上，置顶的最上）。搜索正文（几个词同时出现，也按意思找）；标签、日期、搜索能叠加。在某个标签下新建自动带上这个标签。
- **每条笔记**：双击或「编辑」就地改；「引用」（两边都显示链接）；「置顶」；「删除」。太长的折起来，「展开全文」。
- **标签的「⋯」**：置顶（只有第一级；置顶的能展开子标签，标签树里不再重复）；图标（48 个线条图标或一个 emoji，任何一级都能设，点标签前的图标也能换）；改名（所有笔记里一起改，下一级、置顶、图标跟着走；改成已有的就是合并）。
- **转成待办**：卡片「⋯」里「转成待办」，右边滑出一步一步的新任务面板（标题是第一行去掉符号和标签，内容是全文，分组默认第一个），改好再保存；笔记留着，两边互相链接（笔记下面列出转成的待办，做完的划掉；任务面板里「来自笔记」）。一条笔记能转好几条。
- **让小拾拆成待办**：一条笔记写了几件事时，像「拆成子任务」那样先列出来（转过的不再列，默认都勾上），选「加到」哪个分组或进行中的目标，点「加上」才加，一步 ⌘Z。
- 删笔记时待办留着，只是不再链接；导出导入时链接跟着。年度总结由小拾写（见「小拾 · 定时任务、今日简报、年度总结」）。

## 重要日期「来日方长」（参考 Days Matter）

- **三种**：纪念日和倒数日（不重复、每年、每月、每周）；生日（每年；出生年份可不填，填了显示几岁；「礼物点子」和「送过的」，每行年份和礼物，新的在上）；证件（只记名称和到期日，不记号码和照片）。不要农历。
- **怎么算**：每条显示「还有 N 天」或「已经 N 天」，重复的数到下一次（当天写「今天」），每年的纪念日写「第 N 周年」，过期证件写「已过期 N 天」。2 月 29 日在平年算 2 月 28 日；每月 31 号在小月算月底。
- **页面**：上面「全部 · 纪念日 · 生日 · 证件」（带个数）和「新日子」；置顶的一条（最多一条）是大卡片；下面一张列表。顺序：过期的证件、按还有几天、已经过去的放最后。在哪个分类下新建就是哪一种。
- **提醒**：每条自己选提前几天（当天、1、3、7、14、30、60、90 天前，最多 5 个；新建时纪念日和生日默认 7 天前，证件 30 天和 7 天前）。首页「快到的日子」从最早的提醒那天显示到当天，过期的证件一直显示到改了为止；今日简报只在提醒的那几天和当天提。不自动生成待办。
- **小拾**能查快到的和全部日子；证件只读名称和到期日，备注不读、不进按意思搜索。不能写。

## 五花八门 · 循序渐进（做模块的模板）

- **是模板，不是模块**：侧栏顶上的加号选「五花八门（清单）」或「循序渐进（进度）」，填名称（不能和已有的重名）、选一个图标（24 个），建出来的每一个（比如「游戏」「日语」）都是侧栏里的一个模块：能拖动、隐藏，排在模块最后，颜色按模板固定。标题右边「⋯」：改名和图标（循序渐进还能改叫法）、管理字段（五花八门）、删除（里面的东西一起删，能 ⌘Z）。
- **五花八门**（通用清单）：每条有「名称」，再加最多 20 个字段：文字、长文字、数字、年份（只记年）、单选、多选、勾选、评分（1～5）、链接（建好后不能换类型）。
  - 表格 + 右侧面板：表格里是名称和选了「表格里显示」的字段；点表头排序（第三下恢复）；搜索（名称和文字）和一个筛选（单选多选的选项、勾选的是 / 否、评分几星以上）；没排序、没筛选时拖动换顺序。
  - 勾选、评分、单选、多选在表格里点一下就改（单选、多选像摸鱼读读的状态那样点标签弹出选项，没有箭头和「不选」，多选能连着勾几个；清空在右侧面板里）。单选、多选的选项按顺序自动配色（Pomelo 定，不能自己选）。
  - 「管理字段」里加、改名、拖动、选显示、删除；选项改名会改掉每一条里的，删掉的选项从每一条里去掉。
- **循序渐进**（通用进度）：和随意画画一样「课程 → 课节」两层：左边课程和进度条，右边课节（编号、名称、类型、状态、完成月份、备注，圆圈一键完成），「下一节」、按最近 6 个月的速度预计哪个月完成。
  - **类型**：每个模块自己一组（一开始没有，标题右边「⋯ → 管理类型…」里加、改名、排序、删除；删掉的类型那些节变「未分类」），像单选一样按顺序配色，表格里点一下就换，能按类型筛选。
  - 两层的叫法建的时候填（默认课程 / 课节，比如「季 / 集」），以后能改，页面、按钮、撤销提示都跟着。它管有固定章节的东西；要达成的事用待办的目标。
- **小拾、搜索、导出**：每个都像一个模块：隐藏了小拾不读、全局搜索不搜；「发给云端」各有一个标签（默认能发）。小拾能查清单和条目、进度和每一节，不能改。全局搜索能搜到条目、课程和课节。导出的数据文件里都有；导入时整个替换它们（侧栏顺序、隐藏、云端设置不跟着）。
- 摸鱼读读、好奇看看、随意画画还是专门的模块。

## 密码「芝麻开门」

- 管一般性的密码（网站、App 账号），不放银行卡密码这类；手动录入。
- **每条**：名称（必填）、分类、链接、用户名、账号、密码（能显示、能随机生成：三组字母，带一个大写和一个数字）、备注。
- **分类**：每条最多一个，「管理分类」里增删改、排序（分类名也加密）；删分类，那些密码变成「未分类」。在某个分类下新建自动带上。
- **归档**：几乎不用的在面板里「归档」，只在「归档」里看得到；搜索照样搜得到（行尾淡淡的「已归档」）；「取消归档」回到原处。
- **列表**：搜索框下面「全部 · 各分类 · 未分类 · 归档」（带条数，空的不显示），右边「管理分类」。名称（带网站名，点了打开）、用户名、账号、密码（只显示圆点）。鼠标移上去能复制，30 秒后从剪贴板清掉，剪贴板工具也不记。按名称排，能拖动调整顺序（搜索时不能拖）；搜索只在当前这一类里搜（含归档的）；能撤销。

- **回复**：流式、停止、重试；思考过程折叠、单独保存，不发回给模型。双方消息按 Markdown 显示：表格、代码高亮和复制、公式（`$…$`、`\(…\)`、`$$…$$`、`\[…\]`；金额的 $ 不误判；右键复制 LaTeX）；页面内查找；跨消息选择复制得到纯文字；「复制整段对话」。看旧消息时不强制滚到底。链接交给浏览器，模型输出的 HTML 当文字显示。

- **上下文快满**：先提示，确认后总结较早的对话（原文保留，摘要只对原来那条路径有效）；「总结并继续」总结完把输入框里的问题接着发。

### 附件、项目资料、记忆

- **附件**：点选、拖入、⌘V 粘贴图片或从附件库复用，文件复制一份保存；点选和拖入的还记下原文件在哪（Word 工具箱、文本工具箱改的就是原文件）。能读 PDF、Markdown、文本、Word（.docx、.doc）、PowerPoint（.pptx，每页的文字）、Excel（.xlsx、.xls、.ods）和 CSV、图片（PNG、JPEG、GIF、WebP、HEIC）、网页；都能当附件、项目资料，也能进知识库。「+ → 添加网页…」、项目资料「添加 → 网页…」存下网页的正文和网址。
  - **表格**：每张表第一行是表头。一共 200 行以内整张发；更大的只发表头和前 50 行，这一问小拾多一个「查表」工具（按行号、含某些字、某列等于某值取行，一次最多 200 行）。
  - **图片**：云端模型都当作能看图，发之前缩小，一问最多 8 张（最近的）。本地模型看不了：图片胶囊写「本地模型看不了图片」，问题照发，回答里说明并提醒换云端。图片不建索引。
  - **追问时**：同一条路径上前面问题带的附件还会一起发，但和这一问新附上的分开，写明「前面附过」，免得小拾当成新的再介绍一遍。
  - **放不下的长文件**：开着「读文件」技能、模型能用工具时，先给目录和按问题挑出的段落，小拾再按段号补读（见「Work」）；否则分段读完再汇总（显示进度、能停止，存下要点和页码）。
- **项目资料**：每个项目自己的资料（格式同附件，不进附件库，同一文件不重复）。输入框「资料」菜单选这条消息用哪些（全文发送，选择保留到之后的消息）。「替换为新版本」保留旧版本，旧消息仍对应当时的版本。资料能「建立索引」（能停止、重试、取消），之后在项目里提问自动检索至多 6 段相关内容，回答里标出处。
- **记忆**：一两句话的事实或偏好（300 字以内），分全局和项目；项目记忆能同时用于别的项目，项目可以不用全局记忆。能停用、设「仅本地」（选云端时跳过）。对话里 `/记住 …` 弹出确认卡片，点保存才存。每条消息自动挑至多 6 条相关记忆（附「记于」日期），回复下方能看用了哪些；输入框「记忆」菜单能只关下一条、关掉整个对话；设置里有总开关。删项目时它的记忆改成全局并停用。
- **向量服务用不了时**：挑记忆、检索资料或知识库时向量服务用不了，先暂停发送，让我选：不用它们直接发、重试或取消。

### 懂 Pomelo（查数据、小窗、面板里的帮手）

- **问我的数据**：在小拾页或小窗里提问，小拾自己决定查什么（Rust 准备一组只读查询：某个模块、某段时间、某些条件，或直接要合计），能连查几次。合计、平均、占比、连续天数、预计完成都由 Rust 算（和 App 里的统计同一套），小拾只解释和建议。没说时间时自己判断，并写明看的是哪段时间。常问的几类各有专门的查询：总资产怎么变、该跟进哪些投递、上周做完的和拖着的、按口味推荐书影、最近的笔记在想什么、绘画什么时候画完、出行可能漏了什么。
- **查了什么**：回复上方一行「查了：钱来钱往 · 2026 年 9 月支出（42 笔）」，点开看内容；回答里第一次提到的记录能点开。查到的存进对话：追问时最近 3 次回答查到的（截短）跟着当时的问题一起发，发之前按现在的规则再筛一遍；回看、导出都有。
- **能读哪些**：除了芝麻开门（永远不读）和隐藏的模块，都能读。**发给云端**在「设置 → 小拾」按模块选：默认钱来钱往只给本地模型，其他（含自己建的）都能发。选云端时不能发的不查，回答开头写明「钱来钱往不发给云端，这部分没看」。
- **查几次**：一次回答最多查 4 轮，之后必须回答（要记、要改的还能再提议一轮）；查到的太多就截短并写明还有几条。模型不支持工具时直接回答，「查了」写「这个模型不支持查数据」。要分段阅读的那一问不查数据。
- **右侧小窗**：⌘J 或侧栏顶上的小鸟按钮呼出 / 收起（小拾页里不用）。在窗口右边占一栏，页面往左让开（窗口太窄时浮在页面上）。里面是普通的小拾对话（存在「最近」），顶上能切到最近 8 个对话或开新对话，模型同小拾页。加附件、选资料、写指令、总结留在小拾页。App 重开后小窗收起。
- **当前页面**：小窗输入框上方的小胶囊写着当前模块、页面和筛选（如「钱来钱往 · 收支 · 2026 年 9 月」），打开了某条记录时是那一条，多选时是选中的几条；发消息时一起带上（记录带全部内容），点 × 这一条不带。不能读或不能发给云端的只带「在哪一页」，芝麻开门什么都不带。问题上方「带着：…」点开看带了什么；追问、重新生成、改问题都带着当时的页面。
- **润色**：任务内容和目标复盘、投递备注、书影 / 课节 / 出行 / 收支的备注，呦呦漫游的摘要、图片描述和正文（笔记不要）。输入框角上的小按钮，写这次的要求（空着就是改通顺），下面出现改好的版本（标出改动），「替换」才换上，能「再改一次」。
- **补全**：书影补作者 / 导演、国家、类型（先用书单 / 影单检索，查不到才靠模型）；投石问路贴 JD 补公司、岗位、地点（JD 原文进备注）；一步一步把任务拆成子任务；出门走走按目的地和天数建议可能漏的东西；呦呦漫游起草英文标题和英文摘要。前两种只填空着的项；拆子任务和漏带的东西先列出来（默认勾上），「加上」才加，一步 ⌘Z。念念不忘的标签、钱来钱往的分类不做。
- **一句话填好**：收支、任务、投递、书影、新出行的新建面板最上面一行，写一句话回车，各项填好（填过的浅柚红底），检查后自己保存。一次只填一件事（好几件事在对话里说）。
  - 日期词（昨天、下周五、10 月 20 号……）由 Rust 按今天算；分类、分组和目标、渠道、状态、模板、类型按名称对上已有的，对不上就空着。
  - 收支：没说日期是今天，没说币种用最近 60 天最常用的。任务：只说一天就是截止日，分组和目标要提到才填。投递：说了投了 / 面试了才勾那一步，没说日期是今天。书影：看完了没说哪年就是今年。出行：名称、出发日期、模板。
- **用哪个模型**：润色、补全、一句话填好跟着小拾现在选的模型，本地模型没运行就先启动（上次选的那个）；选云端时，「发给云端」里关掉的模块（默认钱来钱往）这些功能不发。

### 一句话记好、改好

- 在对话里说「午饭 35」「这个投递进面试了」，小拾记下或改好。能做的：
  - 一步一步：新任务；完成、改日期、改分组、加子任务、打卡、进度 +1。
  - 钱来钱往：记一笔；改金额、分类、日期；更新账户余额。
  - 投石问路：新投递；勾上下一步、写备注。
  - 摸鱼读读 · 好奇看看：新增；改状态、星级、年份。
  - 随意画画：勾上画完的课节。出门走走：新出行；加物品、勾上装好的。念念不忘：记一条；改笔记。
  - 芝麻开门永远不能；什么都不能删。
- **确认**：回复里一张卡片：要新建的每一条（各项列出）、要改的每一条（改前 → 改后），每条一个勾（默认勾上）。回复写完才能点「确认」「取消」；确认算一步 ⌘Z，之后每条能点开那条记录，撤销了显示「已撤销」；卡片存在对话里。一句话好几件事列在同一张卡片里。
  - 默认：没说币种用最近两个月最常用的；没说分组用小拾挑的（卡片上看得到），没挑就是第一个分组；「投了」没说哪一步就是第一步。日期和名称照「一句话填好」。
  - 找要改的那条：只找到一条直接放进卡片；几条相近的列出来让我选（最多 5 条）；一条都没有就问我。任务只找没完成的；收支只看最近 31 天（说了哪天就看那天）；出行没说哪次就是还没出发的；课节没说哪节就是那门课下一节没画完的。
  - 「完成」照列表里的圆圈：普通任务勾上，重复任务算做了这一次，打卡今天打卡，进度 +1（说了数量就记那个数）。投递「写备注」是在原来的后面加一行。笔记可以整条改写，也可以只换一段，卡片里标出改了哪里。书影已有同名的就改它，不新加。
- **云端**：不能发给云端的模块（默认钱来钱往），用云端模型时新建、修改都不行，回复里说明。
- 不做：系统通知、菜单栏的小点、在 ⌘K 或菜单栏里直接记一笔。

### 搜索和出处

- **按意思搜**：⌘K、对话搜索、念念不忘的搜索框都能按意思找（搜「找房子」也能找到「租房」）：先按字找（马上出来），下面一组「意思相近」（稍后出来，不重复）。向量服务没运行时搜索自动启动它。芝麻开门永远不进索引，隐藏的模块不搜。20 万条时按字 0.1 秒内、按意思 0.3 秒内。向量和重排模型能在设置里换。
- **小拾的搜索**：两个工具：「搜索」（按字和按意思一起找、重排后最多 12 条，也能找到以前的对话）和「读整条」（读某个编号的全部内容），照能读和云端的规则。
- **出处**：回答里用到的资料段落、记录、网页标 [1][2]；回答下面「来源 · N」默认收起，点开列出用到的来源：记录点了像全局搜索那样打开，以前的对话在小拾里打开，资料弹出那一段原文和「打开文件」，网页用浏览器打开。记忆不编号，照旧列在回复下面。

### 插件库

- 左栏最下面的「插件库」：左边技能列表，右边是选中那一项的说明、发出去什么、开关和 Key。Key 只在钥匙串。
- 每个技能两个开关：「启用」和「小拾自己决定用」（关上时只在我点名的那一条用）。输入框任何地方打「/」（紧跟字母数字的不算，比如网址、1/2），菜单最上面一组「技能」，选了输入框上方出现小胶囊（如「/书单检索」），下一条必须先用它，发完就没了。「/记住」这类命令只在开头。
- **现有七个技能**，默认都打开、自己决定用，除了联网搜索：
  - 书单检索、影单检索。
  - 联网搜索：只在按「联网」或打「/联网搜索」的那一条用，那一条先拿问题本身搜一次。
  - 读文件、查知识库：只在问题带了文件、对话有能查的知识库时给（见「Work」「知识库」）。
  - Word 工具箱、文本工具箱：文本工具箱只在有能改的 Markdown、纯文本文件时给；定时任务不给（见「Work」）。
  - 以后的 Excel 工具箱这类也各是一个技能。
- **书单检索、影单检索**：按名称查作者 / 导演、国家、类型、年份。先在 Wikidata 找到这一部（中文名、译名都行），再用 Open Library（书）、TMDb（电影、剧集，要在插件库填 Read Access Token）、Jikan（动漫）核对；查不到就说查不到，不编。书的国家按作者国籍。用在：对话里补全和推荐书影（先核对每一部，标出处）；书影面板的「补全」（查到的直接填，查不到才让模型补）；「一句话填好」和小拾提议的新书影。共用插件库里的「联系邮箱」，只发给 Wikidata、Open Library（带了每分钟 200 次，不带只有 10 次），不填也能用。
- **联网搜索**：用 Tavily（Key 在插件库填），本地和云端模型都能用。输入框「联网」按钮只管下一条。联网的那一条照常能查 Pomelo 数据（照云端规则），搜索词可能带上私人内容。回答标出处，来源是网页标题和网站；搜到的存进对话，追问还用得上。

### 定时任务、今日简报、年度总结

- **定时任务**：左栏最下面「定时」里自己建：名称、什么时候（每天几点、每周几、每月几号或最后一天、每年几月几号）、模型和「思考」（默认开，开着时只列能思考的模型）、要做什么（一段要求）；能开关、改、删、「立即运行」，写着下次什么时候跑、上次的对话。
  - 到点小拾自己查数据、写好，存成一个对话（「名称 · 10/19」）放在列表的「定时」分组（和「最近」不互相拖）；侧栏的小拾、「定时」分组和那一行有个小点，打开就消失。只读数据、只写对话。
  - 到点时 Pomelo 没开，下次打开时补跑最近一次；新建、改了时间、重新打开的不补以前的。没跑成也留下对话写明原因。删任务，它写过的对话还在。
  - 选了本地模型而它没运行就先启动、跑完停掉（只停它自己启动的）；正在运行的是别的本地模型就用它（开头写明）。定时任务一次跑一个，和对话、助手同时跑（本地模型排队）。
- **现成的定时任务**（能改、关、删）：每周一早上回顾上周（做完的、拖着的、花了多少、投递进展）；每月 1 号回顾上个月（收支和总资产、读完看完的、画了多少）；每年 12 月 31 日 21:00 年度总结。
- **今日简报**：首页最上面一张卡片，每天第一次打开首页时写 3～6 句，当天不变，右上「重写」。只写：今天的待办、3 天内到期和过期的；该跟进的投递、在笔试面试的；最近两周的笔记常在想什么（没有笔记就不提）。不发给云端的模块不读，卡片下面写「没看：…」。失败显示原因、能重试，重写时旧的先留着。在「定时」最上面一行：开关、模型和「思考」、「重写今天的」。
- **AI 年度总结**：存成「定时」里的对话，也能「立即运行」（写今年到现在）；1 月补跑的写刚过去的那一年。数据多，建议用云端模型（以后配旗舰模型）；模型的回复上限要够写一封长信。
  - **读什么**：这一年的笔记全文；做完的事和目标、打卡；画完的课；投递的进展；出行（名称、出发日期）；读完看完的书影；和小拾的对话（标题和第一句，私密的、定时任务写的不读）。账本和芝麻开门不读（笔记里写到钱的照样能写）。数字都由 Rust 算好（笔记几条几字几天、做完几件、每月几件、打卡天数和最长连续、书影课节投递出行对话各几个、写笔记最多的月份、最常用的标签），模型只照抄。
  - **和去年比**：Rust 算去年同样的数字和差值（今年没过完时两年都算到同一天；书影按全年）；有去年的年度总结也给模型（私密的不给）。去年什么都没有就不比。
  - **写法**：一封写给「你」的信，像熟悉你的朋友陪你回看这一年：「这一年的关键词」（3～5 个）、总述、「这一年的数字」、按主题分块（读书观影、创作、学业和工作、感情和家人、身体和习惯、和小拾聊的事……有内容才写）、「你写下的话」（3～5 句原话，带日期）、「这一年之最」、和去年比（写进相关的块）、「写给明年」。篇幅看内容；空的月份一句带过；只写信本身。「要做什么」最后发给模型，冲突时照它。
  - **怎么生成**：放得下就一次读完全年直接写（云端基本都放得下）；放不下就先按月整理要点（留日期、人名、事名和原话；没变的月份直接用上次的），再拿要点写全年。思考照这个任务的设置。每月要点折叠在回复上面「每月小结 · N 个月」。
  - **首页**：新年第一周（1 月 1～7 日），简报上方一张「2025 年度总结」卡片：关键词和开头一两句，「看全文」弹出阅读框（底下「在小拾里打开」）。只认 12 月或以后写的那篇。

### 知识库

- **放什么**：选定的文件夹（原地读，不复制；文件变了自动更新）和保存的网页（存一份正文）。文件夹里小拾能读的都读（格式同附件，含子文件夹，大表格读全部行；图片列出来但不建索引，按意思找不到，用云端模型时小拾能看）；隐藏的、Office 临时文件（~$ 开头）、替身、应用程序包、node_modules 跳过；每个文件夹最多 2000 个文件，每个文件 200 MB 以内。不能放 Pomelo 自己的数据文件夹；同一个库里的文件夹不能一个套一个。
- **库**：分成几个库（名字最多 30 字、不重名），能新建、改名、删除、拖动；删库、移除文件夹或网页都不碰原来的文件。都能 ⌘Z。
- **管理**：左栏最下面的「知识库」（输入框「知识库」菜单里也有）：左边是库，右边是这个库的文件夹和网页，每行写着几个文件、正在建立（几 / 几）、几个待更新、几个读不了（点开看原因），找不到文件夹时标红；「发给云端」开关和「⋯」（在访达中打开 / 打开网页、重新建立索引、移除）。
- **查哪些库**：对话选的；没选就跟着项目（「项目设置」里选）；项目也没选就是全部。
- **「知识库」按钮**（输入框，小窗里也有）：按下后这个对话每个问题都查（每个对话记住；新对话默认不按，在选了库的项目里新开的默认按下）。旁边小箭头是菜单：查哪些库、用云端模型时不查的文件夹、「管理知识库…」（开关就是按钮本身，菜单里不重复）。没按时小拾也能自己用「查知识库」技能。
- **看文件、整篇读**：「查知识库」技能也能列出库里有哪些文件（路径、类型、大小、修改日期，能按路径里的字筛），整篇读某个文件（看目录、按段读、按字找，从原来的文件夹现读），读到的段落标出处，点了「打开文件」。这样能回答「这个文件夹里有什么」「总结某份文档」。
- **看图片**：用云端模型时，小拾能看库里的图片（一次一张，一个回答最多 8 张，发之前同附件一样缩小），看的图片也算出处；本地模型看不了，会这样说。Word、PowerPoint、PDF 里嵌的图片看不了。不改文件夹里的文件（要改用 Word / 文本工具箱）。
- **怎么查**：和项目资料一样按意思找、重排，至多 6 段，和项目资料的段落一起编号；出处写「知识库 · 库名：文件名 · 第 3 页」，点了看原文那一段和「打开文件」（网页是「打开网页」）。查之前先把变了的文件算好（「正在更新并检索知识库…」）。
- **什么时候更新**：不监听文件夹；打开小拾页、打开知识库对话框、每 10 分钟比一遍大小和修改时间，只重算变了的（没变的段落沿用原来的）。向量服务本来开着就马上算，没开着就等下次用知识库提问时先算完；添加和「重新建立索引」会启动向量服务。后台正在建立时提问，先用已经建好的。
- **云端**：每个文件夹（和网页）自己设能不能发给云端（默认能）；用云端模型时不能发的不查，菜单里写明。
- 知识库不进导出的数据文件。

### 助手

- 小拾提供的小型 Agent，各有自己的工作流、提示词和页面（占对话的位置，不是对话）：左栏「项目」和「定时」之间的「助手」，每个一行；点别的对话或「新对话」回到对话；离开小拾再回来，上次开着的助手还开着。现在有「Translator」（翻译）和「Pub2MD」（v0.6），v0.7 加「Seeker」。助手的名字由我来定。
- **Translator**：顶部「Translator · 提示词」两个标签。
  - **Translator 页**：源语言（默认自动检测）⇄ 目标语言（默认「中英互译」：原文主要是中文就译成英语，其他都译成简体中文；也能选十二种具体语言）、模型（同定时任务）、「思考」（默认关）、「翻译」（翻译时变「停止」，⌘↩ 也能翻）；下面上下两栏：原文、译文（写着用的模型或进度，能复制）。⇄ 只在两边都是具体语言时能点；两边同一种语言不翻。
  - **提示词页**：自己写的一段（2000 字以内）；四组关键词，每组最多选一个：长度（精简、和原文相当、可以展开）、专业度（通俗、一般、专业、学术）、语气（正式、中性、口语、亲切）、意译或直译（直译、平衡、意译）；下面是实际发给模型的说明。
  - **模型**：本地模型没运行就先启动（翻完不停）；正在运行的是别的本地模型就用它（写明）；选云端时原文发给那个云端模型。
  - **长文**：自动切成几块依次翻、边翻边显示（「正在翻译 2/5」），段落、标题、编号前后一致；本地模型也能翻长文。
  - **只记住上一次**：原文、设置、译文都自动存，不做历史列表。翻译在后台进行，离开再回来接着显示；「停止」留下已翻的部分。不进撤销和导出。

### Pub2MD（助手，v0.6）

- **是什么**：把 PDF、Word、图片经 Mathpix 转成 Markdown，再整理、翻译，每月用几次。用 Rust 在小拾里重做（原来是一个 Python 小项目，已删），叫「Pub2MD」，和 Translator 并列。
- **能做的事**：只提取（Mathpix 转出 MMD、Word、HTML、LaTeX……，不经过模型）；提取 + 整理；提取 + 整理 + 翻译；只翻译（MD、MMD、TXT，不经过 Mathpix）。放进来的：PDF、Word（.docx）、图片（PNG、JPG、HEIC、TIFF……，几张合成一份，多页的 TIFF 每页一页）、文本。选好或拖进来的文件先列在「待发送」里（几张图片合成一份，能移出），点「发送」才开始；一次处理一份，处理时还能再发送，排队依次做；停止一份后接着做下一份，停下或出错的在「最近」里点「继续」，不要了就点「删除」（确认后从列表拿掉，它的文件夹连同中间结果移到废纸篓）。
- **语言和要求**：英文 → 简体中文；简繁互转（先用 OpenCC 转，再让模型过一遍），用词和引号换成读者那边的：繁转简用大陆用词（软件、特朗普、万亿、“”），简转繁用台湾用词（軟體、川普、兆、「」）；书名、作品名、品牌只转字形。翻译要求：文体（通用、学术、文学、新闻，选一个）、领域（公共管理、数学、计算机，交叉学科的文章能选几个，都不选是通用），再加自己写的一段。一份文件里有几篇文章的，每篇单独输出；双语内容能选只留英文或都留。
- **流程**（程序排好，模型只管内容，次数基本固定；页面显示「翻译 · 第 3 / 12 块」这样的进度）：
  - **提取**：Mathpix 转出 MMD 和附件，同时把 PDF 每页画成原页图（Word 没有原页图）。
  - **切块**：程序按 Mathpix 的章节和页、按字数切出草案（大约 2～4 页一块，图表公式多的页少一些；不拆表格、公式、图和图注，尽量不跨章节），标出所有能切的地方，交 Supervisor 审定。
  - **学术论文**：程序和 Supervisor 认出标题和前置信息、作者和单位、摘要和关键词、正文各部分、结论、致谢、参考文献、附录；切块不跨这些部分。
  - **整理**：每块一次，带它那几页的原页图（Worker 是云端模型时；本地模型看不了图，只看文字；这一块只占几行的头尾页不带，免得照着图抄进别的块），对照原页改 OCR 错误、去页眉页脚、接上跨页的句子、核对表格和公式（Mathpix 常漏掉公式右边的编号，照原页图用 `\tag{1}` 补上）；只整理这一块的原文，原页图上前后块的内容不抄进来；抄进来的（哪怕只有一段）程序认得出就删掉。模型丢了钱数前的反斜杠（`\$370bn` 写成 `$370bn`，会被当成公式）时程序补回。几块同时发（默认 4，页面能改）。请求失败（断流、服务一时不可用）等 15 秒、再等 45 秒各试一次，还不行这一块改用备用模型，再不行才停下。
  - **术语表**：Supervisor 一次（只在英文 → 简体中文时），从 Mathpix 的结果挑专有名词、定好译法；和切块审定、整理同时做，不等整理完。思考最多用「低」（挑词定译法靠知识，想久了只会拖慢翻译）。回答不完整时用读得出的条目；没做成就不带术语表接着翻，记进工作日志。
  - **翻译**：每块一次，带术语表和前一块结尾的一小段，不带原页图；一块整理完、术语表也好了就开始翻，不等别的块。参考文献、附录、致谢、作者和单位默认不翻（每份文档能改），整理照做，在译文里原样放在原位置；作者和单位不翻时，论文标题照翻，`\author{}` 里的作者和单位程序保证照原文（模型译了也换回来）。简繁互转不要术语表。程序还会顺手修掉模型常出的小毛病：丢了的 `\$`、`\%`（`%` 在 MMD 里会把后面的图注当成注释）补回，原文没有的网址链接只留文字，零宽字符删掉，英译中时混进的繁体字换成简体字。
  - **只翻译**（MD、MMD、TXT）：不整理，直接切块翻译；输出只有译文、术语表和工作日志。
  - **通读**：Supervisor 最后一次，只找跨块的问题（术语不一致、标题编号、块与块之间断开的句子），顺带改掉程序找出的、夹在中文里的英文词（可能漏译），给出「改哪里、改成什么」，程序照改（要改的那段在全文里只出现一次才改；不翻的部分不改，说明里也告诉它哪些是故意不翻的），没改的写进工作日志。它看不到原文，同一块里的不同译法不去统一。只有一块（或每篇文章都只有一块）、也没有漏译的英文词时不做。
  - **精修**：页面上一个开关，默认关。打开时 Supervisor 逐块审校整理（对照原页图）和翻译（对照整理稿），只挑问题、给改法，程序照改（说明里写明输出格式；把 MMD 标题改成 # 写法的改法不照改）；每块多两次请求（只整理时一次）。长论文的费用约翻倍，交作业、交稿时开，日常阅读不必开。
- **Supervisor 和 Worker**：Worker 做每块的整理和翻译；Supervisor 审定切块、定术语表、出错排查、通读、精修。页面上各选一个模型、各设思考（Supervisor 默认「高」，Worker 默认「关」；除了术语表最多「低」，Supervisor 每一步都照选的强度），再选一个备用模型（只能选云端模型，默认 DeepSeek Flash，也能选「不用」），都记住上次选的；小拾的云端和本地模型都能选做 Worker、Supervisor。Supervisor 的规则写在程序里（从 Pub2MD 的证据规则和检查清单整理），提示词页能看到实际发给两个模型的说明，自己写的那段要求两个都看。
  - **审定切块**：Supervisor 读全文（放不下时读目录和每块的开头结尾），能合并、拆开、挪分界，标出几篇文章、双语、论文的各部分，给每块写一两句交代。程序只接受落在能切的地方（跨页的句子中间隔着页码、页眉、图表时也不能切）、大小合适的改动，其余照草案，记进工作日志；列出了某篇文章却没给它分块的，程序从这篇的标题切开。
  - **出错排查**：网络出错、限流自动等一会儿再试，不找 Supervisor。程序检查不合格的块交给它，它看这块的原文（整理时带原页图）、结果和检查报告，选一种做法：带提示重做、拆成两块重做、打开思考重做、换 Supervisor 的模型来做、接受（写明原因）、停下来。每块最多找它 2 次，一份文档最多 6 次（长文档每三块一次，取多的）；还不行就停下，说明是哪一块，做完的留着，点「继续」接着做。回复长度被思考用完、没写出结果时（GLM-5.3 这类思考关不掉的模型），程序多留空间再试一次，不找 Supervisor。经 OpenRouter 或 Aliyun 用 Qwen 时，阿里云的内容审核可能拦下回答（种族、暴力、战争伤亡之类的内容；输出被拦）：被拦下的那一次（Worker 的、Supervisor 的都算）改用备用模型，工作日志写明；备用模型也被拦下或选了「不用」，就照这一步没成功处理，工作日志写明是被它拦下的。
- **程序怎么检查**：只比文字，不看图（看原页图对照内容是 Worker 和 Supervisor 的事）。被截断：接口说回复到了长度上限，或公式、表格没闭合；太短：和原文的字数比不在正常范围；丢东西：数 MMD 里的公式（钱数前的 `\$` 不算）、表格、图片、脚注、标题，前后对比，章节标题（`\section`）少一个也算；整理时还对标题和段落开头：原文连着两段以上在结果里找不到算漏了；原文没有的标题、连着两段以上原文没有的段落算多了（照原页图抄了别的块），多出来的在结果头尾时程序直接删掉，剩下的过了检查就不找 Supervisor；模型编出原文没有的图片地址，程序删掉那一行；结果里混进给模型的说明（「【这一块】」这类标记）也算没过，模型先把说明照写一遍再答的，程序只留它的回答；输出 MMD 时标题写法要和原文一样（`\section` 不能改成 `#`）；翻译时公式里的 LaTeX、数字、引用编号要原样都在；语言：只数正文里中文字的比例（公式、表格、图片、网址、LaTeX 命令不算）；段落：译文的段落数要和原文对上，每段的字数比不能比这一块平常的少太多（少四分之一就算；60 个词以下的短段要少一半，或少四成且句数（。！？）也比原文少；译文的数字也算字数），报告写明是哪段的开头几个词。长段里只漏一句查不出来，要靠精修。
- **联网查术语**：Supervisor 查。DeepSeek（官方 Search / Fetch）、Aliyun、OpenAI、Anthropic（搜索和读网页）、Google 用各自自带的搜索，其他服务和本地模型用 Tavily。「联网查术语」开关（只在英文 → 简体中文时有）：Supervisor 的服务有自带搜索时默认开，没有时默认关（打开就用 Tavily），关上时都不查。小拾对话里的「联网」照旧用 Tavily。
- **输出**：默认存到「下载」，能换（记住上次的）。每份文档一个子文件夹（如「Attention is All You Need · 2026-10-21」）：原文.mmd（Mathpix 识别的结果，图片指向 assets/）、assets/（附件）、Mathpix 原始结果.zip、整理稿.mmd 或 .md（几篇文章就一篇一个：「整理稿 1 · 标题」）、译文和术语表、工作日志.md（设置、模型、每块的页、部分、请求次数、用时、Supervisor 的交代和经过）。同样的文件再放进来，用上次留下的 Mathpix 原始结果，不再上传。**另存为**：页面上勾 Word、PDF、LaTeX、HTML（默认 Word），处理的最后一步把整理稿和译文（只提取时是原文）交给 Mathpix 转，所以整理稿和译文也会上传给它；LaTeX 和 HTML 是带图片的 zip。图片用 Mathpix 识别时给的链接，提取后 30 天内有效：超过 30 天的、本机的图片进不去，工作日志里写明；转不成不算出错，MMD 结果照样在。处理中的文件放在子文件夹里的隐藏文件夹，做完删掉；出错时留着，能从出错的地方继续。没有自己的数据文件夹。
- **页面**：顶部「Pub2MD · 提示词」两个标签。Pub2MD 页：选文件或拖进来；设置（做哪几步、输出格式、另存为、语言、两个模型和思考、备用模型、同时几块、精修、联网查术语、不翻的部分、输出文件夹）；进度（哪一步、第几块、几次请求、用了多久）；「停止」和「继续」；做完打开输出文件夹、用默认程序打开结果；MMD、MD 结果点了在页面里预览（Mathpix 的显示库，和它网页上看到的一样；能切换这份文档的译文、整理稿、原文、术语表、工作日志）。提示词页：自己写的要求、文体、领域，下面是这样设置时实际发给两个模型的说明。页面最下面一栏是功能简述和测出来的模型搭配（比如 Sonnet 5.5 要开高思考）。只记住设置和最近 10 次处理（文件名、时间、输出位置，能一键打开）；正在处理的离开页面也继续，回来能看到进度。
- **Key 和云端**：Mathpix 的 App ID 和 App Key 在钥匙串，页面上填，只显示「已保存」；没填时不能选文件。不另设「发给云端」开关：选了文件、点了开始就是同意上传给 Mathpix 和选中的云端模型。
- **速度目标**（提取 + 整理 + 翻译，不开精修）：11 页的论文不超过 20 次请求、20 分钟以内；几页的一般文档 5 分钟以内；50 页、3 万词以上、图表公式多的长论文 40 分钟以内（请求次数大约每块 2 次，加 Supervisor 3 次）。

### Seeker（助手，v0.7）

- **是什么**：把 Seeker 文件夹（`~/Documents/Seeker`，我的求职资料）的主体做成小拾的助手「Seeker」，和 Translator、Pub2MD 并列；投石问路继续管投递和进度。
- **第一轮**：中文简历闭环：管理素材和写作规则 → 按 JD 选材 → 润色和组装 → 看差异、确认保存 → 按固定模板导出一页 Word。五个子页：简历、素材、网申、历史、模板与规则。简历页左选材、中间正文、右岗位与建议，窄窗口收成「选材」「助手」两个侧面板。有草稿就接着改，没有就新建（只带基本信息和教育）。
- **编辑和多选**：页首默认工作邮箱、联系电话、个人网站、工作地点（基本信息里的其他字段，比如 GitHub、个人邮箱，也带上但先隐藏），字段能自定义、显隐和排序。经历抬头分时间、名称、角色、地点，下面一行灰字「说明」（项目的概览），要点单独编辑。章节、经历、要点能拖动排序（要点只在原经历里）。拖框或勾选几行后一起删除，删章节或经历带上里面的内容，一步撤销。改简历不回写素材。
- **组装**：「增加」只追加选中且草稿里还没有的素材，不动已有正文、顺序、页首和章节名；「重新组装」从头再来（保留 JD），有草稿时先确认。技术栈那行只在勾了「纯开发岗」时默认选上。素材有了新版只在「来源差异」里提示，我决定要不要更新（更新时仍只用原来选的要点）。项目、工作超过 3 段只提醒，不拦导出。
- **版本和模型**：草稿自动保存，主动「确认版本」或成功导出才留下不变的快照；历史能看、比较、另开草稿。选材、审查润色各自选模型（不跟顶部的聊天模型），记住选择；整份审查只给建议。发给模型的规则按用途挑：共用准则每次都带，「素材润色」给润色，「整体审查」给选材和审查；已确认事实每次都带，经历档案只带和这次经历对得上的。默认不发云端，要在「模板与规则」里允许。
- **网申和投递**：网申资料单独一页，能编辑、复制，不参与选材。岗位保留所有关联过的导出，其中一份是「本次使用」（默认最近关联的，能改）；关联时记下岗位和 JD 的样子，不改投递状态和原来的简历字段。
- **规矩**：Rust 管流程、读资料、组装、导出和确认保存；模型只管选材、润色和写作，只提议，我看了差异确认才写进正文；默认只润色一轮，不自动反复改稿、不自动复审。写作规则是能改的工作流提示词，不另做 SKILL.md 加载；能用程序查的（日期、字数、条数、页数）交给程序。
- **数据**：素材、写作规则、草稿、确认稿和必要的历史都在 `picky.db`（自己的升级脚本、⌘Z、跟着导出和备份）；同一份正文只存一处，当前内容和历史分开。设置（文件夹、模型、模板）不进撤销；Word 导出和它的快照也不撤销。
- **导入 `transfer/`**：先预览再逐项确认，原文件只读。中文素材（`cn-modules/` 的基本信息、教育、技能、项目、工作、网申）、中文规则（素材润色、整体审查）、`SEEKER.md`（共用准则）、`FACTS.md`（已确认事实）、`projects/`（经历档案）会导入；英文资料、题库、归档和其他文件列在「未导入」里。同一来源再导入时只列出变了的，逐项选文件版或保留当前版。导入后由我从 Seeker 删掉原件（删前问我）。
- **Word**：模板用 `cv/cn/` 里选定的那份（一页；经历抬头「时间｜公司或项目｜职位或角色｜地点」，不写求职意向）。选模板时把姓名、联系方式、章节标题、经历抬头、教育抬头、说明、要点对应到模板里的段落（会先猜好），导出时照那一段的格式、制表位和每一栏的字体写，要点里的小标题加粗。只支持段落排版的模板（有表格、图片、域的会拒绝）。分页用本机 LibreOffice 算实际页数，只有一页才能另存；默认存进 `cv/cn/`，只新建、不覆盖；太长时提示精简，不自己缩字号、压行距、删内容。
- **以后**：自动读 Seeker 文件夹的内容，尤其是 `knowledge/` 的源文档（招聘和公司资料），需要时发给模型；`material/`（证书、证件照这些原件）怎么用到时再问。英文简历、面试题库、模拟面试和复盘见 roadmap.md。

### Work（在对话里）

对标 Claude / ChatGPT 的 Work，但保持轻量，真正难的活交给它们。不单独做页面，放进对话里：资料、追问、确认都用对话现成的，用对话现在选的模型。

- **写报告**：照常在对话里问（资料用附件、项目资料、知识库、联网）。写完的回答下面多一个「保存为 Word」：文件名（默认是回答的第一个标题，没有就用对话标题，加日期）、文件夹（记住上次的，默认「文稿」），点「保存」才存；同名不覆盖，加「 (2)」。Word 有真正的标题、列表、表格、引用和代码样式，用到的出处按编号列在文末。存好后能「打开」「在访达中显示」。
- **改文件**（Word 工具箱改 Word，文本工具箱改 Markdown、纯文本；小拾觉得需要时自己用）：能改的是这个问题的附件（点选或拖进来的，改的是原文件；粘贴的截图、从附件库选的没有原文件）、以前用「改文件…」选的那个文件，和知识库里的文件。原地读、原地写，不复制、不留备份。
  - 能改哪些文件直接告诉小拾；它按段读要改的部分（页码目录这类、文本框、空段不能改），再提议改哪几段（能删段、在一段后面加新段落）。真的提议了才有卡片，只在回答里写改法不算。一条回答改一个文件。卡片每段一个勾（默认勾上）和前后差异；「写入文件」只写勾上的，「取消」不写；写入后「打开文件」。
  - 写之前检查文件这期间有没有被改过，改过就不写。Markdown / 纯文本保留原来的换行和编码。Word 只改变了的地方：没改的字保留格式，新加的字跟着旁边的格式，图片、批注、样式不动。
  - Word 的格式也能改：加粗、斜体、下划线，段落改成标题（几级）或列表（项目符号、编号），都用文档里已有的样式（没有「标题 N」样式、没有那种列表可照着时改不了）；新加的段落照着前面那段的样子。字体、颜色、版式不改。
  - 表格当作一段（一行一行，格子用 | 隔开）：只改格子里的字和加粗、斜体、下划线，行数、每行的格数不变，空格子能填；一格里有好几段的、和上面合并的格子、表格里套表格的不能改。
  - 碰到制表符、段内换行的改动，和删掉有书签、批注、图片、分节符的段落，不放进卡片，回答里写明几段。
  - 写文件不能 ⌘Z；卡片存在对话里，导出也有。
- **新建 Word**：Word 工具箱也能新建：小拾把写好的内容（Markdown）放进卡片，写着文件名和文件夹（记住上次的，默认「文稿」），可以改名、换文件夹，点「保存」才存（同名不覆盖）；存好后「打开」「在访达中显示」。
- **读文件**（技能）：读这个问题带的附件和项目资料（小拾里存的那份）：看目录、按段号读、按字找，读到的段落标出处。资料太长放不下时，先给小拾目录和按问题挑出的段落，它再补读。
- 工具箱只提议，写进文件、存成 Word 都由我点。以后助手、定时任务也能用（现在定时任务不给）。

### 导出、空间、设置

- **导出**：小拾页导出当前版本的 Markdown，或含全部版本、附件、摘要的完整包。「设置 → 导出」的数据文件只带记忆、模板、用途预设、全局指令、项目和背景指令、定时任务；导入时全局指令、模板、记忆、定时任务整个替换，项目和预设按名称更新或新增（对话还在原来的项目里）。
- **空间管理**（「设置 → 小拾 → 空间」）：数据库和附件、资料各占多少（附件和资料不进每日备份，也不需要另外备份）；每份副本多大、被几个问题和资料用着，确认后才删（原文件不受影响，用到它的消息显示「文件已删除」，不能撤销）；没有记录的文件也能删；30 天没动过的空对话一键清理（能撤销）。
- **设置 → 小拾**：本地模型状态、向量和重排服务（各自能选模型）、搜索索引、发给云端、云端 Key 和常用模型（按服务分组，每组能折叠、记住开合，组里拖动排序）、记忆总开关。模板、预设、全局指令、记忆在小拾页的「管理」里。
- **不做**：删除单条消息、临时聊天、导入其他 App 的旧聊天、退出后恢复草稿、语音；v1.0 前不做音视频；正文字号和消息间距的设置。
