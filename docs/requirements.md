# 需求

> 已定的需求，只写现状。进度见[开发路线](roadmap.md)，表和计算规则见[数据结构](schema.md)，做法见[技术架构](architecture.md)，样子见[视觉规范](design.md)。

## 总体

- **定位**：第二大脑，个人事务都在这里管。App 一直开着，想到就记，每周整理一次，每天 5～15 分钟。最想解决：事情会忘、截止日期错过；回顾时找不到记录；录入太麻烦。适度自动（填日期、提醒、汇总），不替我做决定。
- **只在这台 Mac 上用**，手机不用。提醒在 App 里，另有几种系统通知。关窗口不退出（菜单栏留一个小柚子），⌘Q 才退出；登录时在菜单栏自动启动、不弹窗口（「设置 → 通用」能关）。
- **界面不放使用提示**，要解释的只放设置页的 (?)。**改名都就地改**（回车或点别处改好，Esc 不改），不弹窗；确认框不写大段说明。
- **删除**确认后直接删，没有废纸篓（见字如面除外）。**撤销**：⌘Z / ⌘⇧Z，最近 100 步；关掉 App、导入、恢复备份后不能撤销。
- **联网**：默认离线，只有：柚子的云端模型（填了 Key、主动选了才用）、插件库（书单 / 影单检索、联网搜索）、「添加网页」、呦呦漫游的发布（推 GitHub、读 Vercel 的上线结果）、Pub2MD（Mathpix、选中的云端模型）、一网打尽的网站图标。汇率、天气不联网。
- **导航**见「界面外框」，打开先到首页。隐藏的模块在导航、全局搜索、首页、柚子里都没有，数据还在。
- **设置**五张纸签：通用（外观、启动、通知、关于）、数据（数据目录和数据库、附件、导出与导入、备份）、柚子（本地模型、云端模型、记忆和帮手、柚子的数据）、模块（呦呦漫游、芝麻开门）、体检；点顶栏的设置回到上次那页。
- **全局搜索**（⌘K 或顶栏搜索框）：搜所有模块和柚子的对话（隐藏的模块、芝麻开门除外）。空格隔开的词都要有，不分大小写；按模块分组，每类最多 6 条，名字开头对上的在前，其余新的在前；↑↓ 选、↩ 打开。下面一组「意思相近」（见「柚子 › 搜索和出处」）。
- **数据体检**（设置的「体检」页；「设置 → 数据」写着有几条）：点一条打开那条记录，隐藏的模块不查。查：没分类的收支（知道退了哪笔的退款不算）；找不到的附件（不在这台 Mac 上或副本没了）；可能重复的书影（书名一样，不计大小写、空格、标点；作者 / 导演一样或一边没写，两边写明不一样算两部）和自建清单里同名的条目；过期 30 天以上的待办（暂停、完成的目标里的不算）；过期的证件；等回音 60 天以上的投递；90 天没记余额的账户（停用的不算）。每组最多列 100 条，写着共几条。
- **不做**：日记、习惯打卡模块、心愿单、物品管理、人情往来、健康记录、整个 App 的锁、全局标签、今日三件事、今日时间线、月度复盘、计时、快捷指令接入、浏览器剪藏、桌面小组件、豆瓣导入、拍照识别。

## 图标库、写字的框

- **图标库**：能挑图标的地方（念念不忘的标签、一步一步的分组和目标，以后的也一样）都从同一个图标库挑：自己画的界面小图标，分写和读、记号、自然和时间、生活、兴趣、工作和工具、符号几组；「不用图标」拿掉，不能填 emoji。模块的贴纸另见「图标和颜色」。
- **写字的框里右键**：边写边显示的框（念念不忘、见字如面、速记小窗、呦呦漫游的正文、写提示词的框）右键出一条纸：上面是这个框认的格式，下面是两个图标库。
  - **格式分组**：格式多的一组收成一行，停上去或点一下旁边再出一条。Markdown 的框分「文字」（加粗、斜体、删除线、行内代码、链接）、「段落」（三级标题、列表、编号列表、引用）、「插入」（代码块、分隔线）；念念不忘只有五种（加粗、高亮、下划线、列表、编号列表），不分组；见字如面见它那一节。能写柚子链接的框（念念不忘、速记小窗的笔记、见字如面）最上面一行是「柚子链接…」。
  - **柚儿园图标**（就是图标库）：点一个，图标出现在字里（存成 `:pm-名字:`），光标当它一个字，退格整个删掉；Pomelo 里显示这段字的地方（笔记卡片、首页便签、待办标题这类）都画成图标。
  - **网站图标**：个人网站的 24 个内容图标，写进 `:名字:`，只有网站显示成图，Pomelo 里就是这几个字。
- **呦呦漫游的纯文字栏**（关于我、职业）：网站会画图标的栏，右键只有「网站图标」（网站不认 Markdown 和柚儿园图标）；网站当纯文字用的栏（联系邮箱、页面开头摘要、时间段、模块标题）没有。

## 界面外框

样子见 `design.md`「外框」。

- **整体**：横贯窗口的顶栏，下面是桌面。首页摆在桌上；打开的模块是桌上的一张纸，别的开着的页叠在右边、露出纸边和贴纸，点露出的地方就换过去。模块里面的布局不变。
- **顶栏**：左起红黄绿、柚子（开柚子瓣）、‹ ›，在纸上时多「回桌面」；右边「桌上开着」（每页一张小贴纸，点了换过去、× 关掉）、「＋」、日期（窗口窄时不显示）、搜索（⌘K，只搜记录）、设置、柚子小窗（⌘J；在柚子页或柚子隐藏时点不了）。图标和红黄绿在同一条中线上。
- **开着的页**：一个模块一页，记住停在哪个子页。从导航（贴纸簿、柚子瓣、「常用」、搜索结果）打开：开着的拿到最前，没开的新开；页面里的链接在本页走。「＋」出贴纸簿。首页不算一页，「回桌面」只把纸挪开。纸右边最多露 4 页，其余在「桌上开着」里。换过去时重新打开（不留滚动位置和面板）。⌘Q 后再开，上次开着的页都在（先显示桌面）。
- **子页纸签**：有子页的模块（钱来钱往、投石问路、呦呦漫游、Seeker、Rater、Translator、Pub2MD、DevJanitor、设置）子页插在纸的上边，页面里不另放分段。
- **前进后退**：最近 50 步；换页、进模块、换子页算一步，打开记录、回桌面、开柚子瓣 / 贴纸簿 / 搜索、关页不算；退到已关的页时回桌面。‹ ›、鼠标侧键、⌘[ ⌘]、⌘← ⌘→（输入框里不算）都行；右键 ‹ › 列出走过的页。
- **快捷键**（都在 Mac 菜单栏的「页签」菜单）：⌘T 新开一页（出贴纸簿）、⌘W 关最前面的页（关窗口 ⇧⌘W）、⌃Tab / ⌃⇧Tab 或 ⌘⇧] / ⌘⇧[ 下一页 / 上一页、⌘1 桌面、⌘2 贴纸簿、⌘3～⌘9 第几个置顶的、⌘, 设置。全局的只有速记小窗的 ⌥Space。
- **速记小窗**（任何 App 里按 ⌥Space，Pomelo 在后台开着就行）：记笔记、记待办（进一步一步，默认今天，记住上次的分组）、问柚子、翻译。能拉大，浮在最上面，每个桌面和全屏 App 上都能呼出。⌘↩ 记下并清空，旁边一会儿有「撤销」（主窗口 ⌘Z 也行）。Esc 存草稿再收起；点到别的窗口自动收起（图钉切成不收起）；收起后回到原来的 App。和主窗口共用数据库、撤销和菜单栏的柚子（菜单里有「速记」，⌥Space 被别的 App 占了时写明）。隐藏的模块（念念不忘、一步一步、柚子、Translator）不出现。
  - 笔记和念念不忘同一种格式，能打 `[[`、加附件、粘贴截图。「存为 .md」存成我选的 Markdown 文件，不记进念念不忘、草稿留着；附件复制到同一文件夹、在文末链接，++下划线++ 写成 <u>，其余照写。
  - 草稿（文字、附件、待办的日期和分组、问的话）随打随存，退出再开还在，不进撤销和导出；「清理没用到的附件」不删草稿里的。
  - 问柚子：能接着问；用柚子页选的模型（这里也能换）和记忆，能查数据、提议记录（卡片在小窗里确认），不带附件、知识库和页面。不进对话列表和搜索；「新对话」直接扔掉，「在 Pomelo 里继续对话」变成普通对话、在柚子页打开。
  - 翻译就是 Translator（同一份设置和「上一次」，提示词在它的页面改），同时只翻一份，收起也接着翻；↩ 或 ⌘↩ 翻译，⇧↩ 换行；再呼出时原文全选，粘贴就换掉。
- **常用**（桌面最下面一排）：置顶的模块，最后是贴纸簿；右键是它的菜单。
- **贴纸簿**（代码里叫 dock）：所有模块（自带的、自建的、柚子的助手）按分类贴着；开着的写「在桌上」；停上去看实时小字。输入框筛选、回车开第一个，对不上就问柚子（在小窗里开新对话）。点空白处或 Esc 收起。
  - 「＋ 模块」（新建五花八门或循序渐进，放进「兴趣」）、「＋ 分类」；右键分类名：改名、在这里新建、删空的分类。拖贴纸换分类，拖出簿子上边就打开。贴纸右键：置顶、隐藏、图标和颜色、移到别的分类；自建的还有「删除…」（连里面记的一起删，能撤销，开着的页跟着关）。隐藏的收在「已隐藏」。分类、置顶、隐藏都记住，不进撤销。
  - **图标和颜色**：每个模块（柚子除外）能挑一张画好的贴纸和一种分类色（薄荷、樱粉、葡萄紫、橙、天蓝），「恢复默认」回到它自己的；这也是模块的颜色（页头、页签、搜索里的小图标）。自建模块新建时就挑，默认用那张贴纸自己的颜色。柚子瓣里只看贴纸，所以同一张贴纸配同一种颜色只给一个模块：别人在用的变淡、点不了（停上去写着谁在用）；自建模块默认的撞了，自动换下一种没人用的颜色。不进撤销；模块删了一起删。
  - **默认分类**（各一种分类色）：日常（一步一步、念念不忘、见字如面、来日方长、钱来钱往、出门走走）、兴趣（摸鱼读读、好奇看看、玩物有志、随意画画、呦呦漫游、有板有眼；没分类的自建模块也放这里）、求职（投石问路、Seeker、Rater）、柚子（柚子、Translator、Pub2MD、Importer、Atlas）、工具（芝麻开门、一网打尽、DevJanitor）；置顶一步一步、念念不忘、投石问路、Seeker、柚子。
  - **实时小字**：一步一步「今天 N 件」（今天要做的和过期的）；念念不忘「今天 N 条」，今天没写就「共 N 条」；来日方长最近的日子「妈妈生日 5 天」；钱来钱往「本月 N 笔」；出门走走下一次出行「东京 11 / 08」；书影游「在读 / 在看 / 在玩 N」，没有就「想读 / 想看 / 想玩 N」；随意画画「完成 / 全部 节」；投石问路「该跟进 N」，没有就「进行中 N」或「共 N 个」；芝麻开门「已锁上 / 已打开」；柚子「N 个对话」，在写时「正在写…」；Translator 目标语言；Pub2MD「N 份在做」；Importer「待核对 N」；Seeker「有草稿」；DevJanitor「可清 N GB」；一网打尽「N 个网址」；五花八门「N 条」、循序渐进「完成 / 全部」。没什么可说的就空着；呦呦漫游不写（要跑 git）。
- **柚子瓣**：点顶栏的柚子，像剥开的柚子展开：每瓣一个分类，模块排在瓣上，中间输入框同贴纸簿。能拖着转、拖动换分类、点瓣名改名、加分类、看已隐藏；和贴纸簿共用分类、置顶、隐藏；调整时原地更新、保持打开。点空白处或 Esc 收起。
- **柚子的表情**：我画的平常、在想、开心、出错，加眨眼、哇、困了、担心，带轻微的动画（呼吸；眨眼、叶子摆、光点浮起；弹跳、闪光；摇头、红色「!」），系统开了「减少动态效果」就不动。鼠标移上去眨眼或「哇」。
  - 平时：今日简报写好后一小时里用简报的心情（轻松、一般 → 平常，很忙 → 在想，有好消息 → 开心，有烦心事 → 担心），其余时候每小时从平常、眨眼、哇、开心里随机换；23 点到 6 点困了。
  - 报状态（优先于心情）：在写（对话、小窗、定时任务）→ 在想；写好 → 开心一会儿，不在柚子页时冒一句「柚子写好了」；出错 → 出错并冒一句话，点柚子清掉（每天的自动备份没成功、呦呦漫游的发布没成功或网站没上线、Pub2MD 有一份没做完，离开那页也报）。
- **助手当模块**：Translator、Pub2MD、Seeker、Rater、DevJanitor、Atlas 在贴纸簿、常用、柚子瓣里和别的模块一样（能分类、置顶、隐藏，名字旁一个小柚子），打开是整页工作台；数据和代码在柚子里，隐藏柚子时一起隐藏。Importer 也在贴纸簿里，没有自己的页面，点了到「钱来钱往 · 导入账单」。

## 附件（笔记、任务、目标）

- 图片显示小图，点开看大图；PDF 和其他文件显示文件名，点了用默认程序打开。不做录音。
- 加附件时存一份副本（同样的内容只存一份），原文件删了不影响。不进每日备份（交给 Time Machine 这类工具），导出的数据文件里只有名字；「设置 → 数据 → 附件」看占多少、清理没用到的。柚子的附件和资料另存（「设置 → 柚子 → 空间」），两边不共用。

## 待办「一步一步」（参考目标地图 GoalMap）

- **结构**：分组（一层）→ 目标 → 任务 → 多级子任务；零散的任务直接放在分组里。不要标签、优先级、情境。分组和目标能从图标库挑图标。
- **目标**：起止时间；状态（进行中、暂停、已完成）；进度按完成的任务自动算；完成后写复盘；不要的直接删。
- **子任务**多层、能折叠，全部完成时上一层自动勾上。
- **时间**：不设，或一个时间段（开始可不填），时间段内每天都在「今天」；过期的标红、留在原来的日期。没有「计划哪天做」。
- **完成后**收进「已完成」并记下时间；分组页里已完成的目标和任务收在「已完成 N」。
- **视图**：今天（默认）、按分组 / 目标、月历、回看（周 / 月 / 年 / 全部：柱状图、按分组排行、合计和日均，下面是清单）。拖动排序。
- **任务栏**只有标题和紧跟的截止日期（2026 / 10 / 03），有子任务的最右边「1/3 ⌄」；不标分组，目标前没有图标。
- **每条记**：标题、内容（多行，能加粗）、链接（网址或本机文件）。⌘N 新任务，今天页能快速添加。
- **四种任务**（后三种不能有子任务）：
  - **普通**：做完勾掉。
  - **重复**：按规则推算每次的日子，勾掉跳到下一次，能「跳过这次」。规则：每天、每周几天、每月几号（可多选）、每年某月某日（可隔几年）、每隔几天或几周，都能填共几次（可不限）和已做几次；或完成后再过几天 / 周 / 月 / 年（从做完那天算）。今天勾掉的那次在「今天完成了」和首页「今天的待办」里显示勾上、划掉，不写下一次的日期。
  - **打卡**：每天或每周固定几天，时间不设或一个时间段；该打的日子出现在今天；面板里有月历，能补打，显示连续天数；时间段里该打的都打了或时间段结束，自动完成。
  - **进度条**：目标数量和单位（「今年读 20 本」），可设时间段；点圆圈 +1，面板里记任意数量；达到目标自动完成。
- **来自笔记**：念念不忘转来的任务，面板里「来自笔记」点了回到那条笔记。
- 不要：备忘、每周回顾、和求职联动。

## 书影「摸鱼读读」「好奇看看」· 画画 · 出行

- **书影**：名称、作者 / 导演、国家、类型（可自己改）、状态、尝尝咸淡（1～5 星）、完成时间（只记年）、备注。已读 / 已看的能在面板里一次次加「重读」/「重看」（哪一年 + 几颗星），表格的完成时间和排序按最近一次。
- **随意画画**：课程 → 课节（编号、类型、课名、状态未开始 / 进行中 / 已完成、完成时间到年月、备注），新课节默认未开始。
- **出门走走**：场景模板 + 每次出行；新出行的清单从模板、以前的某次出行（物品都变回没装）或空白开始。
- 课程、课节、模板、物品都能拖动排序，筛选时也能。
- 不做：封面、自动填信息（只有手动点的柚子「补全」）、读书进度、标签、长篇读后感、绘画作品图和学习时长、出行归档对比、导出 CSV。

## 记账「钱来钱往」

- **最重要**：看总资产怎么变，管好订阅和固定支出；也看钱花在哪、每月分类预算、投资。每周或每月集中整理一次。
- **三页**：收支（明细 + 固定支出）· 资产（账户、余额、汇率、持仓、总资产曲线）· 报表（月 / 年：分类占比、每月趋势、预算；「资产」：账户和持仓的曲线）。
- **币种**：人民币、新加坡元、港币、美元分开记、不换算，报表也分币种；只有总资产按汇率折成人民币。
- **一笔记录**：支出 / 收入、金额、币种、日期、分类（一层，可自己改）、备注。不挂账户：收支和资产各管各的，才能分别设「发给云端」。
- **记多细**：逐笔记，多数靠导入账单。
- **明细**：按任意起止日期筛选；表格里点分类就换，分类筛选里管理分类；多选（按钮、⌘ 点、⇧ 点）后批量改分类（同是支出或收入时）、改币种（数字不变）、删除。
- **导入账单**（柚子的助手 **Importer**；钱来钱往隐藏时它也隐藏）：读账单的是模型，程序只交文件、检查它给的值。支付宝、微信的 Excel，银行的 PDF，Wise、工行等的截图都行；一次可选几个文件，一个文件一份账单。
  - **模型和清单**（只在这页调）：从常用云端模型里选（记住上次的），思考默认关；点「导入」就发。收支不发给云端或没有云端模型时，「导入」「再整理」变灰并写明原因（已导入的照样能核对、入账）。**提示词清单**：我写的要点一行一条（点文字改，清空即删），打勾的生效、都记住；读账单、再整理、查重时排成 Markdown 列表放在「我的要求（优先于上面的做法）」下面（如：Steam 的明细备注统一写「Steam 充值」）。
  - **模型定什么**：每笔的日期、金额、币种、算作（支出、收入、退款、不计收支）、分类（只用已有的）、备注（不超过 80 字），拿不准的写疑点（要我核对什么）。图上没月份时，有星期几就推最近对得上的月份并注明，否则留空；日期在今天之后的标疑点。程序只挡格式不对的那一笔（留空或先按支出、人民币，并标疑点）。Excel 漏掉的行再问一次，还漏就留一行写明，不悄悄丢。
  - **查重**：每一笔和前后 7 天的已有记录对（手记、固定支出、账单入账，和更早导入没入账的行）。同时满足才合并：模型说是同一笔、同金额同币种、日期够近（和手记、固定支出 7 天内，和别的账单 3 天内）、付款渠道不矛盾（支付宝、微信看账单本身，银行看摘要里的「支付宝-」「财付通-」，手记看备注；两边都看得出又不同算不同）、和手记的分类不矛盾。其余的和拿不准的写明理由列成「可能记过」，点「是这笔」就并。程序另把同金额、7 天内的列成候选，没决定的不让入账（模型或我说「不是重复」都算决定）。
  - **核对**：先进「待核对」，确认了才入账；能补一笔、忽略误识别，点开一行对照原图。原件只读、不存副本，原图只在 App 开着时留在内存里（重开后能「选原图」）。
  - **勾选**：表头全选（当前筛出来的）、⇧ 点连选、⌘ 点勾一行、按住往下拖勾一片。勾了能「改分类」（都是支出 / 退款或都是收入时；不计收支和已关联原支出的退款不动；一步 ⌘Z）、「再整理」「入账」（只做勾的）。
  - **再整理**（改了清单后）：模型按原文重做没保存过的行（勾了只做勾的），补空着的日期，判断上次的疑点（能定就划掉写依据，否则写要核对什么），再查一遍重；我保存过的行、批量改的分类、自己定的重复不动。
  - **账单列表**：导入过的账单入账后也留着；能拖动排序、改名（只改显示名）、删除（入账的收支留着，没入账的行一起删）。同名文件再导入先问。
  - 退款在到账那天冲减原消费的分类；自己账户之间转账、钱包充值、还信用卡不算收支，明细留着。入账前都能改，入账能撤销。
- **固定支出**（房租、话费、订阅，也可以是固定收入）：每月几号或每年哪天自动记一笔，漏掉的补上；能停用。
- **账户**：一个账户一种币，分银行、钱包、券商；能停用。不记转账和换汇。
- **更新余额**：选一天（默认今天），填各账户余额和汇率（带出上次的），总资产按每次更新的日子算。**持仓**（券商账户）：选一天，填名称、数量、单价，市值自动算。
- **报表 · 资产**：账户、持仓各一张曲线，只列报表顶上那个币种的；横轴只有更新过的日子；小标签选显示哪些（记住）。
- **预算**：按「支出分类 + 币种」设每月金额；快到变黄，超出变红并写超出多少。
- 不记：贵重物品、负债、借出和 AA、信用卡；不和出门走走关联；不额外加密。

## 求职「投石问路」

- 毕业前集中投：全职、中国大陆，一个求职季 200 个以上。只管投递和进度；简历归 Seeker，题库和面试归 Rater。岗位里能「做简历」、选公司资料、选这次用 `cv/` 里的哪份简历、打开 Rater 的面试。
- **两页**：投递（「该跟进」、按状态筛选、搜索）· 统计（几个数字、每天 / 每周投了几份、漏斗、现在的状态分布）。
- **一条记录**：公司、岗位、地点、渠道（可自己改）、状态、JD 链接、简历（Seeker 里的文件，能选、能点开）、备注。
- **状态**：默认想投、已投递、网申测评 / 笔试、面试、Offer、已接受、被拒，「管理状态」里改名、排序、增删。默认的各有作用：想投 = 一个没勾，已投递满 14 天提醒跟进，Offer 和已接受算拿到，被拒算结束；新加的算中间一步。时间线上用着的状态不能删。
- **时间线**（每条投递自己的）：先点选它有哪些状态（新建时除了想投、被拒都选上，被拒时再选进来），选中的按顺序排开，勾上自动填今天（能改）。现在的状态 = 最后勾上的；投递日期 = 最早勾上的那天。
- **漏斗**：已投递 → … → Offer，每一步写「勾上的 / 有这一步的」；没有这一步的、还没投的不算。
- **跟进**：在等回音的，离那一步满 14 天提醒；点「已跟进」后再过 14 天才再提醒。

## 笔记「念念不忘」（参考 Flomo）

- **定位**：想到就记的收集箱，替代 Flomo。一条笔记只有正文和记录时间。
- **标签**写在正文里：`#标签`、多级 `#一级/二级`。像 Bear 一样，设了图标的标签在正文里把 `#` 画成它的图标（自己没设就用最近一级上级的；见字如面同样）。
- **正文格式**：**加粗**、==高亮==、++下划线++、列表（`- ` / `1. `，Tab 缩进），网址能点。不在编辑时只看效果、不显示 `**` `==` 这些记号（边写边显示的框和首页便签都这样，见字如面例外）；输入框边写边显示成卡片的样子（记号还在、变淡），回车后新的一段马上空出卡片那样的段距。⌘B / ⌘U / ⌘⇧H 加格式，⌘↩ 记下；打 `#` 时光标下面提示已有标签（放不下就在上面）；列表里回车接着编号。速记小窗和以后要写字的模块都用这个输入框，呦呦漫游的正文用同一个底子。
- **页面**：最近 16 周的热力图（点某天只看那天）、「全部笔记」、置顶的标签、标签树（能折叠；同一层按拖出来的顺序，没拖过的按拼音排在后面）；笔记新的在上，置顶的最上。搜正文（几个词同时出现，也按意思找），能和标签、日期叠加。在某个标签下新建自动带上它。
- **每条笔记**：双击或「编辑」就地改；「引用」（两边都显示链接）、「置顶」、「删除」。卡片右键就是它的「⋯」（选中了字时是系统的拷贝）。太长的折起来，「展开全文」。
- **标签的「⋯」**：置顶（只有第一级；置顶的能展开子标签，标签树里不重复）；图标（任何一级都能设，点标签前的图标也能换）；改名（所有笔记里一起改，下一级、置顶、图标、顺序跟着走；改成已有的就是合并）；删除（只去掉标签：所有笔记里去掉它和子标签，笔记留着，只有这个标签的笔记不动；或连笔记一起删）。
- **拖动标签**：拖到一个标签的上半或下半 = 排到它前面或后面（换了一层就是移过去）；拖到中间 = 变成它的子标签、排在最后。移过去就是改名：笔记里一起改，同名的合并。置顶的第一级标签只在置顶里排；Esc 取消。
- **转成待办**：卡片「⋯ → 转成待办」，打开一步一步的新任务面板（标题是第一行去掉符号和标签，内容是全文，分组默认第一个），改好再保存。笔记留着，两边互相链接（笔记下面列出转成的待办，做完的划掉；任务面板里「来自笔记」）；一条笔记能转好几条。删笔记时待办留着、不再链接；导出导入时链接跟着。
- **柚子转为待办**：柚子看笔记里有几件要做的事（一件也行），每件写一张待办卡片：标题、内容、类型（普通 / 重复 / 打卡 / 进度条）和规则、次数、目标数量和单位、时间、链接、位置（分组或进行中的目标，没挑就是第一个）；笔记里的日期词按记下的那天算。先列出来（转过的不再列，默认都勾上），每张能改位置，点「加上」才加，一步 ⌘Z。
- 年度总结由柚子写（见「Atlas」）。

## 文章「见字如面」（参考 Bear）

- **定位**：写成篇的文章和长笔记，替代 Bear，做法多照 Bear（标签管文章、三栏、简洁的 Markdown、底部格式条、按标签分文件夹批量导入导出）。不做 Notion 那样的重型笔记软件，不做云端同步。念念不忘收碎片，见字如面写文章，标签各管各的。存在 Pomelo 自己的库里（附件在数据文件夹），跟着备份、导出；想用别的编辑器就导出 Markdown。
- **三栏**：左标签、中列表、右正文；两道线能拖着调宽，窗口窄时变两栏。双指往左滑一次收起标签栏、再一次收起列表，往右反过来：页面哪里滑都行（正在写的正文上也一样），不用先点；一次滑动只收一栏，连着滑、刚打完字、页面正忙时也一下一下地认。没有收起的按钮。**专心写**：占满整个窗口（顶栏也不见），只剩正文和格式条；Esc 也能退出。
- **筛选**：全部笔记、置顶、没标签的、归档、废纸篓、加密的（各写几篇），再是标签树。**标签**的写法和操作完全照念念不忘（`#父/子`、置顶、图标、改名、拖动、合并，代码共用），两个模块的标签互不相干；在某个标签下新建自动带上它。
- **列表**：加密的预览写「锁着」。搜索框搜标题和正文（几个词同时出现，也按意思找），能和左边选的叠加；「新写一篇」（废纸篓里是「清空废纸篓」，问一次）。打开模块先打开第一篇。
  - **左滑删除**：双指在一条上往左滑或鼠标按住往左拖，这条跟着手移开、露出删除，松手停在那里（滑得太少就收回）；点删除才移到废纸篓，滑多远都不直接删；点露出删除的那条是收回。要顺，跟着手指走。
  - **右键**：一条右键是置顶、导出…、归档、加密、移到废纸篓（废纸篓里是捡回来、彻底删除…；⌘ 选了几篇时是「导出选中的 N 篇…」）；标签右键同它的「⋯」（念念不忘的标签也是）。别处没有浏览器自带的菜单（后退、重新载入），只有正在写的框和选中的字保留。
- **置顶、归档、废纸篓**：置顶的排最前；归档的收起来、不删；删了先进废纸篓，能捡回来，彻底删问一次。
- **写**：边写边存（停 0.6 秒、换一篇、离开时），每次存是一步 ⌘Z；正在写的框里 ⌘Z 先撤销框里的字。新写一篇：第一行是空的一级标题、光标在那里，在某个标签下新建时第二行是这个标签；打出第一个字才存，什么都没写就不留。**输入要顺**（这个模块的核心）：中文输入法（微信输入法、系统拼音）拼字时不吞字、不跳光标；长文章里打字也不卡。
- **正文**：跟着明暗和五套配色。照 Bear 2 直接显示效果：光标在一处格式里（或紧挨着、选中的一头碰到）才露出 `**` 这些记号，移开就收起；引用、表格、代码块这种整块的，光标在那一块时才露出。标题的 `#` 不显示，左边空白里标出几级；在标题开头按 ⌫ 变回正文，换级别用 ⌥⌘1–6 或格式条的「标题」。
- **格式**（全部要做）：标题 1–6 级；加粗、斜体、下划线、删除线；高亮（含 Bear 的五种颜色）；行内代码、代码块（按语言上色）；无序、有序、待办列表；引用、分隔线、链接；互链 `[[标题]]` 和反向链接；表格（能加删行列）；图片和附件（拖进来、粘贴截图）；标题和列表折叠；脚注；提示框（`> [!NOTE]` 这类：备注、提示、重要、注意、小心五种，各一种底色，开头一个图标、不写「注意」这样的字；Word 里画不了图标就写名字）；数学公式；Mermaid 图（流程图、时序图）。写法同 Bear：标准 Markdown（CommonMark）加 Bear 的几样（`~下划线~`、`==高亮==` 和颜色、提示框、公式、Mermaid、折叠），搬过来的文章照原样显示。
- **点**：待办的框直接勾；标题、有子项的列表项左边的小箭头折叠；图片、公式、图点一下进到源文字里改；链接、互链、标签点了打开（光标所在的那行要按住 ⌘）。
- **格式条**：上面的格式加附件、全部折起来 / 展开；高亮能选颜色（默认色和 Bear 的五种）。两种模式（图钉切，设置里也能改）：一直在（不另占地方），或选中文字时才出来。
- **右键的纸**：最上面「记到念念不忘」「柚子链接…」；下面四行各一组：「文字」（加粗、斜体、下划线、删除线、高亮、行内代码、链接）、「段落」（三级标题、列表、编号列表、待办、引用）、「插入」（代码块、表格、分隔线、公式、流程图、脚注）、「提示框」（五种），光标在表格里多一组「表格」（加删行列）；再是「柚子润色」「柚子续写」和两个图标库。
- **快捷键**：照 Bear，和念念不忘冲突的照念念不忘：⌘B 加粗、⌘I 斜体、⌘U 下划线、⌘⇧E 删除线、⌘⇧H 高亮、⌘⇧C 行内代码、⌘⇧L 待办。⌘1–9 是页签、⌘K 是全局搜索，所以标题用 ⌥⌘1–6（⌥⌘0 变回正文）、链接用 ⌘⇧K。表格里 Tab / ⇧Tab 换格、↩ 加一行。
- **设置**（子页）：正文的字号、行距、段距、宽度能拖着调，默认照 Bear（17 号、行距 1.9、每行后面空 0.2 个字、空行是整整一行、宽 680），「恢复默认」回去；格式条的两种模式。改了马上换，不进撤销。
- **加密**：一篇能用芝麻开门的钥匙锁起来：芝麻开门打开（Touch ID 或主密码）就能看，芝麻开门锁上（5 分钟不用）时它也锁上；没设主密码时不能加密。标题和标签不加密，正文里的图片是普通附件。锁着的不进搜索，柚子看不到。
- **柚子**：和念念不忘一样进全局搜索和「意思相近」；能搜、能读、能引用，年度总结读得到。润色、续写先出确认卡片：右键「柚子润色」（选中一段）「柚子续写」（光标处），「用这段」才写进去；对话里柚子提议改哪篇，确认后一步写进去。加密的、废纸篓里的除外。
- **从 Bear 搬家**（设置子页）：用 Bear 自带的命令行 `bearcli` 只读、一次导完，不做「导入新的」，Bear 那边什么都不动。先列出有多少篇、标签、附件，点「搬过来」才搬；大半已经在这里就不让再搬。搬之前留一份「导入前」备份，整次一步 ⌘Z。
  - 正文原样（还没支持的写法照原文显示）；标签、写的和改的时间、置顶、归档都带上，Bear 废纸篓里的进废纸篓；图片换成 Pomelo 的附件（正文里没写到的接在最后）；`[[互链]]` 按标题对上，Bear 的转义（`[[A\&B]]`、`[[A \| B]]`）照 Bear 认。
  - Bear 的折叠（行尾的 `<!-- {"fold":true} -->`）留在正文里：打开时那一处折着，光标在那行才露出记号；在这里展开、折起不改正文。
  - 标签不分大小写：只差大小写的算同一个，正文里统一成 Bear 左栏的写法（`#nus-iss/asd` → `#NUS-ISS/asd`）。
  - 要搬全：搬完列出带不过来的（加密的，命令行读不出来）、认不出的标签、找不到同名一篇的互链、改了写法的标签。
- **别的导入**（设置子页「导入 Markdown、TextBundle」）：「文件…」（.md、.markdown、.txt、.textbundle、.textpack，能多选）和「文件夹…」。选的文件夹本身不算标签，子文件夹变标签（`读书/小说/x.md` → `#读书/小说`，写在第二行；正文已有这个标签或它的子标签就不加）；相对路径链到的图片和文件变成附件；写的和改的时间取文件的；没标题的用文件名做一级标题。别的文件不导入，列出来。整次一步 ⌘Z。
- **导出**：一篇、选中的几篇（⌘ 点、⇧ 点选，Esc 放开）、一个标签（标签的「⋯」）、全部（设置子页，含归档、不含废纸篓）；Markdown、PDF、Word（.docx）。
  - **弹窗**：格式、样式（PDF 和 Word 才有）、印上（目录、页眉和页码、标签和日期，各自能勾）、存到（默认「下载 / 见字如面」），都记住上次的。导出完在访达里显示，没导出的列出来（附件不在这台 Mac 上的；加密的只在芝麻开门开着时导出明文，锁着就跳过）。
  - **放哪、叫什么**：只导一篇时直接放进选的文件夹；几篇按标签分文件夹，有好几个标签时放第一个标签最深的那一级（有 `#读书` 和 `#读书/小说` 只放「读书/小说」；两个不相干的放正文里先出现的那个），不重复。名字是标题（`/` `:` 换成 `-`），同名的加 2、3，不覆盖已有的文件。每篇旁边一个同名文件夹装附件原文件（不和标签文件夹同名），Markdown 里用相对路径，整个文件夹拷走照样能打开。
  - **Markdown**：正文原样（Bear 的写法、折叠记号、互链、标签都留着），只把附件链接改成相对路径。
  - **PDF**：A4，两种样式：柚儿园（像从 Pomelo 里印出来）和印刷（白纸、宋体正文、黑体标题），样子由 visual-atelier 出。折叠的全部展开印。第一页上面是标题（柚儿园贴见字如面的贴纸），勾了就写日期和标签，再下面是目录（带页码，点了跳过去）；第二页起页眉左边标题、右边「见字如面」，每页页脚是页码。正文里的标签不印。带书签（各级标题）。
  - **Word**：字体、字号、颜色照 PDF 的两种样式（柚儿园带纸色）；目录是 Word 自己的（打开时 Word 问要不要更新，更新后带页码）；页眉、页码同 PDF；公式和流程图是图片，HEIC 这类 Word 打不开的图转成 JPEG。

## 跨模块联动「柚子链接」

- **是什么**：念念不忘、见字如面、摸鱼读读、好奇看看、玩物有志之间能互相链接（很多笔记和文章就是读后感、观后感、玩后感）。标签各管各的。链到 Pomelo 里的东西都用柚子链接色（和网址的链接色分开）。规则见 `schema.md`「柚子链接（跨模块联动）」。
- **三种写法**（存成一样的文字，按名字认，导出的 Markdown 看得懂）：
  - `[[目标]]`：一个小卡（模块的小贴纸 + 名字），点了打开那篇文章、那条笔记、那本书、那部片、那个游戏。在念念不忘或见字如面里打 `[[`，光标下面出提示：每行小贴纸、名字和一行淡墨（书写作者、影写导演、游戏写平台和状态、文章和笔记写日期），各类混排、按对得上的程度排，最多 6 条；隐藏的模块不在里面。
  - `[[目标|字]]`：给选中的字加柚子链接（字是柚子链接色、下面一道虚线）。选一段右键「柚子链接…」（见字如面、念念不忘、速记小窗的笔记），找一篇、一条或一本，选中的字就链过去（没选字就放一个小卡）。Bear 搬来的 `[[标题|别名]]` 就是这种。
  - `![[念念不忘/…]]`（只在见字如面，单独一段）：把一条笔记嵌进文章，画成一张笔记小卡（全文，右上角能去念念不忘看这条），笔记改了跟着变，删了写「这条笔记不在了」；光标进到这一段才露出这行字。导出 Markdown、PDF、Word 时变成一段引用。
- **目标**写成 `模块名/名字`：`摸鱼读读/夜航西飞`、`念念不忘/2026-11-02 21:14`（笔记用记下的本机时间到分钟，同一分钟有两条时加秒）；文章写标题就行（照 Bear；也认 `见字如面/标题`，后面带 `#小标题` 也行）。名字不分大小写，重名的认先加进来的。以后要链到别的东西，给它定一个模块名就行。
- **改名**：书影游改名时，链到它的笔记和文章（加密的除外）一起改，同一步 ⌘Z；还有同名的另一个时不改。文章改标题、笔记不跟着改（照 Bear）。
- **「柚子链接」一栏**：文章、念念不忘的卡片、书影游的面板都列出链到这里的文章和笔记（新的在前；念念不忘的还算引用它的笔记）。书影游那栏能「记一条」：弹出念念不忘的输入框，开头已是链到这一部的小卡，记下就出现在这一栏（念念不忘隐藏时没有）。文章里链到笔记的小卡写那条笔记的时间，停上去看得到开头。加密的文章读不到正文，不算链到别处；被链到时只显示标题。
- **记到念念不忘**：文章里选一段，右键「记到念念不忘」弹出念念不忘的输入框：选的字已填好，下一行「来自 [[这篇]]」，光标在最后，接着打 #标签，「记下」存好。这条笔记链到这篇。
- **书架**（写文章时翻笔记）：能搜、按标签筛笔记；打开时标签栏收起，关掉放回来。按住一张拖进正文（落在段落之间，不落进表格、代码、引用中间），松手就成了嵌进来的小卡。
- 删了一边，另一边的链接写「找不到」；都能 ⌘Z；导出导入、备份带着链接（就是正文里的字）。
- 不做：几条笔记攒成一篇文章；单独的书摘（读书时摘的句子记成念念不忘的笔记、链到那本书）。

## 重要日期「来日方长」（参考 Days Matter）

- **三种**：纪念日和倒数日（不重复、每年、每月、每周）；生日（每年；出生年份可不填，填了显示几岁；「礼物点子」和「送过的」，每行年份和礼物，新的在上）；证件（只记名称和到期日，不记号码和照片）。不要农历。
- **怎么算**：「还有 N 天」或「已经 N 天」，重复的数到下一次（当天写「今天」），每年的纪念日写「第 N 周年」，过期证件写「已过期 N 天」。2 月 29 日在平年算 2 月 28 日，每月 31 号在小月算月底。
- **页面**：在哪个分类（全部 · 纪念日 · 生日 · 证件）下新建就是哪一种；置顶最多一条；排序：过期的证件在前，再按还有几天，已经过去的放最后。
- **提醒**：每条自己选提前几天（当天、1、3、7、14、30、60、90 天前，最多 5 个；新建时纪念日和生日默认 7 天前，证件 30 天和 7 天前）。首页「快到的日子」从最早的提醒那天显示到当天，过期证件一直显示到改了为止；今日简报只在提醒的那几天和当天提。不自动生成待办。
- **柚子**能查快到的和全部日子，不能写；证件只读名称和到期日，备注不读、不进按意思搜索。

## 游戏「玩物有志」

- **正式模块**，和摸鱼读读、好奇看看同一套表格和面板，不能删，只能隐藏。
- **表格**：完成写最近一次的年份，周目写一共几周目；状态想玩 · 在玩 · 通关（颜色照书影）；类型点一下就换。搜名称、平台、国家、备注，能按状态、类型、平台筛。
- **平台**像类型一样能加、改名、排序、删除（「管理平台…」），一开始有 Switch、PS5、PC、手机；删掉后那些游戏的平台变成没填。
- **面板**同书影，名称旁 ✦ 补全国家和类型。**周目**照「重读」：一周目是游戏本身的完成年份，二周目起每次记年份和几颗星。新游戏默认想玩；变成通关时没填年份就填今年。
- **搬到玩物有志**（五花八门清单的「⋯」）：把条目整个搬进来，字段按名字对上（类型、平台、国家、状态、尝尝咸淡 / 评分、完成 / 完成年份、备注），对不上的写进备注（「字段：值」）；想玩、在玩、通关以外的状态也写进备注，「常青」算在玩；没有的类型、平台自动加上。确认框写清哪些字段改了名、哪些进备注；搬完删掉清单，一步 ⌘Z。
- 柚子能查（同书影：口味、列表、统计）、能「补全」；全局搜索能搜到；每月回顾提到通关的游戏（内置提示词没改过才自动加上）。不上首页。

## 五花八门 · 循序渐进（做模块的模板）

- **是模板，不是模块**：贴纸簿里右键分类名「在这里新建」五花八门（清单）或循序渐进（进度），填名称（不能重名）、挑图标和颜色。建出来的每一个（比如「游戏」「日语」）都是一个模块，能分类、置顶、隐藏。标题右边「⋯」：改名和图标（循序渐进还能改叫法）、管理字段（五花八门）、删除（连里面的一起删，能 ⌘Z）。摸鱼读读、好奇看看、随意画画是专门的模块，不用模板。
- **五花八门**（通用清单）：每条有「名称」，再加最多 20 个字段：文字、长文字、数字、年份、单选、多选、勾选、评分（1～5）、链接；建好后不能换类型。
  - 表格里是名称和选了「表格里显示」的字段；点表头排序（第三下恢复）；搜索名称和文字；能筛选的字段各一个下拉（选项、勾选的是 / 否、评分几星以上），能叠着筛；没排序、没筛选时拖动换顺序。
  - 勾选、评分、单选、多选在表格里点一下就改（多选能连勾几个，清空在面板里）。选项按顺序自动配色，不能自己选。
  - 「管理字段」：加、改名、拖动、选显示、删除；选项改名、删除跟着改每一条。
- **循序渐进**（通用进度）：像随意画画的「课程 → 课节」两层：课程有进度条，课节有编号、名称、类型、状态、完成月份、备注（圆圈一键完成），「下一节」，按最近 6 个月的速度预计哪个月完成。
  - **类型**：每个模块自己一组（「⋯ → 管理类型…」里加、改名、排序、删除；删掉的那些节变「未分类」），按顺序配色，表格里点一下就换，能筛选。
  - 两层的叫法建的时候填（默认课程 / 课节，比如「季 / 集」），以后能改，页面、按钮、撤销提示都跟着。它管有固定章节的东西；要达成的事用待办的目标。
- **柚子、搜索、导出**：每个都按单独一个模块算，隐藏、「发给云端」各管各的。柚子能查清单和条目、进度和每一节，不能改；全局搜索能搜到条目、课程和课节。导出的数据文件里都有；导入时整个替换（导航位置、隐藏、云端设置不跟着）。

## 密码「芝麻开门」

- 管一般的密码（网站、App 账号），不放银行卡密码这类；手动录入。
- **每条**：名称（必填）、分类、链接、用户名、账号、密码（能显示、能随机生成：三组字母，带一个大写和一个数字）、备注。
- **分类**：每条最多一个；「管理分类」里增删改、排序（分类名也加密）；删分类，那些密码变「未分类」；在某个分类下新建自动带上。
- **归档**：几乎不用的在面板里「归档」，只在「归档」里看得到，搜索照样能搜到（标「已归档」）；「取消归档」回原处。
- **列表**：按分类看（全部、各分类、未分类、归档）。密码在列表里只显示圆点；能复制，30 秒后从剪贴板清掉，剪贴板工具也不记。按名称排，能拖动调顺序（搜索时不能）；搜索只搜当前这一类（含归档的）。
- **主密码**：自己设（至少 8 个字符），Pomelo 不保存；更新 App 不丢；修改要先输原来的；忘了就打不开。
- **打开**：平时 Touch ID（进这一页自动弹出）；指纹 3 次没对上、距上次输主密码满 3 天、App 更新后第一次，要输主密码。**自动锁**：5 分钟没碰 App（睡眠也算）、手动「锁上」、恢复备份后。
- **任何 AI 都读不到**：加密后才存（备份里也是密文），导出文件里没有，全局搜索不搜，柚子没有读它的命令。安全设计见 `architecture.md`「芝麻开门的安全」。

## 网址收藏夹「一网打尽」

- **是什么**：常用网址的收藏夹，像 Edge 的收藏夹管理；只在柚儿园里管，不和浏览器同步。
- **页面**：文件夹树（展开收起记住；「新文件夹」加在第一层）和选中文件夹里的东西（默认上次看的，没有就第一个），文件夹和网址按自己的顺序混排。⌘N 新网址，⌘F 搜索。
- **点**：网址在默认浏览器打开，文件夹点进去。右键或「⋯」：在浏览器打开、编辑（文件夹是改名）、放首页、移到…、删除。
- **分层**：网址都在文件夹里，第一层只有文件夹（「移到…」只有文件夹能选「最外层」）。文件夹能套任意层；删文件夹连里面的一起删（确认时写明有几个网址）。
- **拖动**：拖到别的行之间换顺序；拖到文件夹上（列表里、树里、路径上的）就移进去、放在最后。树里的文件夹拖到上下边换顺序（换了一层就是移过去），拖到中间就移进去；网址拖到树上总是移进去。新加的放最后。
- **多选**：点选择圈（或 ⌘ 点、⇧ 点选一段）后能一起打开、移到…、删除；这时点一行是选它，拖动时选中的一起走；换文件夹、搜索时清掉。
- **网址**：只收 http 和 https，没写 https:// 自动加上；不写名称就用网站的地址。
- **网站图标**：加网址后从网站本身取一次（不经过第三方，怎么取见 `architecture.md`「模块之间」），存在本机，取不到显示首字母。是缓存，不进备份和导出，删了重新取；开发版和测试不联网，只显示首字母。
- **搜索**：在所有文件夹里按名称、网址、文件夹名找（几个词都要有），结果写着在哪个文件夹；能拖到文件夹上，不能排序。
- **别处**：⌘K 能搜到网址和文件夹，回车打开那个文件夹、那一条闪一下；首页「一网打尽」放标了「放首页」的网址；柚子能查（只读）；导出的数据文件里有，导入时整个替换。

## 首页（桌面）

样子见 `design.md`「首页（桌面）」。

- **桌面**：比窗口宽一倍，左右两屏。按住空白处左右拖（松手接着滑一会儿），触控板横着滑也行；窗口矮时也能上下拖；右下两个点是左右两边，点了滑过去。每一块是一张便签：能拖能甩（碰到桌边弹回来），放在哪记在哪。隐藏的模块首页也没有。日期在顶栏，桌上不另写。每块标题点了进那个模块，每一行点了打开那条记录。
- **左边一屏**：问候语、柚子的今日简报（新年第一周上面还有 Atlas 的信封）、今天的待办、快到的日子（没有就不放）、在读在看、资产小票（翻过来是余额曲线）、念念不忘一条（字多了在便签里上下滚：滚轮、触控板，或按住字上下拖；点一下打开那条笔记）、今年的数字。
- **右边一屏**：本月小月历（哪天有事打点，今天画圈，点了打开日历）、今年按月（完成、笔记、画完、投出，一次看一种）、求职近况、绘画进度、最近记录、那年今日（往年的今天有记录才出现）、一网打尽（放首页的网址，没有就不放）。
- **今天的待办**：同一步一步的「今天」，过期的在前，最多 5 件、多了写「还有 N 件」，圆圈能直接勾；右上角写今天完成几件 / 一共几件。
- **今年的数字**：读完几本、看完几部、画完几节、完成几件待办、记了几条笔记、投出几份。
- **那年今日**：往年同月同日记的笔记、做完的待办和目标、那天出发的出行；一张小卡片一条（新的年份在前，先放笔记），「换一条」看下一条，点了打开；2 月 29 日只对 2 月 29 日。
- **最近记录**：最近 6 条混排：新加的笔记、书影、课程和课节、出行、投递、收支，加上勾掉的待办。
- **资产小票**：最近一次的总资产、比上次多还是少、曲线。**求职近况**：本周投了几份、进行中、拿到，下面是该跟进的和笔试面试中的（最多 6 条）。**绘画进度**：没画完的课程，进度条和「下一节」（点了打开）。
- **不要**：7 天内到期、本月花费和预算、出行打包、天气、问候语下面的「一句话」。

## 日历

- **是什么**：桌上小月历点开的一页，不是模块，不进贴纸簿和柚子瓣；它和设置各有一张自己的贴纸（不能换图标和颜色），开着时也在「桌上开着」里。
- 待办、日子、出行、面试放进同一张月历（规则在 `calendar.rs` 开头），只读。周一开头 6 行，每格最多 3 条，多了写「还有 N 项」；‹ › 换月、「今天」回到本月，上面四个标签选看哪几种（不记住）。点一条弹出小卡片：哪个模块、什么（截止、生日、出发…）、日期和补充，「去某模块看这一条」打开原记录。隐藏的模块不放。

## 个人网站「呦呦漫游」

- **是什么**：在 Pomelo 里编辑、发布个人网站 elenskye.com。网站是独立的项目（`~/Documents/GitHub/personal-website`，推到 GitHub 的 `main` 后 Vercel 自动上线），内容就是它文件夹里的文件；Pomelo 只记文件夹在哪（「设置 → 呦呦漫游」），不另存，不进 Pomelo 的备份、导出、⌘Z、全局搜索、首页和今日简报。做法见 `architecture.md`「呦呦漫游（个人网站）」。
- **本地预览**：没开网站的本地服务就先启动，退出 Pomelo 时停掉它自己启动的。
- **发布**：
  - 「待发布的改动」：内容按条目列（「作品《…》中文」「图片 …」），代码列文件名，点开看差异（图片看前后）；终端里提交了还没推的也列出。没有「放弃改动」，不撤回发布，不提醒。
  - 「发布…」：先从 GitHub 拉最新的（只快进；冲突或分叉就停下交给我）。确认框列出会上线的全部改动，拦下超过 1.5 MB 的图片、超过 5 MB 的其他文件；commit 文本自己写（空白开始）。确认后先跑网站的完整检查（`npm run qa`，和 Vercel 上线前的一样），没过就停下、显示出错处，什么都不提交；过了就把全部改动（内容和代码）一起提交、推到 `main`。不强推、不改 git 历史。
  - 推送后先显示「已推送」，再显示 Vercel 的上线结果。「最近发布」：最近 10 次的 commit 文本、时间、上线结果。
- **编辑**：写出的文件和网站现有写法一模一样，不认识的字段、组件原样保留；保存前文件被别处改过（编辑器、git）就不写，提示先「重新读取」；内容没变的不重写。「保存」或 ⌘S；有没保存的修改时换条目、换页先问。作品、Now、关于我、职业页都分「中文 · English · 并排」。
  - **作品**（Wander）：能按类别、语言、年月筛选，标出缺哪种语言（并排时列表收起，记住上次选的）。中英两份文件的共用字段（类别、话题、年月、封面、画廊、slug）一起写，标题、摘要、正文、图片描述各写各的；缺一种语言时能「新建英文版 / 中文版」（共用字段照另一版）。「⋯」：重新读取、改 slug…（两份一起改，图片不动）、删除作品…（图片留着）。「新作品」：选语言，填标题和 slug（小写英文、数字、短横线），年月默认这个月。
  - **画廊**：每张图中英各自的图片描述和图注，能调顺序、移出；要么没有，要么至少两张（网站的检查要求）。**封面**：选择、从资源库挑、移除或拖进来。
  - **正文**：和念念不忘一样边写边显示（标题、加粗、斜体、代码、删除线、引用、列表、链接、表格、Markdoc 组件；只有一张图的那一行下面显示小图）；↩ 接着列表和引用，Tab / ⇧Tab 调层级，⌘B / ⌘I，自己的 ⌘Z。插图：选文件、从资源库挑、拖进来或粘贴截图。右键「网站图标」插入 `:名字:`（这套图从网站的方案同步来，Pomelo 自己的界面不用）；frontmatter 的文字字段（比如职业页按钮的字）手写 `:名字:`。
  - **预览**：先保存，再在 Pomelo 的预览窗口里打开本地网站的这一页（当前的语言）。
  - **Now**：当下状态（中英各一句，单独保存）；一个月一篇（标出缺哪种语言），新建时选年月和语言，年月建好不改；「⋯」：重新读取、删除这个月。
  - **关于我**：每种语言有一点背景、时间轴（职位 / 身份、公司 / 学校、时间段必填，一句话简介；能加、调顺序、移出）、一点故事；两种语言共用肖像（网站随机显示一张）和画作 / 摄影（按顺序），能选、从资源库挑、拖进来、调顺序、移出。
  - **职业页**：每种语言一页：联系邮箱（必填）、开头摘要、简历下载（按钮文字和一份文档）、页面模块（加、调顺序、删；「小标题 + 要点」或「时间 + 角色 + 机构 + 要点」，换模式会清空这个模块，先问；要点一行一条）、附加内容。
  - **站点**：话题与类别（ID 只用小写英文、数字和短横线，存过不能改；中英文名都要有；写着几篇作品在用，删在用的先问，网站会把它从那些作品上去掉）和外部链接（图标 github、linkedin、email 或别的；名称；链接），各自保存。
- **资源库**：网站用到的图片和文档都在 `public/assets/images`、`public/assets/documents`，每个都登记，各页只引用它们。
  - 在哪一页加文件（选择、拖进来、粘贴）都放进资源库并自动登记：名字换成小写英文，slug 就是名字，用途写加在哪（如「作品《大鱼》」「关于我 · 肖像」）。图片超过 1.5 MB 自动压成 JPEG（HEIC 也转），压不了的（GIF、SVG、AVIF）提示先自己缩小；文档不超过 5 MB。资源库已有一模一样的就直接用；网站别处（love-shuyu、网站自己的图标）有一模一样的就提示、不另存（网站的检查不许重复）。
  - 资源库页：没被用到的标「没在用」，写着每类共多大；能改图片描述（Alt）/ 文档说明和用途。放进文件夹还没登记的，提示「还有 N 个文件没登记 · 登记」。slug 建好不改，一个文件只登记一次。删除前列出哪里在用（照网站的检查找），只删登记；没地方在用时可以连文件一起删。在 Pomelo 外面改了网站文件夹，点「↻」重读（有没保存的修改时先问）。
- **柚子**（点了才用，柚子隐藏时都不出现）：
  - 润色：摘要、图片描述、文档说明、背景、时间轴简介；正文改选中的一段，没选就改全文，「替换」才换上。
  - 补全：没有英文版时，按中文的标题、摘要和正文开头起草英文标题和摘要。
  - 按中文起草：用 Translator 的模型、思考和提示词把中文的标题、摘要、正文译成英文，图片和链接地址、Markdoc 标签原样保留；边翻边写进英文版（这时英文那边不能改），「停止」留下已翻的；英文版已有内容时先问。保存了才写进文件，不影响翻译页的上一次结果。
  - 「设置 → 柚子 → 发给云端」里有呦呦漫游一项（默认能发：网站本来就公开）。柚子不查网站内容（要问就把网址贴给它），也没有写网站的工具。
- **网站改了内容格式**：我告诉 Claude，Pomelo 跟着改；发布前的检查会拦住对不上的。
- **不做**：在线后台、PR 和预览链接、发布提醒、全局搜索网站文章、从笔记图片和附件里挑图、柚子起草图片描述、交给 Pub2MD。

## 系统通知

- **四种**，「设置 → 通用 → 通知」里每种一个开关，默认都开：
  - **一步一步**：今天到期和已过期的待办（打卡和时间段里每天都出现的不算到期，只算截止那天）。
  - **投石问路**：等回音满 14 天、该跟进的投递。
  - **来日方长**：提前提醒的那几天和当天，还有过期的证件（一直提醒到改了为止）。
  - **定时任务**：写好或没写成时马上弹，点了打开那个对话（年度总结打开 Atlas）；停掉的不弹。时间跟着各个定时任务，设置里只有开关。
- 前三种各有一个时间（默认 9:00），每种一天最多一条，写清几件和前几件的名字（「今天到期 3 件 · 过期 1 件」）；那时 Mac 在睡或柚儿园没开，下次打开时补。没东西可说就不弹。
- 点通知打开说的那条（只有一条时）或那一页；柚儿园在最前面时也弹。隐藏的模块不弹。系统设置里关了柚儿园的通知时，设置页那一节写一句、给「打开系统设置」。

## 有板有眼

- **是什么**：在 Pomelo 里看 visual-atelier 的 Design System、Motion Deck（动效零件）、Explore Deck（每个方案一块探索画布）和问卷页，不用开浏览器。画布由 visual-atelier 自己的引擎（bench，只听本机）显示；Pomelo 不存任何一份，只记文件夹在哪（默认 `~/Documents/GitHub/visual-atelier`，页面上「换文件夹…」）。做法见 `architecture.md`「有板有眼」。
- **页面**：没在跑时先「启动」。左栏照 visual-atelier 的菜单分类（Design System、Motion Deck、Explore Deck、Questionnaire、Checks），每类能收起（记住）；点开的 Explore Deck 按页列出画板，每页能收起，默认只展开正在看的那页。平移缩放、换页、单张铺满、Tweaks、深色和减弱动效、批准和退回都在画布界面里做；左栏和画布互相跟着。缩得很小、在视野外的板定格不动，指着、选中、试玩时才动（免得拖慢 Pomelo）。能「重新读画布」「停止」。下次打开回到上次看的那一块。
- **改名、删除**：左栏右键或「⋯」（同 bench 自己的菜单），画布界面里也能做，两边跟着变。
  - Explore Deck、问卷页、画布的每一页、开着的页下面的每张画板：改名（就在那一行里改；画板只改标题，文件名不变）、删除…（先问；删掉的进 visual-atelier 的回收处，画板连同批准记录；能「撤销」放回去，之后要找回让 Agent 从回收处放回）。
  - Design System、Motion Deck 只能改名、不能删（它们是方案的一部分）；只改 bench 和有板有眼里显示的名字，方案的源、云端 Design System 的名字不变；改过的多一项「回到原名「…」」，改名时清空也是回到原名。
- **Checks 和批准状态**：Checks 是「npm run all」（写着上次的结果）。开着的页下面每张画板照 bench 的叫法标「待批」「已批准」「退回」，标完又改过的加「· 改过」，悬停看原因或备注；批准、退回只在画布界面里点。
- **启动和停止**：别处（终端、Agent）已开着画布服务就直接用；「停止」停掉正在跑的那个；Pomelo 启动的在退出 Pomelo 时跟着停。文件夹不在、没装依赖、找不到 Node、端口被占，都在页面上写明白、不能启动。
- **不做**：在 Pomelo 里改画板内容（交给 Agent）、拉回和发回云端、柚子读画布、搜索、备份。

## Atlas（年度总结）

- **是什么**：柚子的一个助手，单独当模块，做视觉化的程序 + Agent；现在做年度总结，以后再做别的数据。视觉由 visual-atelier 设计（各幕怎么画见它的 `schemes/pomelo/atlas/README.md`），页面的样子见 `design.md`「Atlas」，做法见 `architecture.md`「Atlas」。
- **入口**：年度总结由定时任务写（读什么、怎么写、留不留对话见「定时任务、今日简报、年度总结」），只在 Atlas 里看：以视觉为主的旅程，不是纯文字。Atlas 列出写过的每一年，首页新年第一周的信封也能进。往年能补做；今年没过完时「立即运行」写到今天，也能走旅程，写明「截至某日」，只限一年内。
- **形式**：年度小报。新年第一周（1 月 1～7 日）桌上多一个柚子贴纸封口的信封（去年全年最新的那一份），点了进 Atlas，拆开才是小报。小报有仪式感，跟着节拍自己翻（一拍 0.8 秒），碰一下就停；减弱动态效果时默认不自动翻。不配音乐。
- **几幕**：序章（生活星图、年份、一句开场）、留下的日子（一年的热力图和一句原话）、写下的字、重要的时刻、书影相遇（只按年份）、玩物有志、几个具体时刻（完成的目标、出行、拿到的 Offer、来日方长的重要日子，沿时间排；纪念日不算这一年做的事）、去年的回声（即「那年今日」：两年同一天的原话、和去年比）、创作（画完的课程和课节）、求职这一年（投了几份、走到哪一步）、身体和习惯（打卡天数、最长连续）、和柚子聊的事（常聊的话题，私密对话不算）、钱（花在哪、总资产怎么变；发给云端照钱来钱往的设置）、自建模块（一个模块一幕）、终章（柚子的来信）。模型按这一年的实际数据决定放哪几幕（没求职就没有那一幕）。
- **每一幕**大多只讲一件事：一个主要的数字或一张图、一两句话、能点开的原记录；念念不忘、一步一步这样数据多的多放一些。原记录在旅程里弹出，关掉回到原处，另有「在模块里打开」。
- **星图**：每颗亮星是有记录的一天，记得越多越亮，点一颗看那天的记录。**粉星**：模型在序章挑 3～5 条这一年对我最重要、最触动的记录（哪一类都行，要有今年的日子），那天是粉星，和最亮的几天（金星）按日子连成星座；点粉星看那一条。
- **写下的字**：见字如面这一年写了几篇、多少字、和去年比；标签长成一棵树（写得多的枝更粗更长、枝头的柚子更大，没打标签的几篇写在木牌上）；十二支铅笔一个月一支，写得越多削得越短。全由程序画，模型不写话。
- **重要的时刻**：柚子从这一年的文章里挑 3～5 篇，每篇原样抄一句（原文里没有就用那篇的第一句），都能点开那一篇；最后是柚子一两句附言。文章原文只在写的那次给模型看，不存。
- **玩物有志**（紧跟书影相遇）：最喜欢的一部（评分最高）；这一年通关的按通关先后排（多于七个只放评分最高的七个，写还有几个），玩了不止一遍的标几周目；通关几个和去年比、最常玩的类型和平台，再一行「玩到二周目以上」的有几个、是哪几个（没有就不出这一行）。
- **和柚子聊的事**：模型只把这一年的对话按话题归组、起名，从固定的 12 个类别里挑一个（做饭吃喝、求职工作、代码技术、旅行出门、宠物、睡眠、感情、钱、学习、身体、心情、家人朋友；都不合适是「别的」），次数由程序数。每个类别一个专属泡泡，另有 6 个通用的给「别的」和重复的类别，一页里不重样。
- **自建模块**：这一年有数据的都交给柚子决定放不放，一个模块一幕、不限几幕。清单条目按第一个「年份」字段算哪一年，没有就按加进来的那天；循序渐进按完成的课节（学完几节、哪几门、十二个月）。
  - 能放的有：评分（最喜欢的几条）、单选多选的分布、多选的词、数字的合计、和去年比、十二个月、几条条目、一句原话（条目的长文字、课节的备注）；自建模块的条目不能被柚子链接，所以没有链到它们的笔记。
  - **不把程序定死**：Rust 整理好条目、字段、课程和能引用的话；设计给十个零件和三种排法，柚子照 SKILL 给每个模块排（没意思的不放），Rust 核对、填数，不对告诉柚子再要两次，还不行用默认排法。右上角是模块自己的贴纸。柚子的信里也写到自建模块和玩物有志。
- **每次运行留一份**：用年度总结写完后存下的「呈现结果」（后来隐藏的模块、设成私密的对话，打开旧旅程时保持写的时候的样子），记着照哪一版设计做的；同一年可以有好几份（有了新设计再补做往年，旧的那份还在）。**只有我能删**（那一份下面的 ×，能撤销），柚子、定时任务都删不了。
- **设计有名字和版本**：每次定稿由我起名、定版本号，visual-atelier 冻结一份快照同步过来，不再改。只升最后一位是小修，替掉同一条线里旧的（照旧版做的几份改照新的画）；升了前两位是新定稿，两版都留，旧的几份还照旧的画。现在装着 **Tabloid**（年度小报）**1.0.3** 和 **1.1.1**：新写的照 1.1.1（多了玩物有志、自建模块和见字如面的两幕），照 1.0.x 做的照 1.0.3 画。
- **各幕没写成时**：读不出来（空的、没写完、格式不对）就告诉模型哪里不对、再要两次；小毛病（话里的英文双引号、多余的逗号、前后带了别的字）程序自己修。三次都不行，信和数字照样留着，小报照有内容的幕画、没有话，那一份下面写着原因。
- **Atlas 的页**：每年一张封面（这一年最新的一份，由那一版设计画，点了翻开；没写过的年份能「补做这一年」）；「时间穿梭」看这一年做过的每一份（新的在前，写着哪天写的、全年还是截至某天、几幕、哪个模型，没写成的写原因）；「样式」看装着的每一版设计（名字、版本、定稿日期、改了什么、有几份照它做），点一版用最新的一份翻开看样子（只是看，那一份记的样式不变）。

## 柚子（AI）

做法见 `architecture.md`「柚子（AI）」。

### 定位和原则

- 顶栏的柚子就是 Pomelo 的 AI（代码里叫 youzi）：用本地或云端模型聊天、查 Pomelo 的数据，经我确认后记和改。
- **原则**：只经 Rust 命令读写；改前给我看、确认才改，能 ⌘Z；不删 Pomelo 的数据；芝麻开门、启停模型、导入导出、备份恢复、写文件都不交给它。能动磁盘上文件的只有 DevJanitor，也只提议，我在卡片上点了才执行。

### 模型

- **本地模型**：读 `~/Documents/LLM` 的模型清单（聊天、向量、重排，不写死模型名；文件夹由 Claude 维护，柚子不改），模型菜单里选了就切过去，同时只开一个。向量、重排用时自动启动，柚子启动的闲置 30 分钟后停。聊天上下文：14B（和看不出大小的）最多 16K，9B 最多 32K。

  - Claude 的回答被安全检查挡下时，Anthropic 自动换模型接着答（只对 Claude Fable 5 / 5.1、Opus 5 / 5.5、Sonnet 5.5）。

- **思考**：默认都思考，求好不求快；开思考、强度高时多留回复长度。
  - 云端模型在设置里标「不能 / 能开关 / 只能」思考，本地照模型清单（标了会思考的能开关）。只能思考的模型拒绝「不思考」时，去掉这个设置重发。

  - **强度**：每个云端模型在设置里填支不支持、有哪些选项（接口的英文词，如 `low, high, max`）、固定哪个当默认（可不固定，就用模型自己的）；在思考又没另选强度的地方都用它。词原样发给接口，不接受就去掉强度重问。已有的照各家文档预填（DeepSeek `low, high, max`；Anthropic `low, medium, high, xhigh, max`；OpenAI、Google、OpenRouter `low, medium, high`；Aliyun 和不能思考的没有），能改。本地模型只有开关。
  - **能另选强度的地方**：凡是让我选模型或思考的地方（对话、定时任务、今日简报、Translator、Pub2MD 的两个模型、Seeker 和 Rater 的每个功能、Importer、面板帮手）。选项跟着模型变：不思考（能关才有）、默认（写着固定的那个）、各个强度；选的优先，换了模型而它没有这一档就算默认。对话里模型有强度时按钮是菜单，写着现在的强度（如「思考 · max」）。
  - **中间步骤**（总结较早对话、分段读长文件、年度总结的每月阅读这类连续调用）：开关跟着，强度用模型的默认，只有最后的回答用我选的。
- **面板帮手**（「设置 → 柚子」）：润色、补全、一句话填好、贴 JD、拆子任务、打包清单共用三个选项：模型（默认「柚子现在选的」，也能固定一个；固定的云端模型删了就回到柚子现在选的；选了本地模型而别的本地模型在运行，用运行着的）、思考开关、强度（不思考或模型没有强度时只写一句）；后两个跟着模型变，默认思考、模型的默认强度。呦呦漫游的「按中文起草」跟 Translator 的模型和思考，不另设。

### 问我（ASK）

- **是什么**：云端模型在对话里缺了我的决定就做不下去时，发一张卡片（单选、多选、判断，最多 4 题，每题能写「其他」）并暂停；我答完，它在同一条回答里接着写。
- **等待时**：模型不发请求；输入框不能发送，只能回答或停止；不在柚子页时柚子说「柚子在等你回答」；停止后卡片写「没回答」。
- **回答后**：回答记成一行「问了你：… → …」，追问时一起发给模型，导出的 Markdown 里也有。
- **退出 App**：回答算中断，卡片还在；这时回答会作为新消息发出，模型接着聊（查过的可能要再查）。在这个对话里发新问题，卡片就关掉。
- **范围**：只给云端模型，只在对话里（柚子页、右侧小窗、速记小窗、DevJanitor 的 Agent）；定时任务、今日简报、年度总结、复盘记录不问。一条回答最多问 5 次，之后让它自己判断并写明假设。

### 聊天

- **回复**：流式、停止、重试；思考过程折叠、单独存，不发回模型。消息按 Markdown 显示：表格、代码高亮和复制、公式（`$…$`、`\(…\)`、`$$…$$`、`\[…\]`，金额的 $ 不误判）；页内查找；跨消息选中复制得纯文字；「复制整段对话」。看旧消息时不强制滚到底。链接交给浏览器，模型输出的 HTML 当文字显示。
- **同时做几件事**：每个对话、助手、定时任务各自生成，同一对话一次一问。云端模型能同时答；本地模型一次答一个（上下文不缩小），其余写「排队中（本地模型正在回答别的）」。正在写的对话在列表里有小黄点。
- **版本**：编辑问题、重新生成、重试都保留旧版本和各自的后续，能来回切，不画分支树。中断时留下已写的部分，能重试。
- **输入**：Enter 发送、Shift+Enter 换行（中文组词时不误发）；生成时能先写下一条；草稿按对话分开，退出不留。「新对话」发第一句才保存。
- **对话和项目**：标题默认取第一句；改名、置顶、私密、归档（再发消息自动恢复）、批量、拖动、删除都能 ⌘Z（发消息、生成回复不算）。对话、项目文件夹的右键就是「⋯」；消息右键是它下面的按钮（复制、修改问题；复制、保存为 Word、重新生成），公式上多「复制 LaTeX」，选了字是系统菜单。「设置 → 柚子 → 柚子的数据」有「归档的对话 N 段」，点「在柚子里看」打开柚子并展开它。项目有背景指令；能在项目里新建对话、把对话移进移出，删项目保留对话。拖到项目即移入，拖到「最近」移出项目并取消置顶，拖到「置顶」保留项目。
- **私密**：「⋯ → 设为私密」，留在原分组，标题前一把小锁；不进年度总结，柚子的「搜索」「读整条」找不到（别的对话不会引用），⌘K 和对话搜索照样能搜到。
- **对话搜索**：按模型、时间筛选，能含归档，也按意思找；打开结果定位并高亮那条消息（旧版本也行）。
- **模板和指令**：模板能分类、置顶，用「/」菜单插入（输入框下的「模板」只列置顶的），`{{名称}}` 是待填处（Tab 跳下一个），空白页显示 4 个置顶模板。指令分全局、项目、对话、用途预设四层合成，发送前能预览；新对话发第一句前就能选预设、写对话指令。
- **写提示词的框**：凡是我写给模型的（模板、各层指令、用途预设、定时任务和今日简报的提示词、Translator 和 Pub2MD 自己写的那段、DevJanitor 的 SKILL）都边写边显示 Markdown（标记还在、变淡），和呦呦漫游的正文同一个底子。
- **上下文快满**：先提示，确认后总结较早的对话（原文保留，摘要只对原来那条路径有效）；「总结并继续」总结完接着发输入框里的问题。

### 附件、项目资料、记忆

- **附件**：点选、拖入、⌘V 粘贴图片或从附件库复用，存一份副本；点选和拖入的记下原文件在哪（工具箱改的就是原文件）。能读 PDF、Markdown、文本、Word（.docx、.doc）、PowerPoint（.pptx，每页的文字）、Excel（.xlsx、.xls、.ods）和 CSV、图片（PNG、JPEG、GIF、WebP、HEIC）、网页，附件、项目资料、知识库都通用。扫描件 PDF、只有图片的 Word 和 PowerPoint 也能放，内容是一句「没有文字、共几页 / 几张图」，云端模型按页、按图号看（见「知识库」），本地模型看不了。「+ → 添加网页…」和项目资料的「添加 → 网页…」存下网页正文和网址。
  - **表格**：每张表第一行是表头。共 200 行以内整张发；更大的只发表头和前 50 行，这一问多一个「查表」工具（按行号、含某些字、某列等于某值取行，一次最多 200 行）。
  - **图片**：云端模型都当能看图，发前缩小，一问最多 8 张（最近的）。本地模型看不了：写明，问题照发，回答里说明并提醒换云端。图片不建索引。
  - **追问时**：同一路径上前面附过的照样发，但和新附的分开、写明「前面附过」，免得柚子再介绍一遍。
  - **放不下的长文件**：开着「读文件」技能、模型能用工具时按段补读（见「Work」）；否则分段读完再汇总（显示进度、能停止，存下要点和页码）。
- **项目资料**：每个项目自己的（格式同附件，不进附件库，同一文件不重复）。输入框「资料」菜单选这条消息用哪些（全文发送，选择保留到后面的消息）。「替换为新版本」保留旧版本，旧消息对应当时的版本。能「建立索引」（能停止、重试、取消），之后在项目里提问自动检索至多 6 段，回答里标出处。
- **记忆**：一两句话的事实或偏好（300 字以内），分全局和项目；项目记忆能同时用于别的项目，项目可以不用全局记忆。能停用、设「仅本地」（选云端时跳过）。对话里 `/记住 …` 弹出确认卡片，点保存才存。每条消息自动挑至多 6 条相关的（附「记于」日期），回复下方能看用了哪些；输入框「记忆」菜单能只关下一条或关掉整个对话，设置里有总开关。删项目时它的记忆改成全局并停用。
- **向量服务用不了时**：要挑记忆、检索资料或知识库时先暂停发送，让我选：不用它们直接发、重试或取消。

### 懂 Pomelo（查数据、小窗、面板里的帮手）

- **问我的数据**：在柚子页或小窗里问，柚子自己决定查什么、能连查几次（Rust 备好一组只读查询：某个模块、某段时间、某些条件，或直接要合计）。合计、平均、占比、连续天数、预计完成都由 Rust 算（和 App 里的统计同一套），柚子只解释和建议。没说时间就自己判断，并写明看的是哪段。常问的有专门的查询：总资产怎么变、该跟进哪些投递、上周做完的和拖着的、按口味推荐书影、最近的笔记在想什么、绘画什么时候画完、出行可能漏了什么。
- **查了什么**：回复上方一行「查了：钱来钱往 · 2026 年 9 月支出（42 笔）」，点开看内容；回答里第一次提到的记录能点开。查到的存进对话：追问时最近 3 次回答查到的（截短）随当时的问题一起发，发前按现在的规则再筛一遍；回看、导出都有。
- **能读哪些**：除了芝麻开门（永远不读）和隐藏的模块都能读。**发给云端**在「设置 → 柚子」按模块选，默认都能发（含自己建的）；钱来钱往分「收支」「资产」两个开关，收支默认能发（导入账单要用），资产默认只给本地，报表用到哪部分看哪个。DevJanitor 的扫描结果（文件夹名和路径）默认能发。选云端时不能发的不查，回答开头写明（如「钱来钱往不发给云端，这部分没看」）。
- **查几次**：一次回答最多查 4 轮，之后必须回答（要记、要改的还能再提议一轮）；查到的太多就截短并写明还有几条。模型不支持工具就直接答，「查了」写「这个模型不支持查数据」。要分段阅读的那一问不查数据。
- **右侧小窗**：⌘J 或顶栏的「问柚子」呼出 / 收起（柚子页里没有）。里面是普通的柚子对话（存在「最近」），能切到最近 8 个对话或开新对话，模型同柚子页；加附件、选资料、写指令、总结留在柚子页。App 重开后小窗收起。
- **当前页面**：小窗带着当前模块、页面和筛选（如「钱来钱往 · 收支 · 2026 年 9 月」），打开了记录就是那一条，多选时是选中的几条；发消息时一起带上（记录带全部内容），能 × 掉这一次不带。不能读或不能发给云端的只带「在哪一页」，芝麻开门什么都不带。问题上方「带着：…」点开看带了什么；追问、重新生成、改问题都带着当时的页面。
- **润色**：任务内容和目标复盘、投递备注、书影 / 课节 / 出行 / 收支的备注，呦呦漫游的摘要、图片描述和正文（笔记不要）。写这次的要求（空着就是改通顺），下面出现改好的版本（标出改动），点「替换」才换上，能「再改一次」。
- **补全**：书影补作者 / 导演、国家、类型（先用书单 / 影单检索，查不到才靠模型）；投石问路贴 JD 补公司、岗位、地点（JD 原文进备注）；一步一步拆子任务；出门走走按目的地和天数建议可能漏的东西；呦呦漫游起草英文标题和英文摘要。前两种只填空着的项；子任务和漏带的先列出来（默认勾上），点「加上」才加，一步 ⌘Z。念念不忘的标签、钱来钱往的分类不做。
- **一句话填好 / 改好**：收支、任务、投递、书影、出行的面板里写一句话回车。新建面板是「一句话填好」，面板上每一项都能填（出行新建时还能选模板）；编辑面板是「一句话改好」，柚子看着这条现在的样子，只改这句话说到的，也能清空某几项（不要链接了、去掉截止日期）。填过、改过的标出来，我检查后自己保存。一次只填一件事（好几件在对话里说）。
  - 日期词（昨天、下周五、10 月 20 号……）由 Rust 按今天算；分类、分组和目标、渠道、状态、模板、类型按名称对上已有的，对不上就空着；链接只填句子里写了的。
  - 收支：新建时没说日期是今天，没说币种用最近 60 天最常用的（改好时没说的都不动）。任务：只说一天就是截止日，分组和目标提到才填，打卡规则只有每天和每周几天。投递：说了投了 / 面试了才勾那一步，没说日期是今天。书影：看完了没说哪年就是今年。
- **用哪个模型**：润色、补全、一句话填好照「面板帮手」（见「模型」）；本地模型没运行就先启动上次选的；选云端时，不能发给云端的部分不发。

  - **改卡片**：没确认、没取消的卡片（这次或这个对话前面回复里的），我纠正了（「作者是特德·姜」）或检索填错了，柚子重新提议，同样检查后换掉卡片里那一条（不多出一条），我再确认。题库的题是按我的话重写那道题的答案。
  - 默认：没说分组用柚子挑的（卡片上看得到），没挑就是第一个分组；「投了」没说哪一步就是第一步；币种、日期和名称照「一句话填好」。
  - 找要改的那条：只有一条就直接放进卡片；几条相近的列出来让我选（最多 5 条）；一条都没有就问我。任务只找没完成的；收支只看最近 31 天（说了哪天就看那天）；出行没说哪次就是还没出发的；课节没说哪节就是那门课下一节没画完的。
  - 「完成」照列表里的圆圈：普通任务勾上，重复任务算做了这一次，打卡今天打卡，进度 +1（说了数量就记那个数）。投递「写备注」是在原来的后面加一行。笔记能整条改写或只换一段，卡片里标出改了哪里。书影已有同名的就改它，不新加。
- **云端**：用云端模型时，不能发给云端的（见「懂 Pomelo」）不能新建、修改，回复里说明。
- 不做：系统通知、菜单栏的小点、在 ⌘K 里直接记一笔（想到就记用速记小窗）。

### 搜索和出处

- **按意思搜**：⌘K、对话搜索、念念不忘的搜索框都能按意思找（搜「找房子」也能找到「租房」）：先按字找（马上出来），下面一组「意思相近」（稍后出来，不重复）。向量服务没运行时自动启动。芝麻开门永远不进索引，隐藏的模块不搜。20 万条时按字 0.1 秒内、按意思 0.3 秒内。向量和重排模型能在设置里换。
- **柚子的搜索**：「搜索」（按字和按意思一起找，重排后最多 12 条，也能找到以前的对话）和「读整条」（读某个编号的全部内容），照能读和发给云端的规则。
- **出处**：用到的资料段落、记录、网页标 [1][2]（全角的［1］也认）；回答下面「来源 · N」默认收起，点开列出来源：记录像全局搜索那样打开，以前的对话在柚子里打开，资料弹出那段原文和「打开文件」，网页用浏览器打开。记忆不编号，列在回复下面。

### 插件库

- 「插件库」里每个技能写着能做的事（分点）、开关和 Key（只在钥匙串），和一张照程序真实步骤画的流程图：判断分出两条、各写明哪种情况；两边都接着走的在会合那一步并回来，到此为止（或回到前面某一步）的停在那里；有循环就画出回到哪一步。
- **技能名**：通用的 `general-…`，某个助手的用它的名字开头；斜杠命令就是「/技能名」。
- 每个技能两个开关：「启用」和「柚子自己决定用」（关了只在我点名的那一条用）。输入框任何地方打「/」（紧跟字母数字的不算，比如网址、1/2），菜单最上面一组「技能」，选了输入框上方出现小胶囊（如「/general-book-lookup」），下一条必须先用它，发完就没了。「/记住」这类命令只在开头。
- **现有十二个技能**，除了联网搜索都默认打开、自己决定用：
  - general-book-lookup、general-film-lookup（书单检索、影单检索）。
  - general-web-search（联网搜索）：只在按「联网」或打「/general-web-search」的那一条用，那一条先拿问题本身搜一次。
  - general-file-reader、general-knowledge-base（读文件、查知识库）：问题带了文件、对话有能查的知识库时才给（见「Work」「知识库」）。
  - general-word-toolkit、general-text-toolkit、general-excel-toolkit（Word、文本、Excel 工具箱，见「Work」）：文本工具箱只在有能改的 Markdown、纯文本文件时给；定时任务也有这三个。
  - seeker-toolkit（读 Seeker 和 Rater 的资料）和 rater-qbank-resume、rater-qbank-general、rater-qbank-job（见「Seeker」「Rater」）。
- **书单检索、影单检索**：按名称查作者 / 导演、国家、类型、年份。先在 Wikidata 找到这一部（中文名、译名都行），再用 Open Library（书）、TMDb（电影、剧集，在插件库填 Read Access Token）、Jikan（动漫）核对；查不到就说查不到，不编。书的国家按作者国籍。用在对话里补全和推荐书影（先核对每一部，标出处）、书影面板的「补全」（查到的直接填，查不到才让模型补）、「一句话填好」和柚子提议的新书影（柚子说了作者、查到的却是别人时，是同名的另一部，用柚子自己的）。插件库的「联系邮箱」只发给 Wikidata、Open Library（带了每分钟 200 次，不带只有 10 次），不填也能用。
- **联网搜索**：用 Tavily（Key 在插件库填），本地和云端模型都能用。输入框「联网」按钮只管下一条；这一条照常能查 Pomelo 数据（照云端规则），搜索词可能带上私人内容。回答标出处（网页标题和网站），搜到的存进对话，追问还用得上。

### 定时任务、今日简报、年度总结

- **定时任务**：「定时」里自己建：名称、什么时候（每天几点、每周几、每月几号或最后一天、每年几月几号）、模型和思考（默认开；开着时只列能思考的模型，选项跟着模型变）、提示词；能开关、改、删、「立即运行」，写着下次什么时候跑、上次的对话。
  - **面板**：只是一段提示词的（自己建的、每周 / 每月回顾、今日简报）显示提示词，能随便改；一套工作流的（年度总结）像插件库那样画流程图，不贴提示词。
  - 到点柚子自己查数据、写好，存成对话「名称 · 10/19」放进列表的「最近」（和别的对话一样能拖、置顶、进项目）；柚子的入口和那一行有个小点，打开就消失。Pomelo 的数据只读（不提议记录，不给题库 SKILL）。能联网搜索（插件库里开着、填了 Key 就有，不用按「联网」），能用 Word / 文本 / Excel 工具箱（只提议，卡片留在那次对话里，我点了才写；能改、新建知识库里的文件）。不问我（ASK）。
  - 到点时 Pomelo 没开，下次打开补跑最近一次；新建、改了时间、重新打开的不补以前的。没跑成也留对话写明原因。删任务，它写过的对话还在。
  - **年度总结的「留对话」**（面板里，和别的一起「保存」，默认关）：关着时写的过程照样在对话里看得到，写成后这个对话就删掉，信和小报都在 Atlas 里；没写成的那次留着，好看原因。开着就和别的定时任务一样留下来。
  - 选的本地模型没运行就先启动、跑完停掉（只停自己启动的）；正在运行的是别的本地模型就用它（开头写明）。一次跑一个定时任务，和对话、助手同时跑（本地模型排队）。
- **现成的定时任务**（能改、关、删）：每周一早上回顾上周（做完的、拖着的、花了多少、投递进展）；每月 1 号回顾上个月（收支和总资产、读完看完的、画了多少）；每年 12 月 31 日 21:00 年度总结。
- **今日简报**：首页的一张卡片，每天第一次打开首页时写 3～6 句，当天不变，能「重写」。读今天的待办、3 天内到期和过期的；该提醒的日子；该跟进的投递、在笔试面试的；最近两周的笔记（每条带日期和「几天前」，并写明最近一条是哪天、之后有没有再记）。不发给云端的模块不读，卡片下面写「没看：…」。失败显示原因、能重试，重写时旧的先留着。设置在「定时」里：开关、模型和思考、提示词（「保存」「恢复默认」，不进撤销）、「重写今天的」。
  - 默认提示词让模型在最后一行写当天的心情（轻松、很忙、有好消息、有烦心事、一般，卡片上不显示），顶栏的柚子按它换表情（见「柚子的表情」）；提示词里去掉这一条，柚子就一直随机换。烦心事只看今天和最近一两天：几天前笔记里低落、之后没再记的，不当成现在还不开心，可以轻轻问一句最近心境有没有变化。
- **年度总结**：每年 12 月 31 日的定时任务写，也能「立即运行」（写今年到现在）；1 月补跑的写刚过去的那一年。像别的定时任务一样存成对话，小报在 Atlas 里看。数据多，建议用云端模型（旗舰模型我自己在任务里选）；回复上限要够写一封长信。
  - **读什么**：这一年的笔记全文；见字如面的文章（标题和开头）；做完的事和目标、打卡；画完的课；投递的进展；出行（名称、出发日期）；读完看完的书影；来日方长这一年的重要日子（纪念日、生日，写明不是这一年做的事；按月、按周重复的和证件不算）；收支（各分类花了多少、收入）和资产（总资产从年初到最近的变化），各按自己的「发给云端」；和柚子的对话（标题和第一句，私密的、定时任务写的不读）。芝麻开门不读。今年没过完时都只算到今天。数字都由 Rust 算好（笔记几条几字几天、做完几件、每月几件、打卡天数和最长连续、书影课节投递出行对话各几个、写笔记最多的月份、最常用的标签），模型只照抄。
  - **和去年比**：Rust 算去年同样的数字和差值（今年没过完时两年都算到同一天；书影按全年）；有去年的年度总结也给模型（私密的不给）。去年什么都没有就不比。
  - **写法**：一封写给「你」的信，像熟悉你的朋友陪你回看这一年：「这一年的关键词」（3～5 个）、总述、「这一年的数字」、按主题分块（读书观影、创作、学业和工作、感情和家人、身体和习惯、和柚子聊的事……有内容才写）、「你写下的话」（3～5 句原话，带日期）、「这一年之最」、和去年比（写进相关的块）、「写给明年」。篇幅看内容，空的月份一句带过，只写信本身。任务存的那句提示词最后发给模型，冲突时照它。
  - **怎么生成**：放得下就一次读完全年直接写（云端基本都放得下）；放不下就先按月整理要点（留日期、人名、事名和原话；没变的月份用上次的），再拿要点写全年。每月要点用模型的默认强度，写信用任务选的强度；每月要点折叠在回复上面「每月小结 · N 个月」。
  - **给 Atlas 的「呈现结果」**：信写完后，同一个模型接着给各幕写一两句话、从记录里挑引用（序章、终章必有，没内容的幕不给它写），和 Rust 算好的数字快照（今年和去年同期的数字、之最、每天的记录数、打卡、钱、能引用的记录、两年同一天的笔记）一起存下，只存这一次能读的；这一步没写成，信和快照照样留着。对话里信的下面折叠一行「Atlas · N 幕」。
  - **信存两份**：对话里一份，Atlas 里一份（删对话时留着，只在 Atlas 里列出和删）。删了对话，Atlas 里照样能读整封信，明年写信时的「去年的年度总结」也读 Atlas 那份。

### 知识库

- **放什么**：选定的文件夹（原地读，不复制，文件变了自动更新）和保存的网页（存一份正文）。文件夹里能读的都读（格式同附件，含子文件夹，大表格读全部行；图片列出来但不建索引）；跳过隐藏的、Office 临时文件（~$ 开头）、替身、应用程序包、node_modules；每个文件夹最多 2000 个文件，每个文件 200 MB 以内。不能放 Pomelo 自己的数据文件夹；同一个库里的文件夹不能一个套一个。
- **库**：分成几个库（名字最多 30 字、不重名），能新建、改名、删除、拖动，都能 ⌘Z；删库、移除文件夹或网页都不碰原来的文件。
- **管理**：「知识库」（输入框「知识库」菜单里也有）里每个文件夹和网页写着几个文件、图片、扫描件（没有文字的 PDF，和图片一样只认文件名）、建立进度、几个待更新、几个读不了（能看原因），找不到文件夹时标出来；各自能设「发给云端」、在访达中打开 / 打开网页、重新建立索引、移除。
- **查哪些库**：对话选的；没选就跟着项目（「项目设置」里选）；项目也没选就是全部。
- **「知识库」按钮**（输入框，小窗里也有）：按下后这个对话每个问题都查（每个对话记住；新对话默认不按，选了库的项目里新开的默认按下）。它的菜单：查哪些库、用云端模型时不查的文件夹、「管理知识库…」。没按时柚子也能自己用「查知识库」技能。
- **看文件、整篇读**：「查知识库」技能也能列出库里有哪些文件（路径、类型、大小、修改日期，能按路径里的字筛），整篇读某个文件（看目录、按段读、按字找，从原文件夹现读），读到的段落标出处、能「打开文件」，所以能回答「这个文件夹里有什么」「总结某份文档」。
- **看图片**：用云端模型时柚子能看库里的图片（一次一张，发前同附件一样缩小），本地模型看不了，会这样说。Word、PowerPoint 里嵌的图片按图号看（EMF、SVG 这类矢量图看不了）；PDF 按页看整页的样子（列出哪些页有图、哪些页没有文字，扫描件也这样看）。附件、项目资料也一样（读文件技能），问题带这类文件时柚子知道能看。一个回答一共最多 8 张，都算出处。不改文件夹里的文件（要改用工具箱）。
- **怎么查**：和项目资料一样按意思找、重排，至多 6 段，和项目资料的段落一起编号；出处写「知识库 · 库名：文件名 · 第 3 页」，点了看那段原文和「打开文件」（网页是「打开网页」）。查之前先把变了的文件算好（「正在更新并检索知识库…」）。
- **什么时候更新**：不监听文件夹；打开柚子页、打开知识库对话框时和每 10 分钟比一遍大小和修改时间，只重算变了的。向量服务开着就马上算，没开就等下次用知识库提问时先算完；添加和「重新建立索引」会启动向量服务。后台正在建立时提问，先用已建好的。
- **云端**：每个文件夹（和网页）自己设能不能发给云端（默认能）；用云端模型时不能发的不查，菜单里写明。
- 知识库不进导出的数据文件。

- 柚子提供的小型 Agent，各有工作流、提示词和整页工作台（怎么当模块见「界面外框」），不在柚子的对话列表里。现在有 Translator、Pub2MD、Seeker、Rater、Importer、DevJanitor、Atlas，名字由我来定。
- **Importer**：见「记账」的「导入账单」。
- **Translator**（子页「Translator · 提示词」）：
  - **Translator 页**：源语言（默认自动检测）⇄ 目标语言（默认「中英互译」：原文主要是中文就译成英语，其他都译成简体中文；也能选十二种具体语言）、模型（同定时任务）、思考（默认关）、「翻译」（⌘↩ 也行，翻译时变「停止」）；译文写着用的模型或进度，能复制。⇄ 只在两边都是具体语言时能点；两边同一种语言不翻。
  - **提示词页**：自己写的一段（2000 字以内）；四组关键词，每组最多选一个：长度（精简、和原文相当、可以展开）、专业度（通俗、一般、专业、学术）、语气（正式、中性、口语、亲切）、意译或直译（直译、平衡、意译）；能看实际发给模型的说明。

  - **长文**：自动切块依次翻、边翻边显示（「正在翻译 2/5」），段落、标题、编号前后一致；本地模型也能翻。
  - **只记住上一次**：原文、设置、译文自动存，不做历史，和速记小窗的翻译是同一份。在后台翻，离开再回来接着显示；「停止」留下已翻的部分。不进撤销和导出。

### Pub2MD（助手）

- **是什么**：把 PDF、Word、图片经 Mathpix 转成 Markdown，再整理、翻译；每月用几次。
- **能做的事**：只提取（不经模型）；提取 + 整理；提取 + 整理 + 翻译；只翻译（MD、MMD、TXT）。能放 PDF、Word、图片（几张合成一份，多页 TIFF 每页一页）、文本；选好或拖进来的先列在「待发送」，点「发送」才开始，一次一份，后面的排队；停下或出错的在「最近」里能「继续」或「删除」（文件夹移到废纸篓）。
- **语言和要求**：英文 → 简体中文；简繁互转（先 OpenCC，再让模型换成读者那边的用词：繁转简用大陆用词和“”，简转繁用台湾用词和「」，书名、品牌只转字形）。选文体（通用、学术、文学、新闻）、领域（公共管理、数学、计算机，能多选），再加自己写的一段。一份文件里有几篇文章的各自输出；双语内容能选只留英文或都留。
- **两个模型**：Worker 整理和翻译每块；Supervisor 审定切块、定术语表（只在英文 → 简体中文时）、排查出错、通读，开「精修」时逐块审校。各选模型和思考（Supervisor 默认高、Worker 默认关，术语表最多「低」），再选一个云端备用模型（默认 DeepSeek Flash，能选「不用」），都记住。Supervisor 的规则写在程序里，提示词页能看到实际发给两个模型的说明。
- **流程**（程序排好，模型只管内容；页面显示「翻译 · 第 3 / 12 块」；各步细则见 `pub2md/job.rs` 开头）：切块按章节和页（2～4 页一块，不拆表格、公式、图，论文不跨各部分），Supervisor 审定；云端 Worker 整理时带这几页的原页图（改 OCR 错误、去页眉页脚、接上跨页的句子、补公式编号，只管这一块）；翻译带术语表和前一块的结尾，参考文献、附录、致谢、作者和单位默认不翻、原样留在原位；Supervisor 通读只改跨块的问题（术语不一致、编号、断开的句子、漏译的英文词）。几块同时做（默认 4）。模型常出的小毛病（丢了的 `\$` `\%`、编出来的链接和图片、零宽字符、混进的繁体字）由程序修掉。
- **检查和出错**：程序只比文字：截断、长短，公式、表格、图片、脚注、标题的个数，段落对不对得上（漏了，或照原页图抄了别的块），语言比例，给模型的说明混进了结果。不合格的交 Supervisor 处理（怎么选、每块几次见 `job.rs` 开头；一份最多 6 次或每三块一次）。网络出错、限流时等 15 秒、45 秒再试，再不行用备用模型，还不行就停下（做完的留着，能「继续」）。被阿里云内容审核拦下的直接改用备用模型。长段里只漏一句查不出来，要靠精修。
- **精修**：默认关；Supervisor 逐块对照审校、程序照改；长论文费用约翻倍，交稿时开。
- **联网查术语**（只在英文 → 简体中文时，有自带搜索时默认开）：Supervisor 查，DeepSeek、Aliyun、OpenAI、Anthropic、Google 用自带的搜索，其他和本地模型用 Tavily。
- **输出**：默认存到「下载」（记住上次的），每份一个子文件夹：原文.mmd 和 assets/、Mathpix 原始结果.zip（同样的文件再放进来直接用它，不再上传）、整理稿、译文、术语表、工作日志.md。另存为 Word（默认）、PDF、LaTeX、HTML 由 Mathpix 转，所以整理稿和译文也会上传；图片链接 30 天内有效，转不成不算出错。处理中的放在隐藏文件夹，做完删掉，出错时留着用来继续。
- **页面**：能停止、继续、打开结果；MMD / MD 结果在页面里预览（Mathpix 的显示库，能切译文、整理稿、原文、术语表、工作日志）。设置里选 Worker、Supervisor、备用模型、存到哪，填 Mathpix 的 Key，写使用说明（Markdown，能改；默认是功能简述和测出来的模型搭配，能「恢复默认」）。只记住设置和最近 10 次；离开页面也接着做。
- **Key 和云端**：Mathpix 的 App ID、App Key 在钥匙串（「设置」页填），没填不能选文件，写明并能「去设置」。不另设「发给云端」：点「发送」就是同意上传给 Mathpix 和选中的模型。
- **速度目标**（提取 + 整理 + 翻译，不开精修）：11 页的论文 20 次请求、20 分钟以内；几页的文档 5 分钟以内；50 页、3 万词以上的长论文 40 分钟以内。

### Rater

- **是什么**：柚子的助手，只做中文。子页：题库 · 卡片 · 面试 · 规则 · 设置。用云端要 Seeker 允许发给云端。
- **设置页**：Rater 自己的模型和思考（不跟对话的，不进撤销）：「默认」，各功能（题库：补题、润色答案；卡片练习：按 JD 挑卡、追问、点评；面试：准备；复盘：记录、总结），每个功能「跟默认」或单独选。
- **规则页**：用 Seeker 资料里用途为「题库维护」「卡片练习」「面试」「复盘」的规则，编辑同 Seeker，不分语言。补题、润色答案读题库维护和那类题的工作流；卡片练习读题库维护、卡片练习；准备面试读题库维护、面试；复盘的记录读复盘，总结读题库维护、复盘。程序自带的规则在我写自己的之前也显示出来（能「改成我的」）：三个题库 SKILL 各一组工作流（组里有我的规则就不用自带的）；面试组的「速查卡」（挑什么题、补什么追问、速查卡的框架），复盘组的「复盘记录」（怎么问、怎么填表）和「复盘卡」（总结写什么），组里有同名的就用我的。输出格式（JSON）写在程序里。
- **题库**：三类：简历题（照简历问，挂一段中文素材）、通用题、突击题（挂一个岗位，可「改自」别的题）。一道题记问题、答案（我的口述稿）、标签，不编号、不分档；先看差异再确认保存、留历史，保存和删除都能 ⌘Z。秒数按 90 秒 400 字算（汉字一字，英文单词或数字两字），超过 90 秒标出来。练习记录（会几次、不熟几次、最近一次）从卡片练习算，打开题目时显示。答案骨架：一句话结论 → 我做了什么 → 结果（数字和范围）→ 局限或如果重来；假设题只答「我会怎么做」。题在自己那组（素材、岗位）里拖动排序；「选择」后能一起删，或「练一轮」开卡片练习。
- **三个题库 SKILL**：题库页「✦ 让柚子补题」（选类别、经历或岗位、几道、本次要求 → 点选要的题，一步写进）、每题的「润色」（看差异接受）和柚子对话里的三个技能（题放进确认卡片）是同一套。简历题读选的经历和经历档案；通用题读基本信息、已确认事实和经历；突击题读岗位、JD、公司资料、经历和已有的简历题、通用题。都告诉模型已有哪些题；事实只用资料里的，缺的写「（待补：缺什么）」。默认条数：突击题这个岗位第一次 8 道，其余 5 道，最多 12。
- **卡片练习**：
  - 出卡：自己挑（类别、标签、只要不熟的，再勾题）、按 JD（柚子按岗位挑 8 张左右，先通用再简历最后突击，能删能加）、随机（默认 10 张，一轮最多 50）。上次「不熟」的排最前，连着两次「会」的排最后；同时只有一轮在练。
  - 练：一张大卡，点了翻面看答案，再点「会」「不熟」（只答当前这张，最后一张答完自动结束；「停下」时一张没答就当没开始）。默认不打字，「⌨ 打字」能打。「追问」让柚子按这道题、我的答案、打的字和 JD 出一张追问卡（背面是参考答案；每张卡一次，同一道题一轮最多 2 次），「存进题库」才进。
  - 反馈：程序列出不熟、会、追问；打了字或追问过时柚子写点评（总评、说得好的、讲不清的、每张打字卡一条）；「再练不熟的」直接开一轮。
  - 记录按轮存，不写进题目；「最近几轮」能「选择」后一起删。开始、每次会 / 不熟、追问、存进题库、停下、点评、删一轮各是一步 ⌘Z。
- **面试**（每个岗位一组，投石问路岗位面板的「面试」一栏也能进）：准备面试、复盘、总结复盘。
  - **准备面试**：选面试语言（中文 / English）、形式、本次要求。柚子读这个岗位用的简历（「本次使用」的那份：Pomelo 导出的读当时的草稿，别的读 Word / PDF 正文；没有就用那种语言的草稿）、JD、公司资料、相关的题（通用题、简历上经历的简历题、这个岗位的突击题）和经历档案，按面试顺序挑 8～15 道、补 5～10 个可能的追问（带参考答案，「存进题库」才进），写一页速查卡（照规则「速查卡」：岗位要点、自我介绍要点、经历速记「本人职责｜关键数据｜已知边界」、高频题、可能的追问、反问）。速查卡能改、能「另存 Word」（文件夹记住上次的，默认「文稿」，只新建不覆盖）；「用这些题练一轮」开卡片练习。准备稿不改题库和简历。
  - **复盘**（记录的助手）：先选日期、岗位和第几轮（默认接着往下数），再开一个对话小窗（不进柚子的对话列表、搜索和年度总结）：和 Rater 的模型聊，旁边是这场的复盘表：形式、结果（待定 / 通过 / 没过）、每个实际问题、我的回答、面试官的反应、面试官的整体反馈、我的判断（和事实分开）。模型照规则「复盘记录」一问一问边聊边填；它能用插件库的技能（Seeker 资料能读别的复盘和速查卡）、知识库（打开时查全部）和记忆，也先读了这个岗位的 JD、最近的速查卡和以前几轮问过什么。我说齐了、模型标成填好后弹出这张表（能改）：「继续记录」存下并回到选日期、岗位、轮次记下一场，「确认」存下关掉，「返回对话」接着聊。「存成复盘」随时能存，「放弃」删掉对话和表。存下后只留表，对话删掉；没记完就关掉的，在这个岗位的复盘里显示「没记完」（「接着记」「放弃」）。存好的复盘能点铅笔手改。
  - **总结复盘**：先选对照哪份速查卡（默认最新的，也能不对照速查卡、只对照题库）和哪几次复盘（默认那份速查卡之后的，没有就全部；能自己勾），柚子照规则「复盘卡」写：总评（几场一起时看反复出现的问题）、准备到了的、没准备到的（缺在哪段经历、什么事实）、值得加进题库的题（「存进题库」）和至多 2 条长期规则的提议（一句话；「加进规则」才写进 Rater 规则里同标题的那条，没有就新建）。一次录取或拒绝不说明简历好坏。在后台跑，离开页面也跑完，写着「正在总结复盘…」或失败的原因；结果单独一条，在岗位下「总结」里。
  - 准备、改速查卡、存下复盘、放弃没记完的、总结、存进题库、加进规则、删除各是一步 ⌘Z；对话里的聊天、填表和 Word 文件不撤销。

### DevJanitor

- **是什么**：柚子的电脑管家助手：画出这台 Mac 的磁盘和开发环境，安全的一键清理，细的、有风险的和 Agent 聊着清。子页：磁盘 · 清理 · 环境 · Agent · 设置。运行方式（开发版扫「假 Mac」）、扫描怎么做见 `architecture.md`「柚子（AI）」。
- **两层**：常规扫描只管粗的：各处多大、大文件、明显能清的类别（自带的和 Agent 加的）。某个文件夹里具体留什么、删什么，由 Agent 自己往里查、判断；程序只给它查看和动手的接口，和一份怎么清的 SKILL。
- **什么时候扫**：打开页面时上次扫描超过 10 分钟就在后台重扫（先显示上次的，扫完换上）；也能「重新扫描」，扫时能「停下」。不定时扫，不自动清理。扫描结果随时能重建，不进备份、导出和撤销。
- **扫哪里**：整块磁盘，App、个人文件夹、Homebrew、资源库都能一层层点进去，系统本身只显示总数（用掉的减去扫到的）。给 Pomelo 开了「完全磁盘访问权限」才扫邮件、Safari、别的 App 的数据，没开时写着几处没扫和「打开系统设置」；还进不去的标「没权限」。大小照访达算（1 GB = 10 亿字节），硬链接只算一次。
- **磁盘页**：一层层点进去（能回上层），列出这一层最大的几项（点了在访达中显示）。也看运行内存：内存压力和最占内存的几个程序、其他、空着各占多少，只看。
- **一键清理**：只放删了能重建、不丢我东西的，确认后直接删（不进废纸篓，否则腾不出空间）。大小按真能腾出的算（pnpm 的 node_modules、Conda 环境链到包缓存的部分不算），不到 5 MB 不列。项目只认个人文件夹里的，以所在 Git 仓库为准（资源库和点开头的文件夹不算：编辑器扩展、全局包、npx 缓存里的 node_modules 不是项目）。
  - 类别：项目里的 node_modules；Rust 的 target（含 Pomelo 自己的，它超过 20 GB 仍会自动清）；Python 虚拟环境（.venv、venv）和 __pycache__；前端构建产物（dist、.next、.astro、.turbo、`.vercel/output`）；包管理器的下载缓存（npm、pnpm、cargo、pip、Homebrew）；Conda 的包缓存（conda clean，不影响环境）；Gradle、Maven 的缓存；Xcode 的 DerivedData、旧的设备支持、用不到的模拟器；认得的 App 缓存（`~/Library/Caches` 里删了 App 会再生成的）；Codex 的运行时；日志；Agent 加的。每类在设置里能关掉，关了就不进一键清理。
  - 默认勾上：下载缓存，和很久没动的项目里的依赖和编译结果（天数在设置里，默认 30 天），其余不勾。个人网站的 node_modules 不默认勾（呦呦漫游本地检查前要在网站文件夹跑一次 npm ci）。
  - 正在用的标「在用」、不能勾：项目的开发服务器开着、正在编译，App 正开着（它的缓存）。
  - 废纸篓能单独清空（写着多大），确认后清空。
- **只列出来**（选了能「移到废纸篓」）：大文件（1 GB 以上）和很久没打开的（一年、100 MB 以上）；下载里的安装包和压缩包（.dmg、.pkg、.zip 这类）；删掉的 App 留下的（Application Support、偏好设置、Containers 里以 App 编号命名、没有装着的 App 认领的，同一家公司的 App 还在就算它的；按 App 合成一行，不到 1 MB 不列）；重复的文件（个人文件夹里 10 MB 以上、内容完全一样的，只在本机比较）；不认得的 App 缓存（macOS 自己的不列）；Xcode 的 Archives；Mail 的数据（邮箱和索引、打开过的附件、缓存；写着删了会怎样：不用 Mail 要先在「系统设置 → 互联网账户」关掉每个账户的邮件，不然会重新下载；「我的 Mac 上」的邮箱只在本机，要完全磁盘访问权限才扫得到）。个人文件夹里点开头的文件夹算工具自己的地方，里面的文件不进大文件和重复的文件（归环境页）。Docker 只显示大小（镜像、容器、构建缓存），清理交给 Agent。
- **不记清理记录**。贴纸簿的「可清 N GB」是一键清理里能勾的合计。
- **环境页**（只看，卸载交给 Agent）：装了的开发环境都检测出来：Java（各个 JDK、默认哪个）、Conda（每个环境的 Python 版本、包的数量和大小，和包缓存）、Python（系统、Homebrew、pyenv、项目里的虚拟环境）、Node（nvm 的各版本、全局包）、Rust（工具链、各项目的 target）、Homebrew（装了什么、留着的旧版本）、Gradle、Maven、Docker（镜像、容器、数据卷）、Xcode 和模拟器、VS Code 的扩展、.NET SDK，也认 Go、Ruby、Flutter、Android SDK 这些常见的。
  - 每个写版本、在哪、多大、谁装的（Homebrew、nvm、conda、安装包）、默认用哪个、依赖（多少包、最大的几个）。版本和默认只看环境自己的小文件（JDK 的 release、Conda 的包清单、venv 的 pyvenv.cfg、nvm 的默认版本、rustup 的设置）和系统工具（java_home、xcode-select），不读别的文件内容。
  - 套在另一行里的（Homebrew 的旧版本、编辑器扩展的旧版本、Docker 的镜像）不重复算大小；受保护的标「受保护」，要管理员密码才能删的标出来，读不了的标「没权限」。
  - Ollama、Hugging Face、Claude Code、Codex、Eclipse、MySQL、TeX、R 这些列在「其他认得的」；认不出来的大文件夹（个人文件夹里点开头的、`~/.cache`、`/opt` 下面的）去掉认得的还有 100 MB 以上的，列在「其他（认不出来的）」，让 Agent 帮着认。
- **Agent 页**：和 Agent 聊，不进柚子的对话列表、搜索、⌘K、贴纸簿的数和年度总结。只有一个对话，退出再开还在；「新对话」删掉旧的（确认一次）。选模型（默认「柚子现在选的」，记住）和思考。不带柚子的记忆、知识库，不查柚儿园的数据；一个回答最多查 12 轮（柚子是 4 轮）。设置页的「发给 Agent 的说明」：SKILL（做事的规矩）能改，「保存」「恢复默认」，不进撤销；开头和「现在的情况」由程序每次写好，能点开看。「现在的情况」只写清理页清单的总数，清单里有什么由 Agent 自己去查。
  - **能看**：扫描结果（名字、大小、时间）、清理页的清单、开发环境（版本、包的列表），也能自己往任何文件夹里一层层查名字、大小、时间。不读文件内容。
  - **只读命令自己跑**：程序里定好的一份只读清单（du、ls、find、mdls、brew list、conda env list、pip list、npm ls -g、docker system df、java -version 这类），Agent 直接跑、马上看输出，回答里是一行「查了」，不出卡片；只能是一条普通命令（不接管道、重定向、变量），60 秒没跑完就停。清单外的要跑就出卡片。开发版和测试不真跑。用云端模型时这些名字和路径都会发出去（Seeker 文件夹、Pomelo 的数据目录也一样）。
  - 自己知道的不够判断时，自己决定联网搜索（插件库里开着、填了 Key 才有）；拿不准时用「问我」（只给云端模型）。
  - **只能提议**，三种卡片，我点了才执行：
    - 移到废纸篓：列出位置、大小和为什么能删，每项一个勾（受保护的默认不勾，勾了再确认一次）；做完每项写「移到废纸篓了」或没移的原因。
    - 跑命令：一张卡片一条不换行的命令，写清做什么、会删掉什么、能不能恢复、大概腾出多少；点「执行」才跑（用我终端里的环境，nvm、conda 能用），显示输出和退出码，能「停下」、「复制命令」。什么命令都能提议；要管理员密码的（sudo，比如删 JDK）只给命令，我自己在终端里跑。
    - 加进一键清理：名字、在哪（`*` 代表一个文件夹名里的任意字）、怎么认、怎么重建、要不要默认勾、现在有几处多大；只能是个人文件夹里工具自己的地方（至少两层；文稿、下载、桌面、图片这些和受保护的地方不行）。确认后加进去、马上重扫，在一键清理里单独一类；设置里能删。
    - 每张都能「不要」。加、删规则能 ⌘Z；清理、移到废纸篓、跑命令不能撤销。卡片边写边出现（等「问我」时也在），回复还在写时点不了；没提议成的（比如路径不在）在回答里写一行「查了」说原因。点过的结果（移了哪些、退出码和最后一段输出、加上了没有、点了「不要」）跟着那条回答，下一问发给 Agent。
  - **受保护的地方**：Pomelo 的数据目录、钥匙串、本地模型（`~/Documents/LLM`）、Seeker 文件夹、个人网站文件夹里除了依赖和构建产物的东西、系统本身。都能看，Agent 也能提议动，但卡片标「受保护」，点「执行」后再确认一次；一键清理（含 Agent 加的类别）永远不进这些地方。
- **设置页**：一键清理的各类能改名（点名字改，清空改回原名；Agent 加的规则改名能 ⌘Z），清理页跟着显示新名字。页面上的字都能选中复制。
- **柚子**能只读地查扫描结果（磁盘、能清多少、开发环境）；今日简报不提。
- Agent 的对话、卡片和加的规则在 `youzi.db`，跟着每日备份，不进导出的数据文件。

### Work（在对话里）

对标 Claude / ChatGPT 的 Work，但保持轻量，真正难的活交给它们。不单独做页面：资料、追问、确认都用对话现成的，模型用对话现在选的。工具箱只提议，写进文件、存成 Word 都由我点；定时任务也能用，助手不给。

- **写报告**：照常在对话里问（资料用附件、项目资料、知识库、联网）。回答能「保存为 Word」：文件名（默认是回答的第一个标题，没有就用对话标题，加日期）、文件夹（记住上次的，默认「文稿」），点「保存」才存，同名不覆盖、加「 (2)」。Word 有真正的标题、列表、表格、引用和代码样式，出处按编号列在文末。存好后能「打开」「在访达中显示」。
- **新建 Word**：Word 工具箱也能新建：柚子把写好的内容（Markdown）放进卡片，文件名、文件夹能改（规则同上），点「保存」才存。
- **改文件**（Word 工具箱改 Word，文本工具箱改 Markdown、纯文本；柚子觉得需要时自己用）：能改这个问题的附件（点选或拖进来的才有原文件，粘贴的截图、从附件库选的没有）、知识库里的文件。原地读写，不复制、不留备份。
  - 能改哪些直接告诉柚子；它按段读要改的部分（页码目录这类、文本框、空段不能改），再提议改哪几段（能删段、在一段后面加新段）。真的提议了才有卡片，只在回答里写改法不算。一条回答改一个文件。卡片每段一个勾（默认勾上）和前后差异；「写入文件」只写勾上的，「取消」不写；写入后能「打开文件」。
  - 写之前检查文件这期间有没有被改过，改过就不写。Markdown / 纯文本保留原来的换行和编码。Word 只改变了的地方：没改的字保留格式，新加的字跟着旁边的格式，图片、批注、样式不动。
  - Word 的格式也能改：加粗、斜体、下划线，段落改成标题（几级）或列表（项目符号、编号），都用文档里已有的样式（没有「标题 N」样式或没有那种列表可照着时改不了）；新加的段落照着前面那段。字体、颜色、版式不改。
  - 表格当作一段（一行一行，格子用 | 隔开）：只改格子里的字和加粗、斜体、下划线，行数、每行格数不变，空格子能填；一格里有好几段的、和上面合并的格子、表格套表格的不能改。
  - 制表符、段内换行的改动，和删掉有书签、批注、图片、分节符的段落，不放进卡片，回答里写明几段。
  - 写文件不能 ⌘Z；卡片存在对话里，导出也有。
- **读文件**（技能）：读这个问题带的附件和项目资料（柚子里存的那份）：看目录、按段号读、按字找，读到的段落标出处。太长放不下时，先给目录和按问题挑出的段落，柚子再补读。
- **改 Excel**（Excel 工具箱）：只认 .xlsx，能改的文件同 Word 工具箱。柚子先读（每张表多大，再一行行带位置的格子；公式连结果一起，日期、百分比是看得懂的样子），再提议：改格子里的数字、文字、日期和公式（空格子能填，样式不动；普通格子写日期或百分比时配上那种格式；原来是编号这类文字的还是文字）、加行（样式照上面那行，公式不自动填）、删行。卡片每处一个勾，写着哪张表哪一格或哪几行、改前改后；「写入文件」只写勾上的，写之前检查文件没被改过，不留备份。
  - 加删行时，下面的行和所有表里用到它们的公式、合并格、条件格式、数据验证、超链接、筛选、定义的名称都跟着挪；删掉的格子被公式用到时变 #REF!。加在某个公式范围最后一行后面、公式在这几行外面时（比如最后一条明细后面加一行，合计 =SUM(B3:B5) 在下面），范围扩到新行、算进合计（照「往清单里加一条」的意思，和 Excel 自己插行不同），回答里说一句。公式用到它自己所在的格子（循环引用）不放进卡片。
  - 改不了的不放进卡片，写明原因：设了保护的表；合并格除左上角以外的格子；数组公式；有图表或图片、表格对象、批注、数据透视表的表不能加删行（改格子可以）；有合并格、条件格式、数据验证或超链接只在这一行的不能删；公式写错（括号对不上、没写完）；会占好几格的新函数（FILTER、SORT、UNIQUE 这些）。
  - 公式结果等 Excel 打开时才重算（文件里写明打开时全部重算）。
  - 也能新建 .xlsx（像新建 Word）：卡片里能看到前面的行，能改名、换文件夹，点「保存」才存，同名不覆盖；第一行加粗，列宽照内容。

### 导出、空间、设置

- **导出**：柚子页导出当前版本的 Markdown，或含全部版本、附件、摘要的完整包。「设置 → 导出」的数据文件带哪些柚子的东西、导入时怎么替换，见 `schema.md`「数据文件（导出 / 导入）」（对话和附件不在里面）。
- **空间管理**（「设置 → 柚子 → 空间」）：数据库和附件、资料各占多少（附件和资料不进每日备份，也不用另外备份）；每份副本多大、被几个问题和资料用着，确认后才删（原文件不受影响，用到它的消息显示「文件已删除」，不能撤销）；没有记录的文件也能删；30 天没动过的空对话一键清理（能撤销）。
- **不做**：删除单条消息、临时聊天、导入其他 App 的旧聊天、退出后恢复草稿、语音、正文字号和消息间距的设置；音视频以后再说。
