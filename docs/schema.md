## 通用约定

- 每条记录都有一个整数编号 `id`，以及「创建时间」`created_at` 和「修改时间」`updated_at`。下面的表格里省略这三项。
- 纯日期写成 `2026-09-28`，年月写成 `2026-09`。
- 选项类字段（比如状态）在数据库里存英文代码，界面上显示中文。改中文叫法不需要动数据。
- 手动排序用 `sort_order`（数字越小越靠前）。
- 作者、国家等是普通文字。输入时会联想已经填过的值，帮助写法统一。

## 状态

书单、影单、绘画课程共用同一套状态，只是中文叫法不同：

| 代码 | 摸鱼读读 | 好奇看看 | 随意画画 |
|---|---|---|---|
| `unmarked` | 待标记 | 待标记 | 待标记 |
| `todo` | 想读 | 想看 | 未开始 |
| `doing` | 在读 | 在看 | 进行中 |
| `done` | 已读 | 已看 | 已完成 |

- 新建记录时默认是「待标记」。
- **完成时间**只记到年月（如 `2026-09`）。标为「已读 / 已看 / 已完成」时，如果完成时间还没填，就自动填当月。改回其他状态时不自动清除，需要的话手动修改。

## 出门走走

分成「场景模板」和「每次出行」两部分。每次出行时，从模板复制一份清单，之后勾选、增删都不影响模板，出行记录也能留下来。

**packing_templates**（场景模板，如「国内游 3~7 天」「回家」「出国 5~10 天」）

| 字段 | 含义 |
|---|---|
| `name` | 场景名，不能重名 |
| `sort_order` | 排序 |
| `note` | 备注 |

**packing_template_items**（模板里的物品）

| 字段 | 含义 | 说明 |
|---|---|---|
| `template_id` | 所属模板 | 删除模板时一起删除 |
| `category` | 类别 | 如 重要物品、随身、护理、兴趣 |
| `name` | 物品 | 必填 |
| `note` | 备注 | 同一物品在不同场景可以有不同备注 |
| `sort_order` | 排序 | |

**trips**（一次出行）

| 字段 | 含义 | 说明 |
|---|---|---|
| `name` | 名称 | 如「2026 国庆 · 回家」 |
| `template_id` | 来自哪个模板 | 只作记录；模板删了，出行还在 |
| `depart_on` | 出发日期 | 可不填 |
| `note` | 备注 | |

**trip_items**（这次出行的物品）

| 字段 | 含义 | 说明 |
|---|---|---|
| `trip_id` | 所属出行 | 删除出行时一起删除 |
| `category` | 类别 | |
| `name` | 物品 | |
| `note` | 备注 | |
| `packed` | 是否已打包 | 是 / 否 |
| `sort_order` | 排序 | |
