# 数据结构

共 13 张表，当前数据库版本是 8。

| 版本 | 内容 |
|---|---|
| 1 | 设置 |
| 2～4 | 书单、书的类型、影单 |
| 5 | 类型表（类型可以自己增删改） |
| 6 | 绘画课程、课节 |
| 7 | 出门走走：模板、模板物品、出行、出行物品 |
| 8 | 一步一步：分组、目标、任务 |

## 通用约定

- 每条记录都有编号 `id`、创建时间 `created_at`、修改时间 `updated_at`，下面的表格里省略。
- 日期写成 `2026-09-28`，年月写成 `2026-09`。
- 选项类字段（比如状态）存英文代码，界面显示中文。
- `sort_order` 是手动排序（越小越靠前），新加的记录排在最后。
- 名称、备注等文字会去掉首尾空格，空文字存为「没填」。

## 状态

书单、影单、绘画课节共用一套状态，叫法不同：

| 代码 | 摸鱼读读 | 好奇看看 | 随意画画 |
|---|---|---|---|
| `unmarked` | 待标记 | 待标记 | 待标记 |
| `todo` | 想读 | 想看 | 未开始 |
| `doing` | 在读 | 在看 | 进行中 |
| `done` | 已读 | 已看 | 已完成 |

- 新建记录默认「待标记」。
- **完成时间**只记年月。标为完成时，如果还没填，就自动填当月；改回其他状态时不会自动清除。
- 例外：在绘画课节前的圆圈上「取消完成」相当于撤销，会一起清空完成时间。

## 类型

**kinds**：可以自己增删改的类型列表。书和影视叫「类型」，出门走走叫「类别」。

| 字段 | 含义 |
|---|---|
| `module` | 属于哪个模块：`books` / `films` / `drawing` / `packing` |
| `name` | 名称，同一模块里不能重名，最多 20 个字 |
| `sort_order` | 排序，也决定出门走走里的分组顺序 |

- 各条记录里只记 `kind_id`（属于哪个类型）。改名只改这里一处。
- 删除类型后，属于它的记录变成「未分类」，不会被删掉。
- 默认值：书「虚构、非虚构、漫画、其他」；影视「电影、剧集、动漫」；课节「正课、DLC 跟画、LIVE 辅导」；行李「重要物品、随身、护理、兴趣」。

## 设置

**settings**：`key`（名称）、`value`（值）。比如「上次打开的页面」。

## 摸鱼读读 · 好奇看看

**books** / **films**：两张表的结构相同，只是作者一栏在影视里叫导演。

| 字段 | 含义 |
|---|---|
| `title` | 书名 / 名称，必填 |
| `author` / `director` | 作者 / 导演，多人用「 / 」隔开 |
| `country` | 国家 |
| `kind_id` | 类型，可不填 |
| `status` | 状态 |
| `rating` | 尝尝咸淡，1～5 星，可不填 |
| `finished_month` | 完成时间（年月） |
| `note` | 备注 |

## 随意画画

**drawing_courses**（课程）：`name` 课程名（不能重名）、`note` 备注、`sort_order`。

**drawing_lessons**（课节）：

| 字段 | 含义 |
|---|---|
| `course_id` | 所属课程；删除课程时课节一起删除 |
| `code` | 编号，如 `2B`、`7S_1`，只用来显示 |
| `kind_id` | 类型 |
| `title` | 课名，必填 |
| `status` · `finished_month` · `note` | 状态、完成时间、备注 |
| `sort_order` | 课程内的顺序（编号不能用来排序） |

## 出门走走

建一次出行时，从模板复制一份清单；之后两边各改各的，出行记录也能一直留着。

**packing_templates**（模板）：`name` 模板名（不能重名）、`note` 备注、`sort_order`。

**packing_template_items**（模板里的物品）：`template_id` 所属模板（删模板时一起删）、`kind_id` 类别、`name` 物品、`note` 备注、`sort_order`。

**trips**（出行）：`name` 名称、`template_id` 来自哪个模板（只作记录，模板删了出行还在）、`depart_on` 出发日期、`note` 备注。

**trip_items**（这次的物品）：`trip_id` 所属出行（删出行时一起删）、`kind_id` 类别、`name` 物品、`note` 备注、`packed` 是否已装好、`sort_order`。

## 一步一步

参考「目标地图」：分组 → 目标 → 任务 → 多级子任务。

**todo_groups**（分组）：`name` 名称（不能重名，可以用 emoji 开头）、`sort_order`。

**todo_goals**（目标）：`group_id` 所属分组、`name`、`status` 状态（`active` 进行中 / `paused` 暂停 / `done` 已完成 / `abandoned` 已放弃）、`start_date` · `end_date` 时间、`note` 备注、`review` 复盘、`sort_order`。

**todo_tasks**（任务）：

| 字段 | 含义 |
|---|---|
| `group_id` · `goal_id` | 所在的分组和目标（不属于目标的任务，`goal_id` 为空） |
| `parent_id` | 上一层任务；为空就是顶层任务。子任务的分组和目标跟着顶层任务走 |
| `title` · `note` · `link` | 任务、备注（都可以用 `**加粗**`）、链接 |
| `plan_date` | 计划哪天做 |
| `due_date` | 截止日期；和 `start_date` 一起就是时间段 |
| `done` · `done_at` | 是否完成、完成时间（导入的旧完成项没有时间） |
| `collapsed` | 子任务是否折叠 |
| `sort_order` | 同一层里的顺序 |

- 删除分组、目标或任务时，下面的东西一起删除。
- **勾选规则**：勾上一个任务，它下面的子任务一起勾上；子任务全部勾上时，上一层自动勾上；取消勾选或新加子任务时，上一层自动取消。
- **进度**：只数最底层的任务（没有子任务的那些）。目标的状态由我手动改，全部完成时会提示。
- **今天**：没完成、不在暂停或已结束目标里的任务中，计划日期是今天或更早的、截止是今天的、今天在时间段里的。**已过期**：截止日期已过；没有截止日期的，计划日期已过。

## Excel 导入对照

| Excel 里 | 导入后 |
|---|---|
| 想读 / 想看、在读 / 在看、已读 / 已看、未开始 | `todo`、`doing`、`done`、`todo` |
| 好奇看看里没填状态的 38 部 | 待标记 |
| ★ ~ ★★★★★ | 1～5 星 |
| 书的类型 / 影视的类型 | 分别先记为「虚构」/「电影」 |
| 多位作者、导演之间的「&」 | 统一改成「 / 」 |
| 课节的类型 | 对应同名类型；编号为 DLC、LIVE 的，编号留空 |
| 出门走走的 3 个场景 | 3 个模板，共 34 件物品；「本次打包」的 ✓ 不导入 |
| 行的先后顺序 | `sort_order`；课程、模板按第一次出现的顺序 |

## 数据文件（导出 / 导入）

Pomelo 自己的数据文件格式（JSON），导出和导入用同一种。`pnpm import:xlsx` 从 Excel 生成的也是它。

| 部分 | 内容 |
|---|---|
| `format` · `formatVersion` | 固定为 `pomelo-export`；版本 2（版本 1 也能导入） |
| `exportedAt` · `appVersion` | 导出时间、导出时的 App 版本，只作记录 |
| `kinds` | 每个模块的类型名称，按顺序排列 |
| `modules` | 各模块的数据：`books`、`films`、`drawing`（课程里套课节）、`packing`（模板和出行，各自套物品）、`todo`（分组里套目标和任务，任务里套子任务） |

- 记录之间用**名称**关联，不用编号：类型写名称，出行来自哪个模板也写模板名。
- 顺序就是列表里的顺序；创建时间、修改时间都会带上。
- 导入时，文件里有哪个模块就替换哪个模块，连同它的类型列表；文件里没有的模块不动。
- 版本 2 新增了类型列表和出门走走的时间。
