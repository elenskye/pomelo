# 数据结构

共 21 张表，当前数据库版本是 12。

| 版本 | 内容 |
|---|---|
| 1 | 设置 |
| 2～4 | 书单、书的类型、影单 |
| 5 | 类型表（类型可以自己增删改） |
| 6 | 绘画课程、课节 |
| 7 | 出门走走：模板、模板物品、出行、出行物品 |
| 8 | 一步一步：分组、目标、任务 |
| 9 | 一步一步：任务类型（重复、打卡、进度条）、完成记录 |
| 10 | 一步一步：日期简化（不再有计划日期）、重复任务的「已经做了几次」 |
| 11 | 一步一步：打卡改用时间段、每月重复改成按次数 |
| 12 | 钱来钱往：账户、余额、汇率、持仓、收支、固定支出、预算 |

## 通用约定

- 每条记录都有编号 `id`、创建时间 `created_at`、修改时间 `updated_at`，下面的表格里省略。
- 日期写成 `2026-09-28`，年月写成 `2026-09`。
- 选项类字段（比如状态）存英文代码，界面显示中文。
- `sort_order` 是手动排序（越小越靠前），新加的记录排在最后。
- 名称、备注等文字会去掉首尾空格，空文字存为「没填」。

## 状态

书单、影单、绘画课节共用一套状态，叫法不同：

| 代码 | 摸鱼读读 | 好奇看看 | 随意画画 |
|---|---|---|---|
| `unmarked` | 待标记 | 待标记 | 待标记 |
| `todo` | 想读 | 想看 | 未开始 |
| `doing` | 在读 | 在看 | 进行中 |
| `done` | 已读 | 已看 | 已完成 |

- 新建记录默认「待标记」。
- **完成时间**只记年月。标为完成时，如果还没填，就自动填当月；改回其他状态时不会自动清除。
- 例外：在绘画课节前的圆圈上「取消完成」相当于撤销，会一起清空完成时间。

## 类型

**kinds**：可以自己增删改的类型列表。书和影视叫「类型」，出门走走叫「类别」。

| 字段 | 含义 |
|---|---|
| `module` | 属于哪个模块：`books` / `films` / `drawing` / `packing` |
| `name` | 名称，同一模块里不能重名，最多 20 个字 |
| `sort_order` | 排序，也决定出门走走里的分组顺序 |

- 各条记录里只记 `kind_id`（属于哪个类型）。改名只改这里一处。
- 删除类型后，属于它的记录变成「未分类」，不会被删掉。
- 默认值：书「虚构、非虚构、漫画、其他」；影视「电影、剧集、动漫」；课节「正课、DLC 跟画、LIVE 辅导」；行李「重要物品、随身、护理、兴趣」。

## 设置

**settings**：`key`（名称）、`value`（值）。比如「上次打开的页面」。

## 摸鱼读读 · 好奇看看

**books** / **films**：两张表的结构相同，只是作者一栏在影视里叫导演。

| 字段 | 含义 |
|---|---|
| `title` | 书名 / 名称，必填 |
| `author` / `director` | 作者 / 导演，多人用「 / 」隔开 |
| `country` | 国家 |
| `kind_id` | 类型，可不填 |
| `status` | 状态 |
| `rating` | 尝尝咸淡，1～5 星，可不填 |
| `finished_month` | 完成时间（年月） |
| `note` | 备注 |

## 随意画画

**drawing_courses**（课程）：`name` 课程名（不能重名）、`note` 备注、`sort_order`。

**drawing_lessons**（课节）：

| 字段 | 含义 |
|---|---|
| `course_id` | 所属课程；删除课程时课节一起删除 |
| `code` | 编号，如 `2B`、`7S_1`，只用来显示 |
| `kind_id` | 类型 |
| `title` | 课名，必填 |
| `status` · `finished_month` · `note` | 状态、完成时间、备注 |
| `sort_order` | 课程内的顺序（编号不能用来排序） |

## 出门走走

建一次出行时，从模板复制一份清单；之后两边各改各的，出行记录也能一直留着。

**packing_templates**（模板）：`name` 模板名（不能重名）、`note` 备注、`sort_order`。

**packing_template_items**（模板里的物品）：`template_id` 所属模板（删模板时一起删）、`kind_id` 类别、`name` 物品、`note` 备注、`sort_order`。

**trips**（出行）：`name` 名称、`template_id` 来自哪个模板（只作记录，模板删了出行还在）、`depart_on` 出发日期、`note` 备注。

**trip_items**（这次的物品）：`trip_id` 所属出行（删出行时一起删）、`kind_id` 类别、`name` 物品、`note` 备注、`packed` 是否已装好、`sort_order`。

## 一步一步

参考「目标地图」：分组 → 目标 → 任务 → 多级子任务。

**todo_groups**（分组）：`name` 名称（不能重名，可以用 emoji 开头）、`sort_order`。

**todo_goals**（目标）：`group_id` 所属分组、`name`、`status` 状态（`active` 进行中 / `paused` 暂停 / `done` 已完成 / `abandoned` 已放弃）、`start_date` · `end_date` 时间、`note` 备注、`review` 复盘、`sort_order`。

**todo_tasks**（任务）：

| 字段 | 含义 |
|---|---|
| `group_id` · `goal_id` | 所在的分组和目标（不属于目标的任务，`goal_id` 为空） |
| `parent_id` | 上一层任务；为空就是顶层任务。子任务的分组和目标跟着顶层任务走 |
| `title` · `note` · `link` | 标题、内容（都可以用 `**加粗**`）、链接 |
| `start_date` · `due_date` | 普通、打卡、进度条：时间段的开始和结束（开始可以不填，只有截止日期） |
| `due_date` | 重复：「这一次」是哪天，由规则推算，不用自己填 |
| `plan_date` | 重复（完成后）：从哪天开始 |
| `done` · `done_at` | 是否完成、完成时间（导入的旧完成项没有时间） |
| `collapsed` | 子任务是否折叠 |
| `sort_order` | 同一层里的顺序 |
| `task_type` | 类型：`normal` 普通 / `repeat` 重复 / `checkin` 打卡 / `progress` 进度条 |
| `repeat_rule` | 重复规则，重复和打卡用（见下） |
| `repeat_total` | 重复（除了「完成后」）：一共几次，空着就是不限 |
| `done_before` | 重复：开始用 Pomelo 记录之前已经做了几次 |
| `repeat_until` | 旧字段，现在不用 |
| `target` · `unit` | 进度条：目标数量、单位（本、份） |
| `period` | 旧字段，现在固定为 `all`（进度条只按累计算） |

**todo_logs**（完成记录）：`task_id` 哪个任务（删任务时一起删）、`day` 哪天、`amount` 数量（默认 1）。重复任务每做完一次记一条，打卡每天一条，进度条每记一笔一条。

**重复规则**：`daily` 每天、`weekly:6` 每周六（`weekly:1,2,3,4,5` 工作日，周一是 1）、`monthly:1,15` 每月 1 号和 15 号（没有 31 号的月份用最后一天）、`every:3d` / `every:2w` 每隔 3 天 / 2 周、`after:7d` 完成后 7 天。打卡只能用每天或每周几天。

- 删除分组、目标或任务时，下面的东西一起删除。
- **勾选规则**：勾上一个任务，它下面的子任务一起勾上；子任务全部勾上时，上一层自动勾上；取消勾选或新加子任务时，上一层自动取消。
- **进度**：只数最底层的任务（没有子任务的那些）。目标的状态由我手动改，全部完成时会提示。
- **今天**：没完成、不在暂停或已结束目标里的任务中，截止是今天或更早的、今天在时间段里的。**已过期**：截止日期已过。
- **重复**：新建或换了规则时，从今天（或开始日期，取晚的）起找第一个该做的日子。做完一次记一条，日期挪到下一次；下一次一定在「这一次」和「做完那天」之后，所以拖晚了也不会欠一串。一共几次做满、或下一次超过结束日期，就算整个完成。「跳过这次」只挪日期、不记。
- **已经做了几次** = `done_before` + 记录条数；不能少于已经记录的次数，也不能多于一共几次。
- **打卡**：按规则该打卡、又在时间段里的日子出现在今天。补打和取消只能在时间段里、今天以前该打卡的日子。时间段结束后自动算完成（每天第一次打开 App 或日期变了的时候检查）。
- **进度条**：累计达到目标自动完成；有时间段的，和普通任务一样在时间段内每天出现在今天。
- 这三种任务不能有子任务。

## 钱来钱往

金额都存成「分」的整数（123.45 元存 12345），所以不会有小数误差。币种是 `CNY` 人民币 / `SGD` 新币 / `HKD` 港币 / `USD` 美元。不同币种从不直接相加，只有总资产会按当月汇率折成人民币。

**fin_accounts**（账户）：`name` 名称（不能重名）、`kind` 类型（`bank` 银行 / `wallet` 钱包 / `broker` 券商）、`currency` 币种（一个账户只有一种；有记录后不能改）、`closed` 停用、`note`、`sort_order`。

**fin_balances**（每月余额）：`account_id`、`month` 月份、`amount` 余额。同一账户每月一条。券商账户的余额就是账户总值。删账户时一起删。

**fin_rates**（每月汇率）：`month`、`currency`、`rate`（1 单位合多少人民币）。人民币不用存。

**fin_holdings**（持仓）：`account_id`（只能是券商账户）、`month`、`name` 名称、`quantity` 数量（可不填）、`value` 市值（账户的币种）、`sort_order`。每次保存会整月替换。

**fin_entries**（收支）：`flow`（`out` 支出 / `in` 收入）、`amount`（大于 0）、`currency`、`day` 日期、`kind_id` 分类、`account_id` 账户（可不填；填了的话币种必须和账户一样）、`fixed_id` 是哪个固定支出自动记的、`note` 备注。删账户或固定支出时，记录留着，只是不再关联。

**fin_fixed**（固定支出，也可以是固定收入）：`name`（不能重名）、`flow`、`amount`、`currency`、`kind_id`、`account_id`、`rule` 周期（`monthly:15` 每月 15 号，没有这天的月份用最后一天；`yearly:03-01` 每年 3 月 1 日）、`next_day` 下次哪天记、`stopped` 停用、`note`、`sort_order`。

**fin_budgets**（预算）：`kind_id` 支出分类、`currency`、`amount` 每月金额。同一分类每个币种一条；删分类时一起删。

**分类**放在类型表里：支出（模块名 `fin_out`）默认「餐饮、交通、购物、住房、通讯、订阅、学习、娱乐、医疗、旅行、其他」，收入（`fin_in`）默认「津贴、奖学金、家里、投资收益、其他」。

- **总资产**：某个月所有账户的余额 × 当月汇率之和。缺哪个币种的汇率，那个月就不算总数，并提示缺什么。
- **固定支出**：到了 `next_day`（每天第一次打开 App、日期变了、或刚保存时检查），就自动记一笔（备注写名称），再把 `next_day` 挪到下一次；中间漏掉的几次会一起补上。
- **预算**：按「分类 + 币种」比当月这个币种的支出。

## 数据文件（导出 / 导入）

Pomelo 自己的数据文件格式（JSON），导出和导入用同一种。`pnpm import:xlsx` 从 Excel 生成的也是它。

| 部分 | 内容 |
|---|---|
| `format` · `formatVersion` | 固定为 `pomelo-export`；版本 5（更早的版本也能导入） |
| `exportedAt` · `appVersion` | 导出时间、导出时的 App 版本，只作记录 |
| `kinds` | 每个模块的类型名称，按顺序排列（钱来钱往有两套：`fin_out`、`fin_in`） |
| `modules` | 各模块的数据：`books`、`films`、`drawing`（课程里套课节）、`packing`（模板和出行，各自套物品）、`todo`（分组里套目标和任务，任务里套子任务）、`finance`（账户里套余额和持仓，另有汇率、固定支出、收支、预算） |

- 记录之间用**名称**关联，不用编号：类型写名称，出行来自哪个模板也写模板名。
- 顺序就是列表里的顺序；创建时间、修改时间都会带上。
- 导入时，文件里有哪个模块就替换哪个模块，连同它的类型列表；文件里没有的模块不动。
- 版本 2 新增了类型列表和出门走走的时间；版本 3 新增了任务类型和完成记录（任务里的 `logs`）；版本 4 新增了重复任务的 `doneBefore`，重复任务的日期改放在 `dueDate`；版本 5 新增了钱来钱往，打卡的时间段改放在 `startDate` / `dueDate`（导入旧文件时都会自动转换）。
