# 视觉规范

> 要改视觉，先改这份文档，再改主题变量（`src/index.css`）。v1.0 前统一打磨一次。

## 气质

**清爽、温柔、带一点柚子味，像 macOS 原生应用一样安静。** 模块名俏皮（摸鱼读读、尝尝咸淡），整体轻松有温度，但不花哨。内容是主角，颜色只表示状态和重点，不做装饰。

## 颜色

灵感来自柚子：柚皮的黄绿、红柚果肉的珊瑚红、柚子瓤的暖白。浅色、深色两套，跟随系统；文字和背景对比度都达到 WCAG AA。

| 柚瓤白 | 页面背景 | `#FAF8F4` | `#1C1B19` |
| 桌面 | 顶栏、纸外面的底色 | `#F3F0E9` | `#232120` |
| 卡面 | 表格、卡片、面板 | `#FFFFFF` | `#292724` |
| 分割线 | 边框、分隔 | `#E8E3D9` | `#3A3734` |
| 墨色 | 正文 | `#2B2824` | `#ECE8E1` |
| 淡墨 | 次要文字 | `#6F685F` | `#A29B91` |
| 柚红 | 主色：主按钮、选中、链接、焦点框 | `#C4503B` | `#EE7B66` |

**状态色**（底色 / 文字）：待标记 `#EFECE6` / `#6F685F`；想读·想看·未开始 `#E3EDF8` / `#33628F`；在读·在看·进行中 `#FBEFC8` / `#855C00`；已读·已看·已完成 `#E2F0D6` / `#3F6D27`（深色各一套，在 `index.css`）。星级点亮是实心 `#E9A825`，未点亮是淡墨空心。

**模块色**（只用在模块图标上）：摸鱼读读 湖蓝 `#3A7FBA`、好奇看看 葡萄紫 `#8466C4`、随意画画 柚红 `#CC5540`、出门走走 柚皮绿 `#588A2C`、一步一步 柚子黄 `#B07A10`、钱来钱往 青绿 `#2E8B80`、投石问路 梅紫 `#9C5B8F`、念念不忘 栗子棕 `#9A6B4A`、来日方长 樱桃粉 `#C2547A`、呦呦漫游 竹青 `#3A8A5C`、五花八门建的 靛蓝 `#4E5FB0`、循序渐进建的 橄榄 `#7D7A2A`、芝麻开门 岩灰 `#64748B`、小拾 杏子橙 `#C96E28`；小拾的助手当模块后：Seeker 玫瑰 `#B5527A`、Translator 湖青 `#3B8FB0`、Pub2MD 鸢尾紫 `#6F62A8`、Rater 胭脂 `#B0414E`。模块坞的分类色从模块色里按顺序借：柚子黄、青绿、湖蓝、梅紫、竹青、杏子橙、岩灰、樱桃粉、葡萄紫、柚皮绿。

**选项色**（五花八门的单选 / 多选选项、循序渐进的类型）：按在列表里的顺序配，蓝、橙、绿、黄、粉、紫、青、灰八种（`--tag-1`～`--tag-8`，底色 / 文字，深浅各一套，都达到 AA），第 9 个起从头再来；不能自己选。

**图表色**：固定顺序（蓝、橙、青、黄、粉、绿，深色各调一档，检查过色弱可读性），跟着分类走、不跟着排名走；收入蓝、支出橙，其余合成灰色「其他」。只用 `--chart-*`。

## 文字、布局、图标、动效

- 字体全部用「手札体-简」（找不到时用苹方），只有常规和粗体，粗体用它自带的那一款（不然系统会把常规体描粗、发糊）；文件路径用等宽字体。**例外**：小拾里问题和回答的正文用苹方（读长文不累），代码用等宽字体。字号：正文 14、次要 12、页面标题 22 粗、统计数字 20 粗；行高 1.6。
- 外框见下面的「外框」。
- 页面三层：**标题 + 统计** → **工具栏**（搜索、筛选、新增）→ **内容**。编辑时从右侧滑出面板（宽 400），不跳转。
- 间距以 4 为单位；圆角：按钮和输入框 8，卡片和面板 12。只有浮层（面板、弹窗、下拉菜单）有柔和阴影。能滚动的区域四周留 4 像素，焦点框不会被切掉。
- 界面图标用 Lucide 线条图标，16 号、线宽 1.5。模块图标：脚印、翻开的书、场记板、调色盘、行李箱、钱包、公文包、羽毛、带爱心的日历、指南针、钥匙、小鸟；自己建的模块用建的时候选的图标（24 个：形状、清单、手柄、音符、耳机、相机、电视、咖啡、餐具、购物袋、礼物、衣服、飞机、山、叶子、新芽、哑铃、爱心、星星、学士帽、语言、代码、拼图、奖杯）；首页是房子、设置是齿轮（淡墨色）。内容里的 emoji 原样显示。菜单栏是啄点鸟单色图：实心模型就绪，空心没运行。
- 动效只用 0.15～0.2 秒的轻柔过渡（柚子和柚子瓣例外）；系统开了「减少动态效果」就关掉。

## 外框（v0.7 阶段 ①，照原型 r4）

- **顶栏**：高 51，横贯窗口，底色是「桌面」，下面一条分割线。左起：红黄绿；柚子（左边留 90，和绿灯隔开一点，比红黄绿之间的空稍宽；38 的图标，鼠标移上去和展开时浅底圆角）；‹ ›（28 宽，不能用时变淡）；一条短竖线；页签。右边：开发版多一个淡墨小胶囊「开发版」、淡墨日期「10 月 27 日 · 周二」（窗口窄于 1100 时不显示）、搜索框（卡面底细边，放大镜和淡墨「搜索」，不写快捷键）、齿轮、杏子橙的圆形小拾按钮（白色小鸟）。所有图标和页签的中线对齐红黄绿的中线（`tauri.conf.json` 的 `trafficLightPosition` 是 x 18、y 27.5：红黄绿的圆心在 y − 2 处，正好是顶栏中线 25.5）。
- **页签**：高 30、圆角 8，模块色小图标 + 名字（太长省略；有子页的写「Seeker · 简历」），× 在鼠标移上去或当前页签上出现；当前的是纸色底 + 细边 + 小阴影，其余淡墨、鼠标移上去浅底；最后一个「＋」。右键 ‹ › 弹出下拉菜单，每行模块图标和页名。
- **纸和索引签**：纸是柚瓤白、圆角 14（右边 4）、左边一列缝线点、柔和阴影，上下左露出 14～16 的桌面。索引签宽 118、高 31，右端圆角：模块色 16% 的浅底、模块色图标、名字；当前的变成纸色、往左伸出连着纸、粗体；最上面首页、模块坞（灰），空一格是置顶的模块；鼠标移上去往右挪 3 像素。窗口窄于 1100 时只剩图标（名字在鼠标提示里）。
- **模块坞**（一页）：标题「模块坞」；淡墨「图钉 置顶」下一排大格子（宽 112：40 的圆角模块色图标、粗体名字、淡墨实时小字；助手左上一只杏子橙小鸟）；窗口窄于 1100 时格子宽 94、图标 32；下面分类卡片自动排列：模块色圆点、粗体分类名（点了直接改）、淡墨个数，鼠标移上去右边出现「+」（空的分类还有 ×）；每个模块一行：26 的图标、名字、置顶的淡墨小图钉、右边淡墨实时小字。最后一张虚线卡片「＋ 分类」；最下面淡墨「已隐藏 N ⌄」，展开是变淡的几行。格子和行鼠标移上去右上出现「⋯」；拖动时被拖的变淡，能放的地方一圈柚红虚线。菜单：置顶 / 取消置顶、隐藏 / 取消隐藏，分隔线下淡墨「移到」和每个分类（圆点、名字，当前的打勾）。
- **柚子瓣**：盖住纸和索引签（半透明柚瓤白加模糊）。中间一个大柚子（直径约 600，按窗口高缩放）：外圈淡黄柚皮；每瓣是分类色 15% 的浅底，瓣之间留缝；模块（42 的图标 + 名字）排在瓣中间一圈，置顶的左上淡墨图钉，助手右上小鸟；瓣名在柚皮外面（分类色加深的粗体，点了直接改）；中心白圆里淡墨日期和圆角输入框「去哪，或问小拾」，对不上时下面一行「小鸟 问小拾「…」」。左下淡墨「＋ 分类」，右下淡墨「已隐藏 N」。打开时从柚子的位置转着长出来（约 0.4 秒），之后在里面调整分类、拖动、改名都原地更新（不再长一遍），收起时缩回去；打字时没对上的模块变得很淡，对上的图标外一圈浅柚红。
- **柚子图标**：照草图画：外圈柚皮 `#EBB36E`、果肉 `#F8D694`，平常、在想、眨眼、困了中间多一圈瓤 `#F0C17C`；五官棕 `#9D5D36`；叶子 `#8DA872`；光点和星星金 `#DCAA52`；出错的「!」是 `#CD7865` 圆底白字。在想时右上两颗光点浮起，开心时左上和右边两颗星，困了右上「z z」。动画：平常慢慢呼吸；在想叶子摆、隔一会儿眨眼；开心弹两下、星星闪；出错摇两下、「!」弹出；眨眼歪一下头；哇跳一下。冒出的话是柚子下面一张小卡片（左上角小圆角，出错时边框带红）。

## 文案

- 全中文，保留俏皮的叫法。按钮用简单动词：新增、保存、删除、导出。空白页可以俏皮（「书架空空，去摸会儿鱼吧」），但不附操作说明。
- **不写使用提示**：不提示快捷键、怎么操作、可以撤销；输入框不放示例。要解释的只放在设置页的 (?) 里。
- 删除前确认，确认框里只写会一起删掉什么。

## 通用控件

- **下拉菜单**：自己画的圆角卡片，当前项打勾；选项能分组（淡墨小字组名）；长的分组列表（模型）组名前有小箭头、折起来时组名后面淡墨个数，点组名开合；底部可以有「管理类型…」这类操作。键盘能用；在对话框里也不会被裁掉。
- **日期输入**：框里写「2026 / 10 / 05」和日历图标，空的写淡墨「年 / 月 / 日」；点开是自己画的月历（周一开头，今天细圈，选中柚红实心圆，底部「今天」「清除」）。只选月份的是 3 × 4 格子；只选年的是下拉框。时间段写「开始 到 结束」。
- **表格**：能就地改的格子平时是普通文字，鼠标移上去出现浅底和小箭头。**多选**：右上「多选」按下后变柚红「完成」，行首出现勾选框，选中的行浅柚红底，底部一条操作栏；平时行首不留勾选框的位置。
- **拖拽排序**：按住整行拖（移动几像素才开始），表格型列表鼠标移上去最左边出现把手，其他行让开。
- **可一键完成的条目**（课节、物品、待办）前面是圆圈：空心未完成、带点进行中、打勾已完成；打卡今天打过显示勾；进度条是按比例填满的小饼图。
- **展开收起**：最右边淡墨小字「1/3 ⌄」，收起时箭头朝右。
- **进度条、预算条**：完成是绿色；预算没到 90% 绿，快到黄，超出红并写「超出 S$20」。
- **钱**：带币种符号（¥ / S$ / HK$ / US$），千分位，整数不写「.00」；收入写「+」用绿色，结余为负写「-」用红色。
- **图表**：折线 2 像素，柱子最宽 24、顶部 4 像素圆角，网格线很淡，只有一个坐标轴；鼠标移上去有提示，数字在旁边的清单里也都看得到。多条曲线时每个点有小圆点，上方一排小圆标签切换显示哪些。
- **开关**：小号胶囊，开是柚红，关是淡灰。**小圆角标签**（多选一排的那种）：选中柚红浅底，没选细边淡墨。
- **长列表选择**（岗位、题目、素材、公司资料这类会越来越长的）：输入框样子的按钮（当前选的 + 上下小箭头），点了弹出宽 560 的小窗：标题、右上 ×，搜索框，下面淡墨小字分组，每行左边名字、右边淡墨补充（地点 · 日期、准备 N · 复盘 M），选中的那行柚红细边浅底；点一行选上并关掉，回车选第一行，Esc 关掉。
- **设置页**：每行左边名称和小问号 (?)，右边内容和按钮。
- **差异**（润色、改文件、笔记改写）：删掉的淡墨加删除线，新加的浅柚红底。

## 各处的样子

- **首页**：标题位置是问候语，右边淡墨日期「10 月 8 日 周四」。新年第一周最上面一张「2025 年度总结」卡片（同简报：杏子橙小鸟 + 粗体标题，右上淡墨「看全文」；一行关键词，一两行淡墨开头）；阅读框宽 720、高八成窗口，中间照小拾消息排版，底下「在小拾里打开」。下面「今日简报」卡片（白底细边圆角）：杏子橙小鸟 + 粗体「今日简报」，右上淡墨「重写」（失败时「重试」）；几小段正文（只认 **粗体**）；写的时候一行跳动的淡墨「正在写…」，重写时旧的变淡留着；失败一行红字；最下面淡墨「没看：…」。再下面「2026 年」一排数字格（淡墨小字：模块图标 + 读完；20 粗的数字 + 淡墨单位）。再下面两栏 3 : 2，窄于 1024 时一栏。每块粗体小标题（模块图标 + 名字，鼠标移上去出现 ›），下面一张卡片，每行左边标题、右边淡墨小字。总资产是 20 粗的数字、绿 / 红「比上次」和 130 高的曲线（只标首、中、尾三个日期）；求职近况三个小数字，每行右边黄色「该跟进 · 等了 N 天」或状态标签；绘画进度每门课一行：名字、「2 / 40」、进度条、淡墨「下一节 …」。空的块一句淡墨话（「今天没有安排，喝杯茶吧 🍵」）。
- **全局搜索**：像聚焦搜索，窗口上方居中（宽 600），半透明遮罩；放大镜 + 大号输入框，下面按模块分组（淡墨小标题：模块图标 + 名字），每行左边标题、右边淡墨小字，选中的浅柚红底。最下面「意思相近」（闪光图标，找的时候后面「· 正在找…」），每行前面多一个模块小图标。
- **一步一步**：任务栏只有圆圈、标题和紧跟的淡墨截止日期（过期标红），子任务每层缩进一格。从笔记转来的任务，面板「内容」下面一栏「来自笔记」：棕色小羽毛 + 淡墨笔记开头。月历周一开头 6 行，每格列出当天的事，放不下写「还有 N 项」。
- **列表型页面**（随意画画、出门走走、一步一步、循序渐进）：左边列表和进度，右边内容。
- **投石问路**：状态标签按阶段上色（准备灰、等回音蓝、进行中黄、拿到绿、结束淡灰），结束的整行变淡；「日期」后面淡墨「· 等了 7 天」或黄色「· 该跟进」。面板的状态：一排小圆角标签（最后一个齿轮是「管理状态」），下面是时间线：每行小方勾选框（勾上柚红实心白勾），框之间一条细竖线，勾上的右边是日期框。没有「简历」一栏；「Seeker」一栏：标题右边「✦ 做简历」，本次使用的简历一行细边小框（文件图标和文件名，点了打开；英文的淡墨「English」；右边访达图标），以前用过的不显示，下面占满一栏的「选择简历…」；弹窗（宽 720）上面「中文 · English」分段和按文件名找，下面一组一组（粗体名字、淡墨「N 版 · 投石问路：…」），每份一行（文件名、柚红「本次使用 / 用过 · Pomelo 导出」、淡墨日期），点了柚红细边浅底，双击直接用，右下柚红「用于本次投递」。「面试」一栏两个占半栏的大按钮「✦ 准备面试」「＋ 复盘」，下面是这个岗位的准备和复盘（没有就什么都不写）。
- **重读 / 重看**：面板「完成时间」下面，每行年份下拉框 + 星星 + 红色 ×，最下面柚红小字「+ 再读一次」。
- **念念不忘**：
  - 左栏：三个数字（笔记、标签、天）、热力图（16 周，一列一周，`--chart-3` 四档深浅）、「全部笔记」、「置顶」、「标签」树。标签前是 20 像素宽的图标位（线条图标用念念不忘的棕色，emoji 原色，没设是淡墨 #），和名字之间 8 像素；鼠标移上去右边「⋯」。换图标弹窗：8 × 6 线条图标，下面「其他 emoji」输入框。
  - 右边：卡片占满右边（到搜索框的右边）；上面淡墨时间「2026 / 02 / 23 14:39」，置顶的有柚红小图钉。`#标签` 柚红能点，高亮是「在读」的黄底，下划线细线；**段落之间空 0.75 个字高**，列表项之间 4 像素。超过 320 高的折起来，底部渐隐，「展开全文」。引用的笔记在正文下方，左边一条竖线。输入框占位「现在的想法是……」，空的时候写「念念不忘，必有回响」；边写边显示，和卡片一样（空一行是 0.9 个字高，标记符号变淡）。
