# 视觉规范

> 柚儿园现在长什么样、每样东西从哪来、做界面时怎么照着做。功能和规则在 `requirements.md`，怎么测在 `testing.md`。前面十五节是整套视觉和规矩，从头读；最后一节「各处的样子」是每一页的细节，用到再查。

## 气质

**一张摊开的桌面，上面是手账。** 清爽、有活力、手作感：手画的墨线、错开一点的颜色、带白边的贴纸、胶带和纸。纸、胶带、贴纸可以歪，字永远是正的、清楚的。处处有小动静，动起来都像纸和贴纸。内容是主角，颜色只表示分类、状态和重点。

窗口最上面一条顶栏，下面是桌面。首页的便签直接摆在桌上；打开的模块是摊在桌上的一张方格纸，左边一列缝线，左上角拍着它的贴纸，别的开着的页叠在它右边。柚子是唯一的角色：就是 AI，也是顶栏、菜单栏和 App 图标。

不要的样子：后台表格感、通用的细线图标、装饰堆砌（一张卡片最多两条胶带、一张贴纸）。

- **对比度**在方案那边查过（每套配色、明暗都过），这边不另查。

## 字

- 界面只用 `font-sans`：`index.css` 里的 `Pomelo Hand`，就是手札体，常规和粗体各指到它自带的那一款（直接写 `Hannotate SC`，粗体会被系统描粗、发糊）。找不到时用苹方。
- **唯一的例外**：柚子里要读长文的地方（问题和回答的正文、译文、提示词）用苹方（`font-reading`），15 号、行高 1.7。文件路径和代码用等宽（`font-mono`）。
- 字号：正文 14、行高 1.6；次要的字 12～13；模块页的标题 26 粗（`PageHeader`）；柚子页和日历里的月份 22 粗；面板标题 20 粗；首页问候 46 粗。数字是等宽的，金额右对齐就齐。
- 字要清楚：字不歪、不缩放；离它所在的框左右留出空，上下不出框（`ui-lint` 会查）。

## 手画的框和线

元素上写 `data-hand="种类"`，`src/shared/hand.ts`（`main.tsx` 和速记小窗的 `capture/main.tsx` 开头都调 `startHand()`）就把它画进元素里的一层 `[data-hand-painted]`。元素出现、换了参数、变了大小都会补画。同一个 `data-seed` 永远画出同一条线。

| 种类 | 画什么 |
|---|---|
| `sheet` · `desk` | 模块页的纸（方格、缝线、纸纹）· 桌面 |
| `card` · `note` · `ticket` | 白卡 · 便签 · 票 |
| `button` · `field` · `round` · `cell` | 按钮 · 输入框和下拉 · 圆框 · 格子 |
| `pick` | 选中的底：一块手剪的色块 |
| `frame` | 自己定参数的框（`data-r` 圆角、`data-sw` 线宽、`data-amp` 抖动、`data-fill` 填色、`data-tilt` 歪多少、`data-tapes` 胶带） |
| `rule` · `marker` · `strike` | 手画横线 · 荧光笔 · 划掉 |
| `check` · `switch` · `star` | 勾选框 · 开关 · 星星 |

规矩：

1. **纸上的白卡自动变手画卡。** 页面里写 `rounded-card border bg-card` 的框（表格、列表、卡片），在纸上和问柚子的小窗里会被 `hand.ts` 认出来换成手画的卡（加上 `data-auto-card`）。菜单、弹窗、面板里的不换；比一行还小的不换；不想换就加 `data-no-hand`。
2. **手画的边画在字下面一层**，所以：
   - 会滚、会裁的盒子上不画边：外面一层画边，里面一层滚。不然边跟着字滚走，超出的半条被切掉。
   - 卡片里的行、格子不另涂白底（`frame.css` 已经让它们透明）；选中、指着的行涂了底色时两边让出 3。
   - 盖在纸上的整页（导入账单）不涂底色，直接画在纸上。
   - 能滚的区域四周留出边抖出去的那几像素（`-m-1 … p-1`），焦点框也才不会被切掉。
3. **要框就用手画的控件**（`TextInput`、`MdField`、`Dropdown`、`PickField`、`Button`），不用 `fieldClass` 这类直线细边框。
4. **焦点是把线描粗**：输入框有焦点时不另套方框，手画的边粗一点。
5. 故意留的直线框（设置里的配色小样）加 `data-nolint`，界面检查就不报它。

## 外框

整个窗口不滚动、不回弹，只有里面的区域滚。滚动条平时只有一小段淡墨线，鼠标移进那一块才显出来（根元素的 `pm-scroll`）。代码在 `src/app/`，摆法在 `frame.css`。开着的页、前进后退、快捷键这些规则见 `requirements.md`「界面外框」。

- **顶栏**（`TopBar.tsx`，高 51）：左起红黄绿、柚子（点了开柚子瓣）、‹ ›；在纸上时多一条薄荷胶带「回桌面」。右边：淡墨「桌上开着」和一排小贴纸（每个开着的页一张，最前面那张底下一道手画的线，鼠标移上去右上角出 ×；新开的啪地贴上，关掉的撕走）、「＋」、开发版的小胶囊、日期（手画的小纸条，窗口窄于 1100 不显示）、找东西、设置、「问柚子」（柚子探出头；有没看过的定时对话时右上一个小点）。按钮的名字都在落签里，不写快捷键。
- **桌面和「常用」**（`Desk.tsx` 的 `DeskCommon`）：首页的便签摆在桌上。最下面一排「常用」不跟着动：一条薄荷胶带写「常用」，后面是置顶的模块（56 的贴纸，各歪一点，下面名字），最后是手画圆框里的「贴纸簿」。鼠标移上去贴纸抬起一点，按下压一下；右键是它的菜单。
- **纸**（`Desk.tsx` 的 `PaperStack`）：最前面的页是一张方格纸，四周露出桌面（左、上 30，右 112，下 16），微微歪着；左上角拍着这个模块的贴纸（64，歪 8 度）。别的开着的页叠在右边，最多露 4 张，只露纸边和一张 46 的贴纸；鼠标移上去名字垂下来，点露出来的任何地方都换到最前面。新开的页从右边滑进来，换到最前面的页它的贴纸再拍一次。每一页是自己的一层，换页时叠着的只挪位置、不重画。
- **子页纸签**：有子页的模块，子页是插在纸上边的文件夹纸签：没选的是五种分类色的浅底，选中的是纸色、粗体、连着纸。页面里不再放一排分段。
- **柚子那一页**是线圈本：横线纸，上边一排线圈，纸角没有贴纸，左边让出一栏桌面放大柚子和聊过的小纸条（见「各处的样子 › 柚子」）。
- **贴纸簿**（`StickerBook.tsx`）：桌面盖一层淡淡的暗色，一本斜纹纸的本子（最宽 1040）从下面滑上来，微微歪着。左上柚子（打开时「哇」一下）、粗体「柚子的贴纸簿」和一行淡墨「撕一张贴纸，就去那里 · 拖出簿子放到桌上也行」，右上手画输入框「去哪，或问柚子」。下面两栏，分类名写在胶带上（薄荷、柚黄轮着），模块是 66 的贴纸，一行五个，名字在下面（助手旁边一个小柚子）；已经开着的变淡，留一个虚线框，写「在桌上」。左下「＋ 分类」，右下「已隐藏 N」。点一张贴纸，它被撕起来飞走，那一页打开；也能拖到别的分类，或拖出本子上边放到桌上。打字时对不上的很淡，对上的外面一圈荧光笔色的光；都对不上时出一行「没有这一页，问柚子「…」」。右键贴纸：置顶、隐藏、图标和颜色、移到；右键分类名：改名、在这里新建五花八门或循序渐进、删空的分类。
- **柚子瓣**（`Bloom.tsx`）：盖住桌面（半透明的桌面色加模糊）。中间一个手画的大柚子（680，按窗口高缩放）：一圈柚皮，每瓣一个分类、分类色的淡底，瓣里只放贴纸（名字在落签里），瓣名在柚皮外面（点了直接改）；中心是柚子、淡墨日期和输入框「去哪，或问柚子」。能拖着转，松手接着转。打开时从顶栏的柚子那里长出来，线先画出来、贴纸再一个个弹出来；收起时缩回去。在里面调整分类、拖动、改名都原地更新。
- **找东西**（`Search.tsx`，⌘K）：一台小票打印机挂在窗口上方（宽 620）。小票从出纸口吐出来：淡墨「— 柚儿园 · 找东西 —」，大输入框（下面一道手画的线，右边淡墨找到几条），结果按模块分组、一行行打印出来，选中的垫选中色；两道虚线中间写「意思相近」，下面是按意思找到的；没找到时「没找到「…」」和「问问柚子」；最下面虚线下「谢谢光临 · 柚子」。
- **问柚子的小窗**（`src/modules/youzi/SideChat.tsx`，⌘J）：一张手画的卡，宽 380，站在桌面右边，桌面和纸让出位置；窗口窄于 1240 时浮在纸上面，投影深一点。从顶栏的「问柚子」那里长出来，收起时缩回去。顶上一行：小柚子、对话标题和 ⌄（新对话、最近 8 个）、模型菜单、新对话、×。输入框上面一个选中色的小胶囊：定位图标、现在在哪一页或哪条记录、×（这次不带）。它里面的白卡也自动换成手画卡。
- **落签**：鼠标移到小按钮、贴纸上，名字写在一张小纸签上，挂在一根线上垂下来晃两下。写法是元素加 `pm-tip-host`、里面放 `<Tip>`（`src/shared/handParts.tsx`）；`src/shared/tips.ts` 把它挂到最上面一层，不会被纸边、卡片挡住，靠窗口边时纸签往里挪。**线接着图标**（2026-11-11 我定）：挂出来时量出按钮里画的东西（图标的线、贴纸的白边）在正中那一竖上最低到哪，线从那儿开始、往上多伸 1.5 像素，不从按钮的框底下开始；柚子瓣里打字找到的那几张（原地挂出来的）也一样（`hangAt`）。量不到画的东西时照旧挂在框下面。图标按钮用 `IconButton` 就自带。

- **柚子的表情**：顶栏的柚子平常慢慢呼吸、眨眼、看来看去。柚子在写时在想，写好开心一下，出错时是出错的脸并冒一句话；柚子瓣、贴纸簿打开时「哇」，换到一页时开心，回到桌面眨眼；20 秒没动就困了，一动吓一跳；深夜困了。什么时候换的完整规则见 `requirements.md`「界面外框 › 柚子」。

## 典型页

模块里面是四种典型页搭出来的。共用的零件都在 `src/shared/`。

- **页头**（`ui.tsx` 的 `PageHeader`）：大标题，不放图标（模块的贴纸拍在纸角上），左边让开那张贴纸；右边淡墨小字写这一页有多少。
- **白卡**：纸上的表格、列表、卡片都是手画的卡，行和行之间虚线（见「手画的框和线」）。
- **标签**：选项、状态、阶段都是带颜色点的小标签（`pm-chip`）：底是它的浅色，字是墨色。

## 动效

像纸和贴纸在桌上动：按下扁一下、勾上弹一下、纸滑进来、贴纸拍上去、撕起来，什么东西出现都先画出来再弹一下。动效全是同步来的零件（在 `ds.css` 里），**这边只加减类名**（`is-in`、`is-pop`、`is-leaving`…；`hand.ts` 的 `flash` 让只放一次的动画重新放），不另写关键帧。不做声音。

两档：**calm** 是控件的小动静，可以弹、不循环、一次不超过 0.6 秒；**expressive** 是招牌时刻和柚子的表情，一次不超过 3 秒，只有柚子的表情和等待时的动画能循环。

| 招牌时刻 | 什么样 | 在哪 |
|---|---|---|
| 打开的问候 | 便签一张张落到桌上，问候语一笔写出来，荧光笔划过 | `home/HomePage.tsx`（`pm-greet`） |
| 柚子瓣 | 从柚子那里转着长出来，线先画、贴纸再弹；打「柚子」转一圈 | `app/Bloom.tsx` |
| 贴纸簿 | 本子滑上来；贴纸翘起来、撕下来飞走 | `app/StickerBook.tsx` |
| 找东西 | 小票打出来，选了撕下来 | `app/Search.tsx` |
| 开着的页 | 新页滑进来、贴纸啪地拍上；叠着的抽出来一点 | `app/Desk.tsx`、`app/TopBar.tsx` |
| 问柚子的小窗 | 从「问柚子」那里长出来、缩回去 | `modules/youzi/SideChat.tsx`（`pm-chat-pop`） |
| 勾待办 | 果冻弹，墨线划掉那一行（出门走走装好的东西只划线、不弹） | `modules/todo/TaskList.tsx`、`.task-title` |

- **小彩蛋**：撕起简报角上的柚子贴纸，底下写着「今天也辛苦啦」（`home/Whisper.tsx`）；2.5 秒里连戳柚子页的大柚子 5 下，它晕了，贴一张「别戳啦，晕了…」，平时每戳一下换一张脸；柚子瓣里打「柚子」转一圈；勾完今天的待办撒小贴纸；20 秒不动柚子睡着，一动吓一跳。
- **减少动态效果**：系统开了就全都不动，直接是最后的样子，循环停下（`index.css` 里统一关掉，同步来的零件自己也有回退）。用定时器、用代码挪东西的地方先问 `hand.ts` 的 `reducedMotion()`。
- **流畅度**（窗口是 WebKit，有些东西只在它里面慢；量法见 `testing.md`「流畅度」）：
  1. 页面上不放实时的 SVG 滤镜：纸纹是一小块算好的噪声平铺。
  2. 整页大小的层不改 `z-index`、不反复新建：叠着的页谁在上面写死在元素上。
  3. 给最上面那页开层用 `will-change: opacity`，不用 transform（页面里 `position: fixed` 的东西会跟着它定位）。
  4. 改了外框、纸、手画零件或动效，在 Safari 里量一遍；一帧超过 100 毫秒就要查。

## 文案

- 全中文，保留俏皮的叫法，像柚子在跟你说话。按钮用简单动词：新增、保存、删除、导出。
- **不写使用提示**：不提示快捷键、怎么操作、可以撤销；输入框不放示例。要解释的只放在设置页的 (?) 里。
- 空白页一句俏皮话（「书架空空，去摸会儿鱼吧」），不附操作说明。
- **列表行只放最必要的信息。**
- **只有一种东西的列表不写小标题**（一步一步左边不写「分组」，知识库不写「库」，插件库不写「技能」）；一页里有两种以上才各写各的名字（2026-11-09 我定，所有模块）。
- 删除前确认，确认框里只写会一起删掉什么。

## 开发指南

做界面时照这个来。

1. **先看有没有现成的。** 控件用「控件」那张表里的组件；页头用 `PageHeader`，编辑面板用 `SidePanel`，左边一列用 `.side-row` 加 `<Picked />`，图表用 `charts.tsx`。不自己画细边框，不自己拼 `pm-*` 类名。
2. **颜色只用变量。** 不写色值；图表只用 `--chart-*`。便签上不用给深色纸配的颜色。
3. **字体只写 `font-sans`**（不用写，默认就是）；柚子里读长文的地方用 `font-reading`。不直接写 `Hannotate SC`。
4. **白卡照写 `rounded-card border bg-card`**，它在纸上自己变成手画卡。会滚的内容包两层：外面画边，里面滚；能滚的区域用 `-m-1 … p-1`。
5. **动效只加减类名。** 要的动静先在 `ds.css` 里找零件；没有的，回 visual-atelier 加，不在这边写关键帧。
6. **要新图标、新贴纸、新颜色，走 visual-atelier。** 图标：在那边的 `schemes/pomelo/marks/icons.mjs` 画，发版同步，再在 `src/shared/icons.tsx` 加一行。贴纸、空状态插图同理（在那边的 `marks/`）。新模块的颜色 `--module-<键>` 也在那边定（`schemes/pomelo/tokens/targets.json`），同步过来就有；这边在 `src/app/modules.ts` 里写 `color: "var(--module-<键>)"`，再把它加进上面「默认的模块色」那一行。
7. **新加的浮层包一层 `Oops`**（`look="layer"`，给它 `onClose`），照 `src/app/App.tsx` 里贴纸簿那几个的写法。
8. **hook 不写在提前返回的后面。** 组件里 `if (…) return` 后面再调 hook，数据晚到的那一下这一页就显示「这一页出错了」。
9. **有焦点的输入框不能在窗口外面。** WebKit 为了让它露出来，会把整个窗口的内容挪上去、回不来。从窗口外滑进来的东西（贴纸簿）等它进了窗口再给焦点，滑走前先放开。
10. **文案**照上面「文案」：不写使用提示，行里只放最必要的，只有一种东西不写小标题。
11. **我能挑图标的地方用图标库**；页面用 `usePageContext` 告诉问柚子的小窗现在在哪。
12. **改完跑这几样**（细节在 `testing.md`）：

| 做什么 | 命令 |
|---|---|
| 看页面 | 后台跑 `pnpm dev`，开 `http://localhost:1420/?mock`（模拟数据；直接看某页用 `/?mock#/finance`） |
| 界面检查 | `node scripts/ui-lint.mjs`：白板、直线框、被切的手画边、字出框都要清零 |
| hook 的位置 | `node scripts/hooks-lint.mjs` |
| 类型和 Rust 测试 | `pnpm check` |
| 流畅度 | 改了外框、纸、手画零件、动效：照 `testing.md`「流畅度」在 Safari 里量 |

新加或改了 Rust 命令的页面，还要在打包版的真实窗口里点一次（`testing.md`「真实窗口」）。跑界面检查时别改仓库里的文件，页面会刷新。

### 柚子的助手

每个助手是一页自己的工作台：页头是名字加一个小柚子，子页在纸签上。

- **按钮下的状态行**（Seeker 的模型调用、Rater 的总结复盘）：跳动的淡墨「正在审查…」；好了淡墨结果（有东西可看时多「查看」）和 ×；失败红字原因、「重试」和 ×。
- **弹窗**：一行放几个输入框的宽 720，其他 560 或 440；里面的下拉占满它那一格，长文字 … 截断。
- **助手的设置页**（Seeker、Rater）：和 Pomelo 设置页一样的分节卡片（最宽 768）。模型按页分节，每个功能一行：左边功能名，中间模型下拉（第一项「跟默认」），最右思考下拉（选项跟着模型变）。没有模型的功能，它的按钮点不了。
- **Translator**（最宽 896）：子页「Translator · 提示词」。一行：源语言下拉、⇄、目标语言下拉，一条竖线，模型下拉、「思考」，最右主按钮「翻译」（翻译时「停止」）；下面上下两个等高的框：原文输入框、译文（苹方 15），译文框左上淡墨小字写模型或「正在翻译 2/5」，右上「复制」。提示词页：自己写的提示词，四行关键词（左边淡墨组名，右边小按钮），分隔线下淡墨「发给模型的说明」。
- **Pub2MD**（最宽 896）：子页「Pub2MD · 提示词 · 设置」。上面是这一次怎么做（做哪几步、MMD / Markdown、另存为、中英对照、同时几块；翻译时语言方向和「不翻：…」；「联网查术语」「精修」开关）。「选择文件…」、主按钮「发送」；整页能拖进文件；「待发送」每份一行和 ×。正在做的一张卡片：名字、淡墨闪动的步骤（「整理 3/5 · 翻译 2/5」）、细进度条、淡墨请求次数和用时、「停止」。分隔线下是最近做过的：名字、淡墨时间和状态，停下或出错的有「继续」「删除」，完成的下面一排小按钮（MMD、MD 点了预览，其他用默认程序打开）。最下面淡墨的使用说明。设置页：「模型」卡、「文件」卡、「使用说明」（一个写 Markdown 的框）。预览（宽 900、高 86%）：顶上文档名、文件分段、「用默认程序打开」和 ×。
- **Seeker**：顶上一行最右「中文 · English」（档案、网申页不显示）和「↻」。简历页三栏：左「选材」；中间 A4 宽的白卡（居中姓名、章节标题下一条细线、经历抬头一行三栏，要点是边写边显示的输入框）；右边是岗位、目标 JD、「✦ 按 JD 推荐素材」、本次要求和几个占满一栏的按钮。窄窗口左右两栏收成按钮，点开是右侧面板。英文正文：姓名大写，经历抬头两行。
  - **批注**：挂在对着的那块下面（缩进一格），浅底、左边一条主色细线，右边 ✓；有改稿的下面一张小卡片（原文划掉、新字垫选中色）；选了改稿时正文下面浮出「已选 N / M 条修改 · 全选 · 取消选择 · 确认修改」。说整篇的在姓名上面。
  - **简历正文的多选**：没有勾选框；鼠标移上去左边拖动手柄、右边铅笔；点一行选上，⌘ / Shift 加选，空白处拖出半透明的选框；底部「已选 N 项 · 删除所选 · 取消选择」。
  - **资料页**（素材、档案、规则、网申）：上面搜索框和少数按钮；下面一组一组，组名粗体小字 +「＋」「⋯」「↑」「↓」。折叠卡片一行「› 名称　淡墨补充」，停用的整张变淡写「已停用」。规则页组名下淡墨「发给：…」，工具栏「≡ 发给模型的说明」（弹窗宽 880、高 80%）。行和卡片的操作都是鼠标移上去才出现的小图标。程序自带的规则是虚线卡片（淡墨「程序自带的」、右边「✎ 改成我的」）。
