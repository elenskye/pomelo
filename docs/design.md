# 视觉规范

> 初稿（2026-09-28）。v0.1 先按这份规范开发，不细究视觉；之后再专门调整。

## 气质

**清爽、温柔、带一点柚子味，像 macOS 原生应用一样安静。**

- 「柚儿园」谐音幼儿园，模块名也都很俏皮（摸鱼读读、尝尝咸淡），所以整体可以轻松、有温度，但不能花哨。
- 每天都要用的工具，内容永远是主角。颜色只用来表示状态和重点，不做装饰。
- 看起来要像一个认真做的 Mac 应用，而不是网页。

## 颜色

灵感来自柚子：柚皮的黄绿、红柚果肉的珊瑚红、柚子瓤的暖白。浅色和深色两套，跟随系统自动切换。

## 文字

- 字体：全部使用「手札体-简」（Hannotate SC）。它是 macOS 自带的可下载字体，这台 Mac 已经下载好了。万一找不到，会自动换成苹方。
- 手札体只有「常规」和「粗体」两种粗细，所以标题用粗体。
- 文件路径这类需要看清每个字符的内容，改用等宽字体。
- 字号：正文 14、次要文字 12、页面标题 22（粗体）、统计数字 20（粗体）。
- 中文行高 1.6。

## 布局

- 左侧导航栏宽 220，右侧是内容区。右上角的按钮能把它收成 60 宽、只有图标的窄条（鼠标移上去显示名字）；按住模块拖动能调整顺序。两样都会记住。
- 窗口标题栏和内容融为一体（隐藏标题文字，红绿灯按钮浮在侧栏上）。实现成本不高的话，侧栏用 macOS 原生的半透明毛玻璃效果。
- 页面结构统一为三层：**页面标题 + 统计** → **工具栏**（搜索、筛选、新增）→ **内容**（表格或列表）。窗口最窄（900）时，次要的列会自动隐藏。
- 编辑时从右侧滑出面板（宽 400），不跳转页面。
- 间距以 4 为单位，常用 8、12、16、24。
- 圆角：按钮和输入框 8，卡片和面板 12。
- 阴影尽量少，主要靠分割线区分层次。只有浮层（面板、弹窗、下拉菜单）才用柔和的阴影。

## 图标

- 界面图标用 Lucide 线条图标，16 号大小，线宽 1.5。
- 模块图标：一步一步「脚印」、摸鱼读读「翻开的书」、好奇看看「场记板」、随意画画「调色盘」、出门走走「行李箱」、钱来钱往「钱包」、投石问路「公文包」、念念不忘「羽毛」、芝麻开门「钥匙」、设置「齿轮」。
- 内容里的 emoji（比如「家钥匙 🔑」）原样显示。

## 动效

- 只用简短、轻柔的过渡（0.15～0.2 秒），比如面板滑出、状态切换。不做弹跳这类夸张效果。
- 系统开启「减少动态效果」时，关闭所有动效。

## 文案

- 界面全中文。保留俏皮的模块名和「尝尝咸淡」这类叫法。
- 按钮用简单的动词：新增、保存、删除、导出。
- 空白页可以俏皮一点，比如「书架空空，去摸会儿鱼吧」，但不附操作说明。
- **不写使用提示**：不提示快捷键、怎么操作、可以撤销；输入框不放「比如……」这类示例。需要解释的只放在设置页的 (?) 里。
- 删除前一定要确认，确认框里只写清楚会一起删掉什么。

## 实现方式

- 以上颜色、字号、圆角都做成统一的主题变量（Tailwind 主题），组件里不直接写颜色值。
- 下拉菜单是自己画的弹出菜单：圆角卡片、柔和阴影，当前项前面打勾，鼠标经过的项有浅底色；底部可以有「管理类型…」这类操作，用分隔线隔开。支持键盘上下选择、回车确认、Esc 关闭。
- 弹窗用 macOS 原生的弹窗机制，外观按上面的颜色和圆角来画。
- 进度条：已完成是绿色，进行中是浅一点的黄色。
- 可以一键完成的条目（绘画课节、出行物品），前面放一个圆圈：空心 = 未完成，带点 = 进行中，打勾 = 已完成；已装好的物品文字变淡并划线。
- 列表型页面（随意画画、出门走走、一步一步）：左边是列表和进度，右边是内容；分组标题上写「已完成 / 总数」。
- **待办的任务栏**：圆圈贴着左边，后面是标题，标题后面紧跟淡墨色小字的截止日期「2026 / 10 / 03」（过期标红）。别的都不显示：没有备注图标、类型说明、所属分组。子任务每层缩进一格。
- **待办的圆圈**：普通和重复任务是空心圆，点了打勾；打卡任务今天打过就显示勾；进度条任务是一个按比例填满的小饼图。
- **展开收起**：有子任务的任务，在最右边用淡墨色小字写「1/3 ⌄」，收起时箭头朝右。左侧导航的分组也一样，有目标的分组在右边有个小箭头。目标前面不放图标。
- **月历**：一周从周一开始，6 行格子；每格列出当天的事（截止、时间段、重复的每一次、做完的），放不下写「还有 N 项」；点某天，下面列出那天的全部。
- **拖拽排序**：待办的任务和左侧导航，按住整行拖动（移动几个像素才开始，所以点一下还是打开）；表格型的列表（课节、物品、模板）鼠标移上去最左边出现把手（六个点）。拖动时其他行让开位置。筛选时也能拖，看不到的行位置不变。
- **日期输入**：时间段的开始和结束放在同一行，「开始 × 到 结束」。日期框不用系统的：框里写「2026 / 10 / 05」和一个小日历图标，空的写淡墨「年 / 月 / 日」，能清空的在右边有 ×。点开是圆角卡片里的月历：标题「2026 年 10 月」左右两个箭头，点标题换成选月份；周一开头，6 行；今天有细圈，选中的是柚红实心圆，不能选的变淡；底部「今天」和（能清空时）「清除」。键盘方向键挪、回车选、Esc 关。只要选月份的地方（更新余额、持仓）是 3 × 4 的月份格子，底部「本月」。
- **已完成的目标**：分组页里收进「已完成的目标 N」（有放弃的再写「· 已放弃 N」），和任务的「已完成」一样默认折起。
- **设置页**：占满右侧；每行左边是名称和一个小问号 (?)，鼠标移上去显示说明，右边是内容和按钮。其他页面以后需要长说明时也用这种小问号。
- **钱**：带币种符号（¥ / S$ / HK$ / US$），千分位，整数不写「.00」。收入写「+」并用绿色，支出不加符号；结余为负时写「-」并用红色（颜色之外总有符号）。
- **图表**：线条细（折线 2 像素），柱子最宽 24、顶部 4 像素圆角，网格线是很淡的实线；只有一个坐标轴。分类颜色按固定顺序取（蓝、橙、青、黄、粉、绿，深色模式各调一档），跟着分类走、不跟着排名走；收入是蓝、支出是橙，其余分类合成灰色「其他」。文字永远用正文颜色，旁边放色块表示是哪一类。鼠标移上去有提示，但数字在旁边的清单里也都看得到。
- **投递状态标签**按阶段上色（用状态色）：准备灰、等回音蓝、进行中黄、拿到绿、结束淡灰；已结束的整行变淡。「该跟进」用黄色字，过期的截止 / 面试日期用红色。
- **预算条**：没到 90% 是绿，快到了变黄，超出变红，并写「超出 S$20」。
- **念念不忘**：左栏上面是三个数字（笔记、标签、天），下面是热力图：最近 16 周，一列一周、周一在上，用 `--chart-3` 分四档深浅（按最忙那天的比例），没记的是很淡的灰；点某天只看那天，再点取消。右边的卡片最宽 768，左对齐：上面一行是淡墨小字的时间「2026 / 02 / 23 14:39」，置顶的后面有个柚红小图钉，鼠标移上去右边出现「⋯」菜单。正文里的 `#标签` 用柚红字、能点；高亮是「在读」的黄底；下划线细线。超过 320 高的笔记折起来，底部渐隐，下面写「展开全文」。引用的笔记在正文下方，左边一条竖线，前面是引号图标；被引用的写「N 条笔记引用了它」，点开才列出来。输入框和卡片一样是白底圆角，获得焦点时有柚红的焦点框；输入框占位文字「现在的想法是……」。空的时候写「念念不忘，必有回响」。
- **芝麻开门**：没打开时，页面中间一个窄栏（宽 320）：岩灰色的钥匙图标、（能用时）「用 Touch ID 打开」按钮、居中的主密码输入框和「打开」按钮；为什么要输主密码写在上面一行淡墨小字，出错用红字。第一次是「设置主密码」，两个输入框，下面一行小字提醒忘了就打不开。打开后是表格：名称（后面跟淡墨小字的网站名和外链图标）、用户名、账号、密码（八个圆点）；鼠标移到格子上，右边出现复制图标。右上角「锁上」和「新密码」。面板里密码框用等宽字，右边是显示 / 隐藏和魔法棒（随机生成）。空的时候写「芝麻还没开过门」。
- 以后要改视觉，先改这份文档，再改主题变量。
