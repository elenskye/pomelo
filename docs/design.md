# 视觉规范

> 以后要改视觉，先改这份文档，再改主题变量（`src/index.css`）。v1.0 前会统一打磨一次。

## 气质

**清爽、温柔、带一点柚子味，像 macOS 原生应用一样安静。** 模块名俏皮（摸鱼读读、尝尝咸淡），整体轻松有温度，但不花哨。内容是主角，颜色只表示状态和重点，不做装饰。

## 颜色

灵感来自柚子：柚皮的黄绿、红柚果肉的珊瑚红、柚子瓤的暖白。浅色、深色两套，跟随系统。文字和背景对比度都达到 WCAG AA。

| 名称 | 用途 | 浅色 | 深色 |
|---|---|---|---|
| 柚瓤白 | 页面背景 | `#FAF8F4` | `#1C1B19` |
| 侧栏 | 左侧导航背景 | `#F3F0E9` | `#232120` |
| 卡面 | 表格、卡片、面板 | `#FFFFFF` | `#292724` |
| 分割线 | 边框、分隔 | `#E8E3D9` | `#3A3734` |
| 墨色 | 正文 | `#2B2824` | `#ECE8E1` |
| 淡墨 | 次要文字 | `#6F685F` | `#A29B91` |
| 柚红 | 主色：主按钮、选中、链接、焦点框 | `#C4503B` | `#EE7B66` |
| 柚红浅 | 选中项的底色 | `#FBE6E0` | `#3D2621` |
| 警示红 | 删除等危险操作 | `#B8322F` | `#F07167` |

**状态色**（标签底色 / 文字）：待标记 `#EFECE6` / `#6F685F`；想读·想看·未开始 `#E3EDF8` / `#33628F`；在读·在看·进行中 `#FBEFC8` / `#855C00`；已读·已看·已完成 `#E2F0D6` / `#3F6D27`（深色各有一套，在 `index.css`）。星级点亮是实心 `#E9A825`，未点亮是淡墨空心。

**模块色**（只用在模块图标上）：摸鱼读读 湖蓝 `#3A7FBA`、好奇看看 葡萄紫 `#8466C4`、随意画画 柚红 `#CC5540`、出门走走 柚皮绿 `#588A2C`、一步一步 柚子黄 `#B07A10`、钱来钱往 青绿 `#2E8B80`、投石问路 梅紫 `#9C5B8F`、念念不忘 栗子棕 `#9A6B4A`、芝麻开门 岩灰 `#64748B`。

**图表色**：固定顺序（蓝、橙、青、黄、粉、绿，深色各调一档，检查过色弱可读性），跟着分类走、不跟着排名走；收入蓝、支出橙，其余合成灰色「其他」。只用 `--chart-*`。

## 文字、布局、图标、动效

- 字体全部用「手札体-简」（找不到时用苹方），只有常规和粗体；粗体用它自带的那一款（手札体文件把粗体也标成常规字重，不特别指定的话系统会把常规体描粗，笔画发糊）；文件路径用等宽字体。字号：正文 14、次要 12、页面标题 22 粗、统计数字 20 粗；行高 1.6。
- 左侧导航宽 220，能收成 96 宽的图标窄条（窗口三个按钮落在侧栏里）；标题栏和内容融为一体。最上面是「首页」，下面是模块（能拖动排序），最下面是设置。
- 页面三层：**标题 + 统计** → **工具栏**（搜索、筛选、新增）→ **内容**。编辑时从右侧滑出面板（宽 400），不跳转。
- 间距以 4 为单位；圆角：按钮和输入框 8，卡片和面板 12。少用阴影，只有浮层（面板、弹窗、下拉菜单）有柔和阴影。能滚动的区域四周留 4 像素，焦点框不会被切掉。
- 界面图标用 Lucide 线条图标，16 号、线宽 1.5。模块图标：脚印、翻开的书、场记板、调色盘、行李箱、钱包、公文包、羽毛、钥匙；首页是房子、设置是齿轮，这两个用淡墨色。内容里的 emoji 原样显示。
- 动效只用 0.15～0.2 秒的轻柔过渡；系统开了「减少动态效果」就关掉。

## 文案

- 全中文，保留俏皮的叫法。按钮用简单动词：新增、保存、删除、导出。空白页可以俏皮（「书架空空，去摸会儿鱼吧」），但不附操作说明。
- **不写使用提示**：不提示快捷键、怎么操作、可以撤销；输入框不放示例。要解释的只放在设置页的 (?) 里。
- 删除前确认，确认框里只写会一起删掉什么。

## 通用控件

- **下拉菜单**：自己画的圆角卡片，当前项打勾；选项能分组（每组一行淡墨小字的组名）；底部可以有「管理类型…」这类操作。键盘能用。
- **日期输入**：框里写「2026 / 10 / 05」和日历图标，空的写淡墨「年 / 月 / 日」；点开是自己画的月历（周一开头，今天细圈，选中柚红实心圆，底部「今天」「清除」）。只选月份的是 3 × 4 月份格子；只选年的是年份下拉框。时间段写成「开始 到 结束」。
- **表格**：表格里能就地改的（比如收支的分类），平时是普通文字，鼠标移上去出现浅底和小箭头。**多选**：右上「多选」按下后变柚红「完成」，行首出现勾选框，选中的行浅柚红底，底部一条操作栏；平时行首不留勾选框的位置。
- **拖拽排序**：按住整行拖（移动几像素才开始）；表格型列表鼠标移上去最左边出现把手。拖动时其他行让开。
- **可一键完成的条目**（课节、物品、待办）前面是圆圈：空心未完成、带点进行中、打勾已完成；打卡今天打过显示勾；进度条是按比例填满的小饼图。
- **展开收起**：有子项的在最右边淡墨小字「1/3 ⌄」，收起时箭头朝右。
- **进度条、预算条**：完成是绿色；预算没到 90% 绿，快到黄，超出红并写「超出 S$20」。
- **钱**：带币种符号（¥ / S$ / HK$ / US$），千分位，整数不写「.00」；收入写「+」用绿色，结余为负写「-」用红色。
- **图表**：折线 2 像素，柱子最宽 24、顶部 4 像素圆角，网格线很淡，只有一个坐标轴；鼠标移上去有提示，数字在旁边的清单里也都看得到。多条曲线时每个数据点有小圆点，图上方一排小圆标签切换显示哪些。
- **开关**：小号胶囊，开是柚红，关是淡灰。
- **设置页**：每行左边名称和小问号 (?)，右边内容和按钮。

## 各处的样子

- **首页**：页面标题的位置是问候语，右边淡墨日期「10 月 8 日 周四」。下面「2026 年」一排数字格（淡墨小字：模块图标 + 读完；下面 20 粗的数字 + 淡墨单位）。再下面两栏，左右 3 : 2，窗口窄于 1024 时变一栏。每块上面是粗体小标题（模块图标 + 名字，鼠标移上去出现 ›），下面一张卡片，每行左边标题、右边淡墨小字。总资产是 20 粗的数字、绿 / 红「比上次」和 130 高的曲线（只标首、中、尾三个日期）；求职近况上面三个小数字，每行右边是黄色「该跟进 · 等了 N 天」或状态标签；绘画进度每门课一行：名字、「2 / 40」、进度条、淡墨「下一节 …」。空的块写一句淡墨话，比如「今天没有安排，喝杯茶吧 🍵」「还没更新过余额」。
- **全局搜索**：像聚焦搜索，窗口上方居中（宽 600），半透明遮罩；放大镜 + 大号输入框，下面按模块分组（淡墨小标题：模块图标 + 名字），每行左边标题、右边淡墨小字；选中的行浅柚红底。侧栏顶上「柚儿园」右边有放大镜。
- **一步一步**：任务栏只有圆圈、标题和紧跟的淡墨截止日期（过期标红），子任务每层缩进一格。月历周一开头 6 行，每格列出当天的事，放不下写「还有 N 项」。已完成的目标和任务收在「已完成 N」里。
- **列表型页面**（随意画画、出门走走、一步一步）：左边列表和进度，右边内容。
- **投石问路**：状态标签按阶段上色（准备灰、等回音蓝、进行中黄、拿到绿、结束淡灰），结束的整行变淡；「日期」一栏后面跟淡墨「· 等了 7 天」或黄色「· 该跟进」。编辑面板的状态：上面一排小圆角标签（选中柚红浅底，最后一个齿轮是「管理状态」），下面是时间线：每行左边小方勾选框（勾上柚红实心白勾），框之间一条细竖线，勾上的右边是日期框。
- **重读 / 重看**：面板里「完成时间」下面，每行年份下拉框 + 星星 + 红色 ×，最下面柚红小字「+ 再读一次」。
- **念念不忘**：
  - 左栏：三个数字（笔记、标签、天）、热力图（最近 16 周，一列一周，`--chart-3` 分四档深浅，点某天只看那天）、「全部笔记」、「置顶」（置顶的第一级标签，能展开）、「标签」树。每个标签前是 20 像素宽的图标位（线条图标用念念不忘的棕色，emoji 原色，没设是淡墨 #），和名字之间留 8 像素；点图标换图标；鼠标移上去右边出现「⋯」。换图标弹窗：8 × 6 线条图标，下面「其他 emoji」输入框。
  - 右边：卡片最宽 768；上面淡墨小字时间「2026 / 02 / 23 14:39」，置顶的有柚红小图钉，鼠标移上去出现「⋯」。正文 `#标签` 柚红能点，高亮是「在读」的黄底，下划线细线；**段落之间空 0.75 个字高**（明显大于行距），列表项之间 4 像素。超过 320 高的折起来，底部渐隐，写「展开全文」。引用的笔记在正文下方，左边一条竖线。输入框占位「现在的想法是……」，空的时候写「念念不忘，必有回响」。
- **芝麻开门**：没打开时页面中间窄栏（宽 320）：岩灰钥匙图标、「用 Touch ID 打开」、居中的主密码框和「打开」；第一次是「设置主密码」两个框，下面一行小字提醒忘了就打不开。打开后是表格（名称带淡墨网站名，密码八个圆点），格子上鼠标移上去出现复制图标；右上「锁上」「新密码」。面板里密码框用等宽字，右边显示 / 隐藏和魔法棒（随机生成）。空的时候写「芝麻还没开过门」。
