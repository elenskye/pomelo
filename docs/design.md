# 视觉规范

> 以后要改视觉，先改这份文档，再改主题变量（`src/index.css`）。v1.0 前会统一打磨一次。

## 气质

**清爽、温柔、带一点柚子味，像 macOS 原生应用一样安静。** 模块名俏皮（摸鱼读读、尝尝咸淡），整体轻松有温度，但不花哨。内容是主角，颜色只表示状态和重点，不做装饰。

## 颜色

灵感来自柚子：柚皮的黄绿、红柚果肉的珊瑚红、柚子瓤的暖白。浅色、深色两套，跟随系统。文字和背景对比度都达到 WCAG AA。

| 名称 | 用途 | 浅色 | 深色 |
|---|---|---|---|
| 柚瓤白 | 页面背景 | `#FAF8F4` | `#1C1B19` |
| 侧栏 | 左侧导航背景 | `#F3F0E9` | `#232120` |
| 卡面 | 表格、卡片、面板 | `#FFFFFF` | `#292724` |
| 分割线 | 边框、分隔 | `#E8E3D9` | `#3A3734` |
| 墨色 | 正文 | `#2B2824` | `#ECE8E1` |
| 淡墨 | 次要文字 | `#6F685F` | `#A29B91` |
| 柚红 | 主色：主按钮、选中、链接、焦点框 | `#C4503B` | `#EE7B66` |
| 柚红浅 | 选中项的底色 | `#FBE6E0` | `#3D2621` |
| 警示红 | 删除等危险操作 | `#B8322F` | `#F07167` |

**状态色**（标签底色 / 文字）：待标记 `#EFECE6` / `#6F685F`；想读·想看·未开始 `#E3EDF8` / `#33628F`；在读·在看·进行中 `#FBEFC8` / `#855C00`；已读·已看·已完成 `#E2F0D6` / `#3F6D27`（深色各有一套，在 `index.css`）。星级点亮是实心 `#E9A825`，未点亮是淡墨空心。

**模块色**（只用在模块图标上）：摸鱼读读 湖蓝 `#3A7FBA`、好奇看看 葡萄紫 `#8466C4`、随意画画 柚红 `#CC5540`、出门走走 柚皮绿 `#588A2C`、一步一步 柚子黄 `#B07A10`、钱来钱往 青绿 `#2E8B80`、投石问路 梅紫 `#9C5B8F`、念念不忘 栗子棕 `#9A6B4A`、芝麻开门 岩灰 `#64748B`、小拾 杏子橙 `#C96E28`（取自原来 Picky 啄点鸟图标的杏色）。

**图表色**：固定顺序（蓝、橙、青、黄、粉、绿，深色各调一档，检查过色弱可读性），跟着分类走、不跟着排名走；收入蓝、支出橙，其余合成灰色「其他」。只用 `--chart-*`。

## 文字、布局、图标、动效

- 字体全部用「手札体-简」（找不到时用苹方），只有常规和粗体；粗体用它自带的那一款（手札体文件把粗体也标成常规字重，不特别指定的话系统会把常规体描粗，笔画发糊）；文件路径用等宽字体。**例外**：小拾里问题和回答的正文用苹方，读长文不累；代码用等宽字体。字号：正文 14、次要 12、页面标题 22 粗、统计数字 20 粗；行高 1.6。
- 左侧导航宽 220，能收成 96 宽的图标窄条（窗口三个按钮落在侧栏里）；标题栏和内容融为一体。最上面是「首页」，下面是模块（能拖动排序），最下面是设置。
- 页面三层：**标题 + 统计** → **工具栏**（搜索、筛选、新增）→ **内容**。编辑时从右侧滑出面板（宽 400），不跳转。
- 间距以 4 为单位；圆角：按钮和输入框 8，卡片和面板 12。少用阴影，只有浮层（面板、弹窗、下拉菜单）有柔和阴影。能滚动的区域四周留 4 像素，焦点框不会被切掉。
- 界面图标用 Lucide 线条图标，16 号、线宽 1.5。模块图标：脚印、翻开的书、场记板、调色盘、行李箱、钱包、公文包、羽毛、钥匙、小鸟；首页是房子、设置是齿轮，这两个用淡墨色。内容里的 emoji 原样显示。菜单栏用原来 Picky 的啄点鸟单色图：实心是模型就绪，空心是没运行。
- 动效只用 0.15～0.2 秒的轻柔过渡；系统开了「减少动态效果」就关掉。

## 文案

- 全中文，保留俏皮的叫法。按钮用简单动词：新增、保存、删除、导出。空白页可以俏皮（「书架空空，去摸会儿鱼吧」），但不附操作说明。
- **不写使用提示**：不提示快捷键、怎么操作、可以撤销；输入框不放示例。要解释的只放在设置页的 (?) 里。
- 删除前确认，确认框里只写会一起删掉什么。

## 通用控件

- **下拉菜单**：自己画的圆角卡片，当前项打勾；选项能分组（每组一行淡墨小字的组名）；底部可以有「管理类型…」这类操作。键盘能用。显示在最上层，放在对话框里也不会被裁掉。
- **日期输入**：框里写「2026 / 10 / 05」和日历图标，空的写淡墨「年 / 月 / 日」；点开是自己画的月历（周一开头，今天细圈，选中柚红实心圆，底部「今天」「清除」）。只选月份的是 3 × 4 月份格子；只选年的是年份下拉框。时间段写成「开始 到 结束」。
- **表格**：表格里能就地改的（比如收支的分类），平时是普通文字，鼠标移上去出现浅底和小箭头。**多选**：右上「多选」按下后变柚红「完成」，行首出现勾选框，选中的行浅柚红底，底部一条操作栏；平时行首不留勾选框的位置。
- **拖拽排序**：按住整行拖（移动几像素才开始）；表格型列表鼠标移上去最左边出现把手。拖动时其他行让开。
- **可一键完成的条目**（课节、物品、待办）前面是圆圈：空心未完成、带点进行中、打勾已完成；打卡今天打过显示勾；进度条是按比例填满的小饼图。
- **展开收起**：有子项的在最右边淡墨小字「1/3 ⌄」，收起时箭头朝右。
- **进度条、预算条**：完成是绿色；预算没到 90% 绿，快到黄，超出红并写「超出 S$20」。
- **钱**：带币种符号（¥ / S$ / HK$ / US$），千分位，整数不写「.00」；收入写「+」用绿色，结余为负写「-」用红色。
- **图表**：折线 2 像素，柱子最宽 24、顶部 4 像素圆角，网格线很淡，只有一个坐标轴；鼠标移上去有提示，数字在旁边的清单里也都看得到。多条曲线时每个数据点有小圆点，图上方一排小圆标签切换显示哪些。
- **开关**：小号胶囊，开是柚红，关是淡灰。
- **设置页**：每行左边名称和小问号 (?)，右边内容和按钮。

## 各处的样子

- **首页**：页面标题的位置是问候语，右边淡墨日期「10 月 8 日 周四」。下面「2026 年」一排数字格（淡墨小字：模块图标 + 读完；下面 20 粗的数字 + 淡墨单位）。再下面两栏，左右 3 : 2，窗口窄于 1024 时变一栏。每块上面是粗体小标题（模块图标 + 名字，鼠标移上去出现 ›），下面一张卡片，每行左边标题、右边淡墨小字。总资产是 20 粗的数字、绿 / 红「比上次」和 130 高的曲线（只标首、中、尾三个日期）；求职近况上面三个小数字，每行右边是黄色「该跟进 · 等了 N 天」或状态标签；绘画进度每门课一行：名字、「2 / 40」、进度条、淡墨「下一节 …」。空的块写一句淡墨话，比如「今天没有安排，喝杯茶吧 🍵」「还没更新过余额」。
- **全局搜索**：像聚焦搜索，窗口上方居中（宽 600），半透明遮罩；放大镜 + 大号输入框，下面按模块分组（淡墨小标题：模块图标 + 名字），每行左边标题、右边淡墨小字；选中的行浅柚红底。侧栏顶上「柚儿园」右边有放大镜。
- **一步一步**：任务栏只有圆圈、标题和紧跟的淡墨截止日期（过期标红），子任务每层缩进一格。月历周一开头 6 行，每格列出当天的事，放不下写「还有 N 项」。已完成的目标和任务收在「已完成 N」里。
- **列表型页面**（随意画画、出门走走、一步一步）：左边列表和进度，右边内容。
- **投石问路**：状态标签按阶段上色（准备灰、等回音蓝、进行中黄、拿到绿、结束淡灰），结束的整行变淡；「日期」一栏后面跟淡墨「· 等了 7 天」或黄色「· 该跟进」。编辑面板的状态：上面一排小圆角标签（选中柚红浅底，最后一个齿轮是「管理状态」），下面是时间线：每行左边小方勾选框（勾上柚红实心白勾），框之间一条细竖线，勾上的右边是日期框。
- **重读 / 重看**：面板里「完成时间」下面，每行年份下拉框 + 星星 + 红色 ×，最下面柚红小字「+ 再读一次」。
- **念念不忘**：
  - 左栏：三个数字（笔记、标签、天）、热力图（最近 16 周，一列一周，`--chart-3` 分四档深浅，点某天只看那天）、「全部笔记」、「置顶」（置顶的第一级标签，能展开）、「标签」树。每个标签前是 20 像素宽的图标位（线条图标用念念不忘的棕色，emoji 原色，没设是淡墨 #），和名字之间留 8 像素；点图标换图标；鼠标移上去右边出现「⋯」。换图标弹窗：8 × 6 线条图标，下面「其他 emoji」输入框。
  - 右边：卡片最宽 768；上面淡墨小字时间「2026 / 02 / 23 14:39」，置顶的有柚红小图钉，鼠标移上去出现「⋯」。正文 `#标签` 柚红能点，高亮是「在读」的黄底，下划线细线；**段落之间空 0.75 个字高**（明显大于行距），列表项之间 4 像素。超过 320 高的折起来，底部渐隐，写「展开全文」。引用的笔记在正文下方，左边一条竖线。输入框占位「现在的想法是……」，空的时候写「念念不忘，必有回响」。
- **芝麻开门**：没打开时页面中间窄栏（宽 320）：岩灰钥匙图标、「用 Touch ID 打开」、居中的主密码框和「打开」；第一次是「设置主密码」两个框，下面一行小字提醒忘了就打不开。打开后是表格（名称带淡墨网站名，密码八个圆点），格子上鼠标移上去出现复制图标；右上「锁上」「新密码」。面板里密码框用等宽字，右边显示 / 隐藏和魔法棒（随机生成）。空的时候写「芝麻还没开过门」。
- **小拾**（颜色和控件都照 Pomelo，不照 Picky 的原生风格）：
  - **页面**：标题右边是「收起 / 展开对话列表」、「新对话」和模型菜单（本地、云端分组，前面一个状态点：绿就绪、黄加载、红出错、空心没运行，云端是小云朵）。
  - **对话列表**（宽 248）：最上面「搜索对话」，下面依次是「置顶」「项目」（右边一个 +，每个项目一行：箭头、文件夹图标、名字，点一下收起 / 展开，里面的对话缩进一格；有资料的项目第一行是淡墨「资料 N」）、「最近」「归档 N」（默认收起）；分组名是淡墨小字，当前的对话浅柚红底，正在写回复的右边一个跳动的小黄点。行上鼠标移上去右边出现「⋯」（改名、置顶、复制整段对话、导出、移到项目、归档、删除），改名直接在这一行里改。⌘ 点、⇧ 点选几个，选中的浅柚红底加细边，下面浮出一条操作栏（已选 N · 置顶 · 移到 · 归档 · 删除 · ×）。按住一行拖动：被拖的变淡，指针旁跟着它的名字；落在两行之间画一条柚红线，落到分组名或项目上那一行高亮；拖动时空的「置顶」「最近」「归档」也会出现；靠近上下边缘自动滚动。最下面一行淡墨「管理」。
  - **聊天搜索**换掉列表：搜索框、模型 / 时间两个小下拉框和「含归档」开关，每条结果是标题、两行淡墨片段（搜的字深一点）、日期和模型；打开后那条消息闪一下浅柚红，搜的字黄底几秒。
  - **项目资料**对话框（点「资料 N」或项目「⋯」里的「资料…」）：右上「+ 添加」（从文件选择、从附件库），每份一行：格式小标签（PDF 柚红、MD / TXT 灰）、名字、淡墨「第 2 版 · 12 页」，右边是索引状态（「建立索引」、细进度条加「正在建立索引 3/8」和「停止」、「已建立索引」、红色「索引失败」加「重试」、「重新建立索引」）和「⋯」（打开旧版本、替换为新版本、取消索引、移除）。
  - **管理**大对话框：顶上「模板 · 用途预设 · 全局指令 · 记忆」四段切换。模板页左边按「置顶」、各分类、「未分类」分组，底下「新建模板」，右边是名称、分类（旁边「选择」已有分类）、置顶开关、内容（苹方），下面淡墨「待填位置：…」和「删除模板…」，离开输入框就保存。用途预设页是卡片（名称、三行内容、编辑和删除）。全局指令页是大输入框和「保存」。记忆页上面是范围下拉框（全部、全局、各项目）、条数和「新建记忆」，每条一张卡片：苹方正文（停用的变淡）、小圆角标签（全局 / 项目：某某，同时用于…、仅本地、已停用）、淡墨来源和日期（对话中保存的有「打开对话」），右边开关和「⋯」（编辑、设为仅本地、删除）；编辑窗口：正文和「n/300」、保存到、同时用于、仅本地和启用两个开关。
  - **消息**（最宽 768）：我的问题在右边浅柚红气泡，回答在左边；都按 Markdown 排版，正文苹方 15、行高 1.7；代码块浅底细边框，顶上一条写语言和「复制」，长代码、宽表格横向滚动；独立公式居中。思考过程折叠成淡墨「已思考 N 秒」；正在写的回复末尾一个闪烁的小方块。消息下面一排小图标（复制、修改问题 / 重新生成、「‹ 2/3 ›」版本），最新的回复一直显示，其他的鼠标移上去才出现；停止、失败、中断的写一行小字，最后一条有柚红「重试」。换过模型的问题上方一条淡墨分隔线「已切换到 X」。⌘F 在右上角浮出查找框，找到的字黄底，当前的深黄。读到上面时，底部中间一个圆形「↓」。问题上方是它带的文件卡片（格式标签、名字、淡墨「资料 · 第 2 版 · 12 页」），点了用默认程序打开。回复下面一行淡墨「本轮使用了 N 条记忆」，点开是「记于 日期」和内容。查过 Pomelo 数据的回复上方一行淡墨小字「› 查了：投石问路 · 该跟进的投递（2 份）；钱来钱往 · …」（一行放不下就省略号），点开左边一条竖线，每次查询一个淡墨小标题和查到的原文（苹方小字）；没查的写「钱来钱往 · 不发给云端，没看」。分段阅读时回答位置是一张小卡片：「正在分段阅读」「停止」、细进度条、「第 6 段，共 16 段 · 正在阅读 某某 · 第 6 页」；读完的要点折叠成淡墨「分段要点 · N 段」。空白对话在「小拾在这儿」下面两列排最多 4 张置顶模板卡片（图钉、名称、两行淡墨首句）。
  - **输入框**：圆角卡片；底下一排淡墨小按钮「+」「模板」「指令」「记忆」，项目里再加「资料」（选了几份就写「资料 2」），右边圆形发送键，生成时变成停止键。附件和选用的资料是上面一排小胶囊（格式标签、名字、页数或大小、×；资料是浅柚红底），文件拖进窗口时外圈变柚红。「+」里是「添加文件…」「附件库…」（对话框，每行格式标签、名字、页数或大小、「打开」「使用」）；「资料」是带勾的资料列表和「添加资料…」「管理资料…」；「记忆」是「本条使用记忆」「本会话关闭记忆」两个勾和「管理记忆…」，关着时按钮变淡、写「本条不用记忆」「记忆已关闭」「记忆已停用」；「指令」选了预设时后面跟「· 预设名」，点开向上浮出「本轮生效的指令」：每层一个淡墨小标题（全局、项目、会话、预设）和苹方正文，会话那层有「编辑」，下面是预设下拉框、「添加会话指令」和「编辑全局指令与预设…」。输入「/」在上方浮出模板菜单（「置顶」「全部」两组，右边淡墨分类）；`{{名称}}` 待填位置浅柚红底，光标所在的深一点。输入「/记住 …」发送时弹出「记住」卡片：每条一个输入框和「n/300」、保存到、仅本地。
  - **输入框上方的卡片**：上下文快满时「这段对话已用掉约 N% 的上下文」和「总结并继续」「以后再说」，总结时换成「正在总结较早的内容…」；检索时一行淡墨「正在检索项目资料…」；8081 用不了时红字「无法挑选记忆 / 无法检索项目资料」、原因和「不用它们发送」「重试」「取消」。
