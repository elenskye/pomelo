# 视觉规范

> 这里管柚儿园的视觉语言（气质、颜色、字、手画的框和线、图标和贴纸、外框的样子、动效、文案）、几页共用的摆法和现成的控件；不管功能（`requirements.md`）、做界面的规则（`CLAUDE.md`「界面规则」）、测法（`testing.md`）和每一页自己的布局（以代码为准），视觉的源头在 visual-atelier，那边写了的这里只留结论和指针。

## 气质

**一张摊开的桌面，上面是手账。** 清爽、有活力、手作感：手画的墨线、错开一点的颜色、带白边的贴纸、胶带和纸。纸、胶带、贴纸可以歪，字永远是正的、清楚的。处处有小动静，动起来都像纸和贴纸。内容是主角，颜色只表示分类、状态和重点。

顶栏下面是桌面：首页的便签直接摆在桌上；打开的模块是一张方格纸（左边一列缝线，左上角拍着它的贴纸），别的开着的页叠在它右边。柚子是唯一的角色：就是 AI，也是顶栏、菜单栏和 App 图标。

不要：后台表格感、通用的细线图标、装饰堆砌（一张卡片最多两条胶带、一张贴纸）。

## 颜色

5 套配色，各有浅色和深色，在设置 › 外观里换（另有「跟随系统 · 浅色 · 深色」），主窗口和速记小窗一起换：钢笔家族的蓝笔 · 方格纸 `blue`（默认）、紫笔 · 樱粉荧光 `purple`、黑笔 · 牛皮纸 `kraft`，笔色管线条和按钮；色面家族的柚黄桌面 `yellow`、薄荷桌面 `mint`，桌面整片上色，顶栏是墨色。色值、对比度（方案那边每套配色、明暗都查过，这边不另查）和默认的模块色见方案「色彩」。

**不写死色值**，页面里只用这些变量：

| 一族 | 名字 | 用在哪 |
|---|---|---|
| 角色色 | `--color-desk` 桌面、`--color-paper` 纸、`--color-card` 卡面、`--color-line` 细线、`--color-ink` 墨、`--color-ink-soft` 淡墨、`--color-pen` 笔、`--color-primary` 主色、`--color-selected` 选中、`--color-marker` 荧光笔、`--color-link` 链接、`--pm-link-pomelo` 柚子链接（链到 Pomelo 里的东西，和网址链接分开，五套配色一样）、`--color-danger` 危险、`--color-up` 涨、`--color-top` 顶栏 | 外框、手画零件、新写的样式 |
| Tailwind 的名字 | `bg-background`（纸）、`text-foreground`（墨）、`bg-card`、`bg-muted`（桌面色）、`text-muted-foreground`（淡墨）、`bg-primary` / `text-primary`、`bg-accent`（选中）、`text-destructive` | 各页的 class；`index.css` 把它们接到 `pomelo.css` 的变量上 |
| 分类色 | 薄荷、天蓝、樱粉、橙、葡萄紫：`--color-cat-mint`…，各有浅底 `-bg`、淡底 `-tint`、贴纸填色 `-sticker` | 圆点、图表、贴纸、标签的底；不拿来写字 |
| 模块色 | `--module-<键>`（自建的是 `--module-list`、`--module-progress`） | 页面里模块的小图标。默认是它那一类的分类色；在贴纸簿换过颜色的，由 `src/app/moduleLooks.ts` 写在根元素上盖掉 |
| 状态色 | `--status-unmarked-*`、`--status-todo-*`、`--status-doing-*`、`--status-done-*`（各有 `-bg`、`-fg`） | `src/shared/status.tsx` 的状态标签 |
| 选项色 | `--tag-1-*`～`--tag-8-*` | `src/shared/tags.tsx`：五花八门的选项、循序渐进的类型，按顺序配，第 9 个起从头再来，不能自己选 |
| 图表色 | `--chart-1`～`--chart-6`、`--chart-other`、`--chart-grid`、`--chart-axis` | 图表只用这些。跟着分类走、不跟着排名走；收入 `--chart-1`、支出 `--chart-2`，排不上的合成「其他」 |
| 柚子的固定色 | `--color-yuzu` 柚黄、`--color-leaf` 叶子、`--color-blush` 腮红 | 柚黄只当底色和点睛，不当文字 |

- **便签、贴纸、印出来的纸不跟明暗走**：便签纸 `--color-sticky`、贴纸的填色、年度小报和信封（`--color-print-*`、`--color-kraft`）在深色模式下也是浅色，所以便签（`.pm-note`）和胶带上的字、强调色用便签的墨色 `--color-on-sticky`（`index.css` 已接好）。

## 字

- 界面是手札体：`font-sans` 就是 `index.css` 的 `Pomelo Hand`，常规和粗体各指到手札体自带的那一款（直接写 `Hannotate SC`，粗体会被系统描粗、发糊）；找不到时用苹方。
- **例外**：柚子里读长文的地方（问题和回答的正文、译文、提示词）用苹方 `font-reading`，15 号、行高 1.7；见字如面的正文也用苹方（字号、行距在它的设置里），标题还是手札体。文件路径和代码用等宽 `font-mono`。
- 字号：正文 14、行高 1.6；次要的字 12～13；模块页标题 26 粗（`PageHeader`）；面板标题 20 粗；首页问候 46 粗。数字等宽，金额右对齐就齐。
- 字要清楚（不歪、不缩放、不出框）见方案「字体与排版」，`ui-lint` 会查。

## 手画的框和线

元素上写 `data-hand="种类"`，`src/shared/hand.ts` 就把它画进去（主窗口和速记小窗开头都调 `startHand()`；怎么补画见它开头），同一个 `data-seed` 永远画出同一条线。

| 种类 | 画什么 |
|---|---|
| `sheet` · `desk` | 模块页的纸（方格、缝线、纸纹）· 桌面 |
| `card` · `note` · `ticket` | 白卡 · 便签 · 票 |
| `button` · `field` · `round` · `cell` | 按钮 · 输入框和下拉 · 圆框 · 格子 |
| `pick` | 选中的底：一块手剪的色块 |
| `frame` | 自己定参数的框（`data-r` 圆角、`data-sw` 线宽、`data-amp` 抖动、`data-fill` 填色、`data-tilt` 歪多少、`data-tapes` 胶带） |
| `rule` · `marker` · `strike` | 手画横线 · 荧光笔 · 划掉 |
| `check` · `switch` · `star` | 勾选框 · 开关 · 星星 |

规矩：

1. **纸上的白卡自动变手画卡**：写 `rounded-card border bg-card` 的框（表格、列表、卡片）在纸上和问柚子的小窗里自动换成手画卡。菜单、弹窗、面板里的和比一行还小的不换；不想换加 `data-no-hand`。
2. **手画的边画在字下面一层**（会滚、会裁的盒子怎么包见 `CLAUDE.md`「界面规则」）：卡片里的行、格子不另涂白底（`frame.css` 已让它们透明），选中、指着的行涂底色时两边让出 3；盖在纸上的整页（导入账单）不涂底色，直接画在纸上。
3. **焦点是把线描粗**：输入框有焦点时不另套方框。

## 外框

整套外框照方案「方向」里的「外框」（B3 桌面拼贴：顶栏、开着的页、纸签、贴纸簿、柚子瓣、找东西），那边写了的这里不重复；有哪些按钮、怎么用见 `requirements.md`「界面外框」，出现、收起的动静见「动效」。代码在 `src/app/`，摆法在 `frame.css`。

- **窗口**不滚动、不回弹，只有里面的区域滚；滚动条平时是一小段淡墨线，鼠标移进那一块才显出来（根元素的 `pm-scroll`）。
- **顶栏**（`TopBar.tsx`）：「桌上开着」新开的贴纸啪地贴上、关掉的撕走；开发版多一个小胶囊；「问柚子」有没看过的定时对话时右上一个小点。按钮的名字都在落签里。
- **常用**（`Desk.tsx` 的 `DeskCommon`）：桌面最下面一排，不跟着桌面动：一条薄荷胶带写「常用」，后面是置顶模块的贴纸（各歪一点，下面名字），最后是手画圆框里的贴纸簿。悬停贴纸抬起一点，按下压一下。
- **纸**（`Desk.tsx` 的 `PaperStack`）：最前面的页四周露出桌面，微微歪着，左上角拍着模块的贴纸；叠着的页悬停时名字垂下来。新开的页从右边滑进来，换到最前面的页贴纸再拍一次。
- **柚子那一页**是线圈本（见「各处的样子 › 柚子」）。
- **贴纸簿**（`StickerBook.tsx`）：桌面盖一层淡淡的暗色；左上柚子（打开时「哇」）；开着的贴纸变淡；打字时对不上的很淡，对上的外面一圈荧光笔色的光。
- **柚子瓣**（`Bloom.tsx`）：盖住桌面（半透明的桌面色加模糊）；大柚子按窗口高缩放；瓣名在柚皮外面。
- **找东西**（`Search.tsx`）：小票打印机挂在窗口上方，小票上下印着店名和「谢谢光临」；大输入框下面一道手画的线；结果一行行打印出来，选中的垫选中色；「意思相近」写在两道虚线中间。
- **问柚子的小窗**（`src/modules/youzi/SideChat.tsx`）：一张手画的卡站在桌面右边，桌面和纸让出位置；窗口窄时浮在纸上面，投影深一点。输入框上面一个选中色的小胶囊写现在在哪一页或哪条记录。里面的白卡也换成手画卡。
- **落签**：指着小按钮、贴纸时，名字写在一张小纸签上，挂在一根线上垂下来晃两下（`pm-tip-host` + `<Tip>`，`IconButton` 自带）。挂在最上面一层，不被纸边、卡片挡住，靠窗口边时往里挪；线从按钮正中画出来的那一笔下面一点点垂下（不是框的下面）；被指着时自己会动的（叠着的页、歪一下的贴纸），线跟着它走。怎么量见 `src/shared/tips.ts` 开头。
- **出错兜底**（`src/shared/Oops.tsx`）：画的时候出错，只有那一块换成一张手画卡（哪里、错误、再试一次、复制错误；浮层是角上一张小卡、能收起），别处照常用。
- **柚子的表情**：平常的动静见方案「动效」；柚子瓣、贴纸簿打开时「哇」，换到一页时开心，回到桌面眨眼。别的什么时候换见 `requirements.md`「界面外框」的「柚子的表情」。
- **速记小窗**（`src/capture/`）：一页方格纸，控件和主窗口一样是手画的。上面分段切笔记、待办、问柚子、翻译（只剩一样时不显示），右边图钉；笔记框聚焦或拖文件进来时边描粗，附件排在框的底边；翻译有结果时原文、译文上下各半。

## 首页（桌面）

`src/home/`；放哪些块、怎么拖见 `requirements.md`「首页（桌面）」。

- 每一块是一张便签：白卡、横线卡、分类色淡底的卡、黄便签或小票，都歪一点、贴一两条胶带。
- 左边一屏：问候语一笔笔写出来，荧光笔划过，后面一句淡墨的话；今日简报右上角贴着一张能撕起来的柚子贴纸；今天的待办是横线卡（勾了划掉）；快到的日子第一个的天数荧光笔划一下；资产是小票，右上「翻面」；念念不忘一条是黄便签（照笔记的样子画）；今年的数字是一圈圆贴纸。新年第一周简报上面多一个信封（见「Atlas」）。
- 右边一屏：本月小月历事情打颜色点、今天画圈；今年按月是 12 根手画柱子；求职近况该跟进的划荧光笔；一网打尽是网站图标、名字、淡墨网址。

## 日历

`src/calendar/`；是什么、放哪些见 `requirements.md`「日历」。纸上一张白卡的月历：格子之间虚线，今天手画一圈，每条一行（颜色点 + 标题）；四种各一种分类色：待办薄荷、日子樱粉、出行橙、面试葡萄紫。点一条弹出的小卡片上有模块的贴纸。

## 典型页

模块里面是四种典型页搭出来的，共用的零件都在 `src/shared/`。

- **页头**（`ui.tsx` 的 `PageHeader`）：大标题，不放图标（模块的贴纸拍在纸角上），左边让开那张贴纸；右边淡墨小字写这一页有多少。
- **白卡**：纸上的表格、列表、卡片都是手画的卡，行和行之间虚线（见「手画的框和线」）。
- **标签**：选项、状态、阶段都是带颜色点的小标签（`pm-chip`）：底是它的浅色，字是墨色。

| 典型页 | 哪些模块 | 怎么搭 |
|---|---|---|
| 列表型 | 一步一步、随意画画、出门走走、念念不忘、一网打尽、有板有眼 | 左边一列，右边标题、一句统计、分段筛选、白卡里的条目 |
| 表格型 | 钱来钱往、投石问路、书影、五花八门 | 工具栏（手画搜索框、下拉、主按钮）和白卡里的表 |
| 详情型 | 各模块的编辑面板 | `panel.tsx` 的 `SidePanel`：右边滑出一张手画的卡，投影深一点；右上手画 ×；底下虚线上面是删除、取消、保存。编辑不跳转 |
| 统计型 | 钱来钱往的报表、投石问路的统计、DevJanitor 的磁盘 | 数字卡加 `charts.tsx` 的图 |

- **左边一列**：容器 `.side-list`（和右边之间一道虚线），一行 `.side-row`；选中的那行加 `on`，里面第一个放 `<Picked />`（垫一块手剪的底）、字加粗，不整行涂色；悬停浅一点的底。固定的几项和下面的列表之间一道虚线（`.side-rule`）。
- **图表**（`charts.tsx`）：柱子和甜甜圈是手剪的色块加墨线描边，折线是手画的线，网格是淡淡的虚线，只有一个坐标轴；悬停有提示，数字在旁边的清单里也都看得到。有 `ColumnChart`、`LineChart`、`MultiLineChart`、`Donut`、`Sunburst`、`BarList`、`StackBar`、`Meter`、`Heatmap`。

## 控件

样子都是 Design System 的（`ds.css` 的 `pm-*`），这边包成组件。

| 控件 | 在哪 | 样子和动静 |
|---|---|---|
| 按钮 | `ui.tsx` 的 `Button` | 主按钮、次按钮（默认）、危险按钮是手画框；`ghost`、`ghost-danger` 没有框。按下扁一下 |
| 图标按钮 | `ui.tsx` 的 `IconButton`、`RefreshButton` | 只有图标，名字在落签里；刷新的会转到读完 |
| 输入框 | `ui.tsx` 的 `TextInput`、`TextArea`、`SearchInput` | 手画的框，有焦点时边描粗；`TextArea grow` 跟着字长高、不出滚动条；手画卡里的框包 `QuietFields.Provider`，边淡一档、直一些，打字时变回墨色（呦呦漫游的编辑页） |
| 写字的框 | `editor/` 的 `LiteEditor`（念念不忘的格式）、`MdField`（写提示词，Markdown，手画的框、里面一层自己滚） | 边写边显示；右键是一条纸做的菜单（格式、两个图标库） |
| 下拉 | `Dropdown.tsx` | 手画的框；菜单一格格展开，当前项打勾，能分组、能折叠，底部可以有「管理类型…」这类操作；在弹窗里也不会被裁掉 |

- **表格**：能就地改的格子平时是普通文字，悬停出浅底。**多选**：右上「多选」按下后变「完成」，行首出现勾选框，底部一条操作栏；平时行首不留位置。

- **差异**（润色、改文件、笔记改写）：删掉的淡墨加删除线，新加的垫选中色。

## 文案

- 全中文，保留俏皮的叫法，像柚子在跟你说话。按钮用简单动词：新增、保存、删除、导出。
- **不写使用提示**：不提示快捷键、怎么操作、可以撤销；输入框不放示例。要解释的只放在设置页的 (?) 里。
- 空白页、空的块一句俏皮话（「书架空空，去摸会儿鱼吧」），不附操作说明。
- **列表行只放最必要的信息。**
- **只有一种东西的列表不写小标题**（一步一步左边不写「分组」，念念不忘没有置顶标签时不写「标签」，知识库不写「库」，插件库不写「技能」）；一页里有两种以上才各写各的名字。
- 删除前确认，确认框里只写会一起删掉什么。

## 各处的样子

几页共用的摆法。颜色词：「主色」「选中色」（选中的底色）、「淡墨」（次要的字）、红（危险色）都跟着配色走；写「卡片」的都是手画的白卡。

### 模块页

- **行和卡片上的操作**平时不显示，悬停才出小图标（⋯、编辑、复制、拖动手柄、访达）；删一行是行尾红色 × 或红色垃圾桶。
- **拖动**：拖着的那行变淡（树里鼠标旁跟一枚写着名字的小卡片），卡片整张拖时浮起带阴影、别的让位；落在两行之间是一条主色横线（树里缩进到那一层），落进一个组或文件夹是那一行浅底加一圈主色。
- **单栏的页**内容居中，最宽 768（宽一点的工作台 896）。
- **虚线框**表示还不算数或已经不在：程序自带的规则、追问卡、没记完的复盘、没写过的年份、不在这台 Mac 上的附件、删掉的笔记。
- **可一键完成的条目**（课节、物品、循序渐进的每一节）前面是圆圈：空心未完成、带点进行中、打勾已完成。
- **再来一遍的行**（重读、重看、周目、送过的礼物）：面板那一栏每行年份下拉 + 内容（星星或文字）+ 红色 ×，最下面主色小字「+ …」。
- **后台在做的事**（建立索引、Pub2MD、扫描、发布）：细进度条、淡墨的步骤和用时、「停止」；失败是红字原因加「重试」。
- **页面要用的文件夹或服务不在时**：页面中间一句话说原因，加去修的按钮（如「去设置」）。开发版用的是编的东西时（呦呦漫游的副本、DevJanitor 的假 Mac），页头一个淡墨小胶囊写明。
- **设置类的页**（Pomelo 的设置、体检、助手的设置页）：一节一张卡，每行左边名称和小问号 (?)，右边内容和按钮。
- **标签树**（念念不忘、见字如面共用 `modules/notes/TagTree.tsx`）：标签前一格图标位（没设是淡墨 #），悬停右边「⋯」；换图标用图标库的弹窗。正文里的 `#标签` 是 `.pm-hashtag`：墨色字、下面一道这套配色的荧光笔（深色模式深一档），能点；设了图标的把 `#` 画成那个图标（`notes/tagIcons.tsx`）。
- **纸条菜单**（右键、格式条的下拉，`shared/editor/MdMenu.tsx`）：一行行，图标、颜色点贴着字，快捷键靠右；分组的行右边一个小箭头，指着那一行垫选中色、旁边贴着出第二条纸（右边放不下就出在左边，`useSideStrip`）。
- **边写边显示的框**（念念不忘和它的卡片、速记、记到念念不忘、呦呦漫游的正文、写提示词的框）照见字如面排（见 `requirements.md`「念念不忘」的「正文格式」）：每行后面一样的一小段间距（代码块、表格不留）；列表的 `- ` 画成一个点；标题的 `#`、引用的 `>` 只在光标那一行露出；不在编辑时全收起。Seeker 的要点是自己的小框：编辑时 `**` 都露出来。
- **柚子链接**（`shared/links/`，样式在 `links.css`；几种写法见 `requirements.md`「跨模块联动「柚子链接」」）：小卡是柚子链接色的字、同色的淡底，悬停深一点；找不到的是淡墨字、淡墨的淡底，后面小一号「找不到」。写的时候 `[[`、模块名和 `]]` 变淡。`[[` 的提示和「柚子链接…」的查找框是同一种纸，打的字下面划荧光笔；「柚子链接 · N」一栏行之间细虚线。「记到念念不忘」的框（`ClipBox.tsx`）是一张白卡，左上角歪着拍一张念念不忘的贴纸。
- **附件**（`shared/attachments/`）：图片是圆角小方块，其他文件是带图标、名字和大小的小框；拖进来时外圈变主色；不在这台 Mac 上的是虚线框、淡墨。看大图时整个窗口变暗，中间一张图，下面一行白字（‹ 文件名 2 / 3 ›、用默认程序打开、×），← → 换图，Esc 或点空白处关闭。
- **见字如面导出的 PDF / Word**：两种样式照 visual-atelier 的画布 Notes-PDF-Pomelo / Notes-PDF-Print（`src/print/print.css`）；正文和编辑器里一样、记号不显示；柚儿园跟着配色（浅色）、带 App 里的纸纹，印刷的颜色固定。

### 柚子

柚子页、问柚子的小窗、速记小窗、DevJanitor 的 Agent、Rater 的复盘对话是同一套对话的样子。

- **柚子页**：纸是线圈本（横线纸，上边一排线圈，纸角没有贴纸），左边让出一栏桌面：大柚子（`BigPomelo.tsx`）、搜索框、对话的小纸条（各歪一点、左右错开，悬停摆正，打开的那张选中色；项目是牛皮纸文件夹），样式在 `modules/youzi/list.css`。
- **选模型的下拉**：每个模型前面一个状态点，云端的是小云朵。
- **消息**（最宽 768）：我的问题在右边选中色的气泡，回答在左边；代码块浅底，长代码、宽表格横向滚。思考过程折叠成淡墨一行；正在写的末尾一个闪烁的小方块，还没开始写是 `ThinkLine`。消息下面一排小图标，最新的回复一直显示，其他的悬停才出。
- **回复上下的折叠行**（查了什么、来源、分段要点、用了几条记忆）：淡墨小字「› …」，默认收起，点开左边一条竖线。回答里的 [n] 是淡底圆角小数字；提到的记录加淡墨虚线下划线，点了打开。
- **回复下面的卡片**（确认卡片、问我、新建 / 改文件、DevJanitor 的三种）：最宽 448，带文件内容或命令的 672。每条一行：勾（默认勾上）、粗体标题，下面淡墨的项；改的值写「删除线旧值 → 新值」；底部右边「取消」和主按钮。做完后底部换成淡墨的结果，没勾的变淡。
- **输入框**：一张卡片，有焦点时边描粗；底下一排淡墨小按钮，按下的垫选中色，用不了的变淡、点不动；右边圆形发送键（生成时变停止键）。上面一排小胶囊是这一问带的东西（附件、技能、所在的页），文件拖进窗口时外圈变主色；`{{名称}}` 垫选中色。
- **润色和补全**：能润色的输入框悬停时右上角淡墨小星星，点开在下面一张小卡（要求、主按钮），改好的用差异样式，「替换」才换上。栏目标题右边的小操作是淡墨小字加小星星（`AssistAction`）。
- **一句话填好 / 改好**：面板标题下面第一行，左边小星星，淡墨占位；出错一行红字。补全、一句话填上的输入框垫选中色（`bg-accent`），自己改过就恢复。

### 柚子的助手

- 每个助手是一页自己的工作台：页头是名字加一个小柚子，子页在纸签上。
- **按钮下的状态行**（模型调用在后台跑、离开页面也跑完的）：跳动的淡墨「正在…」；好了是淡墨结果（有东西可看时多「查看」）和 ×；失败红字原因、「重试」和 ×。
- **资料卡片**（Seeker、Rater）：折叠卡片一行「› 名称　淡墨补充」，停用的整张变淡写「已停用」。
- **助手的设置页**：分节卡片（最宽 768），模型按页分节，每个功能一行：左边功能名，中间模型下拉，最右思考下拉（选项跟着模型变）。没有模型的功能，它的按钮点不了。
