# 视觉规范

> 初稿（2026-09-28）。v0.1 先按这份规范开发，不细究视觉；之后再专门调整。

## 气质

**清爽、温柔、带一点柚子味，像 macOS 原生应用一样安静。**

- 「柚儿园」谐音幼儿园，模块名也都很俏皮（摸鱼读读、尝尝咸淡），所以整体可以轻松、有温度，但不能花哨。
- 每天都要用的工具，内容永远是主角。颜色只用来表示状态和重点，不做装饰。
- 看起来要像一个认真做的 Mac 应用，而不是网页。

## 颜色

灵感来自柚子：柚皮的黄绿、红柚果肉的珊瑚红、柚子瓤的暖白。浅色和深色两套，跟随系统自动切换。

**基础色**

| 名称 | 用途 | 浅色 | 深色 |
|---|---|---|---|
| 柚瓤白 | 页面背景 | `#FAF8F4` | `#1C1B19` |
| 侧栏 | 左侧导航背景 | `#F3F0E9` | `#232120` |
| 卡面 | 表格、卡片、面板 | `#FFFFFF` | `#292724` |
| 分割线 | 边框、分隔 | `#E8E3D9` | `#3A3734` |
| 墨色 | 正文 | `#2B2824` | `#ECE8E1` |
| 淡墨 | 次要文字、说明 | `#6F685F` | `#A29B91` |
| 柚红 | 主色：主按钮、选中、链接、焦点框 | `#C4503B` | `#EE7B66` |
| 柚红浅 | 选中项的底色（上面的文字用墨色） | `#FBE6E0` | `#3D2621` |
| 警示红 | 删除等危险操作 | `#B8322F` | `#F07167` |

**状态色**（标签底色 / 文字）

| 状态 | 浅色 | 深色 |
|---|---|---|
| 待标记 | `#EFECE6` / `#6F685F` | `#34322F` / `#B3ACA2` |
| 想读 · 想看 · 未开始 | `#E3EDF8` / `#33628F` | `#22303F` / `#8DB8E6` |
| 在读 · 在看 · 进行中 | `#FBEFC8` / `#855C00` | `#3A3120` / `#E8C063` |
| 已读 · 已看 · 已完成 | `#E2F0D6` / `#3F6D27` | `#25341E` / `#93C77A` |

- 星级：点亮的是实心星 `#E9A825`，未点亮的是淡墨色空心星。靠「实心 / 空心」区分，不只靠颜色。
- 进度条：用「已完成」的绿色。
- 文字和背景的对比度都达到 WCAG AA（至少 4.5 : 1），图标至少 3 : 1。以上颜色都已检查过。

**模块色**：只用在侧栏图标和页面标题旁的图标上，浅色和深色通用。

## 文字

- 字体：全部使用「手札体-简」（Hannotate SC）。它是 macOS 自带的可下载字体，这台 Mac 已经下载好了。万一找不到，会自动换成苹方。
- 手札体只有「常规」和「粗体」两种粗细，所以标题用粗体。
- 文件路径这类需要看清每个字符的内容，改用等宽字体。
- 字号：正文 14、次要文字 12、页面标题 22（粗体）、统计数字 20（粗体）。
- 中文行高 1.6。

## 布局

- 左侧导航栏宽 220，右侧是内容区。
- 窗口标题栏和内容融为一体（隐藏标题文字，红绿灯按钮浮在侧栏上）。实现成本不高的话，侧栏用 macOS 原生的半透明毛玻璃效果。
- 页面结构统一为三层：**页面标题 + 统计** → **工具栏**（搜索、筛选、新增）→ **内容**（表格或列表）。
- 编辑时从右侧滑出面板（宽 400），不跳转页面。
- 间距以 4 为单位，常用 8、12、16、24。
- 圆角：按钮和输入框 8，卡片和面板 12。
- 阴影尽量少，主要靠分割线区分层次。只有浮层（面板、弹窗、下拉菜单）才用柔和的阴影。

## 图标

- 界面图标用 Lucide 线条图标，16 号大小，线宽 1.5。
- 模块图标：摸鱼读读「翻开的书」、好奇看看「场记板」、随意画画「调色盘」、出门走走「行李箱」、设置「齿轮」。
- 内容里的 emoji（比如「家钥匙 🔑」）原样显示。

## 动效

- 只用简短、轻柔的过渡（0.15～0.2 秒），比如面板滑出、状态切换。不做弹跳这类夸张效果。
- 系统开启「减少动态效果」时，关闭所有动效。

## 文案

- 界面全中文。保留俏皮的模块名和「尝尝咸淡」这类叫法。
- 按钮用简单的动词：新增、保存、删除、导出。
- 空白页可以俏皮一点，比如「书架空空，去摸会儿鱼吧」。
- 删除前一定要确认，确认框里写清楚会删掉什么。

## 实现方式

- 以上颜色、字号、圆角都做成统一的主题变量（Tailwind 主题），组件里不直接写颜色值。
- 下拉菜单、弹窗用 macOS 原生控件，看起来更像 Mac 应用。
- 以后要改视觉，先改这份文档，再改主题变量。
