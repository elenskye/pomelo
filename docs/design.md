# 视觉规范

> 柚儿园长什么样、东西从哪来、做界面怎么照着做。做什么、怎么表现在 `requirements.md`，怎么测在 `testing.md`。前十五节是整套视觉和规矩，从头读；最后一节「各处的样子」是几页共用的摆法；每一页自己的布局以代码为准。

## 气质

**一张摊开的桌面，上面是手账。** 清爽、有活力、手作感：手画的墨线、错开一点的颜色、带白边的贴纸、胶带和纸。纸、胶带、贴纸可以歪，字永远是正的、清楚的。处处有小动静，动起来都像纸和贴纸。内容是主角，颜色只表示分类、状态和重点。

顶栏下面是桌面：首页的便签直接摆在桌上；打开的模块是一张方格纸（左边一列缝线，左上角拍着它的贴纸），别的开着的页叠在它右边。柚子是唯一的角色：就是 AI，也是顶栏、菜单栏和 App 图标。

不要：后台表格感、通用的细线图标、装饰堆砌（一张卡片最多两条胶带、一张贴纸）。

## 字

- 界面只用 `font-sans`：`index.css` 的 `Pomelo Hand`，就是手札体，常规和粗体各指到它自带的那一款（直接写 `Hannotate SC`，粗体会被系统描粗、发糊）；找不到时用苹方。
- **例外**：柚子里读长文的地方（问题和回答的正文、译文、提示词）用苹方 `font-reading`，15 号、行高 1.7；见字如面的正文也用苹方（字号、行距在它的设置里），标题还是手札体。文件路径和代码用等宽 `font-mono`。
- 字号：正文 14、行高 1.6；次要的字 12～13；模块页标题 26 粗（`PageHeader`）；柚子页和日历的月份 22 粗；面板标题 20 粗；首页问候 46 粗。数字等宽，金额右对齐就齐。
- 字不歪、不缩放；左右离框留出空，上下不出框（`ui-lint` 会查）。

## 手画的框和线

元素上写 `data-hand="种类"`，`src/shared/hand.ts`（主窗口和速记小窗的 `main.tsx` 开头都调 `startHand()`）就把它画进元素里的一层 `[data-hand-painted]`；出现、换了参数、变了大小都补画，同一个 `data-seed` 永远画出同一条线。

| 种类 | 画什么 |
|---|---|
| `sheet` · `desk` | 模块页的纸（方格、缝线、纸纹）· 桌面 |
| `card` · `note` · `ticket` | 白卡 · 便签 · 票 |
| `button` · `field` · `round` · `cell` | 按钮 · 输入框和下拉 · 圆框 · 格子 |
| `pick` | 选中的底：一块手剪的色块 |
| `frame` | 自己定参数的框（`data-r` 圆角、`data-sw` 线宽、`data-amp` 抖动、`data-fill` 填色、`data-tilt` 歪多少、`data-tapes` 胶带） |
| `rule` · `marker` · `strike` | 手画横线 · 荧光笔 · 划掉 |
| `check` · `switch` · `star` | 勾选框 · 开关 · 星星 |

规矩：

1. **纸上的白卡自动变手画卡**：写 `rounded-card border bg-card` 的框（表格、列表、卡片）在纸上和问柚子的小窗里被 `hand.ts` 换成手画卡（加 `data-auto-card`）。菜单、弹窗、面板里的和比一行还小的不换；不想换加 `data-no-hand`。
2. **手画的边画在字下面一层**，所以：
   - 会滚、会裁的盒子上不画边：外面一层画边、里面一层滚（不然边跟着字滚走、超出的半条被切掉）。
   - 卡片里的行、格子不另涂白底（`frame.css` 已让它们透明）；选中、指着的行涂底色时两边让出 3。
   - 盖在纸上的整页（导入账单）不涂底色，直接画在纸上。
   - 能滚的区域四周留出边抖出去的几像素（`-m-1 … p-1`），焦点框也不会被切。
3. **要框就用手画的控件**（`TextInput`、`MdField`、`Dropdown`、`PickField`、`Button`），不用直线细边框的原生输入框。
4. **焦点是把线描粗**：输入框有焦点时不另套方框。
5. 故意留的直线框（设置里的配色小样）加 `data-nolint`，界面检查不报。

## 外框

整个窗口不滚动、不回弹，只有里面的区域滚；滚动条平时是一小段淡墨线，鼠标移进那一块才显出来（根元素的 `pm-scroll`）。代码在 `src/app/`，摆法在 `frame.css`。有哪些按钮、开着的页、前进后退、快捷键见 `requirements.md`「界面外框」；出现、收起的动静见「动效」。

- **顶栏**（`TopBar.tsx`，高 51）：在纸上时的「回桌面」是一条薄荷胶带。右边淡墨「桌上开着」和一排小贴纸（每页一张，最前面那张底下一道手画的线，悬停右上角出 ×；新开的啪地贴上，关掉的撕走）、「＋」、开发版的小胶囊、日期（手画的小纸条，窗口窄于 1100 不显示）、找东西、设置、「问柚子」（柚子探出头；有没看过的定时对话时右上一个小点）。按钮的名字都在落签里，不写快捷键。
- **桌面和「常用」**（`Desk.tsx` 的 `DeskCommon`）：最下面一排「常用」不跟着桌面动：一条薄荷胶带写「常用」，后面是置顶的模块（56 的贴纸，各歪一点，下面名字），最后是手画圆框里的「贴纸簿」。悬停贴纸抬起一点，按下压一下。
- **纸**（`Desk.tsx` 的 `PaperStack`）：最前面的页是一张方格纸，四周露出桌面（左、上 30，右 112，下 16），微微歪着；左上角拍着模块的贴纸（64，歪 8 度）。别的开着的页叠在右边，最多露 4 张，只露纸边和一张 46 的贴纸，悬停时名字垂下来。新开的页从右边滑进来，换到最前面的页贴纸再拍一次。每一页是自己的一层，换页时叠着的只挪位置、不重画。
- **子页纸签**：插在纸上边的文件夹纸签：没选的是五种分类色的浅底，选中的是纸色、粗体、连着纸。
- **柚子那一页**是线圈本：横线纸，上边一排线圈，纸角没有贴纸，左边让出一栏桌面（见「各处的样子」的「柚子」）。
- **贴纸簿**（`StickerBook.tsx`）：桌面盖一层淡淡的暗色，一本斜纹纸的本子（最宽 1040）从下面滑上来，微微歪着。左上柚子（打开时「哇」）、粗体「柚子的贴纸簿」和淡墨「撕一张贴纸，就去那里 · 拖出簿子放到桌上也行」；右上手画输入框「去哪，或问柚子」，它左边两个淡墨字按钮「＋ 模块」（点了出一条纸：新建「五花八门」、新建「循序渐进」）「＋ 分类」；右下「已隐藏 N」。下面两栏，分类名写在胶带上（薄荷、柚黄轮着），模块是 66 的贴纸，一行五个，名字在下面（助手旁一个小柚子）；开着的变淡，留一个虚线框写「在桌上」。打字时对不上的很淡，对上的外面一圈荧光笔色的光；都对不上时一行「没有这一页，问柚子「…」」。
- **柚子瓣**（`Bloom.tsx`）：盖住桌面（半透明的桌面色加模糊）。中间一个手画的大柚子（680，按窗口高缩放）：一圈柚皮，每瓣一个分类、分类色的淡底，瓣里只放贴纸（名字在落签里），瓣名在柚皮外面（点了直接改）；中心是柚子、淡墨日期和输入框「去哪，或问柚子」。拖着转，松手接着转。贴纸弹完把每张重建一遍（WebKit 按第一次画的大小记阴影，不重建是一块糊的、发白的方形）。
- **找东西**（`Search.tsx`，⌘K）：一台小票打印机挂在窗口上方（宽 620）。小票上：淡墨「— 柚儿园 · 找东西 —」，大输入框（下面一道手画的线，右边淡墨找到几条），结果按模块分组一行行打印出来，选中的垫选中色；两道虚线中间写「意思相近」，下面是按意思找到的；没找到时「没找到「…」」和「问问柚子」；最下面虚线下「谢谢光临 · 柚子」。
- **问柚子的小窗**（`src/modules/youzi/SideChat.tsx`，⌘J）：一张手画的卡，宽 380，站在桌面右边，桌面和纸让出位置；窗口窄于 1240 时浮在纸上面，投影深一点。顶上一行：小柚子、对话标题和 ⌄（新对话、最近 8 个）、模型菜单、新对话、×。输入框上面一个选中色的小胶囊：定位图标、现在在哪一页或哪条记录、×（这次不带）。里面的白卡也换成手画卡。
- **落签**：指着小按钮、贴纸时，名字写在一张小纸签上，挂在一根线上垂下来晃两下。元素加 `pm-tip-host`、里面放 `<Tip>`（`src/shared/handParts.tsx`），`IconButton` 自带。**纸签上只写动作**（删除、编辑、上移、刷新、时间穿梭），不写记录的名字和说明：带名字的完整说法放 `IconButton` 的 `label`（读屏和测试用），纸签写 `tip`；`src/shared/tips.ts` 把它挂到最上面一层（不被纸边、卡片挡住，靠窗口边时往里挪）。**线垂在图标下面一点点**：量按钮正中那一竖上画的东西（图标的线、贴纸的白边、看得到的下划线）最低到哪，线从那下面 3 像素开始（`inkBottom`、`GAP`）；方形的浅底、透明的下划线不算；正中那一竖上没有笔画的（引用的两个点、互链的两对括号）量整幅图最低的一笔；什么都没画才挂在框下面。柚子瓣里打字找到的几张原地挂出来（`hangAt`）。**跟着按钮走**：被指着时自己会动的（叠着的页往外抽 16 像素、贴纸歪一下），挂出来后每一帧再量，动停了 0.6 秒才不量。量法见 `testing.md`「WebKit 才有的问题」的「落签」。
- **出错兜底**（`src/shared/Oops.tsx`）：每一页、桌面、每个浮层（贴纸簿、柚子瓣、找东西、问柚子的小窗）各包一层。画的时候出错，只在那一块显示一张手画卡：「这一页出错了」（浮层是角上的「这一块出错了」）、哪里和错误、「再试一次」（浮层是「收起」）和「复制错误」；别处照常用。
- **柚子的表情**：顶栏的柚子平常慢慢呼吸、眨眼、看来看去；柚子瓣、贴纸簿打开时「哇」，换到一页时开心，回到桌面眨眼；20 秒没动就困了，一动吓一跳。别的什么时候换见 `requirements.md`「界面外框」的「柚子的表情」。
- **速记小窗**（`src/capture/`，⌥Space）：系统标题栏「速记」，520 × 320（最小 420 × 280），一页方格纸（22 的格子），控件和主窗口一样是手画的。上面分段「笔记 · 待办 · 问柚子 · 翻译」（只剩一样时不显示），右边图钉。笔记是手画的输入框（「现在的想法是……」），聚焦或拖文件进来时边描粗，附件排在框的底边；待办是「要做的事」加日期和分组；问柚子是「问柚子……」，有对话后「接着问……」，下面「在 Pomelo 里继续对话」；翻译是「要翻译的文字……」，有结果时上下各半。下面一排：回形针、「存为 .md」、淡墨「已记下」和「撤销」，右边主按钮「记下」。有对话或译文时窗口高 560。
- **Mac 菜单栏**：中文的「柚儿园 · 编辑 · 页签 · 窗口」，页面的快捷键都列在「页签」里。

## 典型页

模块里面是四种典型页搭出来的，共用的零件都在 `src/shared/`。

- **页头**（`ui.tsx` 的 `PageHeader`）：大标题，不放图标（模块的贴纸拍在纸角上），左边让开那张贴纸；右边淡墨小字写这一页有多少。

- **标签**：选项、状态、阶段都是带颜色点的小标签（`pm-chip`）：底是它的浅色，字是墨色。

| 列表型 | 一步一步、随意画画、出门走走、念念不忘、一网打尽、有板有眼 | 左边一列，右边标题、一句统计、分段筛选、白卡里的条目 |

## 动效

像纸和贴纸在桌上动：按下扁一下、勾上弹一下、纸滑进来、贴纸拍上去、撕起来，什么东西出现都先画出来再弹一下。动效全是同步来的零件（在 `ds.css` 里），**这边只加减类名**（`is-in`、`is-pop`、`is-leaving`…；`hand.ts` 的 `flash` 让只放一次的动画重新放），不另写关键帧。不做声音。

两档：**calm** 是控件的小动静，可以弹、不循环、一次不超过 0.6 秒；**expressive** 是招牌时刻和柚子的表情，一次不超过 3 秒，只有柚子的表情和等待时的动画能循环。

| 招牌时刻 | 什么样 | 在哪 |
|---|---|---|
| 打开的问候 | 便签一张张落到桌上，问候语一笔写出来，荧光笔划过 | `home/HomePage.tsx`（`pm-greet`） |
| 柚子瓣 | 从顶栏的柚子那里转着长出来，线先画、贴纸再一个个弹；收起时缩回去；打「柚子」转一圈 | `app/Bloom.tsx` |
| 贴纸簿 | 本子滑上来；点的贴纸翘起来、撕下来飞走 | `app/StickerBook.tsx` |
| 找东西 | 小票从出纸口打出来，选了撕下来 | `app/Search.tsx` |
| 开着的页 | 新页滑进来、贴纸啪地拍上；叠着的抽出来一点 | `app/Desk.tsx`、`app/TopBar.tsx` |
| 问柚子的小窗 | 从顶栏的「问柚子」那里长出来、缩回去 | `modules/youzi/SideChat.tsx`（`pm-chat-pop`） |
| 勾待办 | 果冻弹，墨线划掉那一行（出门走走装好的东西只划线、不弹） | `modules/todo/TaskList.tsx`、`.task-title` |
| 全做完 | 一张便签「今天的事都做完啦！」贴上来，撒一把小贴纸 | `shared/cheer.tsx` |
| 柚子在想 | 一小笔绕圈，画完擦掉再画，旁边「柚子在想…」 | `handParts.tsx` 的 `ThinkLine` |
| 柚子的表情 | 呼吸、眨眼、弹跳、摇头… | `app/Pomelo.tsx` |
| 空状态 | 插图一笔笔画出来，再一样样弹 | `EmptyState` |
| 拆信封 | 新年第一周的年度小报 | 在 Atlas 的设计里 |

- **小彩蛋**（另有上表的柚子瓣转圈、全做完撒贴纸，和柚子的困、吓一跳）：撕起简报角上的柚子贴纸，底下写着「今天也辛苦啦」（`home/Whisper.tsx`）；2.5 秒里连戳柚子页的大柚子 5 下，它晕了，贴一张「别戳啦，晕了…」，平时每戳一下换一张脸。
- **减少动态效果**：系统开了就全都不动，直接是最后的样子，循环停下（`index.css` 里统一关掉，同步来的零件自己也有回退）。用定时器、用代码挪东西的地方先问 `hand.ts` 的 `reducedMotion()`。
- **流畅度**（窗口是 WebKit，有些东西只在它里面慢；量法见 `testing.md`「WebKit 才有的问题」）：
  1. 页面上不放实时的 SVG 滤镜：纸纹是一小块算好的噪声平铺。
  2. 整页大小的层不改 `z-index`、不反复新建：叠着的页谁在上面写死在元素上。
  3. 给最上面那页开层用 `will-change: opacity`，不用 transform（页面里 `position: fixed` 的东西会跟着它定位）。
  4. 改了外框、纸、手画零件或动效，在 Safari 里量一遍；一帧超过 100 毫秒就要查。

## Atlas

柚子写的年度总结，做成一本能翻的「年度小报」；页面在 `src/modules/atlas/`，有哪些页、能做什么见 `requirements.md`「Atlas（年度总结）」。

- **封面**（`AtlasPage.tsx`）：由那一份的设计画（`design.cover`）。Tabloid 是小报头版缩小的样子：报头、年份、柚黄的一笔、纸星星、柚子、胶带，左下小框印着设计名和版本，今年没过完盖红章「截至某日」；印出来的纸，明暗都是浅色。整张歪一点，悬停摆正；做过不止一份的底下垫着一张。设计还没读进来、或那一版不画封面时，是一张写着年份和版本的素纸。封面下面「时间穿梭」图标（`TimeTravel`）进这一年的子页；没写过的年份是虚线的空封面。页头「样式」和主按钮「立即运行（写到今天）」。
- **一年的子页**：做过的每一份也是封面排成一排、能左右滑，新写的在前；各幕没写成的用红字写原因，旁边的 × 删这一份。页头「全部年份」回去，「再做一份」。
- **样式的历史**：装着的每一版设计一张它自己画的封面，下面写名字版本、哪天定稿、有几份照它画、新做的用不用它、改了什么。
- **每一份照它那条线最新的设计画**：快照同步在 `src/vendor/pomelo/atlas/<名字>-<版本>/`（`design.js` 和说明它自己的 `design.json`），装着 Tabloid 1.0.3 和 1.1.1。一份记着做的时候是哪一版（如 `tabloid@1.0.0`，库里记的不改），画的时候找同一条线（前两位一样）里装着的那一份（`designs.ts` 的 `resolve`）：1.0.x 做的都照 1.0.3 画、1.1.x 的照 1.1.1。
- **翻开的小报**（`Journey.tsx`）：盖住桌面（顶栏还在），放在一个 frame 里（为什么见 `architecture.md`「Atlas」），看到的就是在 visual-atelier 画布上验收的样子；配色、明暗、减少动态效果都传进去。点星星、纸条弹出原记录，「在模块里打开」回到 Pomelo 的那一条。
- **首页的信封**（`home/YearCard.tsx`）：简报上面一个柚子贴纸封口的牛皮纸信封，也是那一版设计画的。
- 各幕画什么、节拍、聊天页的泡泡都在 visual-atelier 的 `schemes/pomelo/atlas/README.md`，这边不重复。

## 文案

- 全中文，保留俏皮的叫法，像柚子在跟你说话。按钮用简单动词：新增、保存、删除、导出。
- **不写使用提示**：不提示快捷键、怎么操作、可以撤销；输入框不放示例。要解释的只放在设置页的 (?) 里。
- 空白页一句俏皮话（「书架空空，去摸会儿鱼吧」），不附操作说明。
- **列表行只放最必要的信息。**
- **只有一种东西的列表不写小标题**（一步一步左边不写「分组」，念念不忘没有置顶标签时不写「标签」，知识库不写「库」，插件库不写「技能」）；一页里有两种以上才各写各的名字。
- 删除前确认，确认框里只写会一起删掉什么。

## 开发指南

做界面时照这个来（细节在上面各节）。

1. **先用现成的**：「控件」表里的组件；页头 `PageHeader`，编辑面板 `SidePanel`，左边一列 `.side-row` 加 `<Picked />`，图表 `charts.tsx`。不画细边框，不自己拼 `pm-*` 类名。
2. **颜色只用变量**（「颜色」）：图表只用 `--chart-*`；便签上用便签的墨色。
3. **字体只写 `font-sans`**（默认就是），例外见「字」；不直接写 `Hannotate SC`。
4. **白卡照写 `rounded-card border bg-card`**，在纸上自己变成手画卡；会滚的内容包两层、能滚的区域用 `-m-1 … p-1`（「手画的框和线」）。
5. **动效只加减类名**：先在 `ds.css` 里找零件；没有的回 visual-atelier 加，不在这边写关键帧。
6. **新图标、新贴纸、新颜色走 visual-atelier**：图标在那边的 `schemes/pomelo/marks/icons.mjs` 画，发版同步，再在 `src/shared/icons.tsx` 加一行；贴纸、空状态插图同理（那边的 `marks/`）。新模块的颜色 `--module-<键>` 在那边定（`schemes/pomelo/tokens/targets.json`），同步过来就有；这边在 `src/app/modules.ts` 写 `color: "var(--module-<键>)"`，再加进「颜色」的「默认的模块色」。
7. **新浮层包一层 `Oops`**（`look="layer"`，给它 `onClose`），照 `src/app/App.tsx` 里贴纸簿那几个的写法。
8. **hook 不写在提前返回的后面**：`if (…) return` 后面再调 hook，数据晚到的那一下这一页就显示「这一页出错了」。
9. **有焦点的输入框不能在窗口外面**：WebKit 为了让它露出来，会把整个窗口的内容挪上去、回不来。从窗口外滑进来的东西（贴纸簿）等它进了窗口再给焦点，滑走前先放开。
10. **文案**照「文案」；能挑图标的地方用图标库；页面用 `usePageContext` 告诉问柚子的小窗现在在哪。
11. **改完跑**（见 `testing.md`「什么时候跑什么」）：`pnpm check`；`node scripts/ui-lint.mjs`（白板、直线框、被切的手画边、字出框都要清零）；`node scripts/hooks-lint.mjs`。看页面：后台跑 `pnpm dev`，开 `http://localhost:1420/?mock`（某页用 `/?mock#/finance`）。改了外框、纸、手画零件、动效，在 Safari 里量流畅度；新加或改了 Rust 命令的页面，还要在打包版的真实窗口里点一次。

## 各处的样子

几页共用的摆法，做新界面照着做；某一页自己的布局、宽度、按钮上的字以代码为准。颜色词：「主色」是这套配色的主色，「选中色」是选中的底色，「淡墨」是次要的字，红是危险色，都跟着配色走；写「卡片」的都是手画的白卡。

### 模块页

- **行和卡片上的操作**平时不显示，悬停才出小图标（⋯、编辑、复制、拖动手柄、访达）；删一行是行尾红色 × 或红色垃圾桶。
- **拖动**：拖着的那行变淡（树里鼠标旁跟一枚写着名字的小卡片），卡片整张拖时浮起带阴影、别的让位；落在两行之间是一条主色横线（树里缩进到那一层），落进一个组或文件夹是那一行浅底加一圈主色。
- **单栏的页**内容居中，最宽 768（宽一点的工作台 896）。**弹窗**一行放几个输入框的用 720，其他 560 或 440；里面的下拉占满它那一格，长文字 … 截断。
- **虚线框**表示还不算数或已经不在：程序自带的规则、追问卡、没记完的复盘、没写过的年份、不在这台 Mac 上的附件、删掉的笔记。
- **可一键完成的条目**（课节、物品、循序渐进的每一节）前面是圆圈：空心未完成、带点进行中、打勾已完成。
- **再来一遍的行**（重读、重看、周目、送过的礼物）：面板那一栏每行年份下拉框 + 内容（星星或文字）+ 红色 ×，最下面主色小字「+ …」。
- **后台在做的事**（建立索引、Pub2MD、扫描、发布）：细进度条、淡墨的步骤和用时、「停止」；失败是红字原因加「重试」。
- **页面要用的文件夹或服务不在时**：页面中间一句话说原因，加去修的按钮（如「去设置」）。开发版用的是编的东西时（呦呦漫游的副本、DevJanitor 的假 Mac），页头一个淡墨小胶囊写明。
- **设置类的页**（Pomelo 的设置、体检、助手的设置页）：一节一张卡，每行左边名称和小问号 (?)，右边内容和按钮。
- **标签树**（念念不忘、见字如面共用 `notes/TagTree.tsx`）：标签前 20 宽的图标位（没设是淡墨 #），悬停右边「⋯」；换图标是图标库的弹窗（宽 560，一组一组、每行 10 个，左下「不用图标」）。正文里的 `#标签` 是 `.pm-hashtag`：墨色字、下面一道这套配色的荧光笔（深色模式深一档），能点；设了图标的（没设就用最近一级上级的）把 `#` 画成那个图标（字还是 `#`，`notes/tagIcons.tsx`）。
- **纸条菜单**（右键、格式条的下拉，`shared/editor/MdMenu.tsx`）：一行行，图标、颜色点贴着字（间距 8），快捷键靠右；分组的行右边一个小箭头，指着那一行垫选中色、旁边贴着出第二条纸（右边放不下就出在左边，`useSideStrip`）。
- **边写边显示的框**（念念不忘和它的卡片、速记、记到念念不忘、呦呦漫游的正文、写提示词的框）照见字如面排：每行一整行，空行也是一整行，每行后面一样的一小段间距（代码块、表格不留）；列表的 `- ` 画成一个点。格式符号（`**` `==` `++`、链接的括号和地址）只在光标所在的那一处露出，标题的 `#`、引用的 `>` 只在光标那一行，别处只看效果；不在编辑时全收起。各框的格式和字体照旧。Seeker 的要点是自己的小框：编辑时 `**` 都露出来。
- **柚子链接**（`shared/links/`，样式在 `links.css`）：`[[目标]]` 是一个小卡：模块的小贴纸（16，跟着「图标和颜色」）+ 名字，柚子链接色的字、同色 9% 的淡底、圆角 7，悬停淡底深一点；`[[目标|字]]` 是柚子链接色的字加一道虚线，没有贴纸；找不到的是淡墨字、淡墨的淡底，后面小一号「找不到」。写的时候 `[[`、模块名和 `]]` 变淡，名字是柚子链接色。`[[` 的提示和「柚子链接…」的查找框是同一种纸：每行小贴纸、名字（打的字下面划荧光笔）、下面一行淡墨。被链到的那一栏「柚子链接 · N」每行贴纸、标题、淡墨日期，行之间细虚线。「记到念念不忘」的框（`shared/links/ClipBox.tsx`，见字如面和书影游的面板共用）是 440 宽的白卡，左上角歪着拍一张 40 的念念不忘贴纸。
- **附件**（笔记、任务、目标通用，`shared/attachments/`）：图片是 80 的圆角小方块，其他文件是带图标、名字和大小的小框；拖进来时外圈变主色；不在这台 Mac 上的是虚线框、淡墨。看大图时整个窗口变暗，中间一张图，下面一行白字（‹ 文件名 2 / 3 ›、「用默认程序打开」、×），← → 换图，Esc 或点空白处关闭。
- **见字如面导出的 PDF / Word**：两种样式照 visual-atelier 的画布 Notes-PDF-Pomelo / Notes-PDF-Print 画（`src/print/print.css`）；正文就是编辑器里的样子（同一份画法），记号都不显示；柚儿园跟着配色（浅色）、纸上有和 App 里一样的纸纹，印刷的颜色固定。专心写铺满窗口，也是纸色加纸纹，格式栏比平时高一截（落签不被窗口下沿切掉）。

### 柚子

柚子页、问柚子的小窗、速记小窗、DevJanitor 的 Agent、Rater 的复盘对话是同一套对话的样子。

- **柚子页**：纸是线圈本，左边让出一栏桌面，从上到下是大柚子、手画的「搜索对话」框、对话的小纸条（各歪一点、左右错开，字是正的，悬停摆正，打开的那张选中色、粗体；项目是牛皮纸文件夹）。样式在 `modules/youzi/list.css`，大柚子是 `BigPomelo.tsx`。
- **选模型的下拉**：每个模型前面一个状态点，云端的是小云朵。
- **消息**（最宽 768）：我的问题在右边选中色的气泡，回答在左边；代码块浅底，长代码、宽表格横向滚。思考过程折叠成淡墨一行；正在写的末尾一个闪烁的小方块，还没开始写是 `ThinkLine`。消息下面一排小图标，最新的回复一直显示，其他的悬停才出。
- **回复上下的折叠行**（查了什么、来源、分段要点、用了几条记忆）：淡墨小字「› …」，默认收起，点开左边一条竖线。回答里的 [n] 是淡底圆角小数字；提到的记录加淡墨虚线下划线，点了打开。
- **回复下面的卡片**（确认卡片、问我、新建 / 改文件、DevJanitor 的三种）：最宽 448，带文件内容或命令的 672。每条一行：勾（默认勾上）、粗体标题，下面淡墨的项；改的值写「删除线旧值 → 新值」；底部右边「取消」和主按钮。做完后底部换成淡墨的结果（「已确认」「已写入」这类），没勾的变淡。
- **输入框**：一张卡片，有焦点时边描粗；底下一排淡墨小按钮，按下的垫选中色，用不了的变淡、点不动；右边圆形发送键（生成时变停止键）。上面一排小胶囊是这一问带的东西（附件、技能、所在的页），文件拖进窗口时外圈变主色；`{{名称}}` 垫选中色。
- **润色和补全**：能润色的输入框悬停时右上角淡墨小星星，点开在下面一张小卡（要求、主按钮「润色」），改好的用差异样式，「替换」才换上。栏目标题右边的小操作是淡墨小字加小星星（`AssistAction`）。
- **一句话填好 / 改好**：面板标题下面第一行，左边小星星，淡墨占位；出错一行红字。补全、一句话填上的输入框垫选中色（`bg-accent`），自己改过就恢复。
- **写提示词的框**（`MdField`）：手画的框，里面一层自己滚，边写边显示 Markdown。

### 柚子的助手

- 每个助手是一页自己的工作台：页头是名字加一个小柚子，子页在纸签上。
- **按钮下的状态行**（模型调用在后台跑、离开页面也跑完的）：跳动的淡墨「正在…」；好了是淡墨结果（有东西可看时多「查看」）和 ×；失败红字原因、「重试」和 ×。
- **资料卡片**（Seeker、Rater）：折叠卡片一行「› 名称　淡墨补充」，停用的整张变淡写「已停用」。
- **助手的设置页**：分节卡片（最宽 768），模型按页分节，每个功能一行：左边功能名，中间模型下拉（第一项「跟默认」），最右思考下拉（选项跟着模型变）。没有模型的功能，它的按钮点不了。
