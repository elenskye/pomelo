## 2. Pub2MD 页（你来测）

- [ ] 左栏「助手」里是「Translator」和「Pub2MD」；Translator 用起来和以前一样。
- [ ] 选一份 PDF，或者从访达拖进来：先列在「待发送」（× 能移出），点「发送」才开始；开始后能看到步骤、第几块、请求次数和用时。
- [ ] 处理时再发送一份：显示「等着：…」，前一份做完接着做。
- [ ] 「停止」后，「最近」里显示「已停止」；点「继续」从停下的地方接着做，做完的块不重做。
- [ ] 停下或出错的点「删除」：先问一次，确认后从「最近」拿掉，它的文件夹在废纸篓里。
- [ ] 小拾左栏的项目、助手、定时、最近点分组名能折叠；重开 App 还是折叠的。
- [ ] 「备用模型」默认是 DeepSeek Flash，能换成别的云端模型或「不用」，重开还记得。
- [ ] 离开小拾再回来，进度还在。
- [ ] 设置会记住：做哪几步、输出格式、另存为、语言、不翻的部分、联网查术语、精修、两个模型和思考、同时几块、存到哪。
- [ ] 提示词页：写一段自己的要求、换文体和领域，下面「发给模型的说明」跟着变。
- [ ] 做完的文档：点「译文.mmd」打开预览，能切换整理稿、原文、术语表、工作日志；「用默认程序打开」能打开。
