# v0.5 验收清单

v0.5 的开发都做完了，下面是要你在正式版里亲手确认的。验收完这份移到 `archive/`。

**我已经自动验过的**（不用重复）：Pomelo 的类型检查和全部测试；在网站副本上把每一页读了又存（一个文件都不变）、改遍各页后网站的完整检查通过；整套发布推到本机的假远端；Pomelo 启停真的本地服务；网站拿掉 Keystatic 前后各构建一次，网站每一页除图标的属性顺序外一模一样；从 lockfile 干净安装后网站的完整检查通过。

**还没验过的**：真窗口里的拖放、文件选择和预览窗口；真的推到 GitHub 和 Vercel 的结果；真的本地模型和云端模型。

## 1. 先做的事

- [ ] 网站项目的改动（拿掉 Keystatic 等）还没提交：在网站文件夹里看一遍改动。可以自己在终端提交推送，也可以留着，让 Pomelo 的第一次「发布」把它们和内容一起带上。
- [x] 装正式版：升级测试过了（v0.5 没有新的数据库升级脚本，版本号和数据都在），2026-10-20 装好。

## 2. 发布页

- [ ] 打开「呦呦漫游」，没有出问题的提示；右上角「正式网站 · 本地预览 · GitHub · Vercel」都能打开。
- [ ] 「本地预览」能启动（前面一个绿点）、能停止；⌘Q 退出 Pomelo 后，本地预览的网址打不开了。
- [ ] 「待发布的改动」列出网站文件夹里的改动，点开能看差异（文字一行一行，图片前后两张）。
- [ ] 「发布…」：commit 文本不写就发不了；发布时依次走过拉取、检查、提交并推送、上线，最后「已上线」；「最近发布」里有这一次，点了打开 Vercel 的那次部署。
- [ ] 上线后在正式网站上看一眼：页头页脚的图标、各页和以前一样。

## 3. 作品

- [ ] 打开一篇作品，切换「中文 · English · 并排」；改一下摘要保存，「待发布的改动」里只多这一篇、差异只有这一处。
- [ ] 正文边写边显示；把一张图片从访达拖进正文、再粘贴一张截图，都插进去并显示小图。
- [ ] 封面：「选择…」「资源库…」、拖一张图到封面上都行；选一张超过 1.5 MB 的大图，存进网站的不超过 1.5 MB。
- [ ] 画廊：「编辑…」里添加、排序、移出；只剩一张时存不了。
- [ ] 「预览」在 Pomelo 自己的窗口里打开这一页，图片都显示。
- [ ] 新建一篇试用的作品，「新建英文版」「改 slug…」，最后「删除作品…」：删完「待发布的改动」里不再有它。

## 4. 其余各页

- [ ] Now：改当下状态并保存；新建一个月，再删掉。
- [ ] 关于我：时间轴加一行、调顺序；拖一张图进肖像、调顺序、移出。
- [ ] 职业：换一份简历文件（放进这种语言的 `public/cv/` 下）；有内容的模块换内容模式时先问。
- [ ] 资源库：登记一张新图片；删除一个登记前，列出哪里在用。
- [ ] 站点：改一个类别的中文名并保存，本地预览刷新后马上看到（不用重启）。
- [ ] 「设置 → 呦呦漫游」：换成一个不是网站的文件夹，页面说明原因；再换回来。

## 5. 小拾（真的模型）

- [ ] 润色：摘要输入框角上的小星星，本地模型、云端模型各试一次。
- [ ] 补全：没有英文版的作品，「英文标题」旁的「补全」起草英文标题和摘要（浅柚红底）。
- [ ] 按中文起草：英文版正文边翻边写，「停止」留下已翻的；保存后才写进文件。
- [ ] 「设置 → 小拾 → 发给云端」关掉呦呦漫游，再用云端润色会被拒绝；然后打开回来。
- [ ] 在设置里隐藏呦呦漫游：侧栏里没有它；再显示回来。
