# v0.7 验收清单

v0.7（Seeker 嵌入 Pomelo）的八个阶段和八轮优化都做完了。简历、岗位面板、规则、网申和 cv/、小拾和界面你已经验过了，下面只留还没验的：Rater 的三块、R7 和 R8 改的地方（正式版已装到 R8）。第 1～3 节写于 R8 之前：「Rater 的模型」现在在「设置」页签里，复盘和对照照第 5 节。都过了 v0.7 才算完成；验收完这份移到 `archive/`。

**我已经验过的**（不用重复）：

- **自动检查**：类型检查和全部 Rust 测试（2026-10-30 R8，503 个）。
- **模拟版界面**（浏览器、编的资料）：卡片练习、面试准备和复盘；R8 的设置页（默认和单独选的模型分开存）、规则页的新分组和程序自带的三条框架、复盘对话（边聊边填表、说「就这些」弹出确认、继续记录存下并回到第 2 轮、关掉后「没记完」留在岗位下、接着记接上原来的对话、放弃）、总结复盘（后台跑、状态行、单独一条、存进题库和加进规则）、岗位面板的「复盘」直接打开开始框；R7 的审查批注（离开 Seeker 再回来，审查已经跑完、批注在要点下面）、勾选编辑卡片后确认修改、✓ 处理完、只润色选中的要点、素材卡片上的「正在润色… / 润色好了 · 查看」、失败时的红字和「重试」、导出默认名跟着岗位变、插件库的树状流程图。
- **R8 的升级测试**：旧正式版（R7）里 `picky.db` 的升级脚本到 30；在临时数据目录里建好 30 版的库，放一段平常的对话、只有默认模型的 Rater 设置、「面试」组的一条规则和带旧「对照」的复盘，用新包打开：升到 31、多了没记完复盘的表、有「升级前」备份，这几样数据一个字节没变（只多了程序启动时自己补的云端模型清单）。装好后签名是 Pomelo Self-Signed。
- **R7 的升级测试**：R7 没有新的数据库升级脚本；确认旧正式版里已有全部升级脚本，新包在临时数据目录里打开 R6 样子的草稿和素材：能启动、版本还是 30 / 30、Seeker 数据一个字节没变、没有多出升级前备份。装好后签名是 Pomelo Self-Signed。
- **云端真测**（R6 及以前，编的资料；报告在「下载/v0.7 验收」）：Seeker 中英文选材、审查、润色、Summary，三个题库 SKILL、卡片练习、面试。R7 改了审查和润色要点的说法，还没用真模型跑过。

**你来测**：测试碰不到真窗口、钥匙串里的 Key、Word 的版面、文件选择框和真的 Seeker 文件夹，下面这些只能你在正式版里点。

## 1. 题库

- [X]  题库页「让小拾补题」：简历题、通用题、突击题各出一次，勾几道写进题库；⌘Z 一步撤回。
- [X]  一道题「润色」，看差异后接受。
- [X]  小拾对话里说「按某某的 JD 出 5 道突击题」，回复下面出确认卡片，确认后题进了题库。
- [X]  补题、选岗位、选素材这类长列表都是点了弹出搜索小窗，打几个字回车就选上。

## 2. 卡片练习

- [X]  自己挑、按 JD、随机各练一轮：翻面、会 / 不熟、打字、追问（虚线卡）、追问卡「存进题库」、中途「停下」。
- [X]  打了字的一轮结束后，小拾自己写点评；回到题库，练过的题能看到「练过：会 N 次 · 不熟 M 次」。
- [X]  练的时候按 ⌘Z 撤回刚才的「会 / 不熟」，回到那张卡。

## 3. 面试

- [X]  岗位面板「面试」一栏「准备面试」：跳到 Rater 面试页，选语言、形式后「准备」，出速查卡、挑的题和追问。
- [X]  改一下速查卡保存；「另存 Word」后用 Word 打开，看能不能一页印下。
- [X]  「用这些题练一轮」跳到卡片页开练。
- [X]  「＋ 复盘」记一次，「对照」后看准备到的和没准备到的；「存进题库」一道、「加进规则」一条，到规则页「面试」组里看到那一点。

## 4. R7

- [X]  简历页：「审查整份简历」用 GLM 5.3 FlashX 或 Qwen 3.8 Max 跑一次，等的时候去别的页面（和小拾聊几句），回来右栏写「审查好了：N 条批注」，要点下面挂着建议。
- [X]  明确要改的建议下面有一张修改卡片（原文划掉、新字标色）：点几张（变底色），下面「确认修改」，改进了正文；⌘Z 一步撤回。没改的建议点 ✓ 就不见了。关掉 Pomelo 再打开，没处理的批注还在。
- [X]  「润色要点」：什么都没选时点不了；点选（或拖框选）几条要点、一段经历后，按钮写「润色所选要点（N）」，润色完只这几条下面出卡片。
- [X]  English：「按 JD 改写 Summary」的结果是 Summary 下面的一张卡片。
- [X]  素材页、网申页的「润色」：卡片下面「正在润色…」，润色完「润色好了 · 查看」，点了看差异再接受。选一个云端模型、Seeker 设置里关掉「允许发给云端」再点，卡片下面是红字原因和「重试」（试完记得打开）。
- [X]  简历页左上只有「新建」「导出」；「导出」的文件名默认是 `seek-it-公司-v版本`（英文多 `-resume` / `-cv`），版本接着 `cv/` 里同一组最新的那版往后排；换关联的岗位，文件名跟着变，自己改过就不变了。
- [X]  插件库：流程图在右边居中，是一棵往下长的树；判断分出两条实线（各写着「是」和另一种情况），会合的地方两条线再并回来，到此为止的那一边就停在那里。general-film-lookup、rater-qbank-job 这两个最复杂，看看清不清楚。

## 5. R8

- [X]  Rater「设置」：「默认」选一个模型；「复盘 · 记录」单独选另一个、开思考；「补题」跟默认。页签那一排右边不再有模型。去补题、准备面试、复盘，看用的是不是对应的模型（结果和卡片上写着模型名）。
- [X]  规则页：多了「卡片练习」「复盘」两组，各组下面「发给：…」对得上（卡片练习 → 卡片练习；面试 → 面试 · 准备；复盘 → 复盘（记录、总结））。你原来「面试」组里的规则还在「面试」组，现在只发给准备面试；想给卡片练习或复盘用的，编辑时改用途挪过去。
- [X]  面试组的虚线卡片「速查卡」、复盘组的「复盘记录」「复盘卡」：「改成我的」后改一两点（比如速查卡加一节），准备面试 / 总结时照新的写；「发给模型的说明」里能看到。
- [X]  面试页「复盘」：选日期、岗位、第几轮 → 对话窗。像平时一样说这场面试（可以让它查速查卡、以前的复盘、知识库），右边的表跟着填；说齐了，模型标成填好后弹出表，改一处，「继续记录」→ 存好、回到开始框（轮次加一）；再记一场点「确认」。小拾的对话列表、搜索里看不到这些对话；⌘Z 撤回刚存的复盘，那场「没记完」的回来。
- [X]  记到一半关掉对话窗：岗位下「没记完」，「接着记」接上原来的对话；另一条「放弃」。
- [X]  右上角「总结复盘」：默认选最新的速查卡和它之后的复盘；勾两次复盘，「总结」后去别的页面，回来按钮下写「总结好了」，「总结」里有一条（没准备到的写着是第几轮的哪个问题）；「存进题库」「加进规则」各一次，规则在「复盘」组里看到；⌘Z 各撤一步。
- [X]  以前做过「对照」的复盘，打开还能看到对照的结果。
- [X]  岗位面板「面试」一栏：「复盘」直接打开开始框；下面列出总结。
