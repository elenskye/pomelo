# v0.7 验收清单

v0.7（Seeker 嵌入 Pomelo）的八个阶段和五轮优化都做完了，正式版已装到 R5。下面分两部分：我已经验过的，和只能你在正式版里点的。你那部分都过了，v0.7 才算完成；验收完这份移到 `archive/`。

**我已经验过的**（不用重复）：
- **自动检查**：类型检查和全部 Rust 测试（2026-10-29，494 个）。
- **模拟版界面**（浏览器、编的资料）：卡片练习、面试准备和复盘、岗位面板「面试」跳到 Rater；Seeker 简历版本、证书原件、cv/ 加进知识库；选择简历（模板也能选、面板只剩本次使用）、公司名称、规则的编号分点和拖动排序、发给模型的说明、插件库流程图、小拾改前面的卡片、几个页面居中或占满。
- **云端真测**（只用云端，编的资料；报告在「下载/v0.7 验收」）：DeepSeek Flash 和 GLM 5.3 FlashX 各跑一遍 Seeker（中英文选材、审查、润色、Summary）、三个题库 SKILL、卡片练习、面试。测出的问题当场改了。
- **正式版的规则清理**：先备份，再用 R5 的代码读清理后的副本、生成每个功能发给模型的说明，确认没问题才写进正式版（「下载/v0.7 R5 规则清理」）。

**你来测**：测试碰不到真窗口、钥匙串里的 Key、Word 的版面、文件选择框和真的 Seeker 文件夹，下面这些只能你在正式版里点。

## 1. 先做的事

- [ ] 打开正式版：Seeker、Rater 都在模块坞「求职」里。
- [ ] Seeker 文件夹的 `transfer/` 在废纸篓里（我移的），Seeker 设置里没有「从 transfer/ 导入」。确认没问题后清空废纸篓。
- [ ] 在 Rater 的模型下拉里选一个云端模型（Seeker 设置里先打开「允许发给云端」）。用 GLM 5.3 FlashX 的话，「设置 → 小拾」里它的思考设成「总是」。

## 2. 简历

- [ ] 中文：新建或接着改草稿，按 JD 选材、润色，「另存 Word」后用 Word 打开，看是不是一页、版面和模板一样。
- [x] 简历模板是内置的，中文样子已定。
- [ ] English：新建英文简历、选材、「按 JD 改写 Summary」、导出，用 Word 看是不是 keyreply-resume-v5 的样子（两行抬头、自动编号的要点、各部分之间的空行）。
- [ ] 用 Word 打开 `cv/cn/seek-it-cn-template-v2.docx`：是林小柚的完整样例（教育、技能、项目、工作都有）。
- [ ] 历史页最上面「Word 导出」是一张清单，点一行打开那个 Word；下面「简历版本 · 资料修订」。

## 3. 投石问路的岗位面板

- [ ] 某个岗位「做简历」，导出后「Seeker」一栏显示这份。
- [ ] 「选择简历…」：切中文 / English、按名字找，中文里能选 `seek-it-cn-template-v2`；换一份后面板里只剩新选的那一份（点名字打开），⌘Z 回到上一份。
- [ ] 「面试」一栏的「准备面试」打开的框里写着这份简历（本次使用）。
- [ ] Seeker 设置「公司」一行「名称…」：给 seek-boc、seek-keyreply 起名字（比如「中国银行」「KeyReply」），保存后那一行显示新名字；中国银行新加坡分行的岗位面板「公司资料」对上了它。

## 4. 规则

- [ ] 照「下载/v0.7 R5 规则清理/清理记录.md」核对清理后的 16 条规则，要留的、要改的直接在规则页改。
- [ ] Seeker、Rater 的规则页：每条规则是编号的分点，没有「个人约定」；编辑时拖动分点换顺序、「＋ 要点」、删一点，存好后顺序对。
- [ ] 每组下面写着「发给：…」；「发给模型的说明」里规则是 `# 组`、`## 标题`、`1. 分点`，没有【…】。
- [ ] 素材页、规则页每组「⋯」：重命名一个程序自带的组（比如「教育」），选材和 Word 照旧；删掉一个自己建的组后 ⌘Z 回来。
- [ ] Rater 规则页：三个 SKILL 组还没写自己的时是虚线卡片，「改成我的」能存。

## 5. 题库

- [ ] 题库页「让小拾补题」：简历题、通用题、突击题各出一次，勾几道写进题库；⌘Z 一步撤回。
- [ ] 一道题「润色」，看差异后接受。
- [ ] 小拾对话里说「按某某的 JD 出 5 道突击题」，回复下面出确认卡片，确认后题进了题库。
- [ ] 补题、选岗位、选素材这类长列表都是点了弹出搜索小窗，打几个字回车就选上。

## 6. 卡片练习

- [ ] 自己挑、按 JD、随机各练一轮：翻面、会 / 不熟、打字、追问（虚线卡）、追问卡「存进题库」、中途「停下」。
- [ ] 打了字的一轮结束后，小拾自己写点评；回到题库，练过的题能看到「练过：会 N 次 · 不熟 M 次」。
- [ ] 练的时候按 ⌘Z 撤回刚才的「会 / 不熟」，回到那张卡。

## 7. 面试

- [ ] 岗位面板「面试」一栏「准备面试」：跳到 Rater 面试页，选语言、形式后「准备」，出速查卡、挑的题和追问。
- [ ] 改一下速查卡保存；「另存 Word」后用 Word 打开，看能不能一页印下。
- [ ] 「用这些题练一轮」跳到卡片页开练。
- [ ] 「＋ 复盘」记一次，「对照」后看准备到的和没准备到的；「存进题库」一道、「加进规则」一条，到规则页「面试」组里看到那一点。

## 8. cv/ 和 material/

- [ ] 历史页「简历版本」：English 认出 keyreply 和 iss 两组、按版本排好（keyreply-v5 不标「模板」），「比较上一版」能看出差别，keyreply 那组写着对上的 KeyReply 岗位；中文的 template 两版归一组、只有 v2 标「模板」，Pomelo 导出过的标「Pomelo 导出」。
- [ ] 设置里「简历（cv/）」加进知识库；知识库「Seeker」里 material 那一行写「N 个扫描件」。
- [ ] 网申页最下面「证书原件」按子文件夹分好，点一个能用默认程序打开。
- [ ] 小拾里问「我有哪些证书原件」「keyreply 简历第 4 版和第 5 版差在哪」，它查的是 Seeker 资料（证书只给文件名）。

## 9. 小拾和界面

- [ ] 插件库：技能名是 general-… / seeker-toolkit / rater-qbank-…；流程图画出了判断（虚线框，旁边是分支和它接到哪一步）和循环；斜杠命令「/general-web-search」能用。
- [ ] 小拾里说「读完了《巴比伦塔》，三星」这类让它记书，卡片出来后说「作者是特德·姜」：上面那张卡片的作者改过来（不多一张卡片），再点确认。
- [ ] 全屏时：来日方长、呦呦漫游的发布页和站点页在中间；念念不忘的卡片一直排到右边。其他页有留白的告诉我。
