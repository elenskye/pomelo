# v0.7 验收清单

v0.7（Seeker 嵌入 Pomelo）的八个阶段都做完了。下面分两部分：我已经自动验过的，和一定要你在正式版里点的。你那部分都过了，v0.7 才算完成；验收完这份移到 `archive/`。

**我已经自动验过的**（不用重复）：
- **自动检查**：类型检查和全部 Rust 测试（2026-10-28）。
- **模拟版界面**（浏览器、编的资料）：卡片页三种出卡、翻面、打字、追问、存进题库、停下、反馈、⌘Z；面试页准备面试、改速查卡、另存 Word、用这些题练一轮、记复盘、对照、存进题库、加进规则；岗位面板「面试」一栏跳到 Rater；Seeker 历史页「cv/ 里的简历」分组、看正文、比较上一版；网申页「证书原件」；设置里 cv/ 加进知识库。
- **云端真测**（只用云端，编的资料；报告在「下载/v0.7 验收」）：DeepSeek Flash 和 OpenRouter 的 GLM 5.3 FlashX 各跑一遍 Seeker（中英文选材、审查、润色、Summary）、三个题库 SKILL、卡片练习（挑卡、追问、点评）、面试（准备、对照）。测出的问题当场改了（见那里的「验收记录.md」）。
- **打包版**：用临时数据目录打开，`picky.db` 升到 26、新表都在。
- **升级测试**：正式版的数据库能升上来（装之前做，结果写在下面第 1 节）。

**你来测**：测试碰不到真窗口、钥匙串里的 Key、Word 的版面、文件选择框和真的 Seeker 文件夹，下面这些只能你在正式版里点。

## 1. 先做的事

- [ ] 正式版已装好（我装的，版本见 roadmap）。打开后看一眼：Seeker、Rater 都在模块坞「求职」里。
- [ ] Seeker 文件夹的 `transfer/` 已经移到废纸篓（我做的）；Seeker 设置里不再有「从 transfer/ 导入」。确认没问题后清空废纸篓，也可以删掉「下载」里的两份「Seeker transfer 备份」。
- [ ] 在 Rater 的模型下拉里选一个云端模型（Seeker 设置里要先打开「允许发给云端」）。用 GLM 5.3 FlashX 的话，「设置 → 小拾」里它的思考要设成「总是」。

## 2. 简历（阶段 ② ③）

- [ ] 中文：新建或接着改草稿，按 JD 选材、润色，「另存 Word」后用 Word 打开，看是不是一页、版面和模板一样。
- [ ] English：切到 English → 设置里选英文模板 `cv/en/seek-it-keyreply-resume-v5.docx`，看一眼段落对应 → 新建英文简历、选材、「按 JD 改写 Summary」、导出，用 Word 看版面（两行抬头、自动编号的要点、各部分之间的空行）。
- [ ] 投石问路某个岗位「做简历」，导出后在岗位面板看到这份导出和「本次使用」。

## 3. 题库（阶段 ④ ⑤）

- [ ] Rater 规则页：「题库维护」「面试」的规则在；三个 SKILL 组还没写自己的时是虚线卡片，「改成我的」能存。
- [ ] 题库页「让小拾补题」：简历题、通用题、突击题各出一次，勾几道写进题库；⌘Z 一步撤回。
- [ ] 一道题「润色」，看差异后接受。
- [ ] 小拾对话里说「按某某的 JD 出 5 道突击题」，回复下面出确认卡片，确认后题进了题库。

## 4. 卡片练习（阶段 ⑥）

- [ ] 自己挑、按 JD、随机各练一轮：翻面、会 / 不熟、打字、追问（虚线卡）、追问卡「存进题库」、中途「停下」。
- [ ] 打了字的一轮结束后，小拾自己写点评；回到题库，打开练过的题能看到「练过：会 N 次 · 不熟 M 次」。
- [ ] 练的时候按 ⌘Z 撤回刚才的「会 / 不熟」，回到那张卡。

## 5. 面试（阶段 ⑦）

- [ ] 投石问路某个岗位的「面试」一栏「准备面试」：跳到 Rater 面试页，选语言、形式后「准备」，出速查卡、挑的题和追问。
- [ ] 改一下速查卡保存；「另存 Word」后用 Word 打开，看排版能不能一页印下。
- [ ] 「用这些题练一轮」跳到卡片页开练。
- [ ] 「＋ 复盘」记一次（几条问题、回答、反馈、你的判断），「对照」后看准备到的和没准备到的；「存进题库」一道、「加进规则」一条，到规则页「面试」组里看到那条个人约定。

## 6. cv/ 和 material/

- [ ] Seeker 历史页「cv/ 里的简历」（English）：认出 keyreply 和 iss 两组、每组按版本排好，英文模板那份标「模板」；「比较上一版」能看出差别；keyreply 那组后面写着投石问路里对上的 KeyReply 岗位。
- [ ] 中文那边：Pomelo 导出过的简历标「Pomelo 导出」。
- [ ] 设置里「简历（cv/）」加进知识库。
- [ ] 网申页最下面「证书原件」按 awards、certificates、education… 分好，点一个能用默认程序打开。
- [ ] 小拾里问「我有哪些证书原件」「keyreply 简历第 4 版和第 5 版差在哪」，它查的是 Seeker 资料（只给文件名的那部分不会读证书内容）。
